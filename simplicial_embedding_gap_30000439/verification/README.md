# Offline verification

Run `python3 verification/run_all.py` from the extracted source folder. Python3.9 or newer and only the standard library are required; no network, external programs, credentials or numerical dependencies are used. Scripts are copied into temporary isolated folders before execution, so pinned scripts and receipts are never overwritten. The runner compares every deterministic receipt exactly as JSON and omits only the dated primary receipt's timestamp. Geometry is compared with its exact stdout receipt. Any failure exits nonzero.

The five programs check sixteen original rational bounds;396 historical independent bounds/circuit assertions;3,852 independently designed probability/cleaning assertions including ten rejected mutations;841 primary-dependency arithmetic/circuit assertions; and861 exact triangle-pair plus84 isolated-point checks on the seven-facet Fano hypergraph, whose incidence graph has cycle rank8. These finite examples check the local fan construction and inequalities. They do not enumerate the enormous existential witness, replace the universal proofs, establish novelty, or formally verify published dependency theorems.

The exact finite choice is n=2^256, p=2^-384 and m=2^320. Old AI reviews and their receipts apply only to their identified historical inputs. Current manuscript and package receive separate fresh full adversarial reviews in the repository publication program; no historical exact-hash verdict is transferred to the paper. Source ledgers locate imported results, with versions and bounded priority/access limits described in the source/priority reports.
