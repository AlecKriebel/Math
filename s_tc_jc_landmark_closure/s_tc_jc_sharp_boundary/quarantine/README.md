# Quarantined historical release

`withdrawn_positive_v1.1.1/` preserves the complete former positive-theorem
release for auditability.  None of its manuscripts, PDFs, cover letters,
metadata, manifests, or verifiers is current or submission-approved.

The historical theorem claimed a complete JC classification of strongly
tree-child level-2 networks.  Independent review found that its bridge chart
used the wrong gauge, its standard-reduction convention was ambiguous, and
its finite atlas did not provide an end-to-end primitive-topology-to-
polynomial assignment or a proof for arbitrary subdivisions.  The global
positive theorem is therefore **unresolved, not refuted**.

Current source, certificates, and submission files live at the repository
root outside this quarantine.  No release script traverses this directory.
