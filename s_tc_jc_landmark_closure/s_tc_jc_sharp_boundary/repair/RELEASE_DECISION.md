# Fail-closed release decision

The repaired project has two permissible endpoints.

## Endpoint A — positive classification

Release a positive manuscript only if all of the following are independently
verified:

1. the locked standard class and absence/treatment of suppressible
   2-sub-blobs;
2. pointwise one-sided cut preservation;
3. complete root and incoming-port local atlases with topology-to-polynomial
   bindings and exact open-cube separators;
4. arbitrary-subdivision promotion with compatible support probes;
5. a localization proof that does not use the withdrawn bridge chart;
6. full-dimensional sufficiency for every globally valid combination of
   ordinary triangle redirections; and
7. clean-clone regeneration, manuscript build, PDF render inspection, and
   mutation-sensitive independent replay.

The theorem will be stated only for the at-most-one-triangle-per-blob class
unless the automatic-triangle strengthening is separately re-audited.

## Endpoint B — sharpness manuscript

If any positive gate remains open, the submission will be narrowed to the
verified all-`n` Theta sharpness theorem in `W_TC \ S_TC`.  The positive
classification will be described only as an open problem.  This fallback
still requires a new coherent source tree, exact positivity and rank replay,
independent graph/convention review, clean build, and a non-misleading public
page.

No hybrid manuscript may state Endpoint A in its title or abstract while
depending on unresolved gates and then rely on Endpoint B as its only fully
verified result.
