This file records only statements used by the active manuscript.

1. **Definitions 2.1--2.3.** The paper's fixed, already-simple,
   reticulation-preserving mixed graphs coincide with Englander et al.'s
   convention for the networks compared. Their strong tree-child criterion
   requires two incident undirected edges at every tail of a retained
   reticulation edge. Omega's vertex `U` fails this criterion.
2. **Theorem 2.11.** It separates networks with different displayed-quartet
   sets. The two Omega networks have the same set (and the same multiplicity
   pattern), so this theorem does not separate them.
3. **Figure 5 and Lemma 2.14.** Up to reflection, both Omega networks are
   differently labelled type-(2c) quarnets. Lemma 2.14 treats specified
   type-(1b) relabellings, all distinct type-(2a) quarnets, types (3a), (3c),
   and (3d), and one quinnet pair. It contains no type-(2c)-versus-type-(2c)
   assertion.
4. **Corollary 2.17.** This separates type (2c) from prune-leaf classes, not
   from another type-(2c) labelling.
5. **Proposition 2.15.** Englander et al. write
   `q011 q101 q110 - q111^2`. Their collapsed `q111` is the three-distinct-
   nonzero-character JC orbit denoted `q123` in the active manuscript.
6. **Theorem 3.2.** It concerns triangle-free strongly tree-child level-2
   networks. Omega is weakly but not strongly tree-child, so there is no
   contradiction.
7. **Discussion.** The source notes dimensions below naive parameter counts.
   The Omega proof gives one explicit mechanism: core rank six and an Euler
   relation identifying a pendant torus direction with core tangent
   directions.
8. **Data availability.** The v4 source names Zenodo DOI
   `10.5281/zenodo.20193239`. The active theorem does not import that archive
   as evidence; no DOI is created by this project.
