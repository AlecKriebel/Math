## Hard-Cover Normalization

Let the JC Fourier character group be represented by xor in `Z2^2`.  For a
quartet assignment `a_0,a_1,a_2,a_3` with total character zero and a mask `S`,

```text
xor(S^c) = xor({0,1,2,3}) xor xor(S) = xor(S).
```

Thus a split side and its complement induce the same JC edge factor on every
retained quartet coordinate.  The finite verifier checks all 16 quartet masks
and all 64 zero-sum assignments.

Replacing each quartet mask by `min(mask, 15 xor mask)` is exactly quotienting
by unordered quartet split side.  Zipping duplicate full switching-signature
rows is the positive product map on indistinguishable path variables: if
several rows normalize to the same row, the effective semidirected variable is
their product.  The map is onto the open parameter cube because any effective
`z in (0,1)` has, for example, preimage `(sqrt(z), sqrt(z))`.

The quotient is invariant under admissible root relocation: moving the root
only changes which side of a split is recorded and splits one semidirected edge
into two rooted arcs whose factors multiply.  Reticulation-parent flips and
reticulation order changes are handled by canonicalizing over display-column
flips and permutations.  Noncomplement displayed splits are not collapsed: the
verifier finds a zero-sum assignment separating every noncomplement mask pair.

## Bounded Atlas

The bounded atlas intentionally keeps rooted selected-side masks and two root
arc variables.  For a fixed rooted graph this is correct: its raw pullback is
the standard semidirected pullback composed with the positive submersion

```text
(x_left, x_right, other variables) -> (x_left * x_right, other variables).
```

This map is surjective onto the open effective cube and has full rank in the
effective coordinate.  Therefore a polynomial is identically zero, generically
nonzero, or strictly signed on the standard model iff its rooted physical
pullback has the same classification.

There is still a counterexample to quotient invariance: the same labelled
quartet tree rooted on the internal edge and on a pendant edge has different
raw rooted descriptors, while both normalize to the same semidirected
descriptor.  So graph-specific pullback correctness must not be confused with
standard semidirected descriptor invariance.

## Mutations

`verify_all.sh` rejects all required mutations:

- omit complement normalization;
- normalize at width 5 instead of quartet width 4;
- merge noncomplement masks;
- use boundary samples `x=0` or `x=1`;
- reuse a polynomial from the wrong rooted graph.

`certificates/manifest.json`.
