## Theorem 1: exact quartet split-complement quotient

**VERIFIED.** Represent the JC character group by xor in
`G = Z_2 x Z_2`. For a quartet character assignment
`g=(g_0,g_1,g_2,g_3)` with total xor zero and a mask `S`,

```text
xor(S^c) = xor({0,1,2,3}) xor xor(S) = xor(S).
```

JC uses only the indicator that this sum is nonzero. Hence `S` and `S^c`
induce exactly the same edge factor on every retained Fourier coordinate.
The verifier checks all 16 masks against all 64 zero-sum assignments.

Conversely, if two quartet masks are neither equal nor complementary, some
zero-sum assignment makes exactly one of their two sums nonzero. The verifier
checks this JC-indicator statement for every such pair. Therefore

```text
mask -> min(mask, 15 xor mask)
```

identifies exactly the two selected sides of one unordered quartet split; it
does not identify two genuinely different displayed quartet splits. Global
splits that restrict to the same quartet split are, correctly, indistinguishable
on that marginal alone.

If several physical edge rows become the same complete switching-signature
row after normalization, every JC monomial contains those edge variables with
the same exponent. Replacing that row class by the product of its variables is
therefore an exact polynomial factorization. Each product map
`(0,1)^k -> (0,1)` is onto (for example, use all factors `y^(1/k)`), so zipping
duplicate rows preserves the complete open effective parameter image. The
verifier regenerates all 15 JC coordinate polynomials for every quartet of both
reticulate quarantine graphs and checks this product pullback coefficient by
coefficient.

Admissible root relocation only complements selected split sides and/or splits
one effective edge into two rooted arcs whose JC multipliers multiply. A
reticulation-parent flip is the open-domain reparameterization
`lambda -> 1-lambda` together with a switching-column flip. Reticulation order
is a switching-axis permutation. The normalized descriptor canonicalization is
invariant under both operations.

## Theorem 2: the unnormalized bounded atlas is sound

**VERIFIED.** Fix one rooted presentation `R` of a standard semi-directed
local tensor model `S`. Let `x_l,x_r in (0,1)` be the two physical multipliers
created by inserting the root on one effective edge, and let `y` be that
effective multiplier. The rooted tensor map factors as

```text
Phi_R = Phi_S o pi,
pi(x_l,x_r,eta) = (x_l*x_r,eta).
```

This remains true when one root arc enters a reticulation: in each displayed
tree either both root-arc factors represent complementary sides, or the
inactive arc has mask zero and the surviving root side has the full mask; both
give the same zero-sum JC exponent. A dedicated LSA-valid strongly tree-child
quartet fixture has one root arc entering a reticulation. Its two switchings
produce root-mask pairs `(3,12)` and `(15,0)`; the verifier checks all 64
zero-sum assignments in each case. Relocating the root to a pendant edge gives
the same independently reconstructed standard mixed graph and the same
normalized tensor descriptor. The verifier also checks all 15 exact JC
coordinate pullbacks for both presentations.

Separately, all 15 quartets and all four switchings of each quarantined
reticulate graph are checked (7,680 root-arc factor equalities and 450 complete
coordinate pullbacks). Those graphs test the reticulate product quotient and
parent-order invariance, but—correcting the earlier wording—neither has a root
arc entering a reticulation.

The map `pi` is a positive surjective submersion. An exact global rational
section is

```text
x_l = (1+y)/2,
x_r = 2*y/(1+y),
```

which lies in `(0,1)^2` for every `0<y<1`, has product `y`, and satisfies
`partial pi / partial x_l = x_r > 0`.

Consequently, for every graph-derived invariant polynomial or strict
semialgebraic separator `F` on the standard tensor image:

- `F` vanishes identically on `S` iff `F o pi` vanishes identically on `R`;
- `F` is nonzero somewhere/generically nonzero on `S` iff its pullback is so
  on `R`;
- `F` has a strict sign throughout the open standard image iff its pullback has
  that strict sign throughout the open rooted domain.

The converse implications use surjectivity; generic rank preservation uses
the submersion. This proves the exact property needed by the bounded atlas.

There is also an explicit counterexample to a stronger, false claim: the same
labelled quartet tree rooted on an internal edge and on a pendant edge has two
different raw rooted descriptors, although both reduce to the same standard
semi-directed tree and have the same normalized descriptor. Therefore the raw
atlas descriptor must not be advertised or cached as a canonical
semi-directed descriptor. Its graph-specific pullbacks are nevertheless
correct, so regeneration is unnecessary while their exact graph bindings are
retained.

## Active-source and mutation audit

**VERIFIED.** AST inspection binds the checked declarations to reachable nodes
of the active functions rather than accepting comments, dead strings, nested
helpers, or literal-dead branches (including truth-equivalent forms such as
`if 0`). It also verifies direct dataflow from the
normalization to `moved.append(new_mask)` and from `(p,graph_id)` through cache
lookup, fill, and return. The source/target call-site check requires exactly two
live `cached_deck` calls and binds each graph argument to its corresponding
exact graph ID. It verifies that:

- `hard_cover_compiler.full_deck` applies exactly the width-4 complement map;
- `cached_deck` uses `(p, graph_id)`;
- `graph_id` hashes the exact rooted payload `(root, labels, arcs)`;
- source and target calls pass their respective exact graph IDs;
- `atlas_compiler.deck` delegates to `all_port_quartet_deck`;
- `all_port_quartet_deck` intentionally retains rooted selected-side masks.

The verifier rejects all requested mutations and eight direct active-source
mutations:

- remove complement normalization;
- hide normalization in a literal-dead branch;
- overwrite the normalized mask before it is appended;
- normalize against width 5;
- merge noncomplement masks;
- use boundary values `x=0` or `x=1`;
- reuse a polynomial generated from the wrong rooted graph;
- restore a non-graph-specific cache key.
- overwrite the graph-specific key before cache lookup.
- leave correct graph-ID calls under `if 0` while live calls use mixed codes.

The wrapper is check-only: it recomputes every certificate in memory and
compares exact bytes and hashes. Regeneration requires the explicit
`--regenerate` option, so stale source, reports, or certificates cannot be
silently repaired during a purported verification run.
The manifest lists every active source, invariant template, quarantined graph
stream, and quarantine note read by the verifier as a first-class hashed input.
