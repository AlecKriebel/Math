# Proof boundary

The article supplies human proofs of the structural reductions: the fixed
mixed-graph convention, primitive cycle/four-theta exhaustiveness, the
two-colour run/palette reduction, cut and bridge localization, marginal
submersion, restoration, coherent probes, root reduction, contextual triangle
gluing, and the local-to-global theorem.  The palette reduction is also
exhaustively checked on every four-through-eight-port binary word, while an
independent graph implementation replays the reduced palette and finds no
all-switching survivor.

The finite computation proves exactly the bounded directed-relation statement
used in Theorem 6.3.  It retains one row for each three-outgoing canonical
directed relation and for each four-outgoing normalized survivor presentation;
the latter rows also record their further quotient-canonical digest.  For each
row it:

1. reconstructs both decorated rooted graphs;
2. enumerates displayed switchings and descendant masks;
3. derives the complete exact JC Fourier tensors;
4. regenerates the attached polynomial, flattening minor, or equality test;
5. proves strict sign on the open cube or verifies labelled isomorphism / one
   ordinary triangle redirection;
6. verifies every raw-to-canonical transport and restoration-parent edge;
7. checks the exact one- and two-port parent transports used for probe
   coherence.

The reviewer index is transitively closed at record level.  A theorem row
does not merely name a generic verifier: it points to one content-addressed
restoration-root or direct-anchor closure record.  Restoration records list
every reachable hard-cover state and bind every equality terminal to one
compact path record; compact records bind all packed witness, transport, and
polynomial records.  Direct-anchor records bind all one- and two-port child
relations, their graphs, and their graph-derived witnesses.  Deleting or
swapping any link is a tested failure.

The primary and clean-room programs do not share graph canonicalization,
displayed-tree enumeration, descendant-mask construction, separator
selection, or rank code at the load-bearing gates.  Frozen outputs and
regeneration programs are both included: neither is treated as sufficient by
itself.

The package also contains exact component checks for the cut/bridge theorem,
ordinary triangle germ, and the Omega and Theta sharpness families.  Referee
reports and historical failure narratives are not mathematical inputs and are
excluded.

Release provenance is fail-closed at the stage boundary: `seal` exports the
recorded Git object, runs the builder contained in that detached export,
compares every file byte and executable bit with the requested stage, and
archives only the detached reconstruction.  Ignored and untracked working-tree
files therefore cannot enter the archive.  `ACTIVE_MANIFEST.json` records both
the source commit and a deterministic commitment to that prepared payload.
Both the outer command and detached committed builder run in Python isolated
mode with `site` startup disabled; startup-hook environment variables are
neither honored nor inherited.
