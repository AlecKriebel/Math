# Complete root-suppression artifact taxonomy

For a binary LSA-valid rooted input, every cleanup artifact is generated by one local configuration: adjacent root children, necessarily a tree vertex pointing to a reticulation. All later cleanup is iteration of the same root zipper.

| Requested artifact | Classification | Reason / treatment |
|---|---|---|
| Root children already adjacent | Possible | Necessarily `p -> q` with `p` tree and `q` reticulation. This is the root zipper. |
| Both root sides meet the same vertex | Impossible | The two root arcs would be parallel; if interpreted through later merging, the common descendant would violate LSA. |
| Root suppression creates a degree-two vertex | Only after parallel identification | Without adjacency, each root child loses one incidence and gains one. With adjacency, both `p,q` become degree two after the duplicate is identified. |
| Repeated degree-two cleanup | Removable presentation artifact | Exactly iterative root zippers; each step deletes `p,q` and inserts a new root above their other children. |
| Parallel ordinary edges | Only recursively | They arise when the next root children are already adjacent; the zipper repeats. |
| Parallel pair with retained arrows | Possible only as the two copies entering the same root-child reticulation | Both carry the same arrowhead and are replaced by the exact two-terminal JC tensor. A doubly headed copy would require two reticulation root children, impossible in an acyclic one-root binary network. |
| Reticulation disappears | Exactly the root-child reticulation `q` | Its statistical contribution remains in the effective multiplier `kappa`; it is not silently discarded. |
| A 2-sub-blob is created | Possible | The root zipper may be an isolated 2-blob or may lie inside a larger blob. Only this forced root-created gadget is contracted by the quotient. Arbitrary 2-sub-blob suppression is not invoked. |
| Blob merged or separated | Root-presentation only | The final cleaned mixed graph is the quotient object. Its blobs are unchanged by `q`, which is the identity on that graph. |
| Cyclomatic number changes | In the rooted presentation fibre | One reticulation/cycle disappears per zipper. Level in the theorem is the level of the final semi-directed topology. |
| Reticulation count in a blob changes | In the rooted presentation fibre | Same as above; the quotient records the statistically observable topology. |
| Admissible-rooting set changes | Yes | `Root_0=Root_H` is generally a strict subset of `Root_clean`. |
| Omnian created or removed | Possible in a cleanup rooting | Tree-child cleanup rootings contract to tree-child `sd0` rootings. Non-tree-child cleanup roots explain why the strong classes differ. |
| Strong tree-childness changes | Yes | `S_clean` is a proper subset of `S_0`; the exact strict witness is released. |
| Triangle created or removed | Only as a presentation artifact | Parallel theta `(1,1,L)` cleans to the existing cycle factor for `L>=4`; `(1,1,2)` is LSA-impossible and `(1,1,3)` has no tree-child rooting. |
