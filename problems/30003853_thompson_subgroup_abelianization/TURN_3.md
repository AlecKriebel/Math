# Turn 3: solvable images, without passing FP_2 to a quotient

Completed 2026-10-02 UTC. Original unresolved, 3/5 substantive turns; subjective progress 15%. This is a deduction from credited Bieri–Strebel/BGK splitting and Bleak's solvable-subgroup classification. No novelty claim is made for the resulting positive class.

## 1. A homomorphism obstruction for arbitrary lamp groups

**Lemma.** Suppose H has type FP_2(R), R a nonzero commutative ring, and H contains no nonabelian free subgroup. Let rho:H -> A wr Z be any homomorphism to a standard restricted wreath product, for an arbitrary group A. If the composite character to the top Z is nonzero, then rho(H) is infinite cyclic and projection to the top is injective on rho(H).

**Proof.** Normalize the top character to chi:H -> Z onto. The credited BGK Theorem2.7 supplies an ascending HNN decomposition with finitely generated base K <= ker(chi), stable letter s, and H generated by K and s. Its orientation can be chosen so that s^{-1}Ks <= K. The projection of rho(s) to the top is some nonzero integer m, possibly negative. The subgroup rho(K) lies in the restricted base direct-sum_Z A. Its finite generating set has support in a fixed finite subset S of Z, and every element of rho(K) is supported in S.

Conjugating a base element by rho(s) translates its support by m or -m. The lamp component of rho(s) also conjugates individual entries inside A, but conjugation preserves whether an entry equals the identity. Thus the support is still exactly translated, even when A is nonabelian. If rho(K) contained a nonidentity element, the inclusions rho(s)^{-n}rho(K)rho(s)^n <= rho(K) would keep nonempty translated supports within S for all n >= 0, an impossibility. Therefore rho(K)=1. Since H is generated by K and s, rho(H)=<rho(s)>, with nonzero top projection. QED.

No assertion that rho(H) itself has type FP_2 was used. Finiteness properties generally do not pass to arbitrary quotients, so that shortcut would invalidate this argument.

## 2. The exact classification input

Bleak, *An algebraic classification of some solvable groups of homeomorphisms*, arXiv:math/0602038v2 (13 April 2006), Theorems1.1–1.2 and Lemma1.3, pp2–3, equivalently Corollary4.8 p27, gives the following. Define

    G_0=1,
    G_n=direct-sum_{k in Z} (G_{n-1} wr Z).

Every solvable subgroup of PL_+(I) of derived length n is isomorphic to a subgroup of G_n. All maps have finitely many breaks in slope. The standard wreath products and outer sums are restricted, not unrestricted products. The classification theorem and its terminal split-group argument were read; p2 was inspected visually. Published J. Algebra319 (2008), 1368–1397. Primary preprint: https://arxiv.org/abs/math/0602038 . This nontrivial classification is an external input, not reproved here.

## 3. Induction for images, retaining the same domain

**Proposition.** For H as in the lemma, every homomorphism H -> G_n has abelian image.

**Proof.** Induct on n, the case n=0 being immediate. H is finitely generated. Thus its image in the outer restricted sum defining G_n lies in a finite product of the wreath factors: take the union of outer supports of images of a finite generating set. Examine each coordinate homomorphism rho:H -> G_{n-1} wr Z.

If its top character is nonzero, its image is cyclic by Section1. If its top character is zero, its image lies in direct-sum_Z G_{n-1}. Again finite generation of H bounds this image to finitely many base coordinates. Each base-coordinate map has the original domain H and target G_{n-1}, so its image is abelian by the induction hypothesis. Therefore rho(H) is a subgroup of a finite product of abelian groups, and is abelian. All outer coordinate images are abelian, hence the full image is abelian. This completes the induction. QED.

The use of finite support occurs twice and cannot be replaced by unrestricted products. At no stage do we assert that a coordinate image inherits FP_2.

**Corollary.** Every solvable image in PL_+(I) of an FP_2(R) group without a nonabelian free subgroup is abelian. In particular every solvable FP_2(R) subgroup of PL_+(I), hence of F, is a finitely generated free abelian group.

To obtain the first conclusion, embed the solvable image into the corresponding G_n by Bleak and compose with the original homomorphism. The second follows by applying the first to the inclusion; a subgroup of the orientation-preserving interval homeomorphism group has no nontrivial finite-order element, so a finitely generated abelian subgroup is free abelian. For that elementary torsion fact, if f(x)>x or f(x)<x at some point, no positive iterate can fix that point.

This fully covers the solvable part of Question111. It does not say an arbitrary finitely presented subgroup of F is solvable; F itself is a counterexample to that auxiliary assertion. Nor does it extend the conclusion to all elementary amenable groups without a further valid classification input.
