# 30004033: fractional coloring of planar triangle-free subcubic graphs

Exact target: every finite planar triangle-free graph of maximum degree at most 3 has fractional chromatic number at most 8/3. Source code OWR-16763-006; upstream ID 30004033; campaign rank 335.

This is an active, unresolved research packet. One substantive author turn is recorded in TURN_1.md. The five-turn budget has not been exhausted. No solution or historical novelty is claimed.

The normalization used here assigns every vertex a measurable set of measure r=3/8 in a probability space, adjacent sets disjoint. This is equivalent to fractional 8/3-colorability. The universal weighted independent-set formulation is essential; the known unweighted 3n/8 theorem does not settle it.
