# Threshold extension v3

This folder contains a bounded research cycle seeking an asymptotic
simultaneous-amplifier construction beyond the proved hybrid threshold
`R_hyb`.  The first target is the full dilute bounded-gadget tangent cone
with arbitrary positive internal weights and arbitrary positive portal
loads.

## Outcome of the bounded cycle

No exact threshold improvement was found.  The exact milestone is
`SYMMETRIC_PAIR_DOUBLET_NO_GO.md`: symmetric portal-linked pairs cannot
cross the `R_hyb` tangent, even when their inter-pair interaction occurs on
the same weak scale as center invasion.  The obstruction is strict for every
nonzero correlation and is stable under dilute mixtures and ordinary-leaf
compensation.

Run `replay.sh` for the exact certificate.  `HOSTILE_SEARCH.md` records
separate numerical evidence and the precise remaining escape modes.
