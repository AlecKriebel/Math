# Aggregate-odds audit

This folder records an exact obstruction to one proposed proof of the open
stationary aggregate-odds inequality at dB fitness two.

* `LINEAR_POTENTIAL_FARKAS_OBSTRUCTION.md` gives the derivation and the exact
  Farkas vector.
* `verify_linear_potential_farkas.py` independently builds and solves the
  full geometric-union dual over exact rationals.

The component and aggregate odds inequalities remain open.  The certified
graph satisfies both strictly; it only rules out the nonnegative
linear-potential/singleton-certificate architecture.
