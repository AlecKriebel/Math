# Product-chain certificate route

This folder contains an independent product-chain attack on the proposed
universal `r=3/2` fixation-product inequality.

The fixation-product conjecture remains open.  The proved result is a set of
three exact proof-architecture barriers, documented in
`PRODUCT_CHAIN_ROUTE_CLOSURES.md` and verified by
`verify_product_chain_barriers.py`.

The `explore_*` and `search_*` programs are discovery tools only.  Their
numerical output is not used as proof.
