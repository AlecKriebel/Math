# Growing diffuse portal networks

This subfolder treats `Q_s->infinity`, beyond the fixed-rank direct-portal
theorem.

- `DIFFUSE_GROWING_PORTAL_NO_GO.md` derives the exact finite complete-portal
  count chain, the correct nested branching limit, and an all-fitness no-go
  theorem for diffuse regular portal networks with exchangeable incidence.
- `verify_diffuse_limit_exact.py` independently checks every displayed
  finite-rate limit and sign factor using exact symbolic arithmetic.
- `RESEARCH_LOG.md` records the bounded construction cycle.

Fixed-degree expanders, portal-dependent incidence, and nonvanishing portal
population proportions remain open.
