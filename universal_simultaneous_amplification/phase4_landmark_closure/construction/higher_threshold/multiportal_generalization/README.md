# Exchangeable multiportal generalization

This folder proves a `Q`-uniform class no-go for exchangeable active portals
coupled to diffuse strong-pair blades.  The full portal-count phase
`0,1,...,Q` is retained.

- `EXCHANGEABLE_MULTIPORTAL_NO_GO.md`: theorem, derivation, growing-portal
  corollary, and post-establishment audit.
- `verify_multiportal_tradeoff.py`: exact symbolic and rational certificate.
- `check_finite_multiportal.py`: independent exact finite lumping built from
  atomic updates, with numerical absorption solves.
- `verify_finite_lumping_exact.py`: independent rational audit over every
  labelled subset of a nine-vertex, three-portal instance.
- `explore_multiportal.py`: numerical discovery script; not evidence for the
  theorem.
- `RESEARCH_LOG.md`: timestamped research record.
