# Mixed-clique-star checkpoint

`MIXED_CLIQUE_STAR_NO_GO.md` proves a common cross-sum bound for arbitrary
mixtures of separated clique satellites around a growing clique center at
every fixed `r>=sqrt(2)`.

Run the independent exact verifier with:

```bash
python verify_mixed_clique_star.py
```

This is a class no-go theorem, not a universal obstruction.
