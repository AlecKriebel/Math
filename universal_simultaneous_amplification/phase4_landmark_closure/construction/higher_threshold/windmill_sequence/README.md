# Heterogeneous-windmill sequence

`WINDMILL_SEQUENCE.md` contains the theorem, derivation, and strict claim
labels.

- `search_windmill_macro.py`: numerical solver for the separated dB
  strong-pair generator and a labeled nonrigorous Bd one-excursion surrogate.
- `verify_windmill_macro.py`: independent full-chain and symbolic checks.
- `RESEARCH_LOG.md`: research checkpoint.

The family reaches the dB-only limiting threshold `2`, but its Bd fixation
tends zero.  It is therefore a construction primitive and a sharp handoff
falsification, not a simultaneous amplifier.
