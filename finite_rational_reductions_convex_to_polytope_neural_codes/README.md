# Paper 1 publication package

**Title:** *Finite Rational Reductions for the Convex-to-Polytope Conjecture in Neural Codes*

This package contains the 28-page manuscript, clean arXiv source, exact finite-calibration replay, technical appendix, two-page summary, theorem/priority/adversarial audits, and outreach materials.

The paper does **not** claim universal polyhedralization or a curved-only convex code. Its central conclusion is that the conjecture reduces to finite rational binary-meet bridge data and a finite simultaneous convex-attachment problem for repeated neurons.

```bash
./reproducibility/replay.sh
```
