# Four-variant ledger

Throughout, N is a fixed positive integer, X is compact, LE is continuous Euclidean loose embeddability preserving all-pair distance equalities and nonequalities, and H_N means every finite subset embeds loosely in that same R^N without uniform quantitative controls.

| Variant | Recorded outcome | Exact boundary |
| --- | --- | --- |
| Corrected dataset: H_N(X) implies continuous LE of X into the same R^N | False for every N >= 1, by the audited Theorems A/B of Ferudun's 20 October 2026 unrefereed AI-assisted manuscript | Countable compact X_N has H_N but no same-N continuous LE. This is the first scoped existing-resolution classification. |
| Original ordinary uniform/topological reading: H_N(X) implies uniform embedding into the same R^N | NOT resolved by this manuscript/audit | All its X_N actually uniformly embed into R, hence R^N. On compact X ordinary uniform and topological embeddability coincide. The original undefined wording is not silently changed. |
| Later global LE reading: H_N(X) implies LE into some finite R^M, possibly M > N | NOT resolved by this manuscript/audit | Proposition 5.1 proves X_1 is LE into R^2. The same-N obstructions do not answer the larger-target question; no verdict for X_N with N >= 2 is asserted. |
| Compact connected Riemannian assertion: for every manifold there exists a finite N with H_N | Universally quantified assertion is false, by audited Theorem C | Every flat torus with geodesic metric and intrinsic dimension >= 2 fails every H_N. N may depend on the manifold in the question. This is the second scoped existing-resolution classification, not a claim that all manifolds fail. |

Circle exception: intrinsic dimension one is excluded from the torus negative theorem. For a circle of radius r, the planar chord transform is 2r sin(d/(2r)) on 0 <= d <= pi r, which is strictly increasing, hence gives LE and H_2. Three equally spaced points obstruct H_1.

Primary formulations: Chirvasitu, *Quantum isometries*, Oberwolfach Report 45/2019, printed p. 2860, https://doi.org/10.4171/owr/2019/45 ; *(In)equality distance patterns and embeddability into Hilbert spaces*, https://arxiv.org/abs/2101.01242 (Questions 2.1/2.2), journal version https://par.nsf.gov/servlets/purl/10337061 (Questions 3.1/3.2). The later definition of unqualified LE permits some finite-dimensional target.
