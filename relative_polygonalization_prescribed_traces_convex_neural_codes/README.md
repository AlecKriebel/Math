# Relative Polygonalization with Prescribed Traces for Convex Neural Codes

Submission-ready paper package by Alec Kriebel.

- `manuscript/main.pdf`: final 15-page manuscript.
- `arxiv_submission/`: self-contained arXiv source tree.
- `reproducibility/`: exact rational regression verifier and no-network replay.
- `audit/`: theorem, source, priority, and adversarial audits.
- `outreach/`: two-page summary, journal memo, cover letter, and expert-contact draft.
- `release/`: deterministic source and reproducibility archives with SHA-256 hashes.

The paper proves a planar relative polygonalization theorem. It does not claim a three-dimensional convex filling or universal convex-to-polytope equivalence.
