\subsection{Exhaustiveness assertions}

The primitive generator proves exhaustion in the following order.
\begin{enumerate}[label=\textup{(\roman*)}]
\item Cyclomatic number at most two and biconnectivity reduce the undirected core to a cycle or theta graph.
\item Two triangle cycles force theta path lengths $(1,2,2)$; the direct rooting proof and independent finite census exclude this core from $\TCw$.
\item Event placement and orientation enumerate every binary acyclic rooted realization of those cores.
\item The local $\TCs$ criterion and minimum-repair enumeration characterize every permitted port occupancy.
\item Every binary subdivision is an ordered word of ordinary port vertices on a directed core segment.
\item The rigid-support theorem reduces arbitrary words to support plus one- and two-port probes.
\item Canonical mixed-graph codes quotient exactly by labelled isomorphism and, in the observational atlas, by valid ordinary triangle redirection.
\item Directed pair records are generated from the Cartesian product of canonical source and permitted target signature classes and stored under an ordered source--target key; duplicate keys are rejected.
\end{enumerate}
The independent programs use a different canonicalization and reconstruct the same code sets and orbit decompositions.

\subsection{Release policy}

The top-level verifier fails if a required source, certificate, review assertion, manuscript file, figure, transcript, or manifest entry is absent; if a generated object differs from its frozen release copy; or if the PDF preflight reports missing fonts, unresolved references, or malformed pages.  The quick command checks the exact theorem certificates and publication integrity.  The full command also regenerates the finite graph universes and runs every independent reviewer.  The archived transcripts record the software versions, elapsed time, and peak resident memory.
