# Exact reproducibility package

This directory certifies only the theorem in the accompanying sharpness
manuscript.  It does **not** certify the withdrawn positive classification of
strongly tree-child level-2 networks.

The primary verifier starts from the rooted arc lists in `networks.json`.  It
enumerates displayed trees, derives the JC Fourier coordinates, proves the six
symbolic identities, derives both rank-eight Jacobian determinants, isolates
the algebraic parameter `beta`, checks every parameter against the strict
domain `0 < x_e, lambda_r < 1`, and compares all 256 Fourier coordinates
exactly.

The independent verifier is generated by a separate adversarial
implementation.  It shares no graph, Fourier, number-field, isomorphism, or
Jacobian code with the primary program and additionally checks the narrow
`sd_0` rooting convention and the all-taxa cherry-substitution theorem.

## Environment

- Python 3.11 or newer
- SymPy 1.14
- NetworkX 3.6

No floating-point assertion is used.  Decimal output, when present, is for
readability only.

## Replay

From the release root, run:

```sh
python3 reproducibility/verify_release.py
```

The release driver first checks every manifest hash and then runs both exact
implementations in isolated subprocesses.  A successful final line is

```text
VERIFIED: all sharpness-release gates passed
```
