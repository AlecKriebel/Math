# All-dimensional self-audit — not independent verification

The same assistant authored and inspected these source candidates and exact
checks. No independent agent, external researcher or Lean process verified them.
The audit concerns the intended source statements, conventions and reporting
machinery, not accepted proofs.

## Physical and logical points inspected

The matrix strategy structures carry only PSD trace-one state and ordinary
projective-measurement conditions. The universal finite bounds quantify over
arbitrary local dimensions, allowing unused outcomes. They do not assume the
phase spectrum, a particular Schmidt rank, a full-rank reduced state, the
explicit witness, or saturation. Actual real Born probabilities have a named
bridge to encoded correlators. The target additional Bob setting is `none`.

The first-family universal matrix and arbitrary-Hilbert module closures exclude
the concrete witness modules. The second-family normalization is proved from
the actual coefficient formula and finite Fourier identities, not imposed as
part of strategy validity. Same-party commutation is never a physical premise.

Support rigidity is traced from an actual mixed state and scalar saturation
through a PSD-square-root purification, actual partial trace, supported zero
transfer and polar cancellation, to Bob-derived reflection powers and finally
rank counting. A phase relation on the unused ambient complement is not claimed.
Finite exact controls include an unused block that would falsify that upgrade.

The commuting-Hilbert endpoint has complete complex Hilbert-space variables and
actual commuting PVMs. It is independent of the finite-dimensional upper-bound
proof. The full q/qa/qc model-equality wrappers are not supplied or claimed.

Physical Eve results use true sandwiches and partial traces; the binary result
is operator-valued. The one-input conditional distribution handles zero
probabilities without an unproved inverse. No general optimum over all Eve
realizations is claimed. The polar-linear and private-MUB criteria remain
conditional exactly where the manuscript makes them conditional.

The exposure obstruction's constant-diagonal positivity argument was inspected
as an alternative proof. It must not be represented as checking each intermediate
Toeplitz/SVD statement in the paper or as a blanket low-setting no-go theorem.

## Checks actually run and what they cannot establish

The source scanner checks module closure, no import cycles, explicit named-query
coverage (including the two new instances), delimiter/namespace consistency,
locked dependencies and prohibited escape tokens. The 26 Python tests include
intentional omissions, an added unaudited declaration, deletion of an instance
query, a forbidden witness import into a bound, and missing/custom/native axiom
reports. These are tests of the reporting machinery, not Lean proofs.

Exact arithmetic covers finite selected examples through d=12, first/second
functional values, phases, Fourier compression, projectors, the support-sensitive
controls, one-input hidden variables and the binary SOS/witness. It does not
prove universal quantifiers, CFC continuity, matrix order, or a model supremum.
No Python certificate is imported by a Lean proof.

The new general Lean false controls are prepared but not executed. A successful
future run must reject them for genuine proof errors rather than missing imports.
The entire source is in the default build, but only Lean can confirm elaboration
and actual dependency resolution.
