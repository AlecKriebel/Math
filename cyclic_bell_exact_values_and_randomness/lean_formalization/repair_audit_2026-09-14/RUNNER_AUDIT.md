# Independent build-runner audit

Timestamp: 2026-09-15T03:33:32.836153+00:00

Runner/scanner repair is complete for the issues identified below; final whole-project test rerun is pending the import graph and declaration-inventory freeze. This is a reporting-machinery checkpoint, not a Lean proof certificate.

## Findings and repairs

- The original runner accepted a negative control whenever any `type mismatch`, `tactic failed`, or `unsolved goals` appeared. It could accept a statement error or another file's failure. `check.py` now requires every error to have a Lean file/line/column location inside the sole example's explicit tactic proof. It rejects unlocated errors, another file's errors, statement/import errors, and unrecognized diagnostics. Resource exhaustion, abnormal exits, unknown APIs, and forbidden axioms remain rejected.
- A failed tactic is still not proof that its target proposition is false. Several supplied controls intentionally apply a theorem with an incompatible type, including `RejectSettingsUniform` and `RejectConjugation`. Their semantic force comes from independently compiled positive theorems about nonuniformity/conjugation, not merely the compiler failure. Final reviewers must inspect the positive counterparts and actual control diagnostics.
- The source inventory previously missed indented declarations, declarations in the umbrella file, and nested module folders. It could truncate names ending in apostrophes and mishandle a section closed inside a namespace. These cases are now handled. Escaped simple names such as `«prefix»` normalize to the printed Lean name. Unsupported declaration forms (including anonymous instances, private names, and opaque declarations) fail explicitly instead of silently escaping the query inventory.
- Import scanning now includes every module on a single import line; the old regex only saw the first. The project reference audit uses the same scanner and includes nested folders.
- Axiom-output parsing and generated-query validation now support apostrophes in names. The allowed axiom set remains exactly `propext`, `Classical.choice`, and `Quot.sound`.
