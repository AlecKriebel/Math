terminalwise simultaneous independent paths, the stated local bipartite
matchings, and coherent independent prescribed-set out-arborescences are
equivalent if each different-root overlap has at most one directed
vertex-sequence path between any ordered pair after parallel arcs are
collapsed. Same-root overlaps are unrestricted.

The full self-contained base theorem and the stronger root-group theorem
are retained. The latter explicitly uses Frank–Fujishige–Kamiyama–Katoh,
Independent arborescences in directed graphs, Theorem 4. Application of
their Theorem 5 algorithm removes singleton tasks, checks weak connectivity
of the remaining reachable root pools, and charges membership preprocessing.

https://doi.org/10.1016/j.disc.2012.11.006

nine-vertex greedy-prefix obstruction remain. The obstruction has a valid
global family and is not a conjecture counterexample. Alternative directed
paths in different-root overlaps remain unresolved. No novelty is claimed.
