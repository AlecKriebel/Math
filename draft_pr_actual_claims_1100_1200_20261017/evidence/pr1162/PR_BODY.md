## Accepted partial theorem; unrestricted singleton problem unresolved

For strictly increasing positive integer moduli n_i, one canonical forbidden residue 0 <= a_i < n_i, and inclusive activation m >= n_i, the survivor set has logarithmic density whenever, outside a reciprocal-summable exceptional family, the residues satisfy one of finitely many fixed identities q a_i = p n_i + c with integer q >= 1, p, c. The density equals the decreasing limit of the finite-periodic survivor densities. Coprimality, disjointness, bounded residues, and reciprocal summability of the patterned family are unnecessary. Natural density of the infinite survivor set is not asserted.

In the fully patterned class, arbitrary finite positive per-modulus activation thresholds preserve this logarithmic density. The summable exceptional family retains the original activation condition. The audit's explicit counterexample rejects extending threshold invariance to arbitrary summable exceptions; it is not a counterexample to the theorem or to the unrestricted original target.
