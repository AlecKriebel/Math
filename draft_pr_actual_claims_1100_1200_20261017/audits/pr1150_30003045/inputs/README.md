# Mixed Kato kernels: full counterexample at the original index n = 1

Problem 30003045 asks for a three-summand Kato-kernel equality for the compositum of an arbitrary finite purely inseparable extension, a separable quadratic extension, and the projective function field of a bilinear Pfister form that remains anisotropic after the inseparable extension.

The universal equality is false. COUNTEREXAMPLE.md gives a complete counterexample at the permitted original index n = 1, with a degree-four, exponent-two purely inseparable extension and an anisotropic binary bilinear Pfister form. Its norm/residue obstruction excludes the entire sum of three kernels, including the extra Pfister summand. The original n = 0 equality remains valid and is proved separately. This is a full negative answer to the universal question, not a claim of failure at every index or for every field.

The projective quasilinear quadric convention includes the binary, zero-dimensional quadric, whose function field is a purely inseparable quadratic extension. The exponent-one predecessor is not contradicted. The higher-exponent mixed-generator mechanism is credited to Aravire, Laghribi and O'Ryan; the independent Pfister slot and residue proof supply the additional three-summand exclusion. No novelty or priority is claimed.
