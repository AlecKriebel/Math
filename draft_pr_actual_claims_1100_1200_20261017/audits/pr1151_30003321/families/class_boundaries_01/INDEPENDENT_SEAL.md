## Independent hypotheses and falsification plan
1. Least-positive classification: by initiality, g>0 has no positive simpler predecessor; Proposition 5.2 suggests g=2^-n omega^-alpha. Need prove the minimum support exponent is -alpha, all supports bounded below there, and its coefficient group is exactly 2^-n Z. Falsifiers: a least element containing two terms, non-dyadic bottom lattice, support below -alpha.
2. Naive global scaling g^-1 G can fail to preserve initiality. Test alpha=omega and exponent class { -beta : beta<=omega }; exponent translation gives {0,omega-n:n<omega}, which is not initial since e.g. 1 is missing. This falsifies that proof route, not the target.
3. Independent potential repair: keep the exact existing truncation-closed cross-sectional series subgroup, reindex exponents, and rescale only the coefficient at the minimum exponent from 2^-n Z to Z. All other coordinates remain unchanged; their coefficients already satisfy the initial-real-group classification. Coordinatewise multiplication by a positive fixed constant at one coordinate respects finite addition and lexicographic order. This does not replace G by its full Hahn completion.
4. A possible exponent map h: put min Gamma first and map it to 0, then enumerate the remaining Gamma by nondecreasing original birthday, choosing each image as the simplest surreal between already mapped lower and upper exponents. Global choice supplies well-orders within birthday layers, with each predecessor segment a set. Because min is already present, all other images are positive. Because each insertion is a simplest cut in an initial previous image, the running image remains initial. For proper classes, use a set-like class well-order of Gamma; every earlier domain segment must be a set. The least exponent can have arbitrarily large set birthday, but placing it first still leaves each subsequent initial segment set-sized.
5. Crucial no-new-right-ancestor claim: if h(y)>h(x) and h(y)<_s h(x), then y> x and y<_s x. Since image stages are initial, y was inserted earlier. Unless y is the minimum (impossible as y>x), original birthday(y)<=birthday(x). If y is not an original ancestor of x, their longest common sign prefix z is strictly between x and y and simpler than each. z belongs to Gamma and is inserted before y and x (z cannot be the minimum while strictly between them). Then h(z) lies between h(x) and h(y) and is already present when h(y) is inserted, contradicting the proposed ancestor relation using the lexicographic tree separation property. Need check this logic carefully at equal birthdays, limit stages, and after removing min from order.
6. If (4) and (5) hold, Theorem 5.1 transfers initiality: only right-ancestor pairs force dyadic divisibility. The coefficient normalization at h(min)=0 never needs D as a right-predecessor coefficient because it is minimum. Exponents h(Gamma)>=0 and integer coefficient at zero imply membership in Oz. Onto H is by definition the coordinatewise image, with explicit inverse on supports.
