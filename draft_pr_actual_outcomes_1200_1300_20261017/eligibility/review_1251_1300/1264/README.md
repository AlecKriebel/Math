## What is established

- A subharmonic background satisfying an affine upper bound, nonnegative disk plateaus, and sufficient boundary Riesz mass admits logarithmic drilling followed by an affine maximum. The result is finite, subharmonic, uniformly close to the horizontal coordinate on the whole open square, and has explicitly described non-main negative components.
- If the vertical projections of those negative components cover every height, the desired geometry follows. Existence of such all-height data for arbitrarily small error has not been established.
- An explicit compatible one-disk background works for every positive error below one half. It covers only a small interval of heights and provides no simultaneous multiple-disk family.
- The exact open-disk threshold is c ≤ γ log(1/q). Negativity on the closed smaller disk, or a positive radial margin, requires strict inequality. The affine clipping condition x < δ remains separate.
- Uniform affine convergence forces the final functions’ Riesz measures to vanish locally. This alone provides no universal mass-radius obstruction, and the drilling coefficient can be arbitrarily small relative to the negative-core radius in the one-disk example.
