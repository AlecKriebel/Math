# A ramified quotient of an equivariant étale endomorphism

Problem 30000663 / OWR-1452-027, *Unramified Quotients of Equivariant Endomorphisms*.

**Disposition: prior negative resolution of the question as stated.** The smooth normal affine complex surface X defined by x²y=z²−1 admits the effective action a·(x,y,z)=(ax,a⁻²y,z) of the connected reductive group Gm. The map φ(x,y,z)=(2xz,y,2z²−1) is globally étale and commutes with this same action. Its invariant ring is C[z], but its induced quotient endomorphism z↦2z²−1 is ramified at zero.

The image of φ is exactly X minus the entire line {y=0,z=−1}; φ is finite étale of degree two onto that open. It is not surjective onto X. The original question does not assume surjectivity, so this settles that question negatively and refutes its unrestricted connected-reductive assertion. No conclusion is claimed for a formulation with an added surjectivity hypothesis.
