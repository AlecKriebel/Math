# Fuchs additive intersection obstruction for general plane domains

For every fixed radius R > 0, no finite A(R) bounds the hyperbolic density of an intersection by A(R) times the sum of the two domain densities over all plane domains in the radius-R disk. The punctured-disk construction has a connected intersection, so the obstruction also applies under that additional restriction.

This packet concerns Hayman–Lingham Problem 7.73, problem 2307073. The result and construction are credited to Yixin He and Quanyu Tang, *On Fuchs's additive intersection problem for the hyperbolic metric*, arXiv:2603.16676v1, Theorem 1.2 and Section 3. See the [versioned manuscript record](https://arxiv.org/abs/2603.16676v1). This is an authored exposition and audit of that existing result, with no claim of novelty or independent discovery.
