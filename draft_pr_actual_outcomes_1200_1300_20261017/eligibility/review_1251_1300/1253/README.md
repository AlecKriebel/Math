# Equality in three-manifold lower bounds

Problem 30001703 / OWR-4798-030. Authored edition, 11 October 2026 UTC.

For a connected closed 3-manifold M and any fixed field F, Gamma(M)=10 beta_1(M;F) exactly for S^3 or a finite connected sum of S^2-bundles over S^1. Both the orientable product and nonorientable twisted bundle occur. There are no additional connected topological types. The empty sum is S^3.

This is established-theorem coverage credited to Bhaskar Bagchi and Basudeb Datta–Satoshi Murai, with identified named imports. It is not a new classification theorem.
