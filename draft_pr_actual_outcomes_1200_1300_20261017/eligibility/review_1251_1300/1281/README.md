# Real elliptic divisor spaces

This packet gives a complete genus-one proof and mathematical acceptance
audit for problem 30004145, source problem OWR-16933-007.

For a smooth projective geometrically connected real genus-one curve with
real points, fix a positive-degree reduced totally real divisor and its
linear-equivalence class. The nonempty locus with the same number of
support points on each real component is one connected component. If its
support occupies k real components, this locus strongly deformation
retracts onto a torus of dimension k minus one. Its universal cover is
contractible and its fundamental group is free abelian of rank k minus
one. For genus one, k is one or two.

The original nine-point plane cubic fundamental-group dichotomy was
already stated by Oleg Viro in [Round dances of points on a curve](https://ems.press/content/serial-article-files/46800),
printed page 1289, PDF page 45. Viro credits Ayşegül Öztürkalan for the
initial examples and observations. The present proof is an independent
verification; no novelty, higher-genus resolution, or attribution of this
proof to either source author is claimed.

## Review status and preservation

The proof and audit are AI-assisted. They have received no external human
mathematical review and no formal proof-assistant or referee certification.
The acceptance verdict is the recorded mathematical assessment of the
accompanying audit. Cryptographic fingerprints establish artifact identity,
not mathematical truth.

All four accepted proof, audit, and source-metadata files are reproduced
byte-for-byte without editorial changes. The README and two publication
metadata files are the only additions. Statements in the audit about the
absence of external publication or repository changes describe the audit
at its recorded preparation time.

The theorem is confined to positive-degree, unordered, reduced, totally
real divisors in one fixed class and one fixed distribution on a genus-one
curve. It makes no claim for higher genus, collisions, nonreal pairs,
labeled embeddings, variable classes, or connectedness of an entire
reduced real linear system with several admissible distributions.
