# Schubert support under skew sums

Accepted restricted results for OWR-14299904-005 / record 30006523. The Schubert support of a skew sum of ordinary Grothendieck polynomials is exactly the product of the factor supports, and left-weak convexity holds exactly when it holds for both factors. The complete proof, skew-indecomposable reduction, Boolean family, and coefficient-magnitude obstruction are included.
