## Accepted restricted results

For ordinary stable Grothendieck and Schubert polynomials, the skew-sum
factorization uses the same symmetric rectangular factor for both bases.
The Schubert support of a skew sum is exactly the embedded Cartesian
product of the factor supports, and is left-weak convex if and only if
both factors are. The complete polynomial proof, left-weak upper-ideal
and product-interval proof, skew-indecomposable minimal-counterexample
reduction, and parameterized Boolean family from 132 are retained.

The general Schubert-support left-weak convexity conjecture remains
unresolved by this work. No novelty or current-openness claim is made.

The authored example F=S1243-S1342+2 S2341 has the same convex support,
coefficient-sign pattern, unique lowest term, and right-descent restriction
as G1243, yet pi_3 F=S1234+S2314 has a missing interval middle. The full
direct polynomial calculation is included. F is not any Grothendieck
polynomial, so it refutes only a coefficient-blind induction shortcut.
The G2143 example is attributed to Weigandt, Example 1.4. The G13254
right-weak failure is solely a convention check.
