# Weighted bipartite coloring: restricted proofs and local obstructions

Accepted restricted results for AMR-029-0088 / record 3000088. The local parameter b is the maximum optimal unit-bin count at a vertex, not the ceiling of weighted degree. Colors are feasible when their incident weight at each vertex is at most one; adjacent edges may share a color.

- Simple forests have weighted chromatic index b for b>=1.
- Arbitrary parallel bundles with forest support admit 2B-1 colors from supplied feasible B-bin local packings, giving the existential 2b-1 bound.
- Simple cacti admit B+1 colors, or one when b=1. Bipartite simple cacti have exact worst-case index b+1 for every b>=2.
- A parallel forest-support family has index b+1 for every b>=2. It attains 2b-1 only at b=2.
- One frozen optimal b=3 root packing requires five colors to extend; recoloring gives a full graph of exact index four. This is a local-method obstruction, not a conjecture counterexample.

Complete proofs allow arbitrary real weights in [0,1]. The constructive algorithms receive feasible local packings; efficient computation of optimal bins is not claimed. Empty graphs have index zero; nonempty all-zero graphs use one color under the convention that all edges are assigned. Known-subclass attribution and unverified literature limits are explicit.
