# Extra shift invariance: an established finite-generator criterion

Problem 30000035 / OWR-720-001, *Almost Translation Invariant Spaces*.

For a fixed positive integer n and a finite family of L2(R) generators, let S be their norm-closed integer-shift span. The exact criterion for T_(1/n)S = S is that the full Fourier Gramian rank equals the sum of the n residue-cutoff Gramian ranks almost everywhere on [0,1). Zero fibers, dependent generators and variable rank are allowed; no frame or Riesz-basis hypothesis is added.

Credit belongs to Aldroubi, Cabrelli, Heil, Kornelson and Molter, *Invariance of a Shift-Invariant Space*, Theorem 5.2, Journal of Fourier Analysis and Applications 16 (2010), 60–75, [DOI](https://doi.org/10.1007/s00041-009-9068-y), [arXiv:0804.1597v3](https://arxiv.org/abs/0804.1597v3).
