Both the eight-helper end-to-end suite and the independent additional fault
suite passed identically in normal, -O and -OO Python modes. Runtime assertions
are not used as release guards. Synthetic data remain in ignored _local scratch;
root-level durable receipts retain the actual observed results.

The base suite exercises compilation/preparation/build/portable verification,
explicit nested schemas, lexical absolute-path relocation, outside anchors,
retained finite replays, successful and corrupted document receipts, all eleven
public metadata fields, canonical record identity, tracker append recovery,
full-row range checks, saved PR recovery/body synchronization, the operative
strict coordinator with actual shared kit.run, and historical
CHANGES_REQUIRED→root resolution→different CLEAN review sequencing. It checks
exactly eight current/original files and thirteen final PR paths.

The additional suite directly calls the adapted postmerge main with real
workflow gate and saved commit validation while mocking Git/service I/O. The
success case advances a synthetic six-completed state to seven completed and
next1268. Wrong head/body/parent/blob, duplicate row, nonblank B, wrong headers
and unresolved DOI each fail without state advance. The actual shared kit.run
rejects corruption of every one of the eleven supplied fields and of file
size/checksum/inventory/ID before its mocked POST; unchanged metadata permits
one mocked POST. Current actual original8 snapshot/Git blob/MANIFEST bindings
are authenticated read-only in every mode, which certifies integrity only.

The finite test fixtures do not establish actual mathematical or priority
acceptance, real PDF compilation or layout, live Zenodo/GWS/GitHub behavior,
metadata acceptance by a server, or native Git object construction/push. No
real service mutation, Git/index/ref mutation, PR edit or merge occurred.

The first synthetic adaptation run found an inherited old seven-file sentence
in the regression's expected PR body; the test failed closed and that fixture
was corrected before complete successful reruns. The additional test's first
run exposed a reviewer-authored call with the wrong shared-kit save_state
signature; it was corrected to the actual signature and complete successful
runs followed. Neither error affected source inputs or any external state.
