# Verification package: convex-body SOS-density bounds

The main result is the normalized Lebesgue global-SOS upper bound O(r^-2) for every fixed full-dimensional compact convex body and fixed polynomial, at every integer order r>=1. One global square suffices. The paper gives the complete elementary proof and a known worst-case lower example. No firstness, current worldwide openness, new mechanism, arbitrary-reference-measure, general original-objective pushforward or efficient minimizer claim is made.

Read manuscript/main.tex and current_edition/PROOF.md for the elementary argument. current_edition/MOMENT_FORMULATION.md gives the rational square-pyramid example.
