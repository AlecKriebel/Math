# Explicit Beurling-transform counterexamples in an analytic annihilator

Both endpoint questions in the bilinear analytic annihilator of Hayman and Lingham, Problem 7.72, have negative answers under the printed negative-kernel convention. The norm-one input v(z)=z/bar(z) on the unit disc annihilates every integrable analytic test function, while its Beurling transform is 1+log|z|^2 and is essentially unbounded. Explicit polynomials v_m(z)=z^2 sum_{j=0}^{m-1}(1-|z|^2)^j lie in the same annihilator, have norm one and have transform norm H_m, the m-th harmonic number. Each fixed polynomial has bounded transform, but no common uniform constant exists.

This is an exposition and independent explicit verification of consequences of classical formulas, with a self-contained proof.
