The compact-core argument survives the following direct root challenge. Fix the
reference hyperbolic element u once, and conjugate it inside J so one point x of
its axis lies in compact K, with JK=X the convex hull. Every conjugator t to an
element v of J sends this SAME x to the axis of v, entirely contained in X.

overgroup elements carrying K to intersect K, and jvj^-1=sus^-1. Each s supplies
at most one J-class. There is no varying reference point that could introduce
a word-length factor, and proper powers cause no change. Discreteness and the
proper action on the plane make the set finite even with torsion and without
finite generation of the overgroup. Without compactness for J the assertion
would be unjustified; the reconstruction explicitly arranges that hypothesis.
