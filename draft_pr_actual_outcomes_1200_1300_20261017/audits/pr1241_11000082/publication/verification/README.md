# Portable support archive

Run `python3 -B verify.py` from this extracted directory. The standard-library
verifier checks the exact archive inventory, current and original editions,
original Git blob identities, and every explicitly registered authored freeze.
It replays the new root exact diagnostic in normal, -O and -OO modes and the
two assertion-based review diagnostics in normal mode only, on temporary copies.
These are finite consistency checks; the infinite mathematical conclusion rests
on the written proof and its stated standard imports.

The main alternative convex-core proof is in `current_edition/PROOF.md`, with the
paper source in `manuscript/main.tex`. The original arithmetic proof, independent
source-question reconstruction, fresh analytic and geometric adversaries, and
two initially independent priority audits with later cross-challenges accompany
it. Original submission bytes and their Git identities are preserved. The
current attribution is governed by `provenance/PRIORITY_ADJUDICATION.json`:
Ferudun2026 DOI10.5281/zenodo.23301731 records the same target theorem. No
firstness, new-existence, new-mechanism, current-openness or disclosure-lineage
claim is made. The optional older multitwist seed is not used by the paper.

Third-party papers, rendered source images, search-response bodies, credentials
and unrelated work are excluded. Raw-source inventories are receipts of the
specified retrieval/inspection acts, not portable manifests or reauthentication
of omitted bodies. Unavailable historical execution bodies are not replayed.
Finite arbitrary matrix controls do not certify geometric realizability for
all tested parameters, ambient primitivity or the infinite claims.

AI tools were used extensively in research, proof development, literature review,
internal independent/adversarial verification and writing. Unrefereed; no external
