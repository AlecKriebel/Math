# Root priority probe: incidence/total-labeling bridge

17 October2026. Search route: use prior total-labeling results via the
once-subdivided incidence tree, rather than search only exact graph descriptions.
Primary source: Yu, Wang and Liu, arXiv1105.1906v1 (10May2011),
https://arxiv.org/pdf/1105.1906 . Root read Observation1 and Section2,
especially Theorem2.6, Lemma2.7 and the inequality discussion on printed3–4.

Observation1 identifies list(p,1)-total labeling with vertex list L(p,1)
labeling of the incidence subdivision. The displayed negative examples use
p>=4, so do not answer the p=2 tree equality. Theorem2.6 is an upper bound.
Lemma2.7 quotes an exact list bound for a tree with a maximum-degree vertex
all of whose neighbors also have maximum degree. It is material overlap with
known sharp list bounds, but not a negative answer here.

Independent target-case check: for Delta3,p2, every degree3 vertex in a
common[5] labeling must use1 or5. A degree3 vertex with all three neighbors
also degree3 would force all three neighbors to the same opposite endpoint,
violating their pairwise distance2 constraints. Hence that older exact-list6
family cannot have ordinary palette5. It does not establish an earlier6>5
counterexample. No broader priority clearance follows from this probe.
