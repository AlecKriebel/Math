# Mathematical verification work in progress

This research artifact independently checks the specified finite construction,
using exact standard-library global CSP enumeration. It is not yet a frozen
preprint submission package. The mathematical gate passed after clarifying a
supplementary recurrence domain and the source citation's page range; priority
and final publication reviews remain pending.

Run normal Python, -O or -OO on verify.py. Checks use explicit exceptions.
The same deterministic results.json is written under each mode. Source graph,
lists and ordinary witness are loaded as inert JSON and bound to the displayed
construction. The arbitrary-list upper bound and infinite family depend on
complete analytic proofs, not the finite or random checks. Original history
and independent-family freeze records are kept separately and are not rewritten.
