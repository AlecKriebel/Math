## Exact priority question and comparison standard

For every finite tree T, Kohl's statement is χℓ^(2,1)(T)=χ^(2,1)(T), where χ uses the common initial segment {1,…,k} and χℓ requires a labeling from **every** assignment of arbitrary k-element positive-integer lists. Thus χ is ordinary zero-based span plus one. A prior negative resolution need not use the same tree or lists: any rigorously established tree with χℓ>χ, or a stronger theorem implying such a tree, defeats first-resolution priority. A graph with cycles, a fixed-list decision algorithm, an upper bound, a different separation parameter, or a square-list-coloring counterexample does not by itself do so.

The submitted object is the spine a–b–c–d–e with respectively 2,1,0,1,2 added leaves. Its order is11, size10, maximum degree3, radius3, and it has four degree-three vertices. Its ordinary palette size is5 and arbitrary-list number6. All seven internal/spine-and-side-leaf lists are A={1,2,3,4,5}; the four end leaves have B={1,3,4,5,6}. Comparison allows graph isomorphism and global translation/reflection of labels. No exact matching specimen was verified in inspected source figures or descriptions. This is a source-bounded observation, not an exhaustive graph/literature claim.
