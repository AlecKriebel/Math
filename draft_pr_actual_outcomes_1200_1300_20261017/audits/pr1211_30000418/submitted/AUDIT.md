## 1. Exact problem and convention

Kohl's [OWR contribution](https://doi.org/10.4171/owr/2006/07), printed pages 414–416 (PDF pages 36–38), defines a k-assignment by assigning each vertex an arbitrary k-element set of natural numbers. A valid labeling chooses one number from each assigned list, has difference at least 2 on edges, and distinct labels at distance two. The list parameter is the least k for which **every** k-assignment admits such a labeling. No interval-list restriction is present.

Conjecture 4 on printed page 416 asks equality with the ordinary parameter for every tree. That parameter permits the common palette {1,...,k}. Kohl's [2006 dissertation](https://webdoc.sub.gwdg.de/ebook/dissts/Freiberg/Kohl2006.pdf), printed page 124 (PDF page 128), separately gives the convention chi = lambda + 1 and the same tree statement as Conjecture 4.4. Both defining/conjecture pages were visually checked; this is not an inference from a later algorithm paper.

In particular, “palette size 5” here means the ambient interval {1,...,5}, not five freely spaced colors or an arbitrary collection of five labels. Whether zero belongs to the author's natural numbers makes no difference: the exhibited lists are positive, and translating all labels by one preserves all constraints.

## 3. Independent infeasibility proof, with both orientations

For x in A, the labels in A at difference at least 2 from x are, respectively,

- x=1: {3,4,5};
- x=2: {4,5};
- x=3: {1,5};
- x=4: {1,2};
- x=5: {1,2,3}.

All three neighbors of b have list A and must have pairwise different labels. Therefore b can only have label 1 or 5. The same reasoning applies at d. Since b and d are at distance two, their labels differ. The constraints at c then force c=3.

There are exactly two possible orientations:

1. If b=1,d=5, examine a. Its adjacency to b rules out labels 1,2, and its distance two from c rules out 3. Thus a=4 or a=5. If a=4, each a-leaf has B-values {1,6} allowed by the edge, and distance two from b removes 1. Both leaves must be 6. If a=5, edge separation permits {1,3}, and the same distance-two condition forces both leaves to 3. Either case violates a1≠a2.
2. If b=5,d=1, the identical calculation applies at e and its two B-list leaves, with e=4 or 5. Again the two leaves are forced equal.

This proves impossibility without relying on a symmetry shortcut, search output, Hall's theorem, or an external theorem. One bad five-list assignment is enough to disprove the universal five-list guarantee. Monotonicity in list cardinality follows by selecting smaller sublists, so the list parameter is at least 6.

## 5. Arbitrary six-list upper bound and boundary cases

For any finite nonempty tree of maximum degree Delta, choose a root and process vertices in breadth-first order. At a non-root vertex v with parent p, the only earlier adjacent vertex is p; it excludes at most the three integers f(p)-1,f(p),f(p)+1. The earlier vertices at distance two are earlier siblings and, when it exists, the grandparent. All belong to N(p) minus {v}, a set of size deg(p)-1. They exclude at most that many additional integers. Hence the total forbidden set has size at most

\[
3+\deg(p)-1\leq\Delta+2.
\]

A list of Delta+3 distinct integers therefore contains an allowed label. The root has no restrictions. This proves the all-list upper bound, with no assumption about interval lists, bounded label magnitudes, or neighboring-list overlap. For T, Delta=3 gives the required six-list guarantee and establishes the exact list value 6.

Boundary audit:

- For a one-vertex tree, both parameters equal 1 directly. The generic Delta+3 upper bound is valid but loose. The sometimes-quoted ordinary lower bound Delta+2 is not valid for this isolated case and is not used here.
- For a single edge, lists of size 3 always admit labels differing by at least 2. If a chosen endpoint value excluded all three values in the other list, that other list would be its exact three-consecutive-integer neighborhood; a different value at the first endpoint has a different neighborhood and leaves an allowed value. Common lists {1,2} show the lower bound, so both parameters equal 3. The generic greedy bound gives 4 and is again only a loose upper bound.
- In every larger tree, the parent count and grandparent/sibling count above hold independently of whether the root is a leaf, whether the root has one child, or whether a vertex is the first or last child. No hypothetical negative sibling count is invoked.
- Trees are taken to be nonempty connected graphs. If a convention includes the empty graph, its empty labeling is trivial and it does not affect the counterexample.

Finite implementation checks included all 1,442 labeled trees of orders 1 through 6, every choice of root (8,477 rooted cases), two different list patterns each (16,954 greedy runs), and 1,000 additional deterministic random-list cases on trees of up to 35 vertices. These confirm the implementation; the preceding counting argument proves the unbounded theorem.

## 6. Other mathematical claims in the candidate

The pendant-path extension is correct. Attach paths independently beyond the six original leaves. Each new vertex has only its already labeled parent and grandparent within distance two; at most four values of the common five-palette are excluded. New vertices on different added paths are never within distance two of each other. Thus the ordinary witness extends, while the original degree-three lower bound remains. Original distances do not change, so the bad lists on the original vertices still obstruct any list labeling. Maximum degree remains 3, giving list value 6 again. There are infinitely many such trees and their diameters can be arbitrarily large. Independent checks covered 860 extension-length vectors, including mixed and zero lengths. No claim that every extension remains a caterpillar is made.

The rank-compression claim is also correct, with its stated direction. For an n-vertex k-list assignment, the union has at most nk labels. Replacing distinct values by sorted ranks produces lists in {1,...,nk}. A valid labeling of the compressed instance lifts to a valid labeling of the original because differences between original integer values are at least the corresponding rank differences. Consequently an infeasible original assignment compresses to an infeasible one. Feasibility need not survive compression in the other direction. This is a finite-universe principle, not a claim that all such assignments were enumerated.

The tree-state certificate description is sound: a state retains the vertex label and its parent's label; its children's roots must choose distinct feasible child labels avoiding the parent label. All additional interactions between different child subtrees have distance greater than two. Induction from the leaves justifies this recurrence. The audit checks it by enumerating child-label tuples, not by trusting candidate state truth values.
