# Polynomial multipliers: verification and proof supplement v1.0

This package accompanies *Polynomial multipliers of differentiation-hypercyclic functions*, by Alec Kriebel. It gives a valid attributed historical negative answer to Costakis's2008 Question5. Older Gaussian hypercyclicity theory already implies the existence conclusion, even frequently; no new first solution, first existence, current-openness or earliest-priority claim is made.

Run with ordinary Python3 (standard library only):

    python3 -B verify.py

This authenticates every archived authored file, checks original Git-blob/SHA256 identities and current/nested frozen manifests, then actually replays both independent finite exact-algebra drivers under normal, -O and -OO Python. Replays use disposable temporary copies and leave the archive unchanged. Root diagnostics execute three altered algorithm variants and reject them. The independent analytic driver's five controls are deliberately false fixed-fixture fault-model predicates, not five executed mutant programs; its separate clarification is included. Exact outputs are compared semantically with the frozen expected receipts.

Finite algebra checks do not establish hypercyclicity, entire convergence, infinite-order derivative escape, density, probability-one assertions, or priority. Those conclusions rest on the explicit written analytic proofs. There is no simulated Gaussian orbit offered as a proof.

- `manuscript/main.tex`: preprint source; compile with a standard LaTeX distribution or Tectonic using amsmath/amsthm, geometry, lmodern, microtype and hyperref.
- `CURRENT_SIMULTANEOUS_PROOF.md`: standalone elementary annular/Baire argument with attribution.
- `current_edition/`: fresh current mathematical documents; original fixed-p argument retained and historical audit explicitly scoped.
- `original_submitted/` and `provenance/SUBMITTED_SNAPSHOT.json`: immutable eight-file PR-head capture, separate from current additions.
- `diagnostics/root_diagnostics.py`: new exact Gaussian-rational driver and independent ordinary-coordinate product oracle.
- `reviews/source_question_family/freeze_20261017T182054Z/`: original-question-only reconstruction frozen before candidate/later-literature comparison; this is a scoped input boundary, not a claim of complete blind discovery.
- `reviews/analytic_source_adversary/`: fresh candidate-aware original-proof/source review, exact checks, sealed artifacts and later control-scope clarification.
- `reviews/annular_baire_adversary/`: independent direct successive-block verification of the added elementary theorem.
- `reviews/nikula_corollary_adversary/`: separately authenticated primary-theorem input and adversarial Gaussian/clipping deduction.
- `priority/`: two independently frozen extensive bounded priority audits and later cross-challenges, with exact source/inspection/query records. No unsuccessful search is a proof of absence. Date-cause and boundary qualifications are separate addenda preserving frozen reports.
- `provenance/ROOT_PRIOR_IMPLICATION.md`: explicit older-theorem deduction, including frequent-hypercyclic null-orbit stability.

Some retained historical research helper scripts refer to their original audit context and are included as provenance, not advertised as standalone entry points. `verify.py` and the two exact drivers it invokes are the portable replay interface. Historical omitted checks/source bodies are metadata only: current byte checks do not retroactively authenticate an unavailable old execution. Downloaded third-party source PDFs, extracted text, rendered source images, raw search responses, private credentials and tracker rows for other work are excluded. Source receipt paths describe research-time files and do not imply those external bodies are included.

The archive root MANIFEST binds every other member and excludes itself. Nested original/frozen manifests retain their original self-reference policies. The external BUILD_RECEIPT binds the root manifest, final ZIP, PDF and TeX. Fresh whole-package review and external publication receipts are maintained beside the frozen package, avoiding a circular inclusion of reviews of the archive itself.

AI tools were used extensively in research, proof development, literature review, exact computation, internal adversarial verification and writing. This is unrefereed. No external human peer review, journal acceptance or formal proof-assistant certification is claimed. Authored project material is released CC BY4.0; third-party source bodies are not redistributed.
