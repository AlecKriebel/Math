# Portable support archive

Run `python3 -B verify.py` from this extracted directory. The standard-library
verifier authenticates the complete member inventory, current and original
edition manifests, original Git blob identities, and all ten authored proof and
priority freeze manifests. It does not numerically certify the analytic theorem.

The main proof is in `current_edition/PROOF.md` and the TeX paper source in
`manuscript/main.tex`. Distinct full Riesz and classical Sobolev/capacity proofs,
the scoped logarithmic-energy route, independent adversarial derivations and
bounded priority records accompany them. Original submitted files are immutable.
The exact priority scope is in `provenance/PRIORITY_ADJUDICATION.json`.

Third-party papers, source images, search response bodies, credentials and
unrelated research are excluded. Source inventories are sealed receipts of the
documented retrievals and inspections; an integrity replay does not re-fetch or
authenticate those omitted bodies. Historical omitted executions are not replayed.
Written mathematical arguments support the infinite conclusions.

AI tools were used extensively in research, proof development, literature review,
internal independent/adversarial verification and writing. This is unrefereed;
no external human peer review or formal proof-assistant certification is claimed.
