## Short route: deductions checked

1. Range fixing forces each original generator to be an eigenvector: for j different from i, p_j alpha_g(s_i)=0, and multiplying a span expansion by p_j kills every term except its s_j coefficient. Nonzero generators then force that coefficient to vanish. Norm preservation gives unit-modulus remaining coefficients; the action law makes them characters.
2. The exact graph presentation uses T_ij=s_i p_j. Its initial projection is p_j. Outgoing ranges sum to p_i. Conversely outgoing sums give the original s_i, with cross terms zero by the orthogonal right supports. This is an actual equivariant isomorphism, not stable or Morita equivalence.
3. Essentiality rules out sinks and sources and supplies an edge. If the component DAG had more than one component, a terminal component T and a distinct source component S exist. The latter has a directed cycle because it has no incoming external edges and every vertex has an incoming edge. Saturating T cannot absorb that cycle. The resulting proper nonempty saturated hereditary set gives a proper nonzero ideal, contradicting simplicity. The directed-cycle algebra is a matrix algebra over C(T), so pure infiniteness excludes it.
4. For a finite strongly connected graph with an edge and not a directed cycle, every cycle has an exit. The diagonal is a MASA, so an inner implementer of a diagonal-fixing automorphism is a diagonal unitary h. The relation h(mu x)=z_mu h(x), evaluated at the periodic path x=mu mu ..., forces z_mu=1 for every closed path. Comparing theta_v e eta with theta_w eta gives z_e=z_theta_w/z_theta_v. ## Falsification boundaries

- Empty graphs do not meet the revised edge hypothesis. The edgeless singleton has algebra C and a trivial edge action, but cannot be fed into the Kirchberg/MASA proof. The original essential simple purely infinite matrix target loses no case from this repair.
- A one-vertex graph with multiple loops is allowed; a single directed cycle is excluded. Period d=1 makes the return argument tautological, not invalid. Period d>1 and parallel return edges cause no 0–1-matrix confusion; the optional edge matrix restores a primitive 0–1 presentation.
- G trivial, G/K trivial, K=G and nonfaithful actions are covered explicitly. In the all-inner case D_g itself implements alpha_g exactly in A^alpha.
- A projective Pauli family of inner automorphisms is not an honest cocycle for the trivial action. It refutes a generic pointwise-inner shortcut, but not the graph's explicit representation or honest-cocycle lemma.
- Ordinary homotopy, mere faithfulness, ordinary approximate innerness or fixedness under only g would each leave a gap. The current proof supplies the stronger required hypotheses at the relevant steps.
