# Semibrace existence on meet-semilattices: an attributed classification

For the four semibrace identities printed in Dietzel's Problem 3, OWR9/2023, every nonempty meet-semilattice with any prescribed distinguished element admits a semibrace via right projection. A realization that is also an L-algebra exists exactly when the distinguished element is greatest; in every such realization the logical order equals the original meet order. Under the separately attested meet-monoid convention, both existence questions require a greatest element.
