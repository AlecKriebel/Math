# Semibrace existence classification: Problem 30005434

## Result and exact scope

Under Definition 2 as printed in Carsten Dietzel's *Some problems on L-algebras*, every nonempty meet-semilattice admits a semibrace structure. A meet-semilattice admits both that semibrace structure and the printed L-algebra axioms if and only if it has a greatest element. In every joint realization the distinguished element is greatest, and the meet and L-algebra orders coincide.

For the first question, use right projection x·y=y with any distinguished element. For the joint structure on a meet-semilattice with greatest element e, use x·y=e if x≤y and x·y=x∧y otherwise. The proof is valid without finiteness, distributivity, joins, or a least element. The empty set is excluded by the required distinguished element.

A separately attested convention also requires e to be the identity for the meet operation. Under that convention both existence questions have precisely the meet-semilattices with a greatest element as their answer. Earlier versions of the paper documenting this convention predate the workshop; it must not be described as a later invention.

This is an existence classification, not a classification of every multiplication or of structures with additional unstated hypotheses. The y-valued second branch of the workshop's Problem 10 is different and fails meet preservation on the four-element Boolean lattice.
