# Independent exact flow controls

Run `python3 independent_flow_controls.py` from this folder. It uses only the Python standard library, imports no candidate or prior-review code, and rewrites only `INDEPENDENT_FLOW_CONTROLS.json` in this folder. The output is deterministic.

The general proof reconstruction and review verdict are in `INDEPENDENT_DERIVATION.md` and `REPORT.md`. Historical replay receipts preserve both the initial strict-wrapper failure and the fresh component isolation. `PORTABILITY_ASSESSMENT.json` lists every differing historical field and its scope. `INPUT_CUSTODY.json` binds the untouched24 original files to the pinned candidate snapshot. Third-party primary HTML and scratch replay copies remain private and are not included in this review package.
