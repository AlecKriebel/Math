# Designed-tree congestion research note

Alec Kriebel, A designed tree model with a sharp congestion–fragmentation transition, version1.0,21October2026. ORCID0009-0001-9320-500X.

This package contains the paper PDF, matching standalone TeX source, full source/verification ZIP and the canonical existing-tool Zenodo deposit manifest. The ZIP includes all24 original PR397 research files, three independently developed adversarial families, exact and probabilistic finite controls, bounded priority records and a specifically tested replay derivative.

The result is a complete theorem for an explicit specialized model motivated by Aldous's conceptual toy-model request. Sparse physical topology, dense cross-root traffic, capacities growing with size, affine demand with quadratic variance, actual-slope normalization and outer-phase-only every-optimizer conclusions are explicit. The shrinking width is an upper bound. No canonical model, universal traffic theorem, critical profile or worldwide-firstness claim is made. Classical and close prior work are credited; the final1993 KMN journal body remains an edition/access limit.

The original historical replay wrapper and all frozen files are unchanged. The new derivative requires exact active output and allows only enumerated older numerical diagnostics plus declared runtime/public-projection differences, with tested versions and guard controls. It does not claim unpinned bitwise replay.

AI tools were extensively used in research, proof/model development, verification, manuscript preparation and adversarial auditing. Unrefereed preprint; no formal independent human peer review has occurred. Final publication, DOI, tracker and integration receipts belong to the repository audit record; this README does not assert publication before it is verified.
