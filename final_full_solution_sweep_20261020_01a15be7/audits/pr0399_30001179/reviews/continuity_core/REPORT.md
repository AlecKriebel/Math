### Continuity and the full structural inverse

A nonempty word is a finite union of convergent sequences and finitely many final letters. Its supremum is a coordinate or one of the finite block limits. Both sorts of equality to a fixed boundary have zero measure. This proves strong P_t continuity at positive time. At0, an individual positive word has a positive coordinate and is eventually excluded; the vacuum persists. No finite total measure or uniform support bound is assumed.

The ambient sections are norm-continuous H-valued functions in P_tH. P_th supplies every fibre value, and a countable dense set of h supplies a fundamental family. Countable direct sums of these spaces stay separable. Positive dilation on each grade has scaling dimension n+m, with the correct square-root factor r^(-(n+m)/2); it gives local triviality for t>0.

For fixed grades and an alternating pattern, the concatenation unitary is fixed as time varies; only input projection and translation change continuously. Different unrestricted patterns can have the same output grade. One must not infer a bounded global concatenation map on all of H*H without the interval projections. The actual argument instead uses the well-defined partial isometries V(s,t)=u_(s,t)Q(s,t), each with norm≤1, already established by the disjoint run charts. Fixed pattern/grade calculations establish strong continuity on a dense set, and this uniform operator bound extends it. The truncation projections on the source commute with Q, so they preserve the needed support restrictions.
