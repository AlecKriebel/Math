# Prepared preprint and source package

Alec Kriebel, *A continuous free product system not generated by its tensor core*, version 1.0, 21 October 2026 UTC. ORCID 0009-0001-9320-500X.

This folder holds the matching PDF and TeX, source/verification ZIP, citation/license notices and the one canonical existing-tool Zenodo deposit manifest. No provider call, deposit staging, DOI allocation, or publication is performed by preparation. `PACKAGE_STATUS.json` records `publication_ready: false` until the parent completes root reproduction and fresh complete-package reviews.

The theorem gives the explicit continuous separable pointed Hilbert-space counterexample to the universal tensor-core generation question posed by Skeide in 2009. Its core F has the proper finite-word free hull K in E. Separate adapted-cocycle, forward tensor-recovery and classification questions are untouched. The exact continuity convention and all proof details are stated in the paper.

The verification ZIP preserves all eleven originals and all three sealed scientific review families. A new standard-library wrapper strictly checks exact types, inventory, paths, symlinks, hashes and normal/optimized control outputs. It forces the original assertion scripts to run with assertions enabled and does not treat their optimized output as verification. Tests include active negative controls. The finite computations do not establish the analytic infinite-dimensional theorem.
