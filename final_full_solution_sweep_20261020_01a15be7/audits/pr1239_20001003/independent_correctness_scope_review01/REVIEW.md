## Universal proof, independently challenged

The graph must have n+1 vertices, one distinguished sink, and a reduced n-by-n Laplacian. A full graph Laplacian is singular. Integer row-basis operations mean left multiplication by GL_n(Z), preserving the specified row lattice. Permitting arbitrary rational basis operations would trivialize the question; permitting a non-unimodular adjugate multiplier would likewise allow a multiple of the identity and change the lattice. Those are different questions from the source's exact-lattice convention.

For row input M, the primer's matching column input is M^T. If UM=L is symmetric, then M^T U^T=L, and conversely. One cannot instead substitute im(M) for im(M^T). This distinction is material: M=((1,4),(2,4)) has the graphical row lattice generated by(1,0),(0,4), while M^T has the nongraphical row normal form((2,0),(1,2)). Both answers were independently checked.

Given nonnegative integer multiplicities, adjacency-degree subtraction and the sum of rank-one edge matrices produce the same reduced L. Conversely, symmetry, nonpositive off-diagonal entries and nonnegative row sums recover exactly those multiplicities, including the sink edges. The quadratic form is a sum of nonnegative squared differences and sink-coordinate squares. A zero vector of that form is constant on each nonsink support component and vanishes on each component attached to the sink. Hence nonsingularity is equivalent to connectivity to the sink; a positive determinant condition does not silently admit disconnected support.

Loops contribute equally to the outdegree and the same-vertex adjacency term, so they cancel. Removing them changes neither the reduced matrix nor support connectivity. No bound on raw loop counts is claimed or needed. Sink edges are ordinary undirected edges; the sink need not be an absolute directed sink.

The written Cauchy–Binet proof of the tree determinant identity is complete. Expanding integer weights into edge copies gives L=BB^T. A selected edge cycle gives dependent incidence columns; a disconnected selection has a nonsink-component indicator in its left kernel. A selected tree has determinant+/-1 by leaf expansion, including n=1. Each nonloop edge can be extended to a spanning tree. Replacing its copy by any of the m parallel copies yields m distinct trees, proving m<=det L. Nothing requires that the edge occur in every tree. In a realization det L equals the index D, so every nonloop class is bounded by D, and each diagonal is bounded by nD. A diagonal bound of D would be false and is explicitly detected by the checks.

Finally, rows of L in row_Z(M) give the unique integral matrix U=LM^{-1}=L adj(M)/det M. If det L=D=|det M|, then det U=+/-1, so UM=L is an allowed basis change and the lattices are equal. This is also an independent direct proof of the inclusion-plus-index step. Divisibility of v adj(M) by positive D tests row membership exactly, regardless of the sign of det M. The finite box has precisely n(n+1)/2 edge classes, so complete enumeration terminates after at most(D+1)^{n(n+1)/2} assignments. This is a necessary-and-sufficient arithmetic decision criterion, with no efficiency claim.

The theorem explicitly assumes n>=1. Rank one is fully covered, with edge multiplicity D and multiplier -1 for input (-D). Rank zero is outside that stated domain.
