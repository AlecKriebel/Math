## What the all-rank finite criterion obtains from classical results

Here is the complete deduction relevant to priority, retaining the fixed lattice throughout. Let Lambda=row_Z(M), n>=1 and D=|det M|. For each of the n(n+1)/2 possible non-loop pairs on the labeled n+1 vertices choose a nonnegative integer multiplicity w_e. Let L(w) be the reduced undirected Laplacian.

If L(w) realizes Lambda, its positive determinant is D. The classical matrix-tree theorem says that determinant counts spanning trees with parallel copies distinguished. Every edge in a connected undirected graph can be extended to a spanning tree. For a parallel class with m copies, substituting each copy in that tree gives m distinct trees, hence m<=D. Loops cancel in the Laplacian and can be removed. Therefore every realization has a loopless representative in the finite box 0<=w_e<=D.

Conversely, for a box candidate, require every row of L(w) to lie in Lambda and det L(w)=D. Row inclusion and equal finite index give equality of lattices. The reduced quadratic form is a sum of nonnegative edge-square terms, so positive determinant forces every vertex to connect to the sink. Row membership is an exact adjugate divisibility check. Then U=L(w)adj(M)/det(M) is integral with determinant+/-1 and supplies the required row operation certificate. Exhausting the box settles a negative instance as well as a positive one.

This supplies all ranks, all nonsingular inputs, zero multiplicities, bridges, parallel classes, loops, chosen sink and negative input determinant. It is not merely a numerical experiment or a special case. The correct diagonal cap is nD, not D. The independent controls include a valid diagonal5 at D=4.

The mathematical mechanism is entirely this classical tree identity, edge extension and elementary lattice index arithmetic. No additional unproved geometric characterization is needed. That is a concrete novelty limitation. I did **not** find an older primary source explicitly packaging precisely this finite box iff for arbitrary input lattices. Calling it an immediate classical deduction is therefore an assessment with the deduction displayed, not an invented citation to an earlier recognition theorem. An elementary new application can be useful; its publication novelty must be assessed explicitly rather than inferred from a failed title search. This audit provides neither an “already solved in full by paper X” finding nor a firstness certificate.
