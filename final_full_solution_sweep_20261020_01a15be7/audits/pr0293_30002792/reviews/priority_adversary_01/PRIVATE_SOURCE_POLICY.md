# Private source handling

All downloaded full copyrighted source bodies, extracted text, and page renderings are in `private_sources/`. That directory is excluded from publication and checkpoints by the local `.gitignore`. Publishable audit files contain only bibliographic metadata, concise paraphrases, short fair-use quotations, theorem/page locators, and file hashes. No commits, pushes, ledger changes, external contact, or remote mutations are authorized to this reviewer.
