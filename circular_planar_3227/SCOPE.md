# Scope and publication boundary

This is an authored mathematical partial-results package for OPG-401 (ID 3227).
The full 20/7 conjecture for finite simple triangle-free planar subcubic graphs
is not solved here. Squares, degree-two vertices, and nonregular graphs are
part of that unresolved target. Research assessment is unsolved after 5/5 turns.
This assessment is not a proof that no later resolution exists in the literature.

Included: authored proofs and audit, public bibliographic references and source
inspection metadata, explicit finite graph/coloring and branching certificates,
standard-library checking code, optional NetworkX search and independent audit
code, exact generated check outputs, negative controls, and replay/seal records.
The finite graphs are explicit authored benchmark/certificate inputs, not copied
catalog datasets. `results.json` contains historical search timings, not a
formal UNSAT proof; the independent branching checker is the finite proof check.

Excluded: source PDFs and copied third-party source text, catalog/dataset
contents, binary dependencies, caches, private coordination/status documents,
private paths and chat links. No queue file is included or modified. This
package preparation performs no external publication.

The sparse and subdivided-core proofs establish special classes only. The
finite dodecahedron exact value is known; its verification asserts no novelty.
The phase result concerns a restricted representation and does not refute
colorability. SAT/UNSAT certificates and phase enumeration are executable
computational proofs, not proof-assistant formalizations. Python, checker
implementations, and graph identification remain trust dependencies. The
independent NetworkX/Floyd–Warshall audit supplements the standard-library
checks and is clearly distinguished from them.

Public source URLs and inspection limitations appear in `SOURCE_GATE.md`.
The original thesis was only checked through indexed primary text, not a
complete download or visual inspection. Nearby fractional-coloring results
are not substitutes for the circular-coloring target.
