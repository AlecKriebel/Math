# Route D - robust primary stationary crossing reconnaissance

**Status:** killed without a theorem or exact counterexample.

A bounded four-dimensional campaign sampled Hurwitz matrices with negative signed principal minors, constructed multiscale positive diagonal witnesses, and classified the earliest sampled stability loss along the resulting one-parameter paths. The JSON output is explicitly numerical reconnaissance.

Even a path whose first loss is oscillatory would not refute the universal statement, because another diffusion direction might have a primary stationary crossing. Conversely, generic simple stationary crossings in sampled paths do not prove the universal perturbation theorem. No exact minimal counterexample and no proof that weak admissibility always has a primary simple transverse realization were obtained. The manuscript therefore keeps weak stationary admissibility separate from first-crossing and wave-exclusion claims.
