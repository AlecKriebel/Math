# Route C - existential-real hardness reconnaissance

**Status:** killed without a theorem.

The membership proof is robust, but hardness requires a polynomial-size gadget library for arbitrary polynomial feasibility. The positive steady-flux constraints are linear, while determinants and Hurwitz minors create products only in a tightly coupled way. Addition is easy to represent by flux balance; exact multiplication with strictly positive classical-mass-action rates, controlled equilibrium scalings, and a single stationary-minor output was not isolated.

Numerical or heuristic embeddings were not accepted. The paper claims membership in the existential theory of the reals and NP-hardness, but not existential-real hardness or completeness.
