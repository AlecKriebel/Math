\section{Purpose and independence protocol}

This supplement records the Phase III proof reconstruction and validation
artifacts.  The proofs below were rewritten from definitions and are organized
in dependency order.  The independent implementation under
\texttt{independent\_verifier/} imports no code from the inherited candidate
package.  Agreement with the inherited implementation was treated as a
regression check only; exact proofs and definition-level tests are the basis
for the validation outcome.

The central scope is weak stationary linear instability: some nonzero spatial
mode has a positive real eigenvalue.  No first-crossing, wave-exclusion, or
nonlinear pattern claim is introduced in this supplement.

\section{Exact data-level separating examples}

\subsection{Unsigned and signed interaction graphs}

Consider
\[
J_0=\begin{pmatrix}
-7&-5&-4\\-7&-7&-5\\-3&-4&-6
\end{pmatrix},\qquad
J_1=\begin{pmatrix}
-7&-1&-2\\-7&-4&-4\\-3&-7&-6
\end{pmatrix}.
\]
Both have the same complete all-negative signed interaction graph.  Their
characteristic polynomials are respectively
\[
 \lambda^3+20\lambda^2+66\lambda+47,
 \qquad
 \lambda^3+17\lambda^2+53\lambda+16,
\]
and both satisfy the cubic Hurwitz inequalities.  Every signed principal minor
of $J_0$ is positive.  The $(2,3)$ principal determinant of $J_1$ is $-4$, and
\[
 D=\diag(9,1/9,1/9),\qquad \det(D-J_1)=-281/81.
\]

Apply the fixed-row case of the row realization theorem.  Each network has the
same ordered stoichiometric matrix
\[
 [e_1,-e_1,e_2,-e_2,e_3,-e_3]
\]
and all positive-equilibrium Jacobians are $RJ_kH$ with $R,H\succ0$ diagonal.
For every principal set the signed determinant is multiplied by a positive
factor.  Thus the first network can never be stationary-destabilized, while
the second is admissible at $R=H=I$.  Levels 1 and 2 therefore fail for the
network-wide existential problem.

\subsection{The stoichiometric matrix alone}

Both two-species networks use
\[
 \Gamma=[e_1,-e_1,e_2,-e_2].
\]
For the first, take sources
\[
 (2,0),\quad(1,2),\quad(2,0),\quad(0,3)
\]
and add the corresponding stoichiometric column to form each target.  Unit
steady flux gives
\[
 A=\begin{pmatrix}1&-2\\2&-3\end{pmatrix},
\]
which is Hurwitz and has a positive first diagonal entry.  For the second, use
sources
\[
 (1,0),\quad(1,0),\quad(0,1),\quad(0,1).
\]
The steady-flux equations pair the positive and negative reaction in each row,
and their source contributions cancel, so $A(v)=0$ for every positive steady
flux.  The two networks have the same indexed $\Gamma$ and opposite answers.

Level 3 is a Coates graph of one selected Jacobian and is not a
parameter-independent network representation.  Level 5, the indexed pair
$(\Gamma,Y)$, is sufficient by the exact formula.  Level 6 determines and is
determined by Level 5 when reaction indices and integer labels are retained.

\section{Certificate formats and software limitation}

A YES certificate contains the reconstructed network, one principal branch,
and all coordinates in one explicitly isolated real algebraic number field.
The verifier checks the canonical equations and signs from the network data.
A NO certificate contains a Real Nullstellensatz identity for every branch (or
one selector-encoded branch).  Identity checking is exact polynomial
arithmetic.

The release does not vendor a complete cylindrical algebraic decomposition or
Nullstellensatz generator.  Consequently the command-line classifier may
return \texttt{UNRESOLVED} for a raw network without a supplied certificate.
This is an implementation limitation, not a claim that failed search proves a
NO instance.

\section{Strengthening routes not claimed}

\begin{enumerate}
\item The row-realization sources have molecularity growing with the binary
input.  Parallel bounded reactions would be pseudo-polynomial, and no exact
finite-rate auxiliary-species gadget was proved.
\item The source problem is \textsc{Partition}; no strongly NP-hard interval
family was obtained.
\item No exact addition/multiplication gadget library established
$\exists\R$-hardness.
\item A bounded numerical campaign found generic simple stationary first
crossings along the constructed paths, but this neither proves universal
primary-crossing equivalence nor excludes another path with an earlier wave
crossing.
\item The fixed-$n$ code implements circuit projection and exact
preprocessing, not a complete practical general CAD solver.
\end{enumerate}
