# Existing finite Morse analogue for virtual resolutions

Source identifier: 20000012. Queue rank: 1857. Disposition: `already_solved`. Turns: `1/5`.

This disposition applies ONLY to AIM Problem 4.5's broad question of whether a Morse-theoretic analogue exists for virtual resolutions. It does not claim an AIM-maintainer status update, a new theorem, or settlement of the generated Cox-chart specialization or universal minimization problem. Those stronger questions remain unresolved by this package and outside accepted scope.

The published Hanlon–Hicks–Lazarev finite sheaf-valued construction supplies a positive analogue, used in toric line-bundle resolutions. PROOF_AUDIT.md gives an independent finite cancellation proof and its exact hypotheses. An infinite locally finite acyclic counterexample rules out an unrestricted extension. Local Cox cancellation is distinguished from global descent throughout.

Han's later v3 preprint is supplementary, not necessary for the disposition. Its normal toric subvariety / simplicial projective ambient hypotheses and complex coefficient framework are retained. No universal minimization, global Betti optimality, or uniqueness is claimed.

Run `python3 verify.py` and `python3 -O verify.py` from this directory. The verifier checks an exact flat inventory, hashes, metadata, and complete replay of one finite rational cancellation regression. This regression illustrates identities for one finite example; it is NOT computational certification of the general proof. The mathematical acceptance rests on the authored proof and its scope, not on checksums or a finite test.
