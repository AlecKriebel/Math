## Exact dependency

The FPRAS paper's Theorem 1.1 (`thm:main`, TeX lines 132–143) asserts one uniform classical randomized algorithm on every finite simple undirected unweighted graph G and rational 0 < epsilon < 1, 0 < delta < 1/2. The output is a nonnegative rational; its relative-epsilon guarantee has probability at least 1-delta. If Z(G)=0, every execution outputs zero. Worst-case bit time, including unsuccessful executions, is polynomial in the full encoding length, epsilon^-1, and log(delta^-1). This is exactly the kind of unweighted base algorithm needed by a polynomial-size simple-graph reduction. It imposes no connectivity, density, near-perfect/perfect ratio, or positive-count lower bound beyond the integral fact Z(G)>=1 on its nonzero branch.

A zero FPRAS output alone does not identify infeasibility: bad random tapes may produce zero for Z(G)>0. Exact detection uses the separate deterministic perfect-matching feasibility test. The empty graph is handled as Z=1; positive odd order or a failed feasibility test returns zero. Binary vertex-count encodings are bounded before allocation using n>2|E|. This matters when mapping follow-on exact zero detection to the base theorem.

The paper explicitly excludes compressed edge multiplicities and weighted inputs from the stated application model (TeX 351–356 and 3126–3127). Intermediate positive rational weighted colored graphs are explicit objects built by the algorithm, and do not themselves assert the desired binary-weighted hafnian FPRAS. The separately proved deletion sampler (Lemma 10.2, `lem:deletion-sampler`, TeX 3203–3290) supplies feasible output on every run and TV error tau in worst-case polynomial time in input length and tau^-1. It uses fresh count calls and exact feasibility tests, and does not follow from the bare word FPRAS. The main formal declaration inspected exports counting, not that sampling lemma.
