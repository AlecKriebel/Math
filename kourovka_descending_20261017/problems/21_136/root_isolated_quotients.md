# Isolated infinite-order classes persist through specified normal kernels

Checkpoint: 24 October 2026. Full21.136 discovery estimate **12%**, pending fresh independent review of the stronger kernel scope. This is a local reduction, not a solution. The first abelian-kernel mechanism was found by the Lie approach agent; the ordinary-integer iterated-commutator extension below was derived separately by the coordinator.

Say that the class of an infinite-order element x is relatively isolated if some open neighborhood U of x has every infinite-order element conjugate in G to x. This is weaker than an open conjugacy class in G. The class-space reduction supplies such an x in a hypothetical countably based counterexample, but none of the arguments here assumes that U contains only infinite-order elements.

## The local quotient lemma

**Proposition.** Let G be profinite, A a closed normal subgroup, and x an infinite-order element with relatively isolated conjugacy class. Suppose A has an abstract locally nilpotent subgroup of finite index (closedness of that subgroup is not needed for the argument). Then xA has infinite order in G/A, and its class is relatively isolated there.

The conclusion also holds if A is torsion. A further finite sequence of quotient passages is allowed when each specified kernel satisfies one of these hypotheses.

**Proof.** Write pi:G->Q=G/A, b=pi(x), and choose the isolating open neighborhood U. Suppose first that b has finite order r. If y in pi(U) had infinite order, any lift u in U would have infinite order. Isolation would give u conjugate to x, so y would be conjugate to b and have finite order, a contradiction. Thus pi(U) consists entirely of torsion elements.

Consider D=C_Q(b), a closed profinite subgroup. Choose an open subgroup K of D such that bK is contained in pi(U). Every k in K commutes with the finite-order b, while bk has finite order. Hence k has finite order: if (bk)^s=1, then k^(sr)=1. Thus K is a torsion subgroup. It has finite index in D by compactness, and D is torsion as well: every d has a positive power in the core of K and hence a further power equal to1.

Choose an integer n>1 such that n is congruent to1 modulo r and x^n belongs to U. This is possible by restricting to the procyclic closure of x: the intersection with U contains a congruence neighborhood of the generator x. More explicitly, choose an open normal N of G with xN contained in U and let e be the order of xN in G/N; n=1+er suffices. The element x^n has infinite order. Isolation supplies g in G such that

    x^g = x^n,       y^g := g^-1 y g.

Since b^n=b, pi(g) centralizes b, and D is torsion. Consequently g^m belongs to A for some positive m. Set a=x^r in A. It has infinite order, and

    a^(g^m) = a^(n^m).

Let L<=A be abstract locally nilpotent of finite index. Some positive powers a^s and (g^m)^t belong to L, by passing to the finite-index core of L in A. Put c=a^s, h=g^(mt), and d=n^(mt)>1. We have c infinite order, c,h in L, and c^h=c^d. The abstract group generated by c,h is nilpotent, of some finite class k. Repeated commutators give

    [c,h,...,h] = c^((d-1)^k) = 1,

with k occurrences of h and [u,v]=u^-1 u^v. The ordinary integer (d-1)^k is nonzero, contradicting the infinite order of c. This contradiction proves that b has infinite order.

Finally pi(U) is open, since a continuous surjective homomorphism of profinite groups is open. Any infinite-order element y in pi(U) lifts to an infinite-order u in U and is therefore conjugate to b. Thus the class of b is relatively isolated.

If A is torsion, the image b cannot have finite order to begin with: x^r in A would then force x itself torsion. The same final argument passes isolation to the quotient. This proves the torsion-kernel version too. QED.

The proof uses ordinary integer powers, not an invalid inference from nilpotence in a finite primary residue ring. It applies to arbitrary profinite cardinality and does not pass the global class-count condition to A or to a closed subgroup.

## Finite normal-series consequence

Suppose G has a finite series of closed G-normal subgroups from1 toG whose factors are torsion or virtually abstract locally nilpotent. Any relatively isolated infinite-order class would persist through the successive quotient groups and eventually yield an infinite-order element in the trivial group, impossible. Thus G has no such relatively isolated class.

For an arbitrary G of this restricted class satisfying the original small-class hypothesis, choose a countably based quotient preserving an infinite-order element as in `root_class_space.md`. The quotient inherits the class bound and a finite series of the same type: normal images remain closed, images of torsion groups are torsion, and an image of a finite-index locally nilpotent subgroup has the same two properties. The Polish class space would supply a relatively isolated infinite-order class, contradicting the preceding paragraph. Therefore such a G is torsion. This is a restricted-class theorem; it does not assert that an arbitrary profinite group has this finite normal series.

In particular this local mechanism covers finite-derived-length soluble groups, using their closed characteristic derived series. The earlier normal-kernel proof already covered that original-problem subclass. The present distinction is persistence of an individual isolated class even when the quotient is not assumed torsion.

## What the local argument actually forces in an unrestricted counterexample

If x is a relatively isolated infinite-order element and A is a closed normal subgroup for which xA has finite order, the first part of the proof is unconditional. It gives an infinite-order a in A, an h in A, and an ordinary integer d>1 with a^h=a^d. Thus A contains a closed finitely generated metabelian subgroup generated by a,h: the procyclic closure of a is normal there, since a and a^d are conjugate and conjugation cannot properly include one closed subgroup of a profinite group in itself. The quotient by that procyclic subgroup is procyclic.

This subgroup need not inherit P0, dense torsion, or the small ambient class count. Applying the metabelian locality theorem to it without establishing its own hypotheses would be invalid. Existence of the relation a^h=a^d in a pro-p group is not itself contradictory when p divides d-1. Compact affine groups already realize it, and generalized Higman constructions must be checked before invoking a finite-quotient obstruction for self-conjugate variants.

The exact full-scope gap remains the existence of an arbitrary profinite group with a nonempty countable Polish infinite-order class space. This note excludes specified kernels, not every possible normal structure. No complete resolution, originality claim, preprint or DOI is asserted.
