Let \(s_j=v_p(j!)\) and \(\eta_j=m s_j\).

| Feature | ArXiv v2 | Accepted manuscript | Fraga's expressly corrected prescription |
|---|---|---|---|
| Operator on \(A\) | \(L_a^{j-\eta_{s_j}}d^{s_j}L_a^{\eta_{s_j}}\) | \(L_a^{j-\eta_j}d^{s_j}L_a^{\eta_j}\) | Uses \(\eta_j\) and a protected/direct pullback interpretation |
| Positive-division branch | Says \(p\mid s_j\) | Says \(p\mid j\) | Uses \(s_j>0\), equivalently \(j\geq p\) |
| Opposite branch | Says \(p\nmid j\) implies \(s_j=0\) | Same assertion | Uses \(j<p\) |
| Affine-unit operator display | Uses \(\eta_{s_j}\) | Still uses \(\eta_{s_j}\) | Uses \(\eta_j\) |
| Unit recursion | Next term appears on both sides | Same self-reference remains | Right side uses preceding term |
| Sums defining \(W\) | Bound index \(i\), free index \(j\) | Same index mismatch remains | Uses one consistent bound index |
| Pullback movement | Shield exponent \(\eta_j=m v_p(j!)\) for \(j\) pullbacks | Replaced by an explicit bound \(i\geq j(p-1)/4\) | Uses one block of \(m\) operators per pullback |
| Repeated section legality | Repeats arbitrary \(d:pA\to A\) | Still repeats arbitrary \(d\) | Treats legal repeats conservatively and supplies a specified totalization |

These are observable source differences, not evidence that the author intended every possible repaired formula. In particular, it would be inaccurate to attribute the entire typo list for arXiv v2 to the accepted article: the operator on \(A\) and the movement statement have changed. Conversely, the accepted article does not by itself remove all the reading issues identified in the later preprint.

The branch involving \(p\mid j\) must not be silently equated with \(s_j>0\): factorial valuations concern all factors up to \(j\). This comparison concerns the expressions printed in the sources; it is not an original mathematical resolution of the Notebook question.

Fraga's preprint claims both failure of the literal display to be a total construction and success of its own fully specified factorial-compatible corrected prescription. Its Section 1 explicitly does not claim equivalence with every conceivable clarification of the original display. That limitation must be preserved. It also does not permit a priority claim merely from substituting a different clarification: one would have to identify a distinct mathematical statement and establish a result not already covered.

The publisher's Version of Record was not obtained; the institution's accepted manuscript is the closest directly accessible journal-source artifact in this audit. A final priority classification should retain that limitation.
