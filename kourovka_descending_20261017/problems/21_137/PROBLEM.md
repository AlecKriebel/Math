# Kourovka Notebook 21.137 — source and known resolution

Source: 21st edition, official October 2026 update 3 (modified 20 October 2026), printed p. 199, PDF page index 198. Proposer: L. Wilson. The latest official main file and updates-only file both mark this problem with an asterisk and give a negative solution notice.

## Full mathematical statement

For a finite p-group G, suppose the literal power set P_p(G) = {g^p : g in G} is a subgroup. Must P_p(G) be powerful? The problem also asks the following explicit special cases: for odd p, when G has exponent p^2, must P_p(G) be abelian; and for a 2-group G of exponent 8, when P_2(G) is a subgroup, must it be abelian?

The literal set of powers must not be silently replaced by the subgroup generated by powers. For odd p, powerful means [K,K] <= K^p; for p=2 it means [K,K] <= K^4. These are the conventional finite p-group definitions used by the source.

## Previously known negative answer

The official notice gives:

- K. Muliarchyk's 13 August 2026 preprint, a p=3 example of order 3^15, exponent 9, whose literal cube set is a nonabelian subgroup isomorphic to UT_3(F_3) x C_3^3.
- A. Chang's letter of 1 August 2026: a Sylow 2-subgroup of S_8 has exponent 8, and its literal square set is a subgroup C_2 x D_8, nonabelian and not powerful.
- Muliarchyk's September 2026 uniform construction for every odd p: G has order p^(3p+1), exponent p^2, and P_p(G) is isomorphic to UT_3(F_p) x C_p^(p-1), a nonabelian group of exponent p. This also improves the order of the displayed p=3 example to 3^10.
