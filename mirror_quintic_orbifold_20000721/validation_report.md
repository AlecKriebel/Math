# Validation scope

The two accepted computation scripts are transformed only by lowering every assertion into an explicit conditional exception. The build compares the full AST, including all expressions and output calls, against exactly that transformation; it does not merely compare function names or selected anchors. The original report, reviews, and acceptance disposition are byte-preserved. Public source metadata is copied from the dated recovery, without private extraction fingerprints or source documents.

Direct normal and optimized runs must reproduce full accepted stdout, all generated exact JSON, and independent text. The additional residual check evaluates the residual dimension, polynomial degree, vanishing derivatives at X=1, and leading functional for fixed genera 2–53. These finite checks supplement, not replace, the symbolic proof in REPORT.md.

Mutation controls alter a Picard–Fuchs denominator factor, inverse-series sign, genus-zero and genus-one normalization, residual-degree bound, and leading-coefficient functional. Each must fail through an explicit mathematical guard in both execution modes. Recursive inventory controls cover altered/missing/extra files, nested files and manifests, symlink files/directories/root manifest, unsafe parent/absolute/backslash/dot paths, duplicate entries and self-listing. An unmodified inventory is first required to pass in each mode.

The manifest excludes only its exact root name. Nested manifests are ordinary inventoried files, not blanket-excluded entries. This package contains none. Hashes are integrity diagnostics, not proof or cryptographic signatures. No program here claims all-genus convergence, nonzero leading terms at every genus, geometric ambiguity, or closure of the original problem.
