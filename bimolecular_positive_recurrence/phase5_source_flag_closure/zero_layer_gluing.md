# Zero-layer gluing without local-coboundary assumptions

The final argument does not glue finite phase coboundaries.  Every zero
alternative produced by the normalized-log compactification is already a
linear function of species counts that is constant on the entire complex
set of the one linkage class.

The only possibilities are:

1. **All-top conservation**
   \[
   w\cdot X,
   \qquad w\cdot y=a\quad(y\in\mathcal C).
   \]

2. **Top-indicator conservation**
   \[
   M_K=\sum_{i\in K}X_i,
   \qquad q_K(y)=1\quad(y\in\mathcal C).
   \]

3. **Service-token conservation**
   \[
   M_K-\sum_{D\in\mathcal D}X_D,
   \]
   where every top complex contains exactly one \(K\)-particle and one
   service particle, while every lower complex contains neither.

In each case the linear form has the same value on both endpoints of every
reaction, so it annihilates every reaction vector.  No local coboundary,
Schur complement, or asymptotic averaged invariant is used.

Along the bad subsequence the positive part contains at least one divergent
species.  In the service-token case every negative-coordinate species lies
in the fixed set \(J\).  The conserved quantity therefore diverges along a
single communicating class, a contradiction.

This gives the required global zero-layer gluing directly and rules out
credit duplication: a zero branch is not transferred to another local
phase; it is eliminated by an exact class-wide conservation law.
