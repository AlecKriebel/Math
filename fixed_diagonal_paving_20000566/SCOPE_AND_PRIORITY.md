# Status and scope decision

Completed five substantive approaches and exact symbolic checks. The 4×4 profile is correct but not a new original-problem solution: its structure and endpoint are prior-art specializations.

A materially stronger result was obtained and independently checked: for any admissible finite diagonal d sorted decreasingly and 1≤r≤n, every orthogonal projection with diagonal d has an r-paving with some common fiber-dependent norm bound below 1 if and only if

Σ_{i=1}^{kr+1} d_i < (r−1)k+1, for every k≥0 with kr+1≤n.

This uses the classical Schur–Horn and Rado–Horn/Edmonds theorems. Sufficiency is exactly Casazza–Edidin Proposition 9.6. The report proves necessity via a coupled fractional eigenvalue construction, extending their recorded equality obstruction. The finite universal question is explicitly present in the actual 2014 workshop participant statement A.4, not merely inferred from an older source. Thus it is appropriate to mark that precise finite universal formulation mathematically resolved by this proof, while leaving novelty unestablished and not claiming a prescribed or dimension-uniform ε bound. The abbreviated live question remains ambiguous in isolation.

Real versus complex: the universal criterion is the same, because every violating diagonal admits a real obstruction. Individual-projection behavior need not be diagonal-determined, even for strict paving: an explicit real 6×6 common-diagonal pair has π₂=1 and π₂=2/3. Existential classification and sharp quantitative constants remain separate questions.

Source/priority screen: inspected original recovery and five previously recovered primary sources; additionally located Edmonds 1965, Casazza–Edidin §9, Carlen–Lieb real Schur–Horn, and 2014 workshop A.4. Targeted searches for the prefix-inequality necessity and Casazza–Edidin Problem9.7 returned the old formulation and related works, but no verified later closure. This bounded negative result cannot establish novelty or current open status.
