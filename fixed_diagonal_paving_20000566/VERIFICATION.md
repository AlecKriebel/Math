# Verification limits and controls

The manuscript contains the general proof. Finite tests do not prove the universal theorem. The 28,092 quarter-grid cases (n=1 through 6, admissible integer total mass) compare all-subset and sorted-prefix criteria. They are exhaustive only on that finite grid. The symbolic M4 checks cover identities and exact representative extrema; all seven partition types are analyzed in the proof. All 31 unordered nonempty two-partitions of the M6 pair are evaluated exactly. Additional checks cover fractional real orthogonal conjugation, integer/zero/full-rank compression cases, strict versus weak prefix boundaries, matroid obstruction, and all six symbolic pair characteristic polynomials.

The original accepted scripts contain assertions. Their guarded publication derivatives replace every assertion with an explicit conditional RuntimeError. Full normalized ASTs and assertion counts are preserved in CHECK_PROVENANCE.json and independently reconstructed by check_provenance.py. No other AST edit is permitted. The runner compares complete stdout and generated JSON bytes, not a success substring, under ordinary Python and -O. Complete baseline stdout is in outputs/.

MATHEMATICAL_MUTATION_CONTROLS.json records complete sanitized stdout/stderr for 11 actual mathematical changes, each rejected in both modes (22 checks). Mutations alter profile identities, witnesses, fractional coupling, fractional/complement/integer ranks, strict necessity boundary, and the matroid obstruction. These are regression controls, not a theorem verifier. Reproduce with python mutation_controls.py; it automatically runs each mutation in both modes without changing the package.

INVENTORY_CONTROLS_NORMAL.json and INVENTORY_CONTROLS_OPTIMIZED.json record 13 attacks each, including extra/missing/changed files, nested manifests (both listed and unlisted), file/directory/manifest symlinks, unsafe paths, duplicate entries and unlisted empty directories. Every attack must fail for its expected specific reason, after verifying the unmodified baseline. Reproduce with python inventory_controls.py and python -O inventory_controls.py. Capture outputs outside the package to preserve its frozen inventory.

The manifest includes all files except itself, and rejects hidden/unlisted additions recursively. An external private receipt pins the manifest and complete inventory. Local verification alone cannot authenticate a maliciously rewritten manifest; the externally pinned hash is necessary. A separately commissioned package audit remains required before publication.
