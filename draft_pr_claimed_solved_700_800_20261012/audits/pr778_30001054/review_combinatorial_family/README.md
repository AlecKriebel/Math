# Independent combinatorial audit packet

Read REPORT.md for the precise result and its scope. INITIAL_POSITION.md predates historical review opinions; none were consulted. EXACT_RESULTS.json is generated by the independent finite verifier. SOURCE_RETRIEVALS.json and SOURCE_READING.json preserve source identity, redirects, failures and complete reading ranges.

With Python 3 and no external packages, run from this directory:

```
python3 -B verify_custody.py
python3 -B -O verify_custody.py
python3 -B replicate.py
python3 -B -O replicate.py
```

All four are read-only and portable with the whole directory. replicate.py verifies math under both ordinary and optimized execution, positive controls, custody controls, and exact recursive custody. It uses the packet's WITNESS_INPUT.json, semantically identical to the frozen candidate witness.

Separately, with the original neighboring intake layout present:

```
python3 -B check_adjacent_inputs.py
python3 -B -O check_adjacent_inputs.py
```

This checks exact bytes of the three source/candidate inputs read before independent analysis. It is deliberately separate from portable packet custody. No file timestamps enter either verification. Top-level MANIFEST.json excludes only itself and includes all remaining hidden/nested authored files. Symlinks, special filesystem entries, unexpected membership and empty directories fail custody.

The finite checker uses explicit exceptions rather than assert. Enumeration verifies every accepted indexed n=2 word and all shift/reversal/label-exchange transformations. Positive controls construct separated geodesics for n=2,...,7. This audit does not certify novelty, priority, or the stronger theorem's proof.
