## Checkable comparison and conclusion

Reversing each ordered event preserves this count, so the pre-/post-switch convention cannot rescue membership in either DGHP2005 or Novick2012. Those sources explicitly exclude this weak input. Their older necessary conditions plus the current elementary calculation do not establish that someone previously published the literal negative answer.

No primary source in the bounded search has been identified as publishing the exact definition defect, the accepted period, or another counterexample to the same weak universal statement. This is not a firstness certificate. The intended properly constrained realization problem already has an affirmative credited literature answer; the current scope correction cannot truthfully be framed as a new resolution or refutation of that proper theorem. Its supported increment is an explicit diagnosis of the weak wording, with scholarly novelty still unestablished.
