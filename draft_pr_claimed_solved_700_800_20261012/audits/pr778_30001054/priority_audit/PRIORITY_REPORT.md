## Checkable obstruction and the exact old-to-new implication

Set A=(1,2,1',2'), B=(1,2,2',1'), C=(2,1,2',1'). Repeat A,B,A,B,C,B,C,B. Each term respects both endpoint orders and every step is a single adjacent cross-body transposition. Reverse-and-toggle R exchanges A,C and fixes B; the second four terms are R of the first four. The least period is eight because any smaller least period divides eight and A differs from the term four steps later, C.

The post-switch ordered events are (2',1'),(1',2'),(2',1'),(2,1),(1,2),(2,1),(1,2),(1',2'). Each of the four supporting directed types occurs twice; all four mixed directed types occur zero times. The target tangent system has internal tangents and therefore mixed events. Goodman–Pollack Proposition10 and both checked Novick definitions provide independently checkable versions of that old necessary inventory. Reversing each event to convert DGHP's pre-switch convention changes neither the zero mixed-event count nor the multiplicity obstruction. Starting phase, traversal reversal, and relabeling preserve the obstruction.

This derivation distinguishes an old necessary mechanism from an earlier complete answer. A prior source with any weakly admissible nonrealizable word or an explicit proof of weak-axiom insufficiency would defeat priority for the universal negative; it need not contain this exact eight-term word. None was established in the bounded checked sources. Conversely, an old affirmative theorem for valid arrangements and a stronger prior definition do not logically constitute such a negative answer.

The fully separated E-input branch is different. If a period contains E=(1,1',2,2',...,n,n'), rotate its start there. R(E) reverses the order of each pair of body blocks. Exactly four endpoint-pair orders per pair of bodies differ, so adjacent-swap distance is 4 binomial(n,2). A stipulated half-period has precisely that many moves. Every move therefore reduces that distance, and each cross-body endpoint pair switches once in the half-period. The complementary half then supplies the complementary directed events. Thus this extra input forces the missing switch-once restriction. The eight-term witness contains no fully separated term. No polygonal-construction conclusion follows for that restricted input.

The local check_word.py verifies the finite facts with explicit runtime guards, including under Python -O. It does not purport to reprove HP, test arbitrary arrangements, certify priority, or solve the E-input polygonal request.
