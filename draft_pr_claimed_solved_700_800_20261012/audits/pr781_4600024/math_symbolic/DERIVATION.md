# Independent symbolic/topological derivation

Custody: PR781-SYMBOLIC-4A38C3C-20261016. Scope: PR781, problem4600024, head4a38c3ccc4cac918fb75fd4b97449f3ebd2e0f7f.

Let X be a nonempty irreducible two-sided shift over finite A, with regular language L including epsilon. Fix a local map F extending a map f:X→X; let its width be ell. For finite input u, let h(u) be the consecutive-window output, or epsilon if |u|<ell. Set I={u:h(u)∉L}. It is regular: run a DFA for L on generated output while retaining a bounded input buffer. It is an ideal: h(u) is a factor of h(puq), so nonmembership in factorial L persists after padding. Also I∩L is empty because any u∈L appears in a point of X.

1. **Changing domain, alphabet, or rule does not escape canonical neighborhoods.** If a block extension G:S→X exists and S uses an alphabet containing A, restrict S to A^Z. This is still an SFT containing X: add the finitely many excluded one-letter symbols to a forbidden presentation. Let q dominate its finite forbidden lengths. Then X[n]⊆S for n≥max(2,q). Extend the F and G windows to their union interval J. For n≥|J| every J-window in a point of X[n] occurs in X, so their output symbols agree. Thus some X[n] is mapped into X by the fixed F. Conversely such an X[n] itself witnesses extension. This uses pointwise language extension, never an assumption that agreement on X means agreement on all of S.

2. **Finite-word and point tests agree.** A bad word in the language of X[n] appears in a point and produces a forbidden output block. Conversely an output point outside X has a finite forbidden block; enlarging its input interval by the memory and anticipation gives an I-word in L(X[n]). Therefore F(X[n])⊆X iff I∩L(X[n]) is empty. If f is onto, the reverse inclusion X=f(X)⊆F(X[n]) gives equality. Without onto, retain only inclusion.

3. **Canonical graph and short words.** Its vertices are L_(n-1) and edges are L_n. Irreducibility of X gives a path between any two vertices, including when X is periodic. Every finite path consequently extends in both directions. For |u|≥n, membership in L(X[n]) is precisely the length-n factor test. For |u|<n it is membership in L itself: extend the occurrence to an n-word. This finite short-word exception is essential; the vacuous n-factor predicate alone would accept unused letters. Appending-symbol edge labels with every vertex initial/final recognize exactly L(X[n]), because they are labels of bi-infinite extendable paths, even when their length is less than n-1.

4. **Existence implies LT separation.** The finite list of forbidden n-factors and the finite short-word exception describe an LT language L(X[n]); if X[n] witnesses the map, this language separates L from I.

5. **Why any LT[k] separator works at every n≥max(2,k).** Fix such an n and suppose w∈I∩L(X[n]). Using irreducibility, join all n-words into one U∈L, padding within X until |U|≥n+k. In X[n] join U, then w, then U, obtaining W∈I. Independently join U to U inside X, obtaining V∈L. Both V and W contain precisely all n-words of X. Every k-word of X extends to an n-word, so they contain precisely all k-words too. Their prefixes and suffixes of length k-1 are identical, inherited from U. For profiles with left size floor(k/2) and right size ceil(k/2), interior occurrences are exactly splits of the k-factors. Left/right truncated profiles are determined by those boundaries; the length condition excludes simultaneous truncation. Hence V and W have the same profile set. An LT[k] separator cannot accept V and reject W. This contradiction treats an arbitrary w and an arbitrary eligible n, proving the full all-n statement. No empirical stabilization or finite word cutoff enters.

6. **Published finite bound closes the criterion.** PRZ2014 Theorem4.2 converts LT separation of two regular languages recognized by the same finite monoid M to LT[k] separation for k=4(|M|+1). Applying step5 with N=max(2,ell,k) gives the single canonical test. A common monoid exists by the transition monoid of the disjoint union of the two complete DFAs. The NFA also mentioned in PRZ's statement can always be supplied; it imposes no extra restriction on L or I. Full finite product reachability decides I∩L(X[N]) exactly. No workable complexity bound is asserted.

**Automorphism boundary.** Complete the inverse local map arbitrarily off X. On X the inverse composed with F is the identity, hence the same local identity holds on X[n] for all sufficiently large n. If F maps such a neighborhood into X, the identity forces X[n]⊆X. Thus extension of an automorphism forces X to be SFT; the converse uses S=X. In the even shift, forbidden 0 1^m 0 with odd m have all proper factors in L. Choosing m+2>n gives an obstruction in X[n] for every n. This defeats arbitrary larger windows/completions through step1, and defeats LT separators through step5. A constant map to 0^Z still extends from the full shift, illustrating precisely the onto/equality boundary.
