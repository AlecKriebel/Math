# Version 1.0.0 release notes

Version 1.0.0 freezes the original exact ten-complex construction before any
fixed-support rate-family strengthening. It includes the complete manuscript,
reaction data, the original integer rates, two substantively independent exact
verifiers, and an itemized proof audit.

Both verifiers pass. The second verifier reconstructs the field from raw
reaction data and independently recovers the radical decomposition by
saturation and ideal-intersection elimination. The accompanying audit passes
all twenty required checks, including the three structural lower bounds.

The manuscript and mathematical claims are unreviewed. The public Zenodo
record and repository tag establish a citable disclosure date, not proof of
priority or correctness.
