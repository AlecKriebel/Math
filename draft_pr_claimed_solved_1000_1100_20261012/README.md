# Draft PR claimed-solved publication program, #1000–#1100

This program proceeds in ascending PR-number order, beginning with #1000.
Only open draft PRs whose problem has status exactly `claimed_solved` in
`unsolved_math_prioritization/QUEUE.md` are eligible. Every other status is
skipped without mathematical review, audit, repair, comment, closure, merge,
or publication preparation.

For eligible PRs, acceptance requires mathematical reproduction and independent
adversarial review, an independent priority audit against the exact original
problem, a submission-ready preprint and verification package, fresh review/fix
cycles until no actionable concerns remain, publication using the repository
Zenodo kit, a verified DOI tracker entry, and merger of the accepted result.
Irreparable in-scope claims may be closed with an evidence-backed explanation
after reasonable repair attempts.

All program artifacts live here. The shared checkout remains on `main`.
Other shard workers are not contacted and their changes are not included in
this program's commits. No individuals are contacted. Preprints disclose
extensive AI use and their unrefereed status. Progress percentages estimate
completion of this program, not confidence that a theorem is true.

The current pass is complete: all 101 drafts have queue status `queued` and
were skipped. See `DISPOSITION.md` and `dispositions.csv` for the final result.
