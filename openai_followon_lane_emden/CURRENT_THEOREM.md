# Exact target and success criteria

Let n be an integer at least 3, p,q>1, and 1/(p+1)+1/(q+1)>(n−2)/n. Set α=2(p+1)/(pq−1), β=2(q+1)/(pq−1). Thus pβ=α+2 and qα=β+2.

## Core claims awaiting verification

1. For every nonempty proper open connected domain Ω⊊Rⁿ and every nonnegative pair u,v∈C²(Ω) satisfying −Δu=vᵖ, −Δv=uᑫ pointwise, u(x)≤C d(x)^(−α), v(x)≤C d(x)^(−β), with d(x)=dist(x,∂Ω) and C=C(n,p,q). No boundary condition or boundary smoothness is imposed here.
2. The matching gradient estimates |∇u|≤C d^(−α−1), |∇v|≤C d^(−β−1); on an exterior domain containing {|x|>R}, corresponding |x| decay for |x|≥2R.
3. On H={x_n>0}, a nonnegative pair C²(H)∩C(closure H) satisfying the system and u=v=0 on ∂H is identically zero. Any boundedness assumption must be stated if needed, rather than omitted by analogy.
4. On each fixed bounded connected C² domain Ω, nonnegative zero-Dirichlet classical solutions in C²(Ω)∩C(closure Ω) have a uniform L∞ bound C(Ω,n,p,q). Exact W²,r and C¹,γ boundedness/compactness conclusions and any stronger domain regularity required for C²,γ closure assertions remain to be verified.

These are hypotheses until the needed entire Liouville theorem and all transfers pass. The space C² means all partial derivatives through order two exist and are continuous. No claim for arbitrary distributional/weak solutions is inferred without a bootstrap hypothesis. Critical/supercritical hyperbolae, p≤1, q≤1, weighted boundary estimates, and parabolic results are excluded.
