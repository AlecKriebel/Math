\section*{Sharp contrast optimum at fixed equilibrium scaling}
Let
\[
T(H)=8h_Z\sum_{j=2}^{m-1}\frac1{h_j}.
\]
Homogeneous relative stability implies $T(H)>1$.  If $D$ satisfies the exact
stationary criterion and $d_{\min}=\min_i d_i$, then
\[
d_Z>8h_Z\sum_{j=2}^{m-1}\frac{d_j}{h_j}
\ge d_{\min}T(H).
\]
Since $d_{\max}\ge d_Z$,
\[
\chi_D(D)=\frac{d_{\max}}{d_{\min}}>T(H).
\]
Conversely set every $X$-species diffusion coefficient equal to one and take
$d_Z=T(H)+\varepsilon$.  Because $T(H)>1$, the contrast is
$T(H)+\varepsilon$ and the stationary criterion holds.  Therefore
\[
\boxed{\inf\{\chi_D(D):D\succ0,\ \Theta(H,D)>0\}=T(H).}
\]
The infimum is not attained because the design inequality is strict.


\section*{Unit-equilibrium linear optimum}
At $H=I$,
\[
T(I)=8(m-2).
\]
Hence
\[
\boxed{\inf\{\chi_D(D):D\succ0,\text{ a stationary zero occurs on }sD\}
=8(m-2).}
\]
An explicit approaching sequence is
\[
d_1=\cdots=d_m=1,
\qquad d_Z=8(m-2)+\varepsilon,
\quad \varepsilon\downarrow0.
\]
The threshold is an infimum, never an attained contrast.
