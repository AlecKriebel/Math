\section*{Conservation-gauged zero harmonic}
Let
\[
s=-\frac14B_m(r,r).
\]
The homogeneous correction is defined by
\[
A_mw_0=s,
\qquad c^Tw_0=0.
\]
Compatibility holds because $c^TB_m(r,r)=0$.  The augmented system
\[
\begin{pmatrix}A_m&c\\c^T&0\end{pmatrix}
\binom{w_0}{\zeta}=\binom{s}{0}
\]
is nonsingular: $A_m$ is invertible on $c^\perp$, and its right kernel vector
has nonzero pairing with $c$.

The exact solution is
\[
(w_0)_1=\frac{182448m-373417}{31752(8m-17)},
\]
\[
(w_0)_2=\frac{1008m^2-20459m+37138}
{31752(m-2)(8m-17)},
\]
\[
(w_0)_i=(w_0)_2-\frac{i-2}{126(m-2)}
\quad(3\le i\le m-1),
\]
\[
(w_0)_m=-\frac1{81},
\qquad
(w_0)_Z=\frac{16861m-34044}{7938(8m-17)}.
\]
Substitution verifies both the equation and the conservation gauge.
