\section*{Zero-mode gauge and compatibility}
The reaction Hessian satisfies $c^TB_m(u,v)=0$ for all $u,v$, because every
reaction vector is orthogonal to $c$.  Thus
\[
A_mw_0=-\frac14B_m(r,r)
\]
is compatible with the range $c^\perp$.  The exact gauge
\[
c^Tw_0=0
\]
selects the unique correction in the fixed integrated conservation class.
