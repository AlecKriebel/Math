\section*{Rational primary crossing}
Set $a=b=1$, $H=I$, and let $L_i=227m-451-3i$.  Define
\[
r_1=1,\quad r_i=-\frac{L_i}{96(m-2)}\ (2\le i\le m-1),\quad
r_m=-\frac{11}{16},\quad r_Z=\frac1{40},
\]
and
\[
d_1=\frac{257}{240},\quad d_2=\frac{m+1}{227m-457},\quad
 d_i=\frac3{227m-451-3i}\ (3\le i\le m-1),\quad
 d_m=\frac{43}{165},\quad d_Z=21.
\]
Every denominator is positive for $m\ge3$, and direct substitution gives $(A_m-D_m)r=0$.
With $\ell_Z=1$, the left nullvector is
\[
\ell_1=-\frac{45880}{5123},\quad \ell_2=\frac{783160}{15369},\quad
\ell_i=\frac{59520160(m-2)}{5123(227m-448-3i)},
\]
for $3\le i\le m-1$, together with $\ell_m=219835/10246$.  The reduced boundary matrix has rank two and a nonzero $2\times2$ minor, so both kernels are one-dimensional.
