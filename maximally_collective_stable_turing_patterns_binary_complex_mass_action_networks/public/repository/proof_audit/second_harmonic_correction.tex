\section*{Second-harmonic correction}
The second harmonic is the unique solution of
\[
(A_m-4D_m)w_2=-\frac14B_m(r,r).
\]
Set
\[
\sigma=\frac1{126(m-2)},
\qquad
T_i=\frac{K_{i-3}K_{i-2}K_{i-1}K_i}{K_{-1}K_0K_1K_2}.
\]
The interior recurrence is
\[
(w_2)_i=T_i\left((w_2)_2+\frac{\sigma K_2}{3}\right)
-\frac{\sigma K_i}{3},
\qquad 3\le i\le m-1,
\]
because $T_i/T_{i-1}=K_i/K_{i-4}$.  Let
\[
\mathcal Q_m=589180301m^3-3500015940m^2+6930529579m-4574434500.
\]
The boundary values are
\[
(w_2)_1=\frac{11(8832129632m^3-52772027580m^2+105099636403m-69768261675)}{2457\mathcal Q_m},
\]
\[
(w_2)_2=\frac{(91m-183)(27306456137m^3-163220086095m^2+325200697288m-215972758800)}{6804(m-2)\mathcal Q_m},
\]
\[
(w_2)_m=-\frac{3123724821523m^3-18723524680620m^2+37405968085217m-24907679699400}{176904\mathcal Q_m},
\]
\[
(w_2)_Z=-\frac{25(82375210916m^3-488921724540m^2+967289665339m-637893501255)}{68796\mathcal Q_m}.
\]
After $m=u+3$, the coefficients of $\mathcal Q_m$ are
\[
589180301,\ 1802606769,\ 1838302066,\ 624878904,
\]
so the boundary system is nonsingular for every $m\ge3$.
