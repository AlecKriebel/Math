# Zenodo preprint upload checklist

- [ ] Open Zenodo and select **New upload**.
- [ ] Upload every file in `files/`; do not upload the parent metadata/checklist
  files unless you want them visible in the record.
- [ ] Set `Exact_Diffusion_Design_Preprint_v1.0.11.pdf` as the preview/default
  file.
- [ ] Answer **No** to “Does this upload already have a DOI?”
- [ ] Select **Publication → Preprint**.
- [ ] Copy the title, date, creator, description, version, language, keywords,
  licenses, and related identifier from `ZENODO_METADATA_COPY_PASTE.md`.
- [ ] Confirm creator ORCID `0009-0001-9320-500X`.
- [ ] Set files to **Public** with no embargo.
- [ ] Leave funding/grants blank; no specific funding applies.
- [ ] Link software DOI `10.5281/zenodo.22625980` using **Is supplemented by**;
  do not enter it as the preprint DOI.
- [ ] Save the draft and resolve every validation message.
- [ ] Preview the record and visually open both PDFs.
- [ ] Confirm the draft contains exactly the eight intended upload files.
- [ ] Compare filenames, sizes, and checksums against `SHA256SUMS.txt`.
- [ ] Publish only after the preview is correct.
- [ ] Copy the assigned preprint DOI into the placeholder citation and retain it
  for the bioRxiv and journal metadata.
