# Journal submission checklist

- [ ] Approve all author metadata and declarations.
- [ ] Add a verified ORCID if supplied; verify the immutable version 1.0.3 release URL and add an archival DOI only if one is later deposited.
- [ ] Approve AI-assistance wording.
- [ ] Upload main manuscript, supplement, editable source, figures, and data/code statement.
- [ ] Confirm that no source project or private workflow file is included.
- [ ] Confirm manuscript class/format against the selected journal portal.
- [ ] Inspect the final publisher-generated PDF.
