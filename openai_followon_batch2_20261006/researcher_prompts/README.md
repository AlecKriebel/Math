# Ten standalone researcher prompts — batch two

Copy one complete text file into a new AI researcher chat. Each contains its own exact research target, proposed mechanism, mandatory scope limits, sources, and the entire research/review/publication protocol; no shared boilerplate needs to be supplied. The protocol authorizes publication when used as an instruction by the human. Writing these prompts does not execute their research or publish their proposed papers.

Each prompt requires a persistent goal, upstream and priority audits, at least two distinct whole-package reviewers and a fresh-review repair loop, production Zenodo publication through the repository tool, and a verified Google Workspace CLI tracker entry. No PR or QUEUE status gates apply. Dedicated folders and main-only scoped commits preserve parallel work. External contact and duplicate GitHub-release publication are excluded.
