# Data provenance

`exoo42_constructed.g6` and `exoo42_constructed.canonical.json` are generated
locally from the published cyclic definition in arXiv:2212.12630. They are not
trusted merely because of that provenance; both local verifiers check them.

The canonical JSON contains graph6, adjacency list, edge list, adjacency matrix,
edge count, sorted degree sequence, construction parameters, and source URL.

The public McKay catalog `r55_42some.g6` was located at
https://users.cecs.anu.edu.au/~bdm/data/r55_42some.g6, but a workspace policy
blocked the local download. No result depends on that missing copy.
