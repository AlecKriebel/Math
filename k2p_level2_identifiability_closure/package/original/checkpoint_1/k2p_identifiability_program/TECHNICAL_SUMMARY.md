# Technical summary

In K2P Fourier coordinates `(1,s,g,s)`, strict stochasticity is exactly

`1-g>0`, `1+2s+g>0`, and `1-2s+g>0`.

Every nonsingular strict edge splits into two strict edges.  For sufficiently small positive `eps`, use

`B=(1-eps,1-eps)` and `A=(s/(1-eps),g/(1-eps))`.

This works even when the coordinatewise square root is non-stochastic, and it proves admissible-rooting invariance on the full stochastic cone.  The strict continuous-time cone is `0<s<1`, `s^2<g<1`.

K2P has two nonzero character sectors, so a bridge incidence has separate `s` and `g` gauges.  The JC one-scale fibre is invalid.

At a strict tree–theta collision where the theta Jacobian has exact rank nine in the nine-dimensional three-leaf K2P space, the theta map is a submersion.  It contains an ambient-open neighborhood and therefore contains a full six-dimensional tree germ.  This is a proper one-sided containment; reverse containment and symmetric equivalence fail by dimension.

A submersive local containment composes with any identical external context.  Common strict near-identity edge factors convert a leaf-level equality into equality of exposed port tensors.  Hence, once the theta fragment's topology class and incoming role are certified, the directed move extends to all taxon counts by common subtree substitution.
