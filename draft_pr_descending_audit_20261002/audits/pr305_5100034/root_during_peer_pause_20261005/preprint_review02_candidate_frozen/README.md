# Focal pedal area ratios of closed elliptic billiards

Alec Kriebel · ORCID 0009-0001-9320-500X · version 1.0 · October 4, 2026.

The research note proves the recorded focal equality for strict elliptical caustics, including primitive stars, by proving a common positive phase-independent outer/original multiplier. An exact triangle disproves the interpretation that the common focal ratio is phase constant. Prior observations, even/triangular cases and methods are credited. No absolute historical firstness is claimed.
