## Acceptance criteria

1. Extract the exact open-question statement from each full primary edition, including its geometric domain, variable meanings, quantifiers, hypotheses, exclusions, signed/unsigned conventions, and which numerical equality and/or invariance claim is posed.
2. Treat these as hypotheses rather than facts. Preserve edition differences explicitly; do not equate a problem ID or table row across editions without a local correspondence.
3. Distinguish the open question's literal statement, adjacent source context, and any audit inference. Check introductory and concluding conjecture language and relevant definitions.
4. Freeze a source-only claim and a plan of independent mathematical falsification before reading the submission or inherited calculations.
5. Attempt falsification using legitimate boundary/degenerate cases, orientations, focus choice, phase variation, conic type, and collapsed/circular configurations only insofar as the primary source defines them. Do not silently restrict a universal claim to a regular ellipse case.
6. A candidate clears source fidelity only if its strongest locally proved result implies the exact primary target with all permitted cases or explicitly proves an equivalence. A replacement of the target with a corrected but different question must be labeled as such.
7. Reject circular verification that uses an earlier disposition as mathematical evidence. Verify any source correction from primary text and any mathematical correction with checkable derivations or counterexamples.
8. Retain native primary source captures with URLs, retrieval UTC and SHA-256. Log decisions and best-guess completion at meaningful checkpoints.
9. Report exact surviving claim and exact unresolved gap, with falsifiable controls; do not infer historical novelty in this gate.
10. Write only within this audit directory. Do not modify source snapshot files or Git state, install software, publish, contact external people, or act on the PR.
