## Strict Hurwitz invariants, fixed alphabets and forty letters

At each endpoint the word lies in a four-generator B5 subgroup. Target equality in G implies equality with the respective standard full twist already in B5. Positive-monoid embedding then converts equality into positive braid relations. ## Thirty letters: independent check of the computational theorem’s logic

A labelled count vector with fifteen digits in {0,1,2}, together with adjacent-swapped strand order, models every positive word whose pairs cross at most twice. Strand order is uniquely determined by all pair-count parities: each mutual crossing reverses that pair’s relative order. Thus merging *reachable* count vectors preserves possible continuations. All allowed outgoing edges must still be enumerated, and action path independence is not implied by this combinatorial merging.

Let f have all counts2. A reachable c can complete to f exactly when f−c is reachable. Reverse the adjacent-generator sequence of a suffix: it starts at identity and ends at the order at c, using the remaining labelled crossings. Conversely a path to f−c ends at the same order as c because parities agree; reversing it supplies a positive suffix, with no count overflow because additions are nonnegative and end at2. This is a trajectory-reversal argument, not a braid-inversion claim.

If every coaccessible edge carries its source action to its target action, induction proves that all paths to every state have the same action. This explicitly discharges the merging risk. Therefore the six-strand theorem has a finite proof whose completeness hinges on evaluating *every* reachable transition and *every* coaccessible action equality, plus exact z comparison; it is not justified by a digest or census alone.
