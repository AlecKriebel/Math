## Detailed geometry audit

The normalized sphere kernel is dimensionally correct: R^(n-2)(R^2-|x|^2)/|x-zeta|^n, with zeta on the radius-R sphere and normalized measure. Its two factors converge uniformly for every fixed interior x as R grows. The proof does not need bounded-subharmonic Liouville, which would be false in the requested dimensions. The zero-pasted component function is continuous because every finite boundary point has u equal to the level, and it is subharmonic by comparison on bounded components of the intersection with a ball. Irregular boundaries and infinitely many components introduce no counterexample: the pasted functions are globally continuous, and the standard maximum principle does not require a smooth boundary when the comparison function extends continuously to the closure.

The phrase 'at most one bounded component' means bounded function values, never bounded spatial size. Any component of a superlevel set is nonempty and hence its pasted function is nonzero. If no component retained unbounded values, the disjoint-piece lemma would permit at most one component, whose finite value supremum would then bound all values above the level. The same argument applies to children within a chosen parent because a component of the higher superlevel set intersecting that parent lies entirely inside it. No unproved finite branching or König-lemma compactness is assumed.

At stage j, both x_j and x_(j+1) lie in A_j, and the complete finite polygon Q_j is chosen inside that open connected set. Thus the bound u>j holds on every segment interior as well as endpoints. The concatenation can be parameterized on [j,j+1] with finitely many subdivisions; endpoint agreement gives continuity. Degenerate pieces can be omitted or given constant parametrization. No simplicity or regularity beyond local polygonality is required. For compact C, M_C=max_C u is finite, so every j>M_C misses C throughout Q_j. Only finitely many earlier finite polygons can meet C. The preimage of C is then closed and bounded in [1,infinity), hence compact: the map is proper. Every finite spatial compact meets finitely many pieces, so spatial local finiteness also holds. Assigning unit time to each stage prevents an infinite sequence of stages accumulating at finite parameter time. The candidate does not accidentally replace this by vertex subsequences.

The one-sided Liouville proof in Section 6 uses the harmonic mean exactly and kernel lower/upper bounds; it remains valid when h(0)=0. No positivity division or Harnack assertion at a zero is needed. For nonconstant entire harmonic u it therefore supplies sup u=+infinity, satisfying the actual source theorem's hypothesis.

The n>=3 target is fully covered. The analytic argument also works for n=2, but the packet does not promote that range as a new result; n=1 can be handled separately by affine harmonic functions. The bounded subharmonic example is correctly limited to n>2, extended by -1 at 0, and has distributional positive shell Laplacian rather than an unnoticed negative origin charge.
