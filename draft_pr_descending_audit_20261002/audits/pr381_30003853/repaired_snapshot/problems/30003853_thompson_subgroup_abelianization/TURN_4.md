# Turn 4: normal closures of abelianization-torsion witnesses

Completed 2026-10-02 UTC. Original unresolved, 4/5 substantive turns; subjective progress 18%. This direction uses finite PL germs directly and does not assume solvability, closedness or simple derived factors. The endpoint-germ method is classical in interval-group theory; no historical novelty is claimed.

## 1. A normal-subgroup character theorem

Let H be any subgroup of PL_+([0,1]), with finitely many linear pieces for each element; H itself need not be finitely generated. If N is a nontrivial finitely generated normal subgroup of H, there exists a homomorphism lambda:H -> (R,+) which is nonzero on N. When H <= F, lambda can be chosen with values in Z.

**Proof.** Let n_1,...,n_k generate N and put U=union_i supp(n_i), where supp means the open set of moved points. U is also the union of supports of all elements of N: a point fixed by every generator is fixed by every word. Each n_i has finitely many linear pieces, so U is a nonempty finite union of open intervals. Normality makes U invariant under every element of H. An increasing homeomorphism must fix each of this finite ordered list of components setwise. Choose a component (a,b). Every h in H fixes a, whether a is 0 or an interior point.

Since h has finitely many linear pieces, its right-hand germ at a is affine, with positive slope h'(a+). The chain rule at the common fixed point shows

    lambda(h)=log h'(a+)

is an additive homomorphism H -> R. Suppose it vanished on all of N. Then each generator n_i fixes a and has slope1 immediately to its right, so it is the identity on (a,a+epsilon_i) for some epsilon_i>0. Taking the minimum over the finite generating set gives a nonempty initial interval inside (a,b) fixed by every element of N, contradicting that (a,b) is a component of U. Thus lambda is nonzero on N. If H <= F, use log base2; all one-sided slopes are integral powers of2, including at an interior common fixed point which need not be dyadic. QED.

The finiteness of the PL partition matters twice: for finite support components of the generators, and for an actual affine germ at a. There is no claim for arbitrary homeomorphisms or infinitely broken maps.

## 2. The isolator and a necessary condition on any counterexample

Let

    T_H={h in H : h^m in H' for some integer m>=1}.

It is a characteristic subgroup, because it is the inverse image of the torsion subgroup of the abelian group H/H'. It need not equal H'. Every real-valued homomorphism on H vanishes on T_H: m lambda(h)=lambda(h^m)=0.

By Section1, T_H contains no nontrivial finitely generated subgroup which is normal in H. In particular:

1. If h != 1 has a torsion image in H_ab, its normal closure in H is infinitely generated as an abstract group.
2. If H' is finitely generated, then H'=1, so H is abelian.
3. If T_H is finitely generated, then T_H=1; in that case H is abelian and torsion-free, since H' <= T_H and interval homeomorphisms have no nontrivial finite order.
4. A nonabelian subgroup H has infinitely generated H' and infinitely generated T_H.

For item1, the normal closure lies in T_H by characteristicity and contains h. The other assertions are direct applications of the theorem. Here 'finitely generated' is ordinary group generation, not finite normal generation. For example a finitely generated group has a finitely normally generated commutator subgroup, but that says nothing about its ordinary finite generation.

This gives a genuine constraint on any finitely presented counterexample to Question111: each nonidentity torsion witness must normally generate an infinitely generated subgroup. It does not rule that out. F is itself finitely presented with infinitely generated derived subgroup, so finite presentation cannot supply the missing ordinary-generation hypothesis.

## 3. Exact compatibility with the known counterexample

In H_m from Turn1, the lamp r=t-1 represents a class of exact order m for m>=2. Its normal closure is

    (t-1) Z[t,t^{-1}]

inside the additive base. Base conjugation is trivial and conjugation by the top shifts the lamp, so this description is exact. As an abelian group it is freely generated by the shifts t^i(t-1), i in Z: multiplication by t-1 on the Laurent polynomial ring is injective. It is therefore infinitely generated, as Section2 predicts.

This also explains why the normal-closure condition alone cannot prove the source statement. It holds for the source's actual torsion examples. The finite-presentation issue must be addressed elsewhere, such as the splitting argument in Turn1 for this particular ambient group.

## 4. Effective finite input and verification

If finite dyadic PL generators for H and N are given, with N nontrivial and normal in H as a proved hypothesis, an endpoint a of a support component of N and the integer values lambda on the generators of H can be computed by rational piecewise-linear arithmetic. This is a conditional extraction procedure, not an algorithm deciding normality or finite presentation. It uses the normality hypothesis to guarantee that all H generators fix a.

verify_turn4.py provides exact rational PL composition, inversion, endpoint slopes and support extraction. It checks group operations, germ multiplicativity, vanishing commutator germs, and translation of compact bump supports under iterates of a one-bump map. It does not claim a finite sample can certify the general normal-subgroup theorem.
