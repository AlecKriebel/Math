# Priority review

PRIORITY_REPORT.md gives the source-first priority finding, attribution and limits. SEARCH_COVERAGE.json records exact UTC queries, primary-source read scopes, bibliographic discovery aids and exclusions. SOURCE_IDENTITIES.json identifies the three independently acquired principal primary sources.

Raw source PDFs, extracted text, API responses, image captures and complete command evidence remain under private/. They are research evidence, not a public redistribution packet. PUBLIC_MANIFEST.json binds the lean public files. private/PRIVATE_MANIFEST.json binds the retained private evidence. FINAL_SEAL.json binds both manifests and the read-only integrity receipt. The integrity checker verifies evidence identities and coverage consistency; it cannot establish historical novelty.

No outside person was contacted. No Git, index, ref, PR, upload, tracker or installation action was performed in this review.
