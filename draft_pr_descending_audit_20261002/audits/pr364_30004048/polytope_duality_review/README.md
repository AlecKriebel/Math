# Replay and inclusion policy

Public namespace is exactly the file set in PUBLIC_MANIFEST.json plus that manifest itself. Raw primary PDFs, whole extracted source text, rendered pages, gzip raw GitHub API responses, full old/fresh execution captures and capture drivers belong only to private/. Public receipts include hashes, source URLs, exact invocation details and limits; they do not redistribute primary texts or API response bodies.

The private tree must be either completely present with exactly the manifest's file/directory inventory and matching hashes, or wholly absent. Partial presence is a verification failure. Remove the whole private tree when preparing a public copy. Never run either private capture driver again in this closed namespace. New research/capture work must use a new sibling namespace and preserve these files.

    PYTHONDONTWRITEBYTECODE=1 python -B verify_review.py --snapshot /path/to/frozen/snapshot --repo /path/to/Math

The inventory checks stored gzip bytes; decompression separately checks logical API hashes, decoded blob content, commit identities/parents and empty API stderr. Capture argv/cwd/UTC fields remain recorded provenance, not independently certified execution events. It prints JSON only and does not write files or launch capture drivers. The verifier also disables bytecode in-process and in subprocess environments. `--fresh-api` additionally reads every immutable GitHub blob in memory with gh; no response is written.
