## Lower bound reconstructed without a graph optimizer

For rational 0 < theta < 1 and any admissible graph, let F = max_c reached(c)/|A|. If F=1, the desired lower bound is automatic. For F<1 every c has a missed a. The two disjoint B-neighbourhoods have lower bounds summing to |B|, so each has exactly its lower bound and is the other's complement. Thus every c has theta|B| neighbours. Summing edges and using the B-to-C lower inequality forces every B vertex to have theta|C| neighbours as well.

Compress only repeated C neighbourhoods. With rows still the individual B vertices and distinct columns the resulting supports T_i, uniform b_v=1/|B| and q_i=class size/|C| are strictly positive rational probability vectors and satisfy Mq=theta and M^T b=theta. Repeated rows are harmless: they are retained and count the same number of distinct columns. The class A_i of A vertices missed by type i consists exactly of vertices with neighbourhood B minus T_i; its mass p_i is positive. Distinct supports make these classes disjoint. Any other A vertices remain in the |A| denominator and only add possible non-neighbours to a B vertex. Hence for every row v, sum_{i:v in T_i} p_i <= theta. With t=min_i p_i, F=1-t, and a row of maximum distinct-column degree Delta gives t Delta <= theta. Since Delta >= d(theta), every such graph has F >= 1-theta/d(theta). Taking an infimum is now legitimate and requires no attainment assertion.

This is the universal step. Any argument from only two finite examples, or from Turn 1 sampling or Turn 2 fixed-support optimization, would leave the central universal gap open.
