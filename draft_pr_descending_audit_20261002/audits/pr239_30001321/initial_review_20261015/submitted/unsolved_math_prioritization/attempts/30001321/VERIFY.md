# Turn-1 checks

Run `python check_turn1.py` with pre-existing SymPy. It exhaustively
enumerates finite independent environments through time4 for two
different elliptic two-point laws, one symmetric and one biased.
It verifies averaged endpoint laws, two-replica overlaps, quenched-mean
variance, and the exact layer-martingale variance for interval indicators
over multiple lengths and alignments. It separately compares 31 exact
return coefficients per law with the generating function. The receipt
contains 486 exact assertions.

These finite identities do not certify the asymptotic binomial estimates,
the analytic partial theorem, or the still-unresolved superpolynomial
tail conjecture. Independent mathematical review has not yet occurred.
