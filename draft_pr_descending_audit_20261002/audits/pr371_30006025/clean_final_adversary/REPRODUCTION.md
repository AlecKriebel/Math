# Reproduction and evidence boundaries

Use a Python interpreter with SymPy (verified here: Python 3.14.6, SymPy 1.14.0), a local repository containing the frozen commits, and authenticated GitHub CLI only for the optional remote-byte replay. No network communication to individuals is performed. All writes are confined to this audit directory. The repository stays on its current branch.

From this directory:

```sh
python3 audit_reproduction.py --repo /absolute/path/to/Math --python /absolute/path/to/python-with-sympy --remote-bytes
python3 independent_controls.py
```

The first command makes a small ignored shared Git clone with no checkout, extracts only the 47 frozen publication paths, runs all five author checkers, checks every manifest record, extracts the actual historical 37-file WIP author target and replays both historical review scopes. It writes full parsed output and every stdout/stderr byte hash to public JSON receipts, preserving the raw streams privately. GitHub CLI contents API returns the full frozen file bytes for all 47 paths. The second command implements the new control families; its finite exact tests are supplementary evidence.

Replays update generated receipts and invalidate the public manifest; regenerate that manifest deliberately before publication. The shared clone borrows object storage from the supplied local repository, so keep that repository present during replay. The primary-source reading and phase-order seals are human-readable research records and cannot be regenerated by a program as a fresh independent reading. Their hashes remain immutable evidence of this audit's sequence. The source-provenance receipt explicitly separates fresh source statements/hashes from unmatched historical assets. No all-27 historical asset replay is claimed.
