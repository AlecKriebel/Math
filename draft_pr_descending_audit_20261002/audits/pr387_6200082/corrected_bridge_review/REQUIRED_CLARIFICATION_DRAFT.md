# Positive approximation in the free-H4 reduction

This clarification replaces only the first reduction in `CORRECTED_APPLICATION.md`. Its later ambient-cover, packing, homology and interleaving arguments continue to apply. In the two references to connectedness there, use **finitely many path components**; this is exactly sufficient for ABBG's special mm-spaces.

If the free-H4 Cheeger gap failed, choose free geometric groups `G_i` with `h(H4/G_i) -> 0`. These quotients have infinite volume: a finite-volume quotient would make `G_i` a lattice with positive second L²-Betti number by Bowen's Lemma 8.1, whereas a free group has a one-dimensional graph classifying space and zero second L²-Betti number. Fix positive `eta_i -> 0`. By the definition of the Cheeger infimum there are nonempty smooth relatively compact domains `A_i` in `H4/G_i` such that

    H_i := area(partial A_i)/vol(A_i) < h(H4/G_i) + eta_i -> 0.

Thus `H_i` is positive even if a quotient's Cheeger constant is zero. This avoids a literal use of Bowen's Lemma 7.3 with a zero right side. The all-R estimate needed below follows directly from Buser's primary Lemma 7.2, printed page 229, which is formulated for the actual domain ratio `H_i`.

Here Ricci curvature is `-3`, so Buser's curvature parameter is `delta=1` and dimension is `n=4`. Discard a finite prefix with `H_i >= 1`. Choose a fixed sufficiently small smoothing radius `r_* > 0`, satisfying Buser's dimension-dependent radius restriction and `r_* <= 1/2`. Buser supplies relatively compact open sets `T_i` with positive volume and a constant `C`, depending only on dimension and `r_*`, such that

    vol(N_t(partial T_i))/vol(T_i)
        <= C H_i integral_0^t cosh(s)^3 ds,       t >= r_*.

The same estimate for smaller radii follows by monotonicity, if needed. Define

    C_i = N_1(closure T_i).

These are positive-volume compact subsets. For every fixed `R > 0`,

    N_R(partial C_i) subset N_(R+1)(partial T_i),
    vol(C_i) >= vol(T_i),
    vol(N_R(partial C_i))/vol(C_i)
        <= C H_i integral_0^(R+1) cosh(s)^3 ds -> 0.

For the inclusion, a boundary point of `N_1(closure T_i)` has distance one from `closure T_i`; its nearest point is on `partial(closure T_i) subset partial T_i`. Apply the triangle inequality. A finite `1/2`-net of `closure T_i` meets every path component of `C_i`: connect a point of `C_i` to a nearest point of `closure T_i`, then connect that point to a nearby net point along a minimizing geodesic. Both paths stay in `C_i`. Consequently `C_i` has finitely many path components. No assertion that the smoothed threshold set itself has finitely many components is needed.

Now work directly in the original free group `G_i`; no subgroup generated by the fundamental group of a potentially irregular compact set is needed. For fixed `i`, only finitely many `G_i` conjugacy classes have a representative moving a lift of a point of `C_i` by at most `i`. Indeed, choose a compact lift set `D_i` projecting onto `C_i`; such representatives can be conjugated to move some point of `D_i` into the compact `i`-neighborhood of `D_i`, and proper discontinuity gives only finitely many possibilities. Residual finiteness provides a finite-index normal subgroup `F_i` excluding each of those finitely many nonidentity classes.

Let `p_i:E_i=H4/F_i -> H4/G_i` be the finite cover and take the **full** preimage

    K_i = p_i^(-1)(C_i).

It is compact with positive volume and finitely many path components. One way to see the last claim is to note that each path component of `C_i` has at most the covering degree many path components above it, by path lifting. Local covering maps preserve boundaries, and minimizing-geodesic lifting gives

    partial K_i = p_i^(-1)(partial C_i),
    N_R(partial K_i) = p_i^(-1)(N_R(partial C_i)).

Both boundary-neighborhood volume and `vol(K_i)` multiply by `[G_i:F_i]`. Hence their ratio still tends to zero for every fixed `R`.

For a lift `q` of any point of `K_i`, every nontrivial `g in F_i` has `d(q,gq)>i`. To check metric covering radius without confusing it with injectivity radius, take `x,y in B(q,i/4)`. The inequalities

    d(x,gy) >= d(q,gq)-d(q,x)-d(q,y)
             > i-d(q,x)-d(q,y)
             > d(q,x)+d(q,y) >= d(x,y)

show that a nontrivial deck translate cannot shorten the distance between `x` and `y`. Thus the universal-cover map is metric-isometric on each such ball. Closed-ball endpoint issues are avoided by any radius strictly below `i/4`; the supremum in the covering-radius definition is at least `i/4`. In particular the covering radius along `K_i` diverges. The constant `i/4` suffices; the `i/2` injectivity-radius value should not be used as a metric-isometry radius.

The groups `F_i` remain free, so `H_2(E_i;Q)=H_2(E_i;R)=0`. This supplies precisely the inputs needed in the rest of `CORRECTED_APPLICATION.md`, with finitely many path components in place of a single component. Fixed thickening preserves that condition. ABBG explicitly permits finitely many path components in its definition of specialness (§2.3, page 16 and footnote 4), and its simplicial convergence argument permits disconnected nerves. The same uniform bound for every weighted net, ambient good cover and Mayer-Vietoris argument therefore applies without additional changes.

The resulting uniform Cheeger gap and the negative dimension answer remain credited to Bowen with ABBG's repaired approximation dependency. This clarification proves neither a new optimal constant nor a new research result.
