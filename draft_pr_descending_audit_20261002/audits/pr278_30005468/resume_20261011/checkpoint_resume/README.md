# Compact scoped research-checkpoint preparation

`prepare_checkpoint.py` prepares artifacts locally and has no provider-execution entry point. Reviewed reconciliation sources and acceptance pins remain unchanged. Git writes stay in this folder's own `driver.git`, `private_objects`, and each output's `private.index`; existing reconciliation and supplied objects are read-only alternates. The driver must have no remote. Every Git invocation, including initialization, configuration inspection and the batch raw reader, uses `--no-replace-objects`; the environment sets `GIT_NO_LAZY_FETCH=1`. No primary ref/index/config/worktree operation occurs.

Root supplies two JSON files inside `draft_pr_descending_audit_20261002` after the actual provider merge/readback:

- Allowlist: an object with exactly one key, `allowed_paths`, whose value is the nonempty list of exact repository-relative publication paths.
- Full-body manifest: an object with exactly one key, `files`, whose value is a list of objects with exactly `path`, `source`, `bytes`, and `sha256`. `path` must be in the allowlist; `source` must be exactly `/Users/alec/Documents/Math/` followed by that path; `bytes` must be an integer matching the actual regular file, and `sha256` must be its literal lower-case64-hex full-body SHA256.

Both path sets must be identical. This is an exact Root-authored selection, not an authority, grant, or nonce framework. Select only Root's requested scientific reports/results/code, compact public metadata drift/row verification, actual scoped reconciliation/terminal receipts, and two owned progress maps. The helper can enforce paths, types, hashes and excluded names; Root remains responsible for confirming authorship and that selected JSON is compact and excludes third-party import records or full workbook metadata. No semantic authorship claim is inferred from a filename.

Every selected path must be a canonical relative path under `draft_pr_descending_audit_20261002`. Symlinks and symlink ancestors, outside/noncanonical paths, unknown/duplicate paths or JSON keys, missing/deleted source files, mismatching sources/hashes/sizes, binary content, private Git/index, generated skills, source PDFs, full workbook metadata and identified import-record paths reject. Selected content must decode as UTF8 and produces only regular100644 blobs. Existing selected targets of another mode/type reject. No removal operation is supported.

Invocation requires explicit `--main`40-hex commit SHA, `--date`UTC seconds, `--allowlist`, `--manifest`, `--message`, and a new absolute `--output` directory directly inside this checkpoint folder. A fresh immutable MAIN commit and all tree objects must already be available privately; there is no network fallback or MAIN default. Future dates reject.

MAIN empty trees reject. It compares complete before/after leaf inventories and independently parses raw trees to compare every leaf path, mode and OID. A separate recursive raw-tree composition preserves complete unselected sibling identities and must reproduce the private-index root. The raw commit hash independently agrees with the private Git object and exact one-parent commit payload. It preserves every unselected path and supports no deletions.

Each completed run emits only `TREE_PAYLOAD.json`, `COMMIT_PAYLOAD.json`, `CAS_PAYLOAD.json`, `PROOF.json`, `commit.raw`, and `private.index`. The provider tree payload contains the exact fresh MAIN base tree and selected full UTF8 content. The commit has sole parent MAIN.
