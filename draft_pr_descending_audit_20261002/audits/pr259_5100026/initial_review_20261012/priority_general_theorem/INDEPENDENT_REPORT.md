## Why focal polarity does not silently turn this into an existing Poncelet centroid theorem

For unit inversion about M=(k,0), set q²=z²+w² and inverted outer vertices M+(z,w). The outer ellipse transforms to

```
(k²/A²−1)q⁴ + (2kz/A²)q² + z²/A²+w²/B² = 0.
```

For A≠B and M inside the ellipse this is a genuine quartic; a circular quadratic factor can occur at A=B (least period four). The antipedal lines are precisely polars of these inverted vertices about that unit circle, because (R−M)·(U−M)=|R−M|². Consequently a generic conic-side-envelope hypothesis cannot simply be imported from the Poncelet centroid theorem. Changing to the generally different outer-locus focus would change the target. Projective transformations preserve Poncelet incidence but do not preserve arithmetic vertex means; only affine changes preserve means, and generic affine changes also alter Euclidean perpendicularity.
