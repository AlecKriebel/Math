# Independent source audit: 30005244

The original target is Costabel's contribution in [Oberwolfach Report 43/2022](https://publications.mfo.de/bitstream/handle/mfo/3995/OWR_2022_43.pdf?sequence=4), printed pp. 2580–2582. I read the complete contribution and visually checked the pages containing the matrix, the one-third shift and the open question. The report asks for a precise description and proof of the off-real-interval spectral behavior of the finite DDA matrices. The superscript h is a mesh parameter; the target is not the nonzero-frequency infinite-lattice operator.

The explicit original support assumption is only compactness of the particle. No technical boundary regularity or grid-consistency hypothesis is printed. Therefore the review approves the candidate's theorem **under its stated condition (G)**, and specifically its consequence for every bounded Lipschitz or boundary-measure-zero particle. It does not approve wording that quantifies over all compact measurable sets. The geometric qualification is mathematically substantive and must remain in the headline claim and queue/PR description.

The report's operator is the distributional volume operator A_κ. Its diagonal-omitting matrix approximates A_κ−I/3. Thus the continuum eigenvalues compared directly to the matrix are those of S_κ=A_κ−I/3. This shift is correct in the candidate. For the A_κ convention, translate the interval and the discrete matrix by +I/3.

The main established input is Costabel–Dauge–Nedaiasl, [arXiv:2302.13159v3](https://arxiv.org/abs/2302.13159v3), revised 22 October 2023. I read the full supplied primary manuscript, particularly Sections 1.2, 1.6, 2.2, 2.4 and 3.5, and independently checked the arXiv metadata. Proposition 3.15 defines the extremal static lattice interval by the symbol's eigenvalue extrema, contains the continuous interval [−1/3,2/3], and gives the matrix resolvent bound outside the lattice interval. The endpoints used in the candidate are exact definitions, not unproved numerical decimals. I did not obtain the subscription-restricted publisher full text and use the stated v3 numbering.

The source's physical-particle question is given a complete off-interval theorem for geometrically consistent particle sequences, including the usual bounded Lipschitz class. This is a **scope-qualified source resolution**. There is no claim about eigenvalue density inside the interval, quantitative rates, exact decimal endpoints, pathological point-sampled supports or novelty. The proof does not need a bounded nonzero-frequency full-lattice operator, which the source warns can fail for real positive frequency.
