# Public artifact scope

The public author packet is exactly the files listed in FINAL_AUTHOR_MANIFEST.json plus that manifest. It contains original mathematical exposition, executable controls, deterministic outputs, source metadata and historical freeze manifests. It contains no source PDFs, page images, raw imported problem records, private coordination or credentials.

The source files named by SOURCE_MANIFEST.json and SOURCE_ADDITION_T4.json are local research inputs; their URLs, byte lengths and hashes permit independent recovery. SOURCE_LOCATOR_CORRECTION.md supplies the correct page locator for the exact Sharifi download. Historical research states are snapshots rather than the final disposition; FINAL_STATE.json and RESULT.md control the current status.
