# Independent checkpoint 1: source bodies and provisional verdict

2026-10-05 12:22 UTC; preserved before reading any other priority report. Completion estimate 35%.

LP arXiv v5 (27 Aug 2019), Theorem 1.2.4 pp.8–9, classifies all compact bordered line fields by all peripheral winding integers plus the genus-one gcd or higher-genus parity and conditional Arf data. Sections 3.2–3.3 pp.16–20 construct a finite ribbon graph and line field for homologically smooth graded gentle algebras. Remark 3.2.6 p.19 (journal Remark 3.15) gives a finite local sum for graph-cycle winding numbers and explicitly says those numbers suffice to calculate all line-field invariants. Section 3.3 pp.19–20 applies Koszul duality to finite-dimensional degree-zero gentle algebras, with degree-one arrows on the dual. Thus nonsmooth input is not a definitive scope barrier to the LP route. The printed applications only explicitly state a sufficient derived-equivalence criterion and AG-determined special cases; a full general terminating basis/invariant algorithm is not yet extracted from the body.

JSW arXiv 2303.17474v2 (20 Mar 2025), Proposition 4.3 p.12 chooses a standard dissection geometrically; its proof does not itself describe a finite procedure converting an input bound quiver to that dissection. Section 4.2 pp.12–15 then has direct numerical formulas for standard form. This is stronger classification and normal-form information, but not alone a verified full algorithm for arbitrary input.
