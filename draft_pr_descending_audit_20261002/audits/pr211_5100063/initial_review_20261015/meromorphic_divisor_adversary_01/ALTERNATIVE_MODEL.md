# A checkable Jacobi model for the established divisor

This construction was added after the independent derivation was frozen. It gives an explicit analytic model; it does not independently establish the pole bound for F.

Let L=4K/N and choose the unique modulus 0<kappa<1 for which

```
K'(kappa)/K(kappa)=2K'/L.
```

Set a=2K(kappa)/L=K'(kappa)/K' and x0=3K+v (real), and define

```
G(u)=dn(a(u-x0),kappa).
```

The standard dn period lattice is generated by 2K(kappa),4iK'(kappa), so G has periods L,4iK' and antiperiod 2iK'. Its poles on that torus are x0+iK'=R and R+2iK'; its zeros are R+L/2 and R+L/2+2iK'. They are all simple. Thus its divisor agrees exactly with the independently established divisor of F.

F/G has no poles or zeros, hence is a constant C. Both F and G are positive on the real line, so C>0. Evaluation at x0 gives C=F(x0), because G(x0)=1. The quarter-period formula dn(z+K(kappa))=kappa'/dn(z) then gives

```
F(u)=F(x0) dn(a(u-x0),kappa),
F(u)F(u+L/2)=F(x0)² kappa' >0.
```

This supplies a concrete nonzero model with the same two-pole divisor and reflection. The quarter-period input is [DLMF 22.4 table 22.4.3](https://dlmf.nist.gov/22.4#T3). No finite numerical fit or inference of a divisor from plots is involved.
