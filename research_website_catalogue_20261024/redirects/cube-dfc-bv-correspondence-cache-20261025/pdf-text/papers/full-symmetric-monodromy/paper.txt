                                                            ABSTRACT
          Gallagher's weighted-lift construction, posted after Alpoge's announced counterexample, produces a
          three-dimensional Keller map of every generic degree n >= 3. We isolate a simple uniform subfamily and prove
          that its function-field extension has full symmetric Galois closure Sn, hence no nonidentity rational deck
          transformations. A uniform rational collision is also given. Mikhail Szh published the stronger monodromy
          theorem for the entire weighted-lift family before this note appeared. This archival version is retained for
          provenance; only the explicit seed and uniform collision survive as potentially new data.


 1. The explicit family
 Fix an integer n >= 3 and put
                                             u = 1 + xy,   gamma = 1 - [n/(n-1)]xy + x2z.

 Define Fn = (An, Bn, Cn) by
                                         An = {(n-2)u + u2 - (n-1)ungamman-2} / {(n-2)x2},

                               Bn = {(n-2) + 2u - n un-1gamman-2} / {(n-2)x},    Cn = x gamma. (1)

 The apparent quotients by x2 and x cancel identically, so (1) is a polynomial map over Q.
      Theorem 1. For every n >= 3, the map Fn is polynomial and det JFn = 1; the extension C(x,y,z)/C(Fn) has
      degree n and Galois closure Sn; and every rational map sigma satisfying Fn o sigma = Fn is the identity.

 2. Polynomiality and constant Jacobian
 Set v = xy, tau = x2z, and w = u gamma. Define
                                     pn(w) = [2w - n wn-1]/(n-2), qn(w) = [w2 - (n-1)wn]/(n-2).

 Then qn' = w pn' and (1) is (alpha/x2, beta/x, x gamma), where alpha = u + qn(w)/gamma2 and beta = 1 + pn(w)/gamma. As
 polynomials in (v,tau), beta lies in (v,tau) and alpha lies in (v2,tau); substitution proves the required divisibility.
 Put P = BC = gamma + pn(w) and Q = AC2 = w gamma + qn(w). The output change (A,B,C) -> (P,Q,C) has Jacobian -C3.
 The input changes through (x,w,gamma) and the identity w p' - q' - gamma = -gamma give the same Jacobian -C3.
 Therefore det JFn = 1.

 3. Inverse equation and degree
 With Rn(w) = (w2 - wn)/(n-2), the identity qn = w pn - Rn eliminates gamma and gives Rn(w) = wP - Q. Thus the fiber
 polynomial is
                                             Hn(T) = Tn - T2 + (n-2)BCT - (n-2)AC2. (2)

 A root w with gamma = P - pn(w) nonzero recovers the source rationally: x = C/gamma, u = w/gamma, y = (u-1)/x, and z =
 {gamma-1 + [n/(n-1)](u-1)}/x2.

 Writing U = (n-2)BC and V = -(n-2)AC2, the target field is K = C(A,B,C) = C(U,V,C) = C(U,V)(C), since B = U/((n-2)C)
 and A = -V/((n-2)C2). Here C is transcendental over C(U,V). Equation (2) is hn(T) = Tn - T2 + UT + V. It is irreducible over
 C(U,V): being linear in V with coefficient one, any factor independent of V would be a unit. Gauss's lemma preserves
 irreducibility under the purely transcendental base change to K. Hence the extension degree is n.

 4. Full symmetric monodromy
 The discriminant curve of hn is parametrized by
                                                  t -> (U,V) = (2t - n tn-1, (n-1)tn - t2). (3)

 It is irreducible. At t = 0 the polynomial is T2(Tn-2-1), with exactly one double root. It is the unique parameter over (U,V) =
 (0,0), and the derivative of (3) has first coordinate 2, so this is a smooth discriminant point. The one-double-root condition
 is nonempty and Zariski open on the irreducible curve, so generic inertia is a transposition. The root-incidence variety is
 A2, hence connected, so the monodromy action is transitive. Quotienting the Galois closure by the normal subgroup
 generated by finite inertia yields a cover of A2 unramified in codimension one. Purity makes it finite etale, and A2 has no
 nontrivial connected finite etale cover. Therefore the monodromy group is generated by conjugate transpositions. A
 transitive group generated by transpositions is Sn. Finally, a finite algebraic extension is linearly disjoint from the purely
 transcendental extension C(U,V)(C), so this remains the Galois group over the actual target field K.
      Corollary. The rational deck group is trivial. In the Sn-closure, the root field is fixed by a point stabilizer Sn-1,
      which is self-normalizing; hence AutK(L) = N(Sn-1)/Sn-1 = 1.

 5. Uniform rational collision
 Let sn = (4 - 2n)/(n-2). At the target (sn,sn,1), the fiber polynomial is Tn - T2 + (4-2n)(T-1), with simple roots 1 and 2. For r
 in {1,2}, set gr = sn - pn(r) and
                                            Xn,r = (1/gr, r-gr, gr2[gr-1 + n/(n-1)(r/gr-1)]). (4)

 Here g1 = (n+2-2n)/(n-2) and g2 = 2n-1, both nonzero. Exact substitution gives Fn(Xn,1) = Fn(Xn,2) = (sn,sn,1). For n = 3:
 F3(-1/3,4,-54) = F3(1/4,-2,36) = (-4,-4,1).
