                3. Duality theory for linear programming bounds
   In our study of the three-point lattice bound, we will use dual bounds for
infinite-dimensional linear programs. This theory is subtle, because unlike the
finite-dimensional case, there can be a duality gap between the optimal primal
and dual bounds. In this section, we will show that there is no duality gap in the
linear programs that arise in our work. One consequence of this analysis is that the
ordinary linear programming bound has no duality gap, which was conjectured in
[7, Section 4] but has not previously been proved.
   Let C be a closed subset of Rn . The C-constrained linear programming bound is
the infimum of f (0) over all Schwartz functions f : Rn → R satisfying f (x) ≤ 0 for
all x ∈ C, fb(y) ≥ 0 for all y, and fb(0) = 1. Aside from the restriction to Schwartz
functions, which we will address in Proposition 3.5, the ordinary linear programming
bound for sphere packing is the case C = {x ∈ Rn : |x| ≥ 1}, and the three-point
lattice bound and the disjunctive product bound from Section 4 are also special
cases. Furthermore, when Rn \ C is a convex body that is symmetric with respect
to the origin, f (0) vol(Rn \ C)/2n is an upper bound for the packing density in Rn
using translates of Rn \ C (see Theorem B.1 in [8]). We will assume 0 6∈ C, since
otherwise no such f exists. Conversely, a feasible f always exists when 0 6∈ C, for
example by rescaling the input variable to a feasible f in the linear programming
bound for sphere packing.
