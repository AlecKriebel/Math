                                               Abstract
         We record a short reduction from multiplicatively weighted center thresholds to additively
     weighted eccentricities on a graph with bounded integral distances. Combining it with the
     algorithm of Bergé, Ducoﬀe and Habib and a known implicit optimization method gives a
     deterministic O(n log5 (2n)) algorithm for a center, the optimum radius and all centers of every
     ﬁnite unit-edge median graph. This answers the ﬁnite algorithmic form of Open Problem 1 in
     Ducoﬀe’s Oberwolfach report, without a bound on cube dimension. The contribution is the
     threshold observation and its consequence; neither the additive algorithm nor the optimization
     mechanism is new. We specify the exact comparison model and give explicit corrections to two
     estimates in the public preprint proof of the imported algorithm.


1    Problem and prior algorithms
Let G = (V, E) be a ﬁnite, nonempty, connected, simple graph with unit edge lengths, n = |V |,
and shortest-path distance d. For a ﬁnite nonnegative real proﬁle w : V → R≥0 deﬁne

             rw (x) = max w(u)d(x, u),        ρ = min rw (x),       Cw = {x : rw (x) = ρ}.
                       u∈V                           x∈V

A median graph is one in which every triple has a unique vertex belonging to the three pairwise
shortest-path intervals. Ducoﬀe [1, pp. 504–505] asks for an almost linear-time weighted-center
algorithm on median graphs of bounded cube dimension. The weights in this question multiply
distances; additive arrival weights deﬁne a diﬀerent objective.

Theorem 1. Given a graph promised to be median, supplied by adjacency lists, and a ﬁnite non-
negative real proﬁle, one can compute ρ, a vertex in Cw and the entire set Cw deterministically
in O(n log5 (2n)) exact operations. No cube-dimension bound or supplied embedding is required.
Operations on proﬁle values only compare bounded integer multiples kw(u), with 0 ≤ k ≤ n − 1.

    The principal imported theorem is due to Bergé, Ducoﬀe and Habib (BDH) [2]: for a nonnegative
integer arrival proﬁle a, all values
                                                     (             )
                                     Ea (x) = max d(x, u) + a(u)                                        (1)
                                               u∈V

on a median graph can be computed in O(n log4 (2n)) time, including preprocessing. The precise
interface is on pp. 2–3 of the public preprint [3]; its Algorithm 1 is on p. 22 and the overall

2    A threshold identity
Set D = n − 1. Every distance in a connected unit-edge graph is an integer in [0, D]. For R ≥ 0
and u ∈ V put

               bR (u) = max{k ∈ {0, . . . , D} : kw(u) ≤ R},       aR (u) = D − bR (u).         (2)

Zero is an admissible index. If w(u) = 0 then bR (u) = D. For positive w(u) this is the capped ﬂoor
of R/w(u), but binary search on the D+1 integer indices computes it using O(log(2n)) comparisons,
without a real division or unbounded-ﬂoor primitive.

Lemma 2. For every vertex x and R ≥ 0,

                                 rw (x) ≤ R     ⇐⇒     EaR (x) ≤ D.

Proof. For every u, integrality and the distance bound give

                w(u)d(x, u) ≤ R ⇐⇒ d(x, u) ≤ bR (u) ⇐⇒ d(x, u) + aR (u) ≤ D.

For a zero weight both conditions are vacuous. Take the conjunction over u and use (1).

   Thus one BDH call, followed by a scan, returns the entire feasible set FR = {x : rw (x) ≤ R}
in O(n log4 (2n)) operations. The graph and its zero-weight vertices are retained. No subdivision,
Helly property, ball convexity or local-search theorem is required. For R < 0 the feasible set is
empty. For n = 1, or an all-zero proﬁle, the optimum is zero and every vertex is a center.


3    Implicit optimization and complete output
For any vertex x, its radius is an attained maximum and hence has the form kw(u) with 0 ≤ k ≤ D.
Therefore ρ belongs to the multiset of n sorted rows

                           Su = (0, w(u), 2w(u), . . . , Dw(u)),     u ∈ V.

These n2 entries are conceptual and are never materialized. Here is the promised variant of the
prior optimization mechanism [4].


                                                  2
    Maintain an inclusive active index interval [lu , hu ] in each row, initially [0, D], and a feasible
incumbent B = D maxu w(u), witnessed by an arbitrary vertex. Handle n = 1 and B = 0 directly.
Write Lu = hu − lu + 1 for a nonempty interval and let M be their total length. While M > 0,
take the lower middle value qu = w(u)⌊(lu + hu )/2⌋ of every nonempty row, with selection weight
Lu . Sort these values and choose a weighted median q: the total selection weight on either weak
side is at least M/2. Query Fq using Lemma 2.
    If Fq is nonempty, replace B by min(B, q), saving a corresponding feasible witness when it
decreases, and delete all active entries ≥ q. Otherwise delete all active entries ≤ q. Binary searches
within the row intervals implement either deletion exactly, including ties and zero rows. Repeat
until all intervals are empty.
Lemma 3. This process ends after O(log(2n)) queries and returns B = ρ and a center. A ﬁnal
query at B returns exactly Cw .
Proof. Maintain that B is feasible and either B = ρ or an active entry equals ρ. Initially this holds.
A feasible pivot has ρ ≤ q: if equality holds it is saved; if ρ < q, every optimum copy survives. An
infeasible pivot has ρ > q, so every optimum copy again survives. This proves the invariant, and
an empty active set forces B = ρ. Its feasible witness is a center, and FB = Cw .
    For progress, a middle entry of a row of length Lu has at least Lu /2 entries on each weak side.
If q is infeasible, rows with qu ≤ q have total length at least M/2, and at least half of those entries
are deleted. If q is feasible, use rows with qu ≥ q. In either case at least M/4 entries are deleted,
counting multiplicity. This includes singleton rows and equal values. Since M is an integer and
starts at n2 , only O(log(2n)) iterations occur.

    Sorting and all bounded searches require O(n log(2n)) work per iteration and O(n) row storage
beyond the oracle. Thus the total comparison overhead is O(n log2 (2n)). The O(log(2n)) BDH
calls and ﬁnal complete-output call prove Theorem 1. Reading the adjacency lists is absorbed:
median graphs have at most n log2 n edges [3].


4    Model, reproducibility and status
The claim concerns ﬁnite vertex centers in a graph promised to be median. It includes zero weights,
singleton support, exact equality thresholds and multiple centers. It does not solve recognition, the
separate arbitrary-edge-length question, a continuous facility problem, or an unspeciﬁed encoding
of inﬁnite median graphs. Nor does the global threshold algorithm settle the separate unimodality
question in the workshop report [1].
    The optimum can be stored as one pair (k, u) representing kw(u). All real comparisons are
between such pairs. For rational input w(u) = pu /qu with positive denominators and components
of at most B bits, a comparison uses integer products kpu qv and jpv qu of O(B + log n) bits. There
are O(n log2 (2n)) original-weight comparisons; their bit cost and input-reading cost must be paid.
The theorem is not an encoding-independent bit bound. The small integer labels in the imported
algorithm use O(log n) bits, including its internal updates, as checked in Appendix A.
    The accompanying authored-only veriﬁcation package includes the frozen original candidate and
historical audit, new independent proofs and source comparisons, exact rational controls, the source-
proof repair, manuscript source, an oﬄine replay driver and nested hash manifests. Reference all-
pairs and brute-structure routines verify ﬁnite cases; they are expressly not a fast implementation
or an experimental proof of the asymptotic theorem. The universal argument uses the credited
classical structure and algorithms. Hashes establish ﬁle consistency, not authenticity, priority or
formal proof certiﬁcation.

A     Explicit estimates for the imported recursion
This appendix concerns the proof of Theorem 1 of arXiv:2410.10235v1 [3]. It does not assert that
the ﬁnal SODA typesetting contains the same errors; that full chapter was not inspected. BDH’s
algorithm and structural discoveries remain theirs. The complete step-by-step audit and exact
controls are in the supplement.
    That preprint declares log = ln on p. 4, proves cube dimension d ≤ log2 s, then uses ℓ ≤ ln s for
its wide-ladder size in the duplicated-slice volume estimate on p. 24. Its separate displayed product
comparison in Lemma 16 on p. 13 has the wrong direction. Both estimates admit the following
consistent replacement.
    For every recursive graph of order s ≥ 3 use

                                 L(s) = ⌈log2 s⌉,             f (s) = 2L(s).

Compute L(s) as the bit length of s − 1. A cut is balanced exactly when f (s) times its smaller
halfspace size is at least s. Keep the original direct base cases s ≤ 2. The structural arguments
of BDH’s Sections 3–4 apply with this choice: halfspaces and slices are nonempty gated median
graphs; the unique-majority median in an unbalanced instance needs only f (s) ≥ 2. The wide
ladder consists of pairwise orthogonal incident classes, so ℓ ≤ log2 s ≤ L(s). Each slice Si lies in a
minority halfspace of size less than s/f (s). The two recursive calls on each slice consequently have
total volume
                                          ∑
                                          ℓ−1
                                                      2ℓs
                                        2     |Si | ≤       ≤ s.
                                          i=0
                                                      f (s)
Balanced children partition s. Each child in either case has order at most s(1 − 1/f (s)); in the
unbalanced case its order is less than s/f (s). The gate, ﬁber-reweighting and merging identities
depend on gatedness, not this balance constant. Both original-weight and ﬁber-weight slice calls
are retained: a ﬁber weight need not dominate the original value. There is no change of objective
or input graph.
    For completeness, put λ = 4/ ln 2. Since f (s) ≤ 4 log2 s = λ ln s for s ≥ 3, every nonterminal
path from a root of order N satisﬁes
                                        (                )          (               )
                                                  1                           1
                            si+1 ≤ si       1−               ≤ si       1−              .
                                               λ ln si                     λ ln N

Thus sh ≤ N exp(−h/(λ ln N )). At h = ⌈λ(ln N )2 ⌉ this is at most one, so the path has already
reached the s ≤ 2 base case. This proves depth O(log2 N ) directly, without the erroneous product
comparison. The source’s nonrecursive work is O(s log2 (2s)); per-level volume is at most N . The
total remains O(N log4 (2N )).
    For our initial oﬀsets at most N − 1, each ﬁber update adds at most N − 1 to a previous maxi-
mum. Along O(log2 N ) levels all internal arrival labels are O(N log2 (2N )), hence have O(log(2N ))
bits. The cited linear-time median/Theta/halfspace preprocessing [8] is unchanged. It is not recon-
structed as a fast implementation here.
