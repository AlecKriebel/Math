# Read-only closure

Run `python3 -B verify_closure.py` in this review folder. It reads bound inputs and owned artifacts, checks complete native file hashes/MD5, schema and archive occurrence metadata, and final terminal bindings. It performs no network access, scientific import/replay, extraction or file write. `--self-test` mutates only in-memory copies and confirms rejection of altered identity, dates, schema, gates, quantifiers, counts, authority and a forged hash.

The helper checks custody, not mathematical truth. DERIVATION.md and actual primary reading provide the all-parameter proof assessment. Existing immutable source helper is not replayed. No native science program is imported.
