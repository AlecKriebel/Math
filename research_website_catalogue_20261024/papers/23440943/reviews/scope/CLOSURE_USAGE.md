# Read-only custody closure

Run `python3 -B verify_closure.py` here. It authenticates every input and owned byte binding, the literal native schemas/order/history, all29original ZIP occurrences/CRC/metadata/extracted bodies, embedded PDF equality and terminal seal. It checks explicit scope labels; it does not re-prove science or import/execute a native scientific module. It performs no writes, extraction or network access. `--self-test` alters in-memory copies only and checks rejection of misleading identity, history, definition, topology, scope and byte-hash changes.

The topology source program performs scientific work at import time; this helper never imports it. Actual proof and personal primary reading are in DERIVATIONS.md and READ_LEDGER.md. Originals and all prior packets are immutable.
