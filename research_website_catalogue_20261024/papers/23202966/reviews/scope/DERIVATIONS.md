## 1. Exact language and model

Fix an integer h≥2, H={0,…,h−1}, b=h². A letter is an arbitrary relation R⊆H×H. Composition is path order, so (p,r)∈RS iff ∃q:(p,q)∈R∧(q,r)∈S. The empty product is I_H, not the empty relation. Thus L_h consists of all finite relation words with nonempty product, including ε. The encoding places (p,q) at bit ph+q in each b-bit block. Every complete block is the encoding of exactly one relation. The total binary language K_h=enc(L_h) rejects every nonmultiple-of-b length. It is not a promise problem with undefined malformed words.

The machine has one counted initial state, a set of counted final states, a read-only head, and two distinct markers even for ε. Initially the head scans the left marker. A step reads the current symbol, changes state and moves −1,0,+1. Outward marker steps are disabled; rows may be missing. Acceptance is a finite reachable final configuration, including zero steps by default. An infinite nonfinal run contributes no accepting witness. Determinism means at most one successor per state/symbol row. No time, reversal, halting, description-size, or input-length restriction is introduced. This exact model is used below and is matched to the actual foreign theorem bodies in§7.

## 2. Source construction, state ranges, and invariants

The marked source has i,a, all U(p,t) for0≤p<h,0≤t<(p+1)h, and V(q,t) for0≤q<h,q+1≤t<b. Only a is final. Initial marker steps i→U(p,0) move right. Only U(p,0) has a right-marker step to a, a stay. There are no transitions from a.

U(p,t) may skip a bit while t<(p+1)h−1. It may choose a1 precisely in row p, with q=t mod h, and then move right to V(q,t+1), or to U(q,0) when t=b−1. From V, either bit advances the offset until the block boundary, then enters U(q,0). All body moves are rightward. The chosen-edge destination satisfies t+1=ph+q+1≥q+1, so every stated V destination exists. At the row's final offset the U skip is absent; a surviving run cannot skip the entire selected row. After choosing an edge, V cannot choose another edge in that block.

Induct on complete blocks: after j blocks, U(q,0) is reachable iff q is an endpoint of a path through the first j relations from some start vertex. Before the first block every vertex is available. The transition analysis proves both directions of this induction, not just soundness of successful guesses. Only U(q,0) can accept at the right marker, so an incomplete block cannot accept. With ε, i→U(p,0) on the left marker and U(p,0)→a on the right marker give a two-step accepting run. Thus both positive-run and zero-step conventions give exactly K_h for this source.

## 3. Cubic lower bound for this exact source language

Let P_p={(p,p)}, z=enc(I_H). For p∈H and0≤t<b put x_{p,t}=enc(P_p)pref_t(z), y_{p,t}=suff_{b−t}(z)enc(P_p). The lengths of pref_t and suff_{b−t} sum to b, including t=0; diagonal concatenation encodes P_pI_HP_p=P_p and accepts. A crossed pair with t≠u has length3b+t−u. Since0<|t−u|<b, it is malformed. With t=u,p≠r, its decoded product P_pI_HP_r is empty. Hence every one of the h³ diagonal pairs accepts and every off-diagonal crossed pair rejects.

Choose a complete accepting run for each diagonal pair and the state at the x/y cut. Equal cut states in two runs would splice an accepting crossed word. Therefore an ordinary1NFA needs at least h³ states. The same proof applies to marked right-only machines, including stays: a successful run cannot accept before visiting the right marker, because the same finite run would then accept an extra-bit extension of the accepted3b-bit word, a malformed length. Consequently the run reaches the cut, and its suffix never needs cells left of that cut. Splicing retains both markers and all scanned suffix symbols. Assign any cut-position stays consistently to one side. This is not a fooling-set lower bound for arbitrary two-way machines.
