8 Concluding Remarks and Open Problems

e We have shown that for any digraph H, the property Py of being H-free is strongly testable. In
order to prove this result we have first proved a regularity lemma for digraphs, which generalizes
Szemerédi’s regularity lemma for undirected graphs. This lemma might prove useful for tackling
other problems as well. We also gave a precise characterization of all digraphs H for which the
property Py of being H-free has a one-sided error €-tester whose query complexity is polynomial
in (1/e), and showed that the same characterization applies for two-sided error e-testers as well,
where here the complexity is polynomial in 1/e if and only if it is O(1/e). We have addressed
the case when H is an oriented tree, and gave an optimal one-sided error e-tester with query

complexity O(1/e) for this case.
