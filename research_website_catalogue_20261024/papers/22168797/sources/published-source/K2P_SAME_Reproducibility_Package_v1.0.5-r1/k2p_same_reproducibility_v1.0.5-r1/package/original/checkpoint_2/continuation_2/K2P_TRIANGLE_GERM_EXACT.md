# Exact K2P ordinary-triangle germ

## Result

The three labelled orientations of an ordinary three-sunlet share a common
nine-dimensional regular stochastic K2P germ.  The same statement holds in
the strict continuous-time K2P cone.  Equality of their complete stochastic
images is not asserted.  Their complex Zariski closures are all the complete
nine-dimensional affine three-leaf K2P Fourier space.

For the orientation whose reticulation is incident with leaf 3, write

\[
q_{xyz}=a_xb_yc_z\{\delta f_y d_z+(1-\delta)f_xe_z\},\qquad x+y+z=A.
\]

Use the strict common parameter point

\[
a=b=c=(1,\tfrac12,\tfrac12,\tfrac12),\quad
f=(1,\tfrac13,\tfrac13,\tfrac13),\quad
d=e=(1,\tfrac12,\tfrac12,\tfrac12),\quad
\delta=\tfrac12.
\]

It is invariant under leaf permutations, so all three orientations give the
same tensor.  Its six nonconstant pair-orbit coordinates equal `1/12`; its
three mixed-triple orbit coordinates equal `1/48`.

The K2P Jacobian splits at this JC-symmetric point into four symmetric and five
anisotropic output directions.  In logarithmic coordinates the certified
minors are

```text
symmetric determinant   = -1/2
anisotropic determinant = -1/4
product                  =  1/8
```

Hence every orientation has rank 9, the ambient dimension.  The inverse
function theorem gives one common output neighborhood with strict analytic
physical sections.  Every edge also satisfies `g>s^2`, so the neighborhood can
be chosen inside the strict continuous-time cone.
