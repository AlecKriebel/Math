# Directed fixed-full closure for primitive three-port cycle roots

## Theorem

Let the source be either primitive rooted presentation of the ordinary
three-sunlet support, and let the target range over every selected or
marginalized three-port completion of a binary strongly tree-child level-2
primitive component.  Work on the principal positive K2P domain

\[
\mathcal D_+=\{0<s<1,\ 0<g<1,\ g>2s-1\},
\qquad 0<\delta<1.
\]

Every labelled source-to-target direction has exactly one of the following
certificates:

1. a pointwise strict tree/sunlet separator;
2. an exact no-dummy labelled semi-directed isomorphism or ordinary triangle
   relation; or
3. a dummy-bearing fixed-full restoration obligation whose every physical
   completion is pointwise topology-separated, generically separated by an
   exact K2P quadratic, or exactly labelled-isomorphic.

There are no unresolved directions or physical completions.

## 1. Exhaustive primitive universe

The primitive grammar gives two cycle source supports, 1,120 three-port target
completions, and six physical label permutations.  Direct enumeration therefore
gives

\[
2\cdot1120\cdot6=13,440
\]

raw directions.  The independent replay regenerates the graphs, rather than
opening retained descriptors, and compares every canonical ledger row.

The exact base partition is

\[
7452+5964+8+16=13,440.
\]

The first term is the strict tree/sunlet sign gate.  The last two terms are the
no-dummy labelled isomorphism and ordinary triangle terminals.  The middle term
contains every equal-topology record with at least one omitted target role; it
is deliberately not promoted merely because its selected restriction may look
isomorphic or triangle-related.

## 2. Why restoration is fixed-full

Assume, for contradiction, one fixed full directed containment and select the
actual three labels defining one cycle restriction.  The omitted target roles
are then concrete physical labels in those same full networks.  Restore all of
them, in a fixed label order, without changing either network.

For a root with \(k\) omitted roles, the target placement is fixed and the
source has

\[
3\cdot4\cdots(3+k-1)
\]

labelled word placements.  The root multiplicities for \(k=1,2,3,4\) are

\[
324,\ 1896,\ 2784,\ 960,
\]

so the complete physical universe has

\[
324(3)+1896(12)+2784(60)+960(360)=536,364
\]

rows.  The actual full source is exactly one of these rows.  This argument uses
source marginal openness only to pass from a putative full generic containment
to the selected local germ.  It never lifts an abstract parent relation, never
inverts target marginalization, and never assumes target-map openness.

There is no missing factorial of assignments of physical label names to dummy
roles.  Given an actual full pair, the unique simultaneous label permutation
that fixes the three selected labels and sends the physical label occupying the
\(i\)-th sorted target role to \(3+i\) converts it to the enumerated convention.
K2P parameterizations and directed containment are equivariant under this
simultaneous relabelling.  The source placement path then records every possible
relative position and order of those canonically named labels.

## 3. Pointwise topology exclusions

For every labelled quartet the generator computes the complete nonempty set of
displayed splits.  Unequal displayed sets give a zero-versus-strict-positive
K2P invariant on the strict positive model, as in Englander et al., v4,
Propositions 2.9--2.10 and Theorem 2.11.  Consequently these rows have disjoint
physical images, not merely different generic varieties.  This proves 535,920
full-completion exclusions.

For the remaining topology-equal rows, every tree/sunlet triple mismatch is
certified by

\[
T_3=V^2X_g-X_s^2Y_gZ_g.
\]

It vanishes on the tree and has the strictly negative sunlet pullback

\[
-a_s^2b_s^2a_gb_gc_g^2f_s^2\delta(1-\delta)d_ge_g(1-f_g)^2.
\]

All factors other than the leading sign are strictly positive on
\(\mathcal D_+\) with \(0<\delta<1\).  This proves the other 300 pointwise
full-completion exclusions and the 7,452 base exclusions.

## 4. Exact directional quadratics

Only 144 physical rows survive both topology gates.  Twelve are exact labelled
semi-directed isomorphisms.  For each of the other 132 rows, the compiler builds
the graph-derived K2P Fourier polynomial maps \(F_S\) and \(F_T\).  Canonical
descriptor pairs reduce the rows to 54 classes, with multiplicity census

\[
42\times2+12\times4=132.
\]

For every class the stored quadratic

\[
Q(q)=\sum_{(i,j)}c_{ij}q_iq_j
\]

satisfies coefficientwise

\[
Q\circ F_T=0,\qquad Q\circ F_S\ne0.
\]

The verifier reconstructs every listed coordinate pair and coefficient,
multiplies the sparse pullbacks over the integers, checks the target polynomial
is identically zero, and checks the committed source polynomial hash.  It also
re-runs the deterministic exhaustive multihomogeneous degree-two search.

Each certificate contains an exact rational source point.  Every edge pair at
that point satisfies all three strict inequalities defining \(\mathcal D_+\),
every inheritance parameter lies in \((0,1)\), and direct rational evaluation
of \(Q\circ F_S\) is nonzero.  Hence the source pullback is nonzero on a
nonempty physical open set and a generic source-to-target containment is
impossible.  No rank comparison is used for this implication; the included
Jacobian ranks are independent exact rational lower witnesses only.

## 5. Physical terminals and coherent use

The 24 no-dummy base terminals and 12 restored isomorphisms have unique exact
labelled incidence transports.  Triangle transports retain the distinguished
ordinary-triangle edge sets.  Structural encodings of incidence nodes and edge
sets make every transport identifier independent of Python hash iteration.

Thus every dummy-bearing cycle restriction of a putative fixed full containment
either contradicts a pointwise separator, contradicts an exact generic
quadratic, or lands at one of the 12 restored physical isomorphism anchors.
Together with the 24 no-dummy terminals, these 36 anchors are the exact cycle
roots that a subsequent one-/two-probe coherence package must bind.  This
local theorem does not by itself assert that later probe package.

## 6. Independent replay and adversarial tests

The independent verifier separately implements graph insertion, role
promotion, topology witnesses, exact transports, ledger generation, quadratic
pullback evaluation, and rational-domain checks.  It streams and compares all
549,804 raw rows (13,440 base plus 536,364 physical completions).

The mutation suite confirms fail-closed rejection of an omitted base row, an
omitted restoration role, a wrong source placement, a reassigned quadratic,
and a broken transport.  A complete replay also passes with Python assertions
disabled (`python -O`).  The optimized replay exposed and forced repair of a
pre-release hash-seed-sensitive set serialization; the released encoding is
structural and byte-stable.
