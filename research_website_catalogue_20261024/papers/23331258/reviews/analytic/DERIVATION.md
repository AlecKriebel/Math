1. In unit lengths, deleting edges cannot shorten distance and all finite distances are integers. Therefore increasing by at least1 is equivalent to hitting every original shortest path. This equivalence would need care for nonintegral traversal lengths, but those are excluded. A deletion-set certificate and BFS from the three terminals before/after deletion verify the three pair constraints in polynomial time, with explicit infinity handling. Exact rational cost addition/comparison has polynomial bit complexity: denominator-product bitlength is bounded by the sum of input denominator bitlengths. Unit costs give hardness for the rational-cost version without a weighted cover-identity claim.

2. For simple Vertex Cover Q=(V,E), replace each uv by u−b−c−v using two unique new vertices. Then H is tripartite with A=V,B=first subdivision vertices,C=second vertices. All edge types occur whenever m=|E|≥1. If S covers Q, add c when only u is selected, b when only v is selected, either when both; this covers each3-edge gadget at cost1. Thus tau(H)≤m+tau(Q). Conversely, for any H-cover X, let S=X∩V and q be the number of Q-edges with neither endpoint in S. Every gadget needs at least one internal vertex for its middle edge, and the q uncovered-edge gadgets need both. Hence |X|≥|S|+m+q. Adding one endpoint per uncovered edge gives a Q-cover of size≤|S|+q≤|X|−m. This proves tau(H)=m+tau(Q), including disconnected Q and isolates. Repeated endpoint additions can only decrease the extracted size. Original orientations are arbitrary and irrelevant.

3. Attach r,s,t uniquely to A,B,C respectively. Terminals have no mutual edges and disjoint neighborhoods, so distances1/2 are impossible. A cross-part edge supplies a3-edge path for each pair. Every length3 terminal path consists of its two endpoint spokes and one H-edge. A third terminal cannot occur internally because each old vertex has exactly one terminal neighbor. Thus ALL original shortest paths correspond exactly to H-edges uv via {spoke_u,uv,spoke_v}.

4. Delete spokes for an H-cover X to hit all these geodesics. Conversely, from ANY blocker F, select the old vertex of each deleted spoke and one arbitrary endpoint of each deleted H-edge. Every H-edge's geodesic is hit; whichever deleted edge hits it contributes one of its endpoints to the selected vertex set. The extracted X covers every H-edge and |X|≤|F|. This explicitly includes blockers deleting middle edges; there is no protected-edge assumption. Equivalently, unweighted middle deletions can be rounded to endpoint-spoke deletions without increased cardinality. Therefore opt(G_H)=tau(H). This rounding is an unweighted statement and is not asserted for arbitrary rational deletion costs.

5. Reduce a valid nonnegative-budget Vertex Cover instance with m≥1 to G_H and B=m+k. The two exact identities give equivalence for every binary k. There are n+2m+3 vertices, H has3m edges and the terminal spokes number n+2m, giving n+5m total edges. Bit complexity is polynomial even when k is numerically huge; graph size is independent of k's value. Edgeless Q is always YES when k≥0; map it to H=triangle with its three terminal spokes and budget2. All target restrictions hold. This is total on the stated NP-complete nonnegative source domain. General target rational budgets may be negative only as immediate NO cases; positive rational costs do not alter membership or the unit-cost hardness subcase.

6. For each terminal pair add a separate4-edge path with three fresh internal vertices of degree2 and no further incidences; the three paths have disjoint internal vertices. Any simple terminal path that uses one such internal vertex must enter at one of that backup's terminal endpoints and traverse the entire4-edge path before it can leave. Thus no new path of length≤3 is created and initial distances remain3. After deleting an H-cover's spokes, no original3-edge path survives, while all4-edge backups remain, forcing every terminal distance exactly4.

7. Conversely, any feasible augmented blocker under either finite-increase or exact4 constraints must hit every original3-edge geodesic. Backup deletions do not meet those old geodesics and can be ignored for extraction. Select a cover from F∩old_edges as above: |X|≤|F∩old_edges|≤|F|. Therefore both strengthened optima equal tau(H). Nine new internal vertices/twelve new edges are a constant-size augmentation and BFS verifies the extra constraints.
