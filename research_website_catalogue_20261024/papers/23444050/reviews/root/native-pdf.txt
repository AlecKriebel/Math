An explicit counterexample to three-summand Kato-kernel splitting
                                                  Alec Kriebel∗

                                               17 October 2026
                                 Unrefereed, extensively AI-assisted research note




                                                    Abstract
             Question 2 in Laghribi’s contribution to Oberwolfach Report 5/2016 asks whether a mixed
          Kato kernel is the sum of the kernels of a ﬁnite purely inseparable extension, a separable
          quadratic extension, and a bilinear Pﬁster function ﬁeld. We give an explicit negative in-
          stance in H22 , using an exponent-two extension and a binary bilinear Pﬁster form that remains
          anisotropic. The mixed class is exactly a specialization of the generators of Aravire–Laghribi–
          O’Ryan (2019/2020). We prove directly that it remains outside the sum after the additional
          Pﬁster kernel is included, by a universal norm and residue obstruction. The original degree-one
          cohomology case is separately positive. No ﬁrstness claim is made.

   The original question [1, printed p. 251, Question 2] asks whether

                           Kn (LK(B)/F ) = Kn (L/F ) + Kn (K/F ) + Kn (F (B)/F )                            (1)

for every ﬁnite purely inseparable L/F , separable quadratic K/F , and anisotropic bilinear Pﬁster
form B remaining anisotropic over L. As in that source, F (B) is the function ﬁeld of the projective
quasilinear quadric of v 7→ B(v, v). This convention includes an anisotropic binary form, whose
quadric is integral and zero-dimensional.
    The positive exponent-one regime is covered by [2]. Higher-exponent two-ﬁeld nonsplitting and
the mixed generators are antecedent work [3]. The class below is exactly their Deﬁnition 1.3 and
Lemma 3.1 specialization: in their notation take n = m = 1, f0 = 1, f1 = z, and a = s−4 . The only
nonzero generator term is (β 2 z/(1 + β 2 z))2 d log z. Moreover s−4 + s−1 = ℘(s−2 + s−1 ), so these
parameters deﬁne the same separable quadratic ﬁeld. This note supplies the direct three-summand
nonmembership proof; it makes no priority claim for the class, example, or target deduction.

3    The boundary degree and scope
Proposition 2. At n = 0, equality (1) holds for every set of its stated data with B a positive-fold
bilinear Pﬁster form.
Proof. An Artin–Schreier root cannot ﬁrst appear in a purely inseparable extension, since that
root is separable over the base. Nor can it ﬁrst appear in a rational function ﬁeld, whose algebraic
constants are its base ﬁeld. An anisotropic quasilinear form of dimension d ≥ 2 has projective-
quadric function ﬁeld purely inseparable quadratic over a rational ﬁeld in d − 2 variables: use a
projective chart and solve for one squared coordinate. For d = 2, there are no rational variables.

                                                          3
   Separable extension preserves quasilinear anisotropy, by linear disjointness with purely insepa-
rable extensions. Thus the chart description applies over KL. Any Artin–Schreier root over F in
LK(B) descends ﬁrst to KL, then to K, since KL/K is purely inseparable. Hence the composite
kernel is the K/F kernel, and the other two kernels are zero.

    If one separately assigns F (B) = F to a zero-fold form, its n = 0 case follows from the same
purely inseparable injection. No function ﬁeld of an empty projective quadric is needed.
    Two boundaries of the construction are useful. If the Pﬁster slot is z rather than the independent
t, adjoining its ﬁeld kills dz and absorbs ξ. If b = u2 already in the base and β 2 = u, then the
computation over L gives ξL = [s−1 , 1 + uz)L . Since 1 + uz is now in the base, this proves
membership in K(L/F ) + K(K/F ). It does not justify a single-symbol equality in the base: there
d(1 + uz) = u dz + z du. This corrects an auxiliary shortcut in the earlier draft and leaves the
exponent-two example unchanged.
