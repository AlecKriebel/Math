An explicit complex polynomial retract in five variables: a consequence of affine-space cancellation failure
Authors/Creators
Kriebel, Alec
Description
Using OpenAI's explicit complex cancellation fourfold, this consequence note gives split complex-algebra maps and a five-component idempotent polynomial endomorphism of affine five-space whose image has transcendence degree four and is not a polynomial algebra. The cylinder-to-retract implication is classical, as recorded by Nagamine; the cancellation example, stabilization and nonpolynomiality are attributed to OpenAI. The four-variable retract question is not settled. The package includes exact symbolic certificates, written dependency audits and a bounded priority audit. The actual Lean sources were inspected, but a full kernel build was not reproduced; no formal verification of the follow-on theorem is claimed. AI tools were used extensively in research, drafting and verification. This preprint has not undergone conventional human peer review/refereeing; automated reviews are not human peer review. The original note and new verification artifacts are CC BY4.0; the bundled OpenAI Lean sources and adapted build configuration/audit harness retain Apache2.0.
