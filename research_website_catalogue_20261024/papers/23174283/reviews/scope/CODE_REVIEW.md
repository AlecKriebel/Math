# Deposited proof and computation review

All five actual Python program bodies were personally read after the initial seal, then read again during final review. The README, expected-value object and complete historical PROOF.md were also read after the seal. The archived PRIORITY_NOTE.md was not read. No pre-existing review is used as evidence here.

The controlling published TeX gives the all-integer adjacent-Fibonacci-basis arithmetic proof. The deposited PROOF.md preserves an older, compatible Cassini/quadratic-form route: it restricts to m²<q and |r|<q/4, proves m|r|>q/4 for q≥8, handles the remaining pairs by vertical/nonpositive-cosine bounds, and treats q=2,3,5 separately. Its nonzero integer B=ℓ²+ℓm−m² and identity are valid; the contradiction uses q+13q²/16<q² at q≥8. It proves the same minimum. The controlling TeX additionally states and proves unique attainment. No unsupported old proof is substituted for that stronger published statement.

`author_verify.py` uses exact fractions and integers for Cassini, dangerous-residue identities, latitude algebra and 300,237 proof-derived finite pair certificates through q=610. The vertical bound used for large gaps is a true squared-height difference. Its positive-cosine regime relies on the mathematical sine bound, rather than numerically measuring a chord.

`historical_independent.py` separately certifies 114,492 finite chords through q=377. Alternating arctangent series enclose the two terms in Machin's formula; the exact tangent identity fixes the π/4 branch since 4 arctan(1/5)−arctan(1/239) lies in (0,π/2). At a nearest residue, the angle lies in [0,π], where cosine decreases. The degree-24 even Taylor truncation is an upper bound there: after the first term, successive term magnitudes decrease because π²/12<1, and the omitted term is negative. Evaluating it at the lower angular endpoint therefore bounds the actual cosine from above. The integer H is checked nonnegative before squaring against a positive cosine upper bound. A nonpositive upper bound needs only H≥0. This avoids an invalid squaring/sign branch and does not use floating values as certificates.

`proof_controls.py` explicitly exercises all offsets for indices 3…22, four integer ℓ choices per offset, unimodular coordinates/signs, terminal h=1 and rational geometric identities. `identity_controls.py` proves the modular identities at indices 3…200 with integers; its coordinate comparisons through index12 use floating tolerances and are diagnostic. Its historical block labelled subset checks a reflected point's unit norm only, as the README openly acknowledges; it does not prove membership in a separately constructed historical array. Neither that block nor any uninspected array is needed by the target theorem or source isometries.

`verify_package.py` verifies the full declared payload, starts four positive and five rejection processes with explicit -E -B, records complete streams/PIDs/deadlines and rechecks source identity. Our actual normal-mode execution completed with exit0 in 19.4478 seconds and all expected outputs. Every child was reaped, with no timeout or cleanup error. The positive exact counts match the deposited expected object. Each negative control exited1 with the intended assertion reason.

Operational boundary: the supplied package uses Python `assert`, and its README explicitly requires assertions to remain enabled. We followed its normal -E -B invocation. Its initial optimization check is itself an assertion and therefore is not a reliable refusal mechanism if a caller forcibly uses -O; no such robustness is claimed or inferred. No optimized supplied run was used as evidence. The independent verifier in this review uses explicit runtime guards and gives identical normal/-O results. The package requires only the standard library; README states Python3.10+ suffices. Our actual recorded runtime was Python3.9.6, on which every expected operation and result completed; this is not a claim that its authors certify that older runtime.

The runner's PASS is finite-control reproduction and payload integrity. It is not an infinite proof, a novelty certificate, proof-assistant verification, or human peer review. All original native ZIP payloads and public assets were checked byte-for-byte independently at closure, without changes.
