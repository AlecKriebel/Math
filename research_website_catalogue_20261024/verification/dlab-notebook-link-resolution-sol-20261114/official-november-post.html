November 2026 update for the 21st edition

An update for the current 21st edition of “Kourovka Notebook (Unsolved Problems in Group Theory)” is  posted. A separate file contains the updates only. All the changes are also incorporated in the new version of the main PDF file Kourovka Notebook (Unsolved Problems in Group Theory).

Problems are marked with in those cases where some Artificial Intelligence (AI) system proposed a solution that has not yet been confirmed by mathematicians. Such a problem should be regarded as unsolved. Anyone interested in a problem with an unverified AI solution is invited to look into this AI solution and either confirm it or find mistakes — in the first case a solution will be marked as a proper solution with , and in the second altogether deleted.

Further comments/solutions are welcome!

Evgeny Khukhro   khukhro@yahoo.co.uk  and

Victor Mazurov  mazurov@math.nsc.ru

Editors

************************************

This 21st edition contains 150 new problems and a number of comments on about 1000 problems from the previous issues. The section “Archive of Solved Problems” includes all the solved problems from the previous issues that have already been commented on in previous issues, while new solutions are found among unsolved problems in the corresponding sections.
