# Bounded reviewer interfaces

Only six new modules implement this pair. They do not modify installed helpers.

* `stage_model.py`: loads exact content-addressed private snapshots; authenticates the two native schemas without a generic normalized source schema; checks whole custom verdicts and all immutable config/source objects; permits only the declared main id and 121 sentence changes. Explicit live-fence calls verify old public/core/config/prior-packet bytes, with the one exact root-authorized checkpoint-helper supplement.
* `stage_dom.py`: closed structural/attribute grammar with explicit empty iframe raw text. It rejects unknown head/outside-body structures and hiding attributes. It never treats iframe/template/noscript contents as visible article text.
* `build_private.py`: uses the full adopted main trees, generates the existing-style head/wrapper, copies native assets unchanged and appends two index/sitemap entries. It requires `--output-root` and `--build-date`; the output root must be a new private descendant of this packet.
* `check_private.py`: reads output bytes and independently checks complete main/wrapper/head/metadata/readers/downloads/native assets and old aggregate-byte recovery. It does not call renderer functions.
* `integration_controls.py`: explicitly invoked 22-case in-memory new-target suite. It never writes or mutates a positive tree and never runs on import.
* `verify_packet.py`: self-contained standard-library terminal custody. It authenticates all owned bytes, all 607 original/snapshot input bindings, prior packet bindings and paired complete output trees. It imports none of the other five modules and runs no semantic/scientific campaign. Its optional live-baseline mode additionally checks the old production fence.

All implementation uses explicit `require`/exceptions, not assertions that disappear under optimization. The tested interpreters are bundled Python 3.12.14 and Homebrew Python 3.14.6. Tests use `-B` to avoid incidental interpreter cache files. No dependency installation is needed.

Review the original root authorities and editorial inputs first, then `CODE_MANIFEST.json`, the six modules, `BODY_CHANGE_AUDIT.json`, `NATIVE_CONTRACTS.json`, `OVERLAY_MANIFEST.json` and `REPORT.md`. The two pristine trees are `candidate-a/public` and `candidate-b/public`. All proposed canonical URLs belong only to these private payloads; the original paper-level canonical/AA values remain null.

Read-only semantic check, using the bundled runtime:

```text
<bundled-python> -B check_private.py --output-root <this-packet>/candidate-a/public --build-date 2026-11-15
```

Pure terminal closure, without semantic or scientific replay:

```text
<bundled-python> -B verify_packet.py --packet-root <this-packet>
<bundled-python> -B -O verify_packet.py --packet-root <this-packet>
```

Add `--live-baseline` only when checking that the old 585-file released website remains current. Default terminal closure does not assert that a future installation has not occurred. Full ignored raw input bodies stay local and are still authenticated; a checkout without those private bodies intentionally cannot claim a complete local custody closure.
