## Exact gaps and residual limitations

The installer itself has not been supplied for independent code verification, and this report does not approve an implementation. The scientific adoption gate and root execution/publication receipts remain absent. No remote baseline was checked because this task forbids network contacts.

A non-force push plus a preceding remote lookup is not an atomic assertion that the remote still equals BASE: a remote rewind to a strict ancestor of BASE between those operations could still admit the prepared commit as a fast-forward. The root explicitly forbids force options, so this audit records the limitation rather than proposing an unauthorized lease. A concurrent remote advance would ordinarily reject the non-fast-forward push. Separate root publication approval must decide how to handle this remaining race.

Likewise, an advisory index lock does not prevent arbitrary noncooperating writers from changing files or HEAD. Rechecks detect many races but do not create a universal transaction across working files, index, ref, and remote. If any step fails after a mutation, record the exact completed steps and stop; do not automatically reset, erase, or overwrite concurrent work. A root-reviewed recovery action can then address the concrete partial state.
