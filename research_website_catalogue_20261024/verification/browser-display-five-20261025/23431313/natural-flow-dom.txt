    - heading "Abstract" [level=2]
    - paragraph: "We give a complete smooth compact-support proof of the classification asked for in the historical integrable-systems problem source: a real Jordan type occurs on a nonempty open subset of ℝⁿ for a compactly supported smooth Nijenhuis operator exactly when its spectrum is real. The construction realizes arbitrary specified numerical real Jordan data in a commuting local frame. On a same-dimensional torus collar, the torsion equation reduces to (A-λ I)A'=0; an ordered finite path removes every Jordan block and reaches an exact zero band. The nonreal obstruction and earlier semisimple and two-dimensional examples are prior results. We include the precise zero-point rigidity deduction needed for necessity. The historical priority of the full result and of this construction remains unestablished. Extensive AI tools assisted solving, verification and writing. This preprint is unrefereed and has no external human peer review or formal proof-assistant certification."
    - heading "The idea in plain English" [level=2]
    - paragraph: A Nijenhuis operator assigns a linear transformation to each point of a space while satisfying a differential compatibility condition. This paper asks which matrix patterns can hold throughout an open region when the entire field must become exactly zero outside a bounded region.
    - paragraph: Every pattern with real eigenvalues can be realized. The construction allows repeated eigenvalues and Jordan blocks of any size, including matrices that cannot be diagonalized. It fixes both the numerical eigenvalues and the block pattern in a suitable local frame.
    - paragraph: The difficult step is turning the field off without breaking its compatibility condition. The paper makes that transition in a thin neighborhood of a torus, removing the connections within each Jordan block in a controlled order.
    - paragraph: "Outside the chosen region, the matrix pattern is allowed to change. The converse is an established obstruction: a smooth compactly supported real Nijenhuis operator cannot have a nonreal eigenvalue anywhere."
    - heading "The precise result" [level=2]
    - paragraph: For every integer n ≥ 1 and every prescribed numerical real Jordan matrix J whose eigenvalues are all real, there is a globally C∞, compactly supported real Nijenhuis operator on ℝⁿ whose matrix is J in a smooth commuting local frame on a nonempty open domain.
    - paragraph: The construction includes repeated eigenvalues, multiple blocks belonging to the same eigenvalue, blocks of arbitrary size, negative or zero eigenvalues and the zero matrix.
    - paragraph: Conversely, every eigenvalue at every point of any smooth compactly supported real Nijenhuis operator on ℝⁿ is real. Together, these statements give the classification asked for in the printed historical problem.
    - paragraph: The prescribed numerical matrix is realized on an open domain in the same dimension. The theorem does not prescribe the ambient Cartesian-frame matrix or require one Jordan type throughout the whole space.
    - heading "Why the result holds" [level=2]
    - paragraph: In dimensions two and higher, a thin torus neighborhood lets all coefficients depend on one transverse variable. For the block matrix L = [[A(t), b(t)], [0, λ(t)]], the Nijenhuis condition reduces to the ordered equation (A − λI)A′ = 0.
    - paragraph: A finite sequence first removes the transverse coupling, then turns off each Jordan block’s arrows in order and moves its scalar part to zero. Smooth transitions with constant end intervals join these stages and leave exact zero bands at both ends.
    - paragraph: In these dimensions, an embedded torus collar lies in ℝⁿ in the required dimension. The tensor is pushed into that collar and extended by zero; the zero bands make the extension smooth and compactly supported. In dimension one, a smooth compactly supported scalar function suffices.
    - paragraph: For necessity, the paper uses the established local splitting and holomorphic structure of nonreal spectral blocks in a zero-point rigidity argument. Compact support allows extension to a sphere with a neighborhood on which the tensor is zero.
    - heading "Scope and limitations" [level=2]
    - paragraph: The result is C∞ smooth. It does not give a nonzero real-analytic compactly supported operator.
    - paragraph: The matrix J appears in a smooth commuting local frame on a domain chosen by the construction. The ambient Cartesian-frame matrix and an arbitrarily preassigned realization domain are not prescribed.
    - paragraph: Rank, eigenvalues and Jordan type may change outside the realization domain. Global algebraic regularity and a single global Jordan type are not guaranteed; algebraic regularity is distinct from smoothness.
    - paragraph: The nonreal obstruction concerns globally compactly supported operators. It does not forbid local models with nonreal eigenvalues or operators without compact support.
    - paragraph: Earlier work supplies the nonreal obstruction, real semisimple and two-dimensional examples, local point realizations, and the splitting and holomorphic tools. Historical priority of the full result or this construction is not established.
