# Systematic Biology initial-submission checklist

Official instructions: <https://academic.oup.com/sysbio/pages/General_Instructions>
(re-checked 2026-08-25).

- [x] Research Article and named author are explicit.
- [x] Wrapper requests 12-point type, one-inch margins, 1.5 spacing, ragged
  right text, continuous line numbers, and consecutive page numbers.
- [x] Running title is no more than 50 characters.
- [x] Eight keywords are supplied (allowed range: four to eight).
- [x] Generative-AI use is disclosed in the manuscript and cover-letter draft.
- [x] Data Availability follows Acknowledgments in the wrapper.
- [x] The manifest excludes the Zenodo archive from ScholarOne uploads.
- [x] Supplement is designated as a separate PDF.
- [ ] Resolve every `@@TOKEN@@` from author-confirmed information.
- [x] Active corresponding email is bound to `me@aleckriebel.com` from the
  established local publication metadata.
- [ ] Supply the corresponding postal address and telephone.
- [ ] Confirm the funding and competing-interest statements.
- [ ] Deposit code, certificates, and replay scripts in Zenodo; verify the
  reviewer-access link or DOI and repository README files.
- [ ] Decide and record the code/archive license; no license is inferred.
- [ ] Confirm originality, authorship, and that the paper is not under
  simultaneous consideration elsewhere.
- [ ] Compile the main manuscript PDF and inspect every page, line number,
  equation, table, URL, citation, running head, and page number.
- [ ] Compile the supplement PDF and inspect every page; supplementary material
  will not be copyedited.
- [ ] Confirm all figures, if later added, have alt text and appear after first
  mention.
- [ ] Re-check the live portal and official instructions immediately before the
  human author submits.
