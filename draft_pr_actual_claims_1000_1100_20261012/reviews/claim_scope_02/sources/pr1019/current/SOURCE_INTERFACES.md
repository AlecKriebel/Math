## Ordinary area theorem: used only at its actual interface

Averkov–Bianchi, *Confirmation of Matheron's conjecture on the covariogram of a planar convex body*, JEMS 11 (2009), 1187–1202, DOI 10.4171/JEMS/179.

Primary article: https://ems.press/journals/jems/articles/1922

The actual theorem determines every planar convex body from its ordinary area covariogram, among all planar convex bodies. In REPORT.md it is invoked only when the valuation is pure area or when a second independent measurement has explicitly recovered the area covariogram. It is not claimed to invert a single perimeter or mixed covariogram.

## Computational evidence

The authored checker uses only the Python standard library and explicit exception guards. It executes no downloaded source code, makes no network calls, and makes no external changes. Normal, -O and -OO runs each pass 61 checks, including 16 meaningful negative-input checks. Tests cover rational area reconstruction, curvature-pair algebra, scale separation, an exact triangle mixed-area example, lower-dimensional normalization negatives, and an elementary disk asymptotic constant.

The tests do not prove the arbitrary convex-geometric claims. The smooth bump construction and lens-localization proof are mathematical arguments, not finite-sample numerical certificates.
