# Independent analytic derivation frozen before previous verdicts

Target: every nonnegative row-stochastic n by n matrix, n >= 1. Write S = sum a_ij^2, h(a) = a^2 log(e/a), h(0)=0. Claim per A <= exp(-n + e^4 sum h(a)) <= exp(-n + e^4 S(1+log n)). For fixed gamma and S <= gamma this is an affirmative full answer to the original doubly stochastic polynomial-factor question; the known van der Waerden lower bound supplies the other side. Row stochasticity alone cannot give that lower bound. The norm is unnormalized. The pure power consequence only holds for n >= 2.

1. For any law on finite permutations, let B be its marginals, not the input matrix. At any positive-probability exposure history, the conditional law c is supported on unused columns with positive b. Put Z = sum of these b entries. Then Z > 0, r = b/Z is a probability law containing supp c, and KL(c||r) = sum c log(c/b) + log Z >= 0. Entropy chain rule, history averaging, and independent random row orders give H(X) + sum b log b <= sum E log Z. No conditional law on an impossible history is evaluated.

2. Conditional on a supported permutation and its row's independent uniform priority t, its own assigned column remains available; every other assigned column remains with probability 1-t. Hence E Z = b + (1-t)(1-b). Jensen supplies an upper bound on E log Z. Integrating gives -1 - b log b/(1-b). Sampling the assigned column introduces another b, so q(b) = -b^2 log b/(1-b); q(0)=0, q(1)=1. Summing proves H(X) <= -sum b log b - n + sum q(b). Finite supported permutation laws have a positive minimum among their sampled marginals, so logarithms are integrable without an unjustified endpoint limit. Deterministic laws check the q(1) normalization.

3. If per A = 0 the target is immediate. Otherwise Gibbs weights product a divided by per A define a law, with b>0 implying a>0 and doubly stochastic marginals B. The identity log per A = H(mu) + sum b log a gives <= -n + sum q(b) - Dmat, where Dmat = sum b log(b/a). Because both matrices have total mass n, Dmat = sum [b log(b/a)-b+a]. At b=0<a this summand is a and cannot be dropped. The divergence is n KL(B/n||A/n), distinct from an average divergence between sequential and Gibbs permutation distributions.

4. For d(b,a)=b log(b/a)-b+a, d>=0 on its permitted domain by x log x-x+1>=0. For b in (0,1), b log(1/b)<=1-b proves q(b)<=b. It also proves q(b)<=h(b): setting L=log(1/b), this is L/(1-b)<=1+L, equivalent to b L<=1-b. Both endpoint comparisons hold. h'=b(1+2log(1/b))>0 only on (0,1]. If b>=e^2 a, d>=b+a>=q. Otherwise, if b<=a, h(b)<=h(a); if a<b<e^2a, separately b^2<e^4a^2 and log(e/b)<=log(e/a). Thus q-d <= e^4 h(a), including a=b=0, b=0<a, b=1 and equality on the switch line. No monotonicity beyond one is used.

5. Sum the scalar inequality. By row Cauchy-Schwarz S>=1. The n^2 normalized weights p=a^2/S have H(p)<=2log n. Then sum a^2 log(1/a) = (S/2)(H(p)-log S)<=S log n, including zeros. This proves the second target. The constant e^(e^4 gamma) is necessary in the all-n display as a prefactor format; a pure n^C e^-n cannot bound per[1]=1. For n>=2, 1+log n<=3 log n. Fixed uniform k blocks of order m give S=k and (m!/m^m)^k ~ (2pi/k)^(k/2) n^(k/2)e^-n, establishing some necessary polynomial loss, not sharpness of the displayed e^4 constants.
