# Metadata forms and external file manifest

External `zenodo-deposit.json` contains exactly that same metadata object and a `files` list with `paper/forest_transfer_catalan.pdf` and `pr1037_supportkit_v1.0.zip`, relative to its location. It is excluded from the ZIP to avoid an archive self-reference. These local metadata/configuration files are not deposit, assigned-DOI, release or submission/publication records.

All three metadata objects carry the same neutral title, theorem limits, exact-match Ferudun credit, qualified chronology, sole author/ORCID, CC BY 4.0 and extensive AI/unrefereed disclosure. The publication date and version describe this authored exposition, not a claimed first discovery date. Source authors are credited sources, not coauthors. REVIEW_HISTORY.json distinguishes dated preparation and AI reviews by scope and frozen inputs; those records are not human refereeing, journal acceptance, formal certification or submission/publication records. CURRENT_REVIEW_STATE.json records the corresponding candidate operational state.
