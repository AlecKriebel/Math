## Mathematical audit and falsification attempts

A sign-preserving homeomorphism maps that vector to a positive multiple of the same singleton, because every other coordinate must stay zero. The target placement must therefore collide at that edge. Bijectivity proves the reverse direction too. The collision diagonal is consequently a union of whole equivalence classes and therefore of connected strata. This argument uses coordinate signs including zero; equal dimensions are insufficient.

For a missing edge, take i=t a, j=0 and the other labelled vertices at (k+1)a, with a nonzero and t in [-1/2,1/2]. Only the absent pair can collide. For every actual graph edge, the oriented scalar difference is nonzero and has constant sign. The vector equilibrium map is the scalar incidence map B D_t followed by multiplication at each vertex by a. That last map is injective because a is nonzero. Hence the kernel is exactly ker(B D_t). The formula T_t=D_t^(-1)D_0 has strictly positive diagonal entries, satisfies B D_t T_t=B D_0, and has the stated genuine inverse. It gives sign-preserving linear homeomorphisms for every parameter value, with orientation reversals cancelling in the ratio.

The entire continuous configuration path is inside one equivalence class. Its connected image, with the class's subspace topology, lies in a single connected component. This does not require every stratum to be path connected, a generic-rank assertion, local triviality or a stress-space bundle theorem. The path crosses the missing pair's diagonal inside one stratum. That diagonal is not a union of whole strata. The two directions reconstruct all edges from the partition and prove the equality theorem. The proof compares actual subsets of one fixed base; it does not compare edge-coordinate spaces of different graphs directly.

The proof covers d=1, n=1, n=2, empty graphs, zero fibres, isolated vertices, disconnected graphs, arbitrary density, full collisions and deficient affine spans.
