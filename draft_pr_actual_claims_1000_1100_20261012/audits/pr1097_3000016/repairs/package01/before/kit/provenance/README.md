# Captured-stage provenance

Every original audit file at preparation start is individually pinned and has exactly one custody decision. Selected authored records are exact bytes with their original relative path under `selected/`. The eight submitted originals are all included unchanged. Old pending/accepted fields describe their original dated stages; they do not override current paper framing or later root decisions.

For a historical reference, normalize its path relative to the original audit root and find its row in `CUSTODY.json`. An exact copy resolves to that row's `copy_path`; an excluded body/code/config resolves only to the hash and stated omission, not to an invented local file. Baseline stage equality is verified during preparation; after extraction only selected distributed bytes can be checked directly. Source bodies and historical omitted programs are not certified or replayed by the current checker.
