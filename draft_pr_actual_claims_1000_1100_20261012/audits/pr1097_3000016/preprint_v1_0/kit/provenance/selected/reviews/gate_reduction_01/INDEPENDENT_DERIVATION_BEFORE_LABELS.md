# Independent gate-reduction derivation before inherited audit labels

Written after reading only the actual submitted mathematical report and source bibliographic metadata; no sibling report, submitted mathematical audit, acceptance, or status has been consulted. The report itself has an inherited accepted label; that label supplies no evidence here.

Hypothesis: binary-encoded loopless strongly connected directed multigraph reachability with nonnegative source/target is coNP-complete by a deterministic Karp reduction from NONHALTING, contingent on the exact source language and coNP-membership theorem being authenticated.

For n>=2 and positive old degrees, let C be total chips, N=(C+1)^n, M=N+1 and B=N(MD+1). The augmented old threshold is Md_v+1; gate threshold nB+1 and marker threshold 1. Before the first gate, the marker is identically zero, and after t old firings the gate has nB+1-N+t chips. Thus the gate cannot fire until at least N old firings. For the first N projected old moves, before each move all odometer coordinates t_v<=N-1. The exact identity H_v=M z_v+N-t_v shows source-legal z_v>=d_v implies H-legal and source-illegal z_v<=d_v-1 implies H_v<=Md_v-1. Therefore all first N old moves project legally regardless of later schedules or final odometer.

A conserved nonnegative source system has at most N configurations. N legal steps repeat a configuration, whose nonempty legal word repeats indefinitely. A nonhalting instance admits arbitrarily long legal words; the abelian dichotomy prevents one execution terminating while another is infinite. This needs source positivity, finite conservation, and the loop convention, not a period-vector bound.

After precisely N legal old moves, source states remain nonnegative and old reserves N-t_v remain nonnegative. The first gate injects B into every old vertex. Each can complete its count to N in any order using at most N(Md_v+1)<=B of its own chips even if incoming old transfers are discarded. The prescribed net firing vector produces Y. Reverse direction needs no uniqueness of odometer: marker balance k_g-k_m=1 forces at least one gate. The first gate has no marker return before it, hence requires the first N legal old moves. Repeated later gates, marker firings, delayed first gate, and extra old cycles cannot change that prefix conclusion.

Y_old=Mx+MN(in-degree-out-degree)+B is at least B-MND=N. X_g>=1. Total chip conservation can be checked algebraically because sum in-degrees equals sum out-degrees. Strong connectivity follows from every old vertex reaching and being reached by the gate, plus the gate-marker cycle. The output has n+2 vertices; log N=n log(C+1), log M<=log N+1, log B<=log N+log(MD+1), hence polynomial binary size.

Relay removal: replacing each ell>0 loop group by ell old-to-relay and ell relay-to-old arcs preserves old thresholds. Expanded old states equal projected original states minus ell times pending relay returns at the corresponding vertex. Therefore each projected old firing is legal. Relay counts never exceed their corresponding old counts. Old executions lift by immediate relay returns; infinite expanded words must contain infinitely many old firings. A one-vertex input is elementary (zero-degree firing permitted if the definition admits it); replace it by a fixed two-cycle YES or NO before loop removal. Signed normalization adds offset chips and equal loop threshold offsets and preserves every firing word, if needed by a source reduction.

Falsification criteria: a target-reaching path for a halting source; an H-legal old move in the first N steps that is source-illegal; a pre-N gate or marker firing; insufficient cleanup reserve; negative output coordinate; failed strong connectivity; a source theorem that only covers unary, signed, non-strongly-connected, or other encoding; a membership theorem that excludes the chosen class; relay projection illegality; a nonpolynomial binary output bound. Fresh tests must enumerate arbitrary complete target state spaces where feasible and independently verify source state cycles, rather than replay a prescribed vector alone. Invalid variants should demonstrate that such tests detect gate threshold and simulation defects.
