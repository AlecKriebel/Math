# Rooted-arborescence ICP: a sharp splitting boundary

Problem 30001933 / OWR-11451-006, priority rank 1238. Accepted partial result from substantive attempt 1/5. The general rooted-arborescence Integer Carathéodory Property (ICP) question remains unresolved by this work.

## Accepted mathematical scope

1. If deleting the root leaves a cactus in the underlying simple undirected graph, the arborescence polytope belongs to the Gijswijt–Regts sufficient splitting class C and hence has ICP. Parallel arcs, either direction, disconnected cactus components and zero-coordinate degeneracies are covered.
2. Consequently every rooted directed multigraph on at most four vertices belongs to C.
3. An explicit five-vertex, eight-arc rooted graph is outside C: its intersection P ∩ (1−P) has the displayed fractional vertex. Five is the sharp vertex-count threshold for this failure.
4. The same five-vertex polytope has ICP by an explicit TU matching-flow lift and the published coordinate-projection theorem.

The complete symbolic proof is included: the integer-linear unique-lift lemma, universal cactus network, exact fractional-vertex argument, all-subsets matching representation, and projection argument for ICP. The nonunique-lift illustration uses the corrected arborescence {a,c,e,g}; the audit explains why the earlier pair {a,b} was infeasible.
