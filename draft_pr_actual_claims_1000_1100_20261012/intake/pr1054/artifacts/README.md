# Stable division converse: accepted partial approach

Problem 30005477, rank 1203, alias OWR-12697711-012. Status: **UNRESOLVED, 1/5 substantive approaches used**.

For a homogeneous ideal in Drury–Arveson space, the report proves that essential normality of the quotient tuple is equivalent to vanishing degreewise squared adjoint leakage. An exact restricted coordinate-row identity yields one fixed finite homogeneous generating family with a finite-product decomposition bound. Under essential normality that bound is subexponential in degree; summability of the squared leakage is an additional sufficient condition for a degree-independent stable-division constant.

The full converse is not proved. A principal radical ideal already has nonsummable leakage while its stable product-energy constant is one, so accumulated coefficient costs do not establish an obstruction to stable division. A second example proves instability of a prescribed pair in a prime infinite-codimensional ideal; one added generator repairs the entire displayed witness sequence. It gives neither an ideal-level counterexample nor essential normality of that example nor stability of the enlarged family on the whole ideal.
