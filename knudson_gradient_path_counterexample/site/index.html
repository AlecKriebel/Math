A four-vertex counterexample to Knudson’s persistence-gradient conjecture

Alec Kriebel · ORCID · Version 1.0.0 · 23 September 2026

A persistence pair need not have a gradient path in the matching formed from the incident persistence pairs. A triangulated interval already gives a counterexample.

Read the 3-page paperProof & verifiersZenodo upload kit

Four vertices. Three edges. Zero paths.

Insert the simplices in this order, with each face preceding its coface:

a, b, c, d, cd, bd, ac.

Over the field with two elements, reduce each boundary using earlier columns with the same latest nonzero row:

EdgeReduced boundaryPersistence pairIncident?
cdc + d(d, cd)Yes
bd(b + d) + (c + d) = b + c(c, bd)No
ac(a + c) + (b + c) = a + b(b, ac)No

Only the incident pair remains in the matching: VP = {(d, cd)}. A path from the critical edge ac must first descend to a or c. Both vertices are unmatched, so either path stops immediately.

Conclusion. The pair (b, ac) belongs to the persistence pairing, but its gradient-path count in VP is zero.

This disproves Conjecture 2 in Knudson’s 2008 Oberwolfach report, printed p. 1629. The signed boundary calculation in the paper extends the example to any field.

The field must stay fixed

The earlier pair (c, bd) has the path bd → d → cd → c. Cancelling it changes the matching and creates a path from ac to b. That is a path in a different field. The conjecture is about the original VP.

Ordered cancellations in related work, including Bauer, Lange, and Wardetzky’s surface simplification results, are consistent with this example.

Check it in seconds

Download and extract the proof package, then run these commands from its folder. Python 3.9 or later is sufficient; no packages or network access are needed.

python3 verification/verify.py
python3 verification/independent_check.py

The first checker combines boundary reduction, union-find and exhaustive path enumeration. The second reconstructs the barcode from ranks of component maps and checks signed reduction and path reversal. Both passed, including with Python optimization enabled.
