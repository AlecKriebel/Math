# OWR-3392-012 / 30001184

Candidate negative resolution of the generation-only GNS-extension conjecture.
The counterexample is a point-norm continuous, injective C*-E0 dilation of the
two-state Markov semigroup. Its dilation algebra is generated by forward time
translates of C^2, yet its GNS representation kernel is not invariant.

Read PROOF.md for the full construction, exact radical witness and scope.
Run `python3 verify.py` for standard-library exact algebra checks and
`python3 verify_manifest.py` for packet integrity. Checks supplement the proof;
they do not establish all real-time identities by finite testing.

Status: claimed_solved for the universal assertion under the stated generation
hypothesis, subject to fresh independent audit. The conditional extension
problem after separately imposing kernel-invariance, and stronger useful
minimality hypotheses, are not claimed solved. The source permits general
C*-dilations; the example is neither strong nor weak/corner. No claim of a
normal strongly continuous W*-counterexample or verified novelty is made.

Author proof work used one substantive route and stopped on a complete
counterexample. The packet contains original mathematical work and public
verification metadata only.
