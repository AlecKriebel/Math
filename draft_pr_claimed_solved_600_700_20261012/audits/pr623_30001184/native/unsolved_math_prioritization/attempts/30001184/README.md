# Generated continuous dilation with noninvariant GNS kernel

Rank 651; numeric ID 30001184; OWR-3392-012.

**Status: claimed_solved, 1/5 substantive author turns, for the generation-only
universal GNS-descent assertion.** An independent adversarial AI audit accepts
that scoped counterexample. This is an AI-assisted, unrefereed research claim;
literature priority is not established.

The construction is a general unital C*-E0 dilation of the two-state Markov
semigroup. Its dilation algebra is generated by forward translates of the
observed C^2, and its endomorphisms are injective and point-norm continuous.
Nevertheless, the GNS representation kernel is not invariant, so the proposed
passage fails at its first stage.

## Reproduce

Python 3 standard library only. From this directory, or use absolute script
paths from any working directory:

    python3 verify_publication.py
    python3 test_integrity.py

The first command checks an exact allowlist, all sizes and SHA-256 hashes,
both frozen manifests and their binding, the author verifier (76 assertions),
and the separately implemented audit verifier (237 assertions). Replay output
must exactly match the frozen result files. The test command exercises 12
negative integrity controls in disposable copies, under normal and optimized
Python. No input artifacts are altered. The wrapper launches original checks
with isolated, non-optimized Python so their assertions cannot be disabled by
an inherited PYTHONOPTIMIZE setting.

The finite arithmetic controls supplement the all-real-time proof and its
mathematical audit; they do not replace either. Manifest validation is integrity
checking, not a signature or a proof of mathematical correctness.
