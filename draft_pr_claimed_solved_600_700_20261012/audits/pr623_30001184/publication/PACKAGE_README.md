# Forward generation does not ensure GNS descent

Author: Alec Kriebel, independent researcher.
ORCID: https://orcid.org/0009-0001-9320-500X
Version: 1.0. Research note dated 13 October 2026.

The paper gives an explicit continuous general C*-dilation of the two-state
Markov semigroup, exactly generated by forward translates of C2, whose fixed
expectation-GNS kernel fails invariance at every positive time. It provides a
positive kernel witness for every time. Read `CURRENT_PRIORITY_AND_STATUS.md`
for mandatory antecedent credit and exact exclusions. That current notice
also corrects version-specific source locators in earlier
dated packets and review records, which are preserved as historical evidence.
The method is known; the negative source phenomenon is also a short unstated corollary of the prior
BFH clock construction. No literature-first claim is made.

AI tools were used extensively. This is unrefereed and has not received human
peer review. The written analytic proof carries the continuous-time theorem;
finite exact checks and numerical sanity checks supplement it.

## Reproduce

Use Python 3.12 and install the pinned `requirements.txt` in a fresh environment.
SymPy 1.14.0 is needed only for the additional prior-implication matrix checks;
the frozen candidate and most fresh checks use the standard library.
From an extracted package run:

    python3 verify_package.py

The verifier checks the exact inventory and every hash, copies the packet to a
temporary directory and replays the original wrapper, 12 negative integrity
controls, fresh operator/scope checks and both independent prior-implication
checks. The packet itself is not altered. It launches check programs with
isolated non-optimized Python, so inherited optimization cannot disable their
assertions. It rejects malformed or tampered inventories using explicit errors
even if the wrapper is invoked with optimized Python.

    python3 verify_package.py --integrity-only

To export the paper with Tectonic, keep build output outside the extracted
package so its exact inventory remains unchanged:

    tectonic --outdir /path/to/external-build gns_generation_counterexample.tex
