Invariance is a necessary quotient condition, not a useful new sufficient
minimality theorem. A route that restates it as minimality is blocked absent
a new independent mechanism. The counterexample rules out every condition
logically implied by forward generation alone; it does not rule out all
conditions called minimality. A different successful dilation of the same P
would not rescue universal descent for this fixed quadruple.
