## Result and credit

Smooth strictly Kähler boundary data on P¹ × ∂D admit a weak Bedford–Taylor HCMA solution that fails to be twice differentiable at an interior point. The construction uses Ross–Witt Nyström’s published finite-time contact-arc flow. A Green-function comparison and scalar Legendre argument locate the interior second-derivative jump. This package makes no novelty or priority claim.
