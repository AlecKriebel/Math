# Independent theorem-to-target proof

The literal question is unrestricted exact Lagrangian cobordism between Legendrian links in standard contact R3. Use Legendrian isotopy classes as the natural object equality; the witness below also has distinct underlying smooth knot types.

**Imported existence.** [Dimitroglou Rizell–Golovko, Corollary 1.5](https://arxiv.org/html/2409.00290v4) supplies a sufficiently stabilized mirror of 9_46 and a correspondingly stabilized standard unknot, with Lagrangian concordances both ways in standard R3. Both signs of stabilization are required; no numeric count is asserted here.

Call the knots A and B. A Legendrian stabilization is a smooth arc isotopy inside a ball relative its endpoints, so it preserves smooth knot type. The mirror of a nontrivial knot is nontrivial: reflecting a hypothetical isotopy to the unknot would isotope the original knot to an unknot. Thus A and B remain different smooth knot types. Every Legendrian isotopy is a smooth isotopy, so [A] differs from [B]. As an auxiliary primary check, [Schleimer's notes, Example 27](https://sschleimer.warwick.ac.uk/Teach/2010_MA3F2/knot_notes.pdf), printed pp30–31, give determinant 9 for 9_46, versus 1 for the unknot. No actual knot diagram or Seifert matrix was reconstructed computationally here.

Each concordance is an annulus with cylindrical Legendrian ends. For lambda=e^t alpha_std, its pullback eta is closed and vanishes pointwise on each end. An end circle generates H_1 of an annulus. Every period therefore vanishes, and eta=dF globally. F is constant separately on the two ends, as conventional exact cobordism requires. These constants need not coincide. Both annuli qualify for the literal exact relation independently of invoking the theorem's exactness adjective.

Consequently [A] precedes [B] and [B] precedes [A], yet [A] differs from [B]. Antisymmetry fails. Knots are one-component links, so the unrestricted link relation is not a partial order.

This proof is universal conditional on the attributed existence theorem.
