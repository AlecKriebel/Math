Universal mathematical audit

The closure-preserving map is P(m,w)=(m,w) at even m, and P(m,w)=(m+1,w sigma_m) at odd m. The positive terminal crossing is indispensable: inclusion alone adds a split component. P fixes each even tagged endpoint exactly. An unrestricted finite Markov chain therefore yields an even chain if every individual edge is converted explicitly.

The independent calculation gives the following complete coverage. N is the even padded level; block bounds refer to the largest permitted unshifted generator index.

| Unrestricted edge | Even original count | Odd original count |
|---|---|---|
| Defining relation in any context | Same relation at N | Same relation with positive padding tail retained |
| Conjugation | C, blocks at most N−1 | BC, blocks at most N−2, tail sigma_(N−1) |
| Right stabilization | D: append g_N sigma_(N+1), N to N+2 | T: b sigma_(N−1) to b g_(N−1), blocks at most N−2 |
| Right virtual exchange | R, blocks at most N−2 | BR, exchange index N−2, blocks at most N−3, padding tail |
| Left virtual exchange | L, unshifted blocks at most N−2 | BL, unshifted blocks at most N−3, shift both blocks, padding tail |

In particular, BL shifts both old blocks by one but does not shift the separate terminal padding crossing. The old left exchange is at index1, whereas odd padding is at index N−1. BR's old exchange is at index N−2. Confusing the total strand count with Kamada's block braid count would give an incorrect support bound; the submitted formulas avoid that error. Reversing each converted edge covers destabilizations and both arrow directions. Conjugation conventions agree after inverting the conjugator.

Every listed scheme is separately sound: C is conjugation; BC and T compare stabilizations of conjugate or identical old braids; D performs two right stabilizations; R/L are the two exact imported exchanges; BR/BL exchange old braids and then positively stabilize both sides. Odd auxiliary braids used in this soundness proof are not objects of the displayed even calculus. Applicability is tested by concrete word/block support, rather than an existential oracle for an arbitrary odd Markov path, so the claim is not circular.

Completeness follows by applying P to all vertices of the unrestricted chain and using the table on every edge. Soundness supplies the converse. Relations in arbitrary contexts remain valid after right inclusion, with the padding crossing outside the old context. The mixed relation and its inverse consequences cause no extra boundary difficulty. Proposition 3.1 followed by P represents arbitrary nonempty oriented virtual links, including disconnected links. There is no restriction to classical diagrams or knots.
