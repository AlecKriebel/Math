# Independent priority scope

The exact target is ordinary oriented closure, with every allowed state and each explicit move endpoint on an even number of strands. The candidate has four classical schemes (conjugation, retained-positive-terminal conjugation, terminal stabilization replacement, and two-strand stabilization) and eight virtual schemes after adding both exchanges and their retained-terminal forms. Arbitrary word blocks are allowed. This differs from plat or short-circuit closure and does not assert bounded geometric support or minimality.

An earlier theorem counts as an explicit answer only if its object category, ordinary closure, equivalence relation, and even-only move requirement match, or if it expressly supplies an equivalent even-only formulation. An unrestricted Markov theorem is foundational input; its mere availability or elementary deducibility is insufficient to establish that this exact answer was already stated.
