## Exact mathematical target and original source

Arthur J. Krener, *Open Problem: Global Observability of Spaces of Negative Curvature*, Oberwolfach Report 11/2009, printed pp.674–675, DOI [10.4171/OWR/2009/11](https://doi.org/10.4171/OWR/2009/11). The [publisher PDF](https://ems.press/content/serial-article-files/46211) has 88 pages, 747670 bytes and SHA-256 `ef407f7cb1bcf1793d9fb02001b1aa68515342649009e8bdd1c9aecfbf1b7fe9`. These printed pages are PDF pages 82–83, one based. Both complete contribution pages were visually read during this preparation using the preserved rendered primary pages.

The source uses local coordinates on a state manifold and arbitrary finite-dimensional Euclidean output. It defines observability by initial-state/output-history injectivity for some fixed T>0, and uses the exact variational Gramian. Uniform positive/bounded coefficients, uniformly negative curvature and geodesic completeness are the conjectured sufficient hypotheses. It does not state simple connectedness, a global Euclidean state chart, nonzero dynamics or a small-output restriction. The metric coefficient normalization is unspecified. The note verifies fixed-background and fixed-finite-atlas interpretations and excludes no coherent stated hypothesis.

The [publisher record](https://ems.press/journals/owr/articles/3394) reports submission 22 February 2009 and publication 23 December 2009. This authenticates an open-conjecture presentation in the 2009 publication. It does not prove continued worldwide openness through 2026 or exclude an older unrecognized implication of classical theory. Only the mathematical implication as printed is refuted.

The narrow supported description is a nonvacuous two-dimensional counterexample to Krener's conjecture as printed in OWR 11/2009, pp.674–675, obtained by an application of classical constructions.
