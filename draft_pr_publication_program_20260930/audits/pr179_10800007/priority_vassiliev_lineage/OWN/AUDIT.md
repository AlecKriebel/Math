## Result and exact documentary gap

This is a bounded retrieval result, not a claim of historical novelty or proof that no correction/resolution exists. The source explicitly supplied the complex-square-root embedding already in 2015. A prior source need not name these six coefficients to matter. ## Exact mathematical boundary check

Write a(x,y)=a₁x+a₂y+a₀ and b(x,y)=b₁x+b₂y+b₀. On the constant slice (a₁,a₂,a₀,b₁,b₂,b₀)=(0,0,−u,0,0,−v/2), the equations become (x+iy)²=u+iv. A section on any open coefficient neighborhood of 0 restricts to a square-root section on a disk about 0. If s(re^{it}) is that section, q(t)=s(re^{it})/(sqrt(r)e^{it/2}) is continuous and takes only ±1, so it is constant on [0,2π]. Its numerator repeats at the endpoints while its denominator changes sign, a contradiction. Thus no open neighborhood of 0 admits a section; every open cover includes such a member. No admissible open cover exists at any cardinality.

This establishes the literal obstruction independently of the historical search. It does not compute a genus over a deleted base. On C ∖ {0}, two slit domains give square-root branches; they omit 0. A punctured-base genus 2 theorem and the full-plane no-cover theorem have different hypotheses. The source's intended repair remains unknown. For fixed ε>0 the value 0 is an approximate square root when |ζ|<ε², so the local exact obstruction does not resolve Problem 2B.
