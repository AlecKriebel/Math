# No open exact-root cover for Vassiliev's quadratic family

This candidate research note gives the complete negative answer to the literal all-R6, ordinary-open-domain, continuous-exact-root question printed as Vassiliev2015Problem2A. No admissible cover exists at any cardinality. It uses classical topology and the source's own square-root slice. Historical firstness and guaranteed novelty are not established; no unprinted finite-genus repair or approximateProblem2B is solved.

The upload kit intends three files: no_open_root_cover.pdf, its standalone LaTeX source, and verification-package.zip.
