# Author, journal, preprint, and citation-chain priority subcheck

Audit cutoff: 2026-10-01 UTC. This is an independent subcheck within the PR12 priority audit, not a proof review or a certification of novelty. No sibling priority findings or candidate proof were read. Only the supplied source record was used to fix the question. No external communication or Git operations were performed.

## Exact claim and search outcome

The target is the equivalence of two-sided shadowing and generalized hyperbolicity for scalar composition operators `T_f(phi)=phi o f` on **every** `L^p`, `1 <= p < infinity`, induced by an invertible nonsingular bimeasurable dissipative transformation with bounded `T_f` and `T_f^{-1}` and a finite positive-measure wandering set, **without** bounded distortion. Arbitrary sigma-finite measure spaces, the endpoint `p=1`, and possible nonseparability matter. A theorem for all bounded linear operators on a restricted space is only a partial hit unless it covers this entire class.

**No exact all-p/no-bounded-distortion theorem was located in this author/update/citation subcheck.** This is a scoped negative search result. It does not establish that the problem remains open or that the PR's claim is novel. Positive prior content and several demonstrably incomplete author inventories prevent an absolute priority conclusion.

No assertion here promotes a general Banach counterexample into a counterexample in the scalar-composition subclass.
