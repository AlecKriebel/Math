The involution exchanges interiors, fixes one midpoint per edge and fixes the odd vertex class, yielding 2g+2 fixed points for n>=5. Riemann–Hurwitz makes its quotient genus zero.

2. An affine conjugate of the involution has derivative -I even when the conjugating map reverses orientation. Full cone shifts vanish in this congruence. This covers boundary sides as well as interior angles.
