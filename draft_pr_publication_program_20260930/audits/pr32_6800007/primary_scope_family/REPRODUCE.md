The first program reads Git objects, raw pinned data, read-only SQLite and the saved all-state GitHub payload; it does not call a generator or mutate Git/GH/shared files. Its raw prerequisites are ignored research copies under this family `tmp/`, including the two files freshly downloaded at the exact pinned revision. The current inventory and current local records are time-dependent; later replays need not recreate their earlier values. Frozen15-file and actual-base16-path checks remain deterministic.

The second program copies the frozen input into ignored local sandboxes. Its stdout/stderr artifacts are preserved under `control_outputs/`. It intentionally runs false-proof/deleted-proof and two failing arithmetic/cochain controls; exit1 for those latter controls is expected and asserted. All saved original receipts are reproduced byte for byte by the baseline runs. Neither original program reads the proof file.

For fresh source retrievals, use `fresh_fetch.py`, `extract_sources.py` and `complete_source_receipts.py`. Poppler/Ghostscript/Tesseract are local tools. A converted PDF or OCR text is a derivative; verify its source bytes and visually inspect the relevant pages. The2020 author-manuscript full text was read through the public web tool; its direct PDF failed and the publisher route returned HTML, so unavailable publisher bytes cannot be regenerated by asserting an equality. `source_binding_controls.py` tests those actual recorded distinctions. Primary reference copies are intentionally ignored rather than included in the first-party manifest.

The early seal is immutable and must not be regenerated after seeing the proof. `MANIFEST.json` excludes itself and the ignored research copies/isolated originals. It binds all retained first-party programs, receipts, report and control outputs; it certifies package bytes, not mathematical truth.

The supplementary Reid input-binding program requires the fresh ignored fivepage primary PDF/text at the URL/hash in `REID_RETRIEVAL.json`. It verifies exact relators and integer word/presentation consequences; it does not certify census geometry, hyperbolicity or exact holonomy. The complete source argument, including its own computational assumptions, is bounded in `BOUND_INPUT_RESULTS.json`.
