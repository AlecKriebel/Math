## Published older implication, with the full-algebra bridge

Primary ingredient A: Jeong/Park, Polynomial invariants and Vassiliev invariants, Geometry & Topology Monographs4 (2002), pp89–101, published 19 September 2002. Corollary1.5 p91 expressly gives polynomial restriction of every finite-order knot invariant to K connected summed with n copies of a fixed knot. Section3 pp96–97 uses numerical fields Q,R,C and unique restriction polynomials. The complete paper, including its sole figure and references, was read. This is an explicit old theorem about polynomials, not a theorem about radicals.

Primary ingredient B: Ng q-alg/9502017v2 pp12–13 identifies the integer degree-two Conway invariant a2. Jeong/Park p98 also records a2 as additive and as a basis element in order two. The normalization a2(trefoil)=1 follows directly from the Conway skein relation. Independently, Bar-Natan/Ron math/0309282v1 p1 explicitly records rational additive generation of the full rational knot-invariant algebra; that proves the rational knot route but by itself does not justify scalar extension or the full link route.

Let q(K)=a2(K); for links let q(L)=sum over components C of a2(C), forgetting other components when taking each component knot. q has integer actual values, is a symmetric ordinary invariant of order at most two, and is additive under inserting a trefoil connected-sum factor on one component. Let L_n be a split m-component link whose first component is the connected sum of n trefoils and whose other components are unknots.

For any v in the full C-valued link algebra, define w_v(K)=v(K split union (m-1) unknots). Self-crossing resolutions show w_v is a finite-order knot invariant of order at most the order of v. Ingredient A therefore gives a polynomial P_v with v(L_n)=P_v(n). This does not assume V_C=V_Q tensor C. The independent alternative proof inserts d+1 trefoil factors with marked unknotting crossings into L_n. The associated (d+1)-singular link evaluates to Delta^(d+1)v(L_n)=0, so Newton interpolation gives the same finite polynomial for arbitrary characteristic-zero coefficients.

Uniqueness on infinitely many nonnegative integers gives P_(v+w)=P_v+P_w, P_(vw)=P_v P_w, P_1=1. Hence phi(v)=P_v(1/2) is a character on the ENTIRE finite-order algebra. It remains defined when V includes all component counts: restrict to a single fixed m>=1. It also remains valid for unordered components because q is symmetric and the choice of component occurs only in the test family.

Put F=q(2q-1), I=FV. Actual integer q-values force Z(I)=Z(q), a nonempty set containing unlinks. Consequently q lies in I(Z(I)). But phi(q)=1/2 and phi(F)=0, so any claimed full-algebra identity q^N=Fh would yield (1/2)^N=0, impossible. Thus q is outside radical(I). This checks the ambient algebra obstruction, not merely nonmembership in C[q].
