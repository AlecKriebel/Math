# Zenodo upload kit
The deposit manifest and separate metadata JSON contain exactly the same metadata object. They identify one research note and three uploaded files: PDF, LaTeX source, and the verification archive. The verification archive includes the proof companion, exact standard-library checks, primary-source attribution/audit notes, access limits, and a SHA256 manifest.

Use the repository's top-level zenodo_deposit_tool with zenodo-deposit.json. Its local check is read-only. Staging is reversible; publication occurs only after independent whole-package review and requires the exact returned draft ID. Existing human authorization covers publication and the tracker row once all independent review gates pass. Dated preparation and publication receipts are maintained separately; this kit does not claim an upload has already occurred.

Archive entry timestamps are fixed for deterministic bytes and do not assert a creation or public-disclosure date. Third-party source PDFs, extracted text, page renders, service credentials, and operational run folders are excluded.

The metadata records extensive AI use, unrefereed status, old-method credit, limited historical priority findings, and the exact mathematical boundaries. No first-in-history claim or linking-number-generated ideal resolution is made.
