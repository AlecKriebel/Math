## Generic rays, exceptional rays, and the literal target

Fuchs's p.510 direction enumeration starts in an open fundamental interval; p.511 prints Conjecture2.6 after it. The authenticated imported target adds a global bare A0 characterization. The current proof correctly separates these scopes: direct diagonals at alpha=pi/n contradict that conjunction for n>=5, but this starting angle lies outside the odd open interval or on the even endpoint. This audit does not turn that example into a counterexample to the source's restricted generic-sector conjecture.

The parity convention selects one branch using the actual segment count and includes side representatives before reduction. Those details matter mathematically. They are already present in the contemporary comparison above, so explaining them carefully supplies verification value rather than a supported new-result claim. First-vertex existence is also part of the matched theorem, with an older complete-periodicity basis.
