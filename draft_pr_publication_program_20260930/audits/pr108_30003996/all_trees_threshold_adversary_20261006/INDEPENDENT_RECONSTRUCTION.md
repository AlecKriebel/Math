# Independently reconstructed all-size proof

Frozen before reading any author checker, previous review, or another audit.

The exact audited target is the sum, over every vertex r, of costs of the directed copies of the N-1 tree edges in the arborescence induced by T at r. Costs are indexed by roots and arcs. A cost on an r-to-v path in a single rooted tree would be a different target. The source leaves arc orientation conventional; reversal handles both conventions.

Assume a preprocessed 3-CNF formula with n >= 1 variables, m >= 1 nonempty clauses, no repeated literal, and no variable of both signs in any clause. Set B=n+1, K=Bm+n. The graph has hubs t,f, variables v_i, clauses q_j, hub edge tf, both edges t-v_i and f-v_i, and one q_j-v_i edge for each incidence. No graph edge has two clause endpoints. All vectors except the one at t and those at clause roots are zero. At t, both arc copies of tf cost 0, of hub-variable edges cost 1, and of clause-variable edges cost B. At clause root q_j, the only possibly nonzero arcs are v_i->t or v_i->f for variables present in clause j; the value is 1 when the sign in that clause disagrees with that hub, and 0 otherwise. All their reverses cost 0.

For ANY spanning tree, not just a tree obtained from an assignment, let h be the indicator of tf, p the count of hub-variable edges, and q the count of clause-variable edges. Every clause has degree >= 1, and each clause-variable edge contributes to exactly one clause degree. Thus q >= m. Edge counting gives p+q+h=n+m+1. Consequently the exact t-root contribution is

p+Bq = n+m+1-h+nq = K+(1-h)+n(q-m).

Here 1-h >= 0 and q-m >= 0. All costs at other roots are also nonnegative. Since n >= 1, cost <= K implies h=1, q=m, and zero other-root contribution. Equality q=m together with every clause degree >=1 forces every clause degree exactly1. Removing all clause leaves leaves a connected acyclic graph on t,f and all variable vertices. Since tf remains, every variable has at least one hub edge by connectivity and cannot have two, because those edges and tf form a triangle. Therefore it has exactly one. This eliminates all bridge-variable, missing-hub, multiple-clause-attachment and hub-cycle escape routes at threshold. Each variable's chosen hub defines its truth value.

Conversely take any truth assignment and one variable occurring in each clause. Keep tf, exactly one hub edge per variable according to the assignment, and the chosen incidence edge per clause. Its hub-variable core is two stars joined by tf and is connected and acyclic; adjoining clause leaves preserves both properties. It is a spanning tree with t-root cost K.

Now root any such tree away from a particular clause q_j, whose chosen neighbor is v_s. Removing the hub edge of v_s separates a component containing q_j from its chosen hub, so that edge points v_s->h_s. For EVERY other variable v_i, removal of its unique hub edge leaves on the variable side only v_i and the clauses attached to it; q_j is on the hub side, because i != s. That edge thus points h_i->v_i. The root q_j cost table has nonzero entries only for variable-to-hub arcs; therefore no unselected variable, hub edge, clause edge or root contributes by accident. Its contribution is exactly 0 if the selected literal is true and 1 otherwise. This holds even when many different clause leaves choose the same variable. Summing the root contributions yields K plus the number of false selected literals, only for these structured trees.

A satisfying assignment chooses a true literal for every clause and yields cost K. Conversely any tree of cost <= K is structured by the first lemma, and every selected literal is true by the second. Hence all clauses are satisfied. This is the exact decision equivalence. No equality between the optimum over ALL trees and K plus a minimum-unsatisfied-clause count has been used or established.

The graph is connected (every variable touches both hubs; every nonempty clause touches at least one variable), simple, and has N=n+m+2 vertices and at most 1+2n+3m edges. Explicitly giving every root/arc entry takes 2N|E| entries. Entries are at most n+1 and K=nm+m+n <= O(N^2). Thus binary and unary output lengths are polynomial in an ordinary explicit formula input after relabeling distinct variable symbols. The dense zero entries do not change this. A tree certificate can be verified by connectivity/acyclicity and N root traversals, summing polynomially many explicitly encoded integers with polynomial bit length. The decision problem is in NP and the reduction proves strong NP-completeness, subject only to the standard imported NP-completeness of at-most-three-literals-per-clause SAT.

For positive costs, adding 1 to EACH arc for EACH root increases EVERY spanning-tree objective by precisely N(N-1); shifting the threshold by that number preserves the equivalence. For inward orientation replace c_r(u,v) by c_r(v,u); the induced edge orientations reverse and every objective agrees exactly. The finite nonnegative integer subclass is contained in the source's real cost model, so optimizing that general model is NP-hard; no NP-completeness claim for arbitrary unencoded reals is justified or needed.

Preprocessing deserves explicit treatment. Repeated literals can be removed. A tautological clause can be deleted. Any empty clause makes the formula false. No remaining clauses makes it true. Either trivial case can be sent to fixed connected simple two-vertex decision instances with threshold 0: both root/arc vectors zero for a yes-instance, or both directed arcs at one root equal 1 for a no-instance. With nonempty remaining clauses, at least one occurring variable exists. Unused declared variables can be retained if their count is explicit and polynomial, or discarded; sparse or large numeric names must be relabeled by the distinct occurring symbols, rather than expanding to the largest ID.
