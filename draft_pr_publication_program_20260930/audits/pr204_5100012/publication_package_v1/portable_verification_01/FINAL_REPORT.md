## What is portable

verify_portable.py uses only Python's standard library. INPUT_PINS.json pins142
planned publication-material files by relative path,size,SHA256; its own hash
is fixed in the driver. The paths cover original20,source10,complex parent6
plus v2's8,direct8 excluding its private512477-byte inventory,physical47,
repair31,and priority12. Historical records are pinned as records, while live
execution uses only the authored independent verifiers and repaired original
derivatives. No historical bare-assert verifier or historical fixed-runtime
audit wrapper is executed.

Explicit --materials is supported and used in the actual run. Documented
relative defaults cover sibling/parent materials and the original A204
layout. There is no home-directory constant. --output accepts a new owned
receipt path or stdout; --work-dir selects disposable storage. All writes
target temporary layouts and the requested receipt/evidence files, outside
the immutable material families. Material paths containing symlinks are
rejected, and output/work paths are resolved before checking protected roots.

Every scientific subprocess receives -B, the appropriate ordinary/-O flag,
PYTHONDONTWRITEBYTECODE=1 and PYTHONHASHSEED=0. Existing
PR204_RUNTIME_PACKAGES or PYTHONPATH can select dependencies; otherwise
installed packages are used. SymPy1.14.0 and mpmath1.3.0 are required. Nothing
is installed, downloaded or copied from dependencies. The actual software
locations and relevant environment overrides are recorded.

Each case copies only its byte-checked live source, the necessary historical
proof input for the repaired author, or the complex verifier's sealed
six-file parent fixture. The complex-v2 standalone verifier runs directly,
with its exact parent manifest present and checked. Historical PROOF.md is
explicitly a historical hash-binding input, never a new manuscript. Temporary
case layouts are removed immediately in finally, including setup failures.
The actual run uses two workers; the two largest concurrent logical fixtures
contain about84KB total before filesystem metadata overhead.
