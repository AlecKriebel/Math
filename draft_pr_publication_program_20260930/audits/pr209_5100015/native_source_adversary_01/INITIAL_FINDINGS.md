# Initial pinned-source adversarial findings

Status: **CHANGES_REQUIRED** for the initial source bundle only. Replacement sources are not yet pinned or reviewed.

Exact initial pins are in `INITIAL_SOURCE_FREEZE.json`; the three frozen source files are in `source_freeze_initial/`. `audit_initial_offline.py` executes actual frozen functions against synthetic in-memory native providers and files beneath this audit folder. It globally disables the actual subprocess transport. Run with Python 3.14 `-E -S -B -P`; the 30-assertion result is `INITIAL_OFFLINE_RESULTS.json`. The harness uses a synthetic loader to isolate executor/state/verify mechanisms; it does not simulate Root authority or certify a real manifest.

1. **Mandatory: refresh ready PR state before each immutable object POST.** Change the provider's PR209 HEAD after the first binary POST, preserving MAIN. The source still dispatches tree and commit; only subsequent verification rejects. `candidate_live_PR_drift_gap` records all three POSTs. Re-run live source/gate/PR/native-preimage guards before every POST.
2. **Mandatory: refresh local preimages before every POST.** Change a local log after the tree POST. The source still dispatches the commit (`candidate_commit_local_preimage_gap`). Recheck every exact local preimage immediately before dispatch.
3. **Mandatory: bind the existing lock's identity.** Replace a synthetic lock with the identical payload on a distinct inode. `WriterLock` accepts the replacement (`replaced_same_payload_lock_accepted_gap`), because it captures whatever inode it sees. Pin the externally accepted device/inode/payload in the manifest and recheck under flock; never recreate/unlink/replace the actual existing lock.
4. **Mandatory: use descriptor-safe bounded local reads.** The harness replaces the checked regular file with a symlink from the `Path.read_bytes` call boundary. The reader follows the new target and returns its pin (`local_read_symlink_swap_gap`). Use bounded descriptor reads with nofollow, regular-file and identity checks, and safe ancestor traversal before reading; include a race control for directory components as well.
5. **Mandatory: make uncertain immutable object reconciliation possible.** A timeout creates a durable one-dispatch intent and correctly stops that API instance. However, the commit intent contains only a request hash, without the exact reconstructible request or expected object SHA; the original POST also leaves commit timestamps to GitHub. Thus the object cannot be read back by a known identity after a lost response. Store an exact deterministic request and expected native object ID before dispatch; bind a persistent same-attempt guard; reconcile with GET only and do not redispatch automatically.
6. **Mandatory: revalidate source, manifest, Root envelopes, native MAIN and local preimages before each sync install and final receipt/pointer.** Replace the sealed synthetic CAS receipt after VIEW_0 is installed. The source installs all remaining views and creates its actual pointer (`sync_gate_not_refreshed_before_each_effect_gap`) even though `actual_acceptance` now rejects that envelope. The current in-lock refresh happens only once before the loop.
7. **Mandatory from full-source inspection: bound transport while reading.** `subprocess.run(capture_output=True)` buffers all stdout/stderr before checking stdout size; stderr is uncapped. Replace with capped streaming reads and timeout/kill/reap; test overflow on both channels.

Positive controls verify canonical native reconstruction and independent delta checking, opaque preservation of foreign trees including executables/symlinks/gitlinks/empty directories, stale native-preimage rejection, duplicate JSON rejection, unsafe-path rejection, strict byte-count types, static symlink rejection, and same-instance fail-closed uncertain transport.

No native API, Git command, production view/lock, service, publication, tracker, human outreach or other-chat tool was used. No mathematical or priority conclusion is promoted here. No real Root manifest, candidate, CAS or local sync is approved.
