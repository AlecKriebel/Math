# Sources and attribution for the current verification

The exact reference formula is arXiv:2004.12497v11, Table 9, printed p. 11, k804,a: A times A_j^dagger for N congruent 0 modulo 4. Section 2 defines signed consecutive cross-product area; Section 3.9 defines unit-radius inversion of original orbit vertices about original focus f_j. The introduction specifies a confocal ellipse pair. The source does **not** explicitly define N as a least period or exclude repeated shorter cycles. The current positive theorem therefore states its least-period interpretation explicitly. [Original version](https://arxiv.org/abs/2004.12497v11).

The published *Fifty New Invariants*, Table 9, printed p. 350, instead labels an inverse-angle cosine sum k804 and omits this product row. Garcia and Reznik's later *Exploring self-intersected N-periodics*, Table 1, printed p. 7, labels the area product k805,a; the derived column lists 4,4i,8. Proposition 4.9, printed p. 10, gives the simple N=4 value 4. Its 4i concerns a hyperbolic caustic, outside the strictly elliptical theorem. [Published companion](https://doi.org/10.1007/s40598-021-00174-y), [later paper](https://doi.org/10.33039/ami.2022.02.001).

Alper Ferudun's *Focal Inversion Area Products in Elliptic Billiards*, [DOI 10.5281/zenodo.23093706](https://doi.org/10.5281/zenodo.23093706), already states and proves the same least-period theorem, including either focus, coprime stars and repetition scaling, and excludes the unrestricted repeated-list reading. This is Ferudun's DOI, not an identifier assigned to this verification note. No historical firstness, causal independence or simultaneous discovery is inferred from dated records.

Stachel's [Theorem 4.3 and equation (4.9)](https://doi.org/10.1007/s40879-021-00524-2), printed p. 1614, supply canonical coordinates, the vertex shift 2v and coprime closure. The Jacobi modulus is c/alpha; numerical libraries using the parameter require its square. Use dn(u+2K)=dn(u); the opposite sign printed in the surrounding p. 1613 is a source typo. Correct periods/shifts are in [DLMF 22.4](https://dlmf.nist.gov/22.4); see also [22.2](https://dlmf.nist.gov/22.2), [22.6](https://dlmf.nist.gov/22.6), [22.8](https://dlmf.nist.gov/22.8), [22.11.3](https://dlmf.nist.gov/22.11.E3), and [22.13](https://dlmf.nist.gov/22.13).

The local partial-fraction, cyclic master and generalized Landen mechanisms are classical: Khare, Lakshminarayan and Sukhatme, [local identity (42)](https://arxiv.org/abs/math-ph/0306028) and [cyclic identity (20)](https://arxiv.org/abs/math-ph/0207019v2); Khare and Sukhatme, [Landen identities (13), (71)](https://arxiv.org/abs/math-ph/0312074). Chavez-Caliz's [Theorem 6](https://doi.org/10.1007/s40598-020-00154-8) proves the related even-period original/outer-tangent area product; it still requires a focal-specific reduction here. No theorem or method novelty is claimed.
