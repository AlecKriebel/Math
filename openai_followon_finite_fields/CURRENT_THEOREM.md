# Exact target and current strongest result

Target (unproved here): for prime p (binary), m>=1, monic irreducible h in F_p[t] of degree m, and nonzero dense f over K=F_p[t]/h of degree n, output its leading coefficient and distinct monic irreducible factors with positive multiplicities using bit operations polynomial in (n+1)m ceil(log2 p), including field-representation input. h may be supplied with an irreducibility promise or verified deterministically. Construct monic irreducibles of prescribed degree d>=1 over K with complexity polynomial in input plus dense output size (at least dm log p). Degree polynomial is not polynomial in binary log d. Zero polynomial is excluded: it has no unique finite complete factorization; constants return an empty list. No randomness, GRH, integer-factorization oracle or primitive-root oracle is allowed.

Current status: target is a hypothesis; no unconditional resolution certified. Classical conditional reduction from prime-field factoring is being proved and implemented. Family142 depends on family029 uniform Hecke zero-freeness over varying cyclotomic fields containing the twelfth roots of unity, not solely family003 over Q(sqrt(-3)). Both the pivotal analytic dependency and algebraic splitter must pass independent examination. No formal verification of this follow-on is claimed.

Success requires a correct uniform bit model, complete proof or validated exact dependencies, current priority/attribution audit, reproducible code for feasible reductions, two complete-package review passes with final fresh review, actual production publication and verified tracker entry. Publication withheld if core dependency remains unsupported or proof is duplicated without a new in-scope contribution.
