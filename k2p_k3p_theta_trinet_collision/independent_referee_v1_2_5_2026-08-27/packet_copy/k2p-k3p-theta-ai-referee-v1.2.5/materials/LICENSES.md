# Licensing boundaries

This research package contains different kinds of material. A single license
should not be inferred for the whole directory.

## Executable verifier and build code

The executable Python and shell source files (`*.py` and `*.sh`) in this
canonical directory are licensed under the MIT License in `LICENSE-CODE`.

## Manuscript and prose

Copyright in the manuscript PDFs, TeX sources, figures, README files, research
notes, and other prose is retained by Alec Kriebel unless a file states
otherwise. The bioRxiv distribution/reuse option is an author-controlled choice
made in the submission system. This repository deliberately does not select it.

bioRxiv currently offers CC BY, CC BY-NC, CC BY-ND, CC BY-NC-ND, CC0, and a
no-reuse option. The author should select an option only after checking funder
and intended-journal policies. The choice must also be recorded in the final
submission checklist.

## Certificates and verification transcripts

No separate reuse license has yet been assigned to the JSON certificates or
verification transcripts. Before a Zenodo deposit, the author must choose and
record a package/data license in the author-facing Zenodo metadata template.
The MIT code license does not make that choice implicitly.

The exact license displayed on bioRxiv and the license attached to a separate
Zenodo reproducibility deposit need not be identical, but both should be chosen
deliberately and described without suggesting that one automatically governs
the other.
