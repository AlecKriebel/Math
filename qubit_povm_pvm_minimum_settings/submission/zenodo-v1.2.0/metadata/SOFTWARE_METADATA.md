## Description

This record archives the exact verification and reproducibility package for
version 1.2.0 of the associated preprint. It contains rational Bell
coefficients, exact states and POVMs, separation and Lorentz-incidence
symbolic checks, an exact rank-zero simulator, manuscript source and PDFs,
proof/dependency/priority/risk audits, a theorem-to-artifact map, and a one-
command offline runner.

The programs verify finite exact identities and explicit constructions. They
do not formally verify the universal convexity, extremality, physical-
reconstruction, multiplier, or rank-exhaustion arguments, which remain
mathematical proofs in the associated paper.

Associated paper concept: <https://doi.org/10.5281/zenodo.21699160>.
Generative-AI systems were used substantively; the human author accepts
responsibility for the released package.
