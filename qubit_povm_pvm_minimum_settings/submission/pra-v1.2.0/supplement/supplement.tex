\section{Purpose and verification boundary}

The main article is self-contained and contains every load-bearing proof.
This supplement collects the exact witness data, finite-certificate map, and
reproducibility instructions in a compact referee-facing form. The executable
checks verify exact algebraic identities and explicit constructions. They do
not formally prove compactness, convex separation, arbitrary-output extremal
reduction, physical reconstruction, multiplier positivity, or exhaustion of
the rank trichotomy; those are manuscript arguments.

No empirical data were generated or analyzed. The public version-1.1.0
software archive is \url{https://doi.org/10.5281/zenodo.21699224}.
Its stable concept DOI is \url{https://doi.org/10.5281/zenodo.21699223}.
At the time this author-review package was prepared, no version-specific
1.2.0 software DOI had yet been reserved; the current DOI will be inserted
before journal submission.

\section{Exact rational \texorpdfstring{\(3\times2\)}{3-by-2} witness}

Alice has inputs \(x=0,1,2\), Bob has inputs \(y=0,1\), and signs
\[
\alpha_0=\alpha_2=1,\quad \alpha_1=-1,\qquad
\beta_0=1,\quad\beta_1=-1.
\]
With
\[
E_{xy}=\sum_{a=0}^2\sum_{b=0}^1
\alpha_a\beta_b p(a,b|x,y),
\]
the Bell functional is
\[
\mathcal B=10(E_{00}+E_{01}+E_{10}-E_{11})
+\frac35p(0,0|2,0)+\frac35p(1,1|2,0)
+\frac45p(2,0|2,1).
\]
For \(x=0,1\), labels \(0\) and \(2\) have identical coefficients and may
be coarse-grained, so the heterogeneous output architecture is
\((2,2,3)\)-by-\((2,2)\).

Use \(|\Phi^+\rangle=(|00\rangle+|11\rangle)/\sqrt2\), Bob observables
\(B_0=Z,B_1=X\), and Alice observables
\(A_0=(Z+X)/\sqrt2\), \(A_1=(Z-X)/\sqrt2\). Alice's ternary effects are
\[
M_0=\frac{17\id-8X+15Z}{50},\qquad
M_1=\frac{17\id-8X-15Z}{50},\qquad
M_2=\frac{16\id+16X}{50}.
\]
Their rank-one factorizations are
\[
M_0=\frac1{25}\binom4{-1}(4,-1),\quad
M_1=\frac1{25}\binom1{-4}(1,-4),\quad
M_2=\frac8{25}\binom11(1,1).
\]
They sum to \(\id\) and have nonzero eigenvalues
\(17/25,17/25,16/25\). The exact certified chain is
\[
\beta_{\rm POVM}\ge L_0:=20\sqrt2+\frac{16}{25}
>U:=20\sqrt2+\frac35+\frac{4+3\sqrt2}{250}
\ge\beta_{\rm PVM},
\]
with
\[
L_0-U=\frac{3(2-\sqrt2)}{250}>0.
\]
These are an attained lower bound and a global upper bound, not asserted
global optima.

\section{Exact runner and environment}

From the top-level project directory, execute
\begin{verbatim}
./run_all.sh
./paper/build.sh
\end{verbatim}
The reference environment is Python 3.14.6 with SymPy 1.14.0. The PDFs are
built with Tectonic 0.16.9. The exact runner:
\begin{enumerate}[leftmargin=*]
\item verifies the SHA-256 hashes of the eight mathematical artifacts;
\item checks the dense and sparse Bell coefficient tables;
\item checks both explicit strategies, their exact values, and dual data;
\item checks the polynomial identities in the global PVM bound;
\item checks the Lorentz metric, quadratic null-ray map, generic inverse,
exceptional branches, resultants, and second-form regression;
\item checks bounded-flow identities; and
\item runs an independently written exact rank-zero simulator.
\end{enumerate}

The runner is offline and uses no numerical optimization. A successful run is
not represented as formal verification of the universal theorem.
