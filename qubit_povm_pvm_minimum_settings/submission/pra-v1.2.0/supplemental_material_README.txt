Supplemental Material for “Minimum Bell-Setting Complexity for Qubit
POVM–PVM Separation” by Alec Kriebel.

The separate PDF supplies exact Bell-coefficient tables, a concise map from
the manuscript's theorems to finite executable certificates, verifier
instructions, artifact hashes, and an explicit verification boundary. The
main manuscript is self-contained; no load-bearing proof is deferred to the
Supplemental Material. A companion artifact directory and ZIP contain the
machine-readable tables and review aids named by the PDF.

The version-specific paper and software DOIs must be inserted before journal
submission. The bracketed DOI tokens in the unpublished package are not
assigned identifiers.
