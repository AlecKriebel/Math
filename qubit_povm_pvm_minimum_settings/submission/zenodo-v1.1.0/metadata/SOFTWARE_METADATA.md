## Description

This record archives the exact verification and reproducibility package
accompanying the preprint “Minimum Bell-Setting Complexity for Qubit POVM–PVM
Separation.”

The package includes:

- exact rational Bell-coefficient tables;
- exact qubit states and POVM strategies;
- symbolic verification of the \(3\times2\) separation certificate;
- symbolic checks of the Lorentz metric, null-ray map, exceptional fibers,
  and incidence second-variation identities;
- an exact rank-zero deterministic simulator;
- the complete manuscript source and rendered PDFs;
- proof, dependency, literature-priority, equivalence, and risk audits;
- a theorem-to-artifact map and focused expert-review packet; and
- a one-command offline verification runner.

Reference environment: Python 3.14.6 and SymPy 1.14.0. The manuscript PDFs
build with Tectonic 0.16.9.

The executable checks verify finite exact algebraic identities and explicit
constructions. They do not constitute formal verification of the universal
convexity, extremality, physical-reconstruction, or rank-exhaustion arguments,
which are supplied as mathematical proofs in the associated manuscript.
