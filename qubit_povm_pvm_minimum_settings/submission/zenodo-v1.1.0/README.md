## What to upload

For the **Publication / Preprint** record, upload all four files in
`publication/` separately. Select the ordinary paper PDF, whose filename ends
in `-v1.1.0.pdf`, as the default preview.

For the **Software** record, upload the single ZIP file in `software/`.
Do not upload the helper metadata files or additional files to that record.

The `metadata/` directory contains copy-ready field values, descriptions,
keywords, relation instructions, archive-specific source files, and the final
upload checklist. It is not itself part of either Zenodo deposit.

`SHA256SUMS.txt` authenticates every prepared deposit file and helper file.
