# Corrections and revision status

Version 1.2.0 is a bibliographic, positioning, disclosure, and submission-
production revision. It does not correct or alter a mathematical statement.

The revision adds independent contemporaneous work that appeared after the
public 1.1.0 deposit, clarifies which exact claims overlap, and records the
distinct two-input equality and minimum-setting theorem more prominently.

No known erratum applies to the theorem, proof, Bell coefficients, explicit
strategies, analytic PVM bound, or verification artifacts. If expert review
identifies a substantive issue, it will be handled in a separately preserved
version rather than by replacing a public file in place.
