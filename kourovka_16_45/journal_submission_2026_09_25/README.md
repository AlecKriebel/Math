# Kourovka 16.45 journal submission edition

This effort reviews and prepares the counterexample for the **Bulletin of the
Australian Mathematical Society**. The original version 1.0.1 preprint remains
unchanged in the parent problem directory and on Zenodo.

- [Complete submission kit](output/Kourovka16_45_Bulletin_Submission_Kit.zip)
- [Upload instructions](upload/START_HERE.md)
- [Seven-page journal manuscript](output/pdf/kourovka_16_45.pdf)
- [Three-page exact verification note](output/pdf/verification_note.pdf)
- [Author review summary](upload/Review_Summary.md)
- [Research log](RESEARCH_LOG.md)

The main PDF uses the official `baustms` class. The source can also render in
a standalone editor using the AMS fallback, but the packaged PDF uses journal
typography. Exact verification sources, clean replay commands, and expected
certificates are in `supplement/`; the paper cites immutable commit
`be0f06ee0c61739dcda5629e2c4223e7da7951d3` for that package.

Independent structural, computational, literature, final-referee and delivery
reports are retained in `review/`. These are AI-assisted internal audits,
not external human peer review. No substantive proof defect or novelty blocker
was found within their recorded scope. Acceptance is an editorial decision.

Archiv der Mathematik was initially investigated, but its live submission
agreement bars articles largely written by AI. The final target instead has
explicit published provisions for disclosed AI-generated content. The
manuscript retains the full substantive assistance disclosure.

No journal submission, agreement acceptance or external correspondence was
performed. Only the author should complete the journal portal steps.
