# Established inputs and precise primary-source scope

The proof has two established mathematical imports, not new claims:
1. A 2-vertex-connected graph is factor-critical iff it has an all-odd OPEN
ear decomposition. Lovasz, A note on factor-critical graphs, Studia Sci.
Math. Hungar. 7 (1972), 279-280; used in the precise form of Benchetrit--Sebo,
arXiv:1509.05586v1, Theorem 3.2. The original 1972 proof was not recovered in this
preparation. The actual B--S body, Section 1.1 definitions, Proposition 1.13,
Section 3.1/Theorem 3.2/Question 3.3, and Section 3.2 boundaries were read.
The source's obvious ambient-letter typo in its ear-definition sentence is
resolved by its explicit open qualifier/ear count and the author's 2016
primary exposition https://matroidunion.org/?p=1769. Used edges are not
repeated; attachment at a single vertex is excluded. The paper directly
proves extension, induced completion, and all cone/reduction arguments.
2. Explicitly encoded Set Cover is NP-complete. Karp, Reducibility among
combinatorial problems, 1972, 85-103, DOI 10.1007/978-1-4684-2001-2_9. An actual
facsimile reprint was retrieved and its Main Theorem / Set Covering on original
printed 94 and Node Cover to Set Covering map on original 98 visually read.
Primary facsimile https://www.cs.umd.edu/~gasarch/BLOGPAPERS/Karp.pdf.
This is source-problem hardness, not prior publication of graph beta.

Question provenance: Sebo, Problems about uniform covers, with tours and
detours, OWR 51/2014, 2912-2915, Question 4 printed 2914. Actual entire contribution
and printed 2914 rendered page read; the same page's hereditary-hypergraph
Set Cover theorem concerns a different question. Exact primary PDF
https://ems.press/content/serial-article-files/46541. Benchetrit--Sebo 2015
Question 3.3 repeats the question. Its arXiv landing page currently lists only
v1, 18 September 2015; no distinct later full solution is inferred from it.
