# Accepted publication: relative-flow positivity loss

Accepted and merged as PR #521 on 12 October 2026. The current corrected exposition is **Loss of total-space positivity for the normalized relative Kähler–Ricci flow**, Alec Kriebel, version 1.0.

[Published paper and exact verification/source package](https://doi.org/10.5281/zenodo.23331080)

The result is a negative answer to total-space positivity preservation for Naumann’s defining probability-normalized equation (13): a smooth globally strictly positive O(2,2) initial metric has horizontal curvature exactly −1/96 at time (log 2)/2, while fiber curvature remains positive. The flow construction was already known. The result does not settle the Griffiths conjecture or address other normalizations.
