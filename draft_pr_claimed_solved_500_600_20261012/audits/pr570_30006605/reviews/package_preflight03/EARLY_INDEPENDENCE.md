## Universal bridge, independently derived

For each nonnegative threshold R, each integer distance t in [0,D] satisfies t*w <= R exactly when t <= max{k in [0,D]: k*w <= R}. This is true for zero weight, for R=0, equality, and the capped endpoint. Subtracting that budget from D turns all constraints into t+a <= D. The additive eccentricity array therefore returns exactly every feasible vertex. Binary search over integer indices costs O(log(2n)) exact bounded-multiple comparisons per weight, including a zero row. D=n-1 is valid for any finite connected unit-edge graph; medianity enters only the oracle.

Each vertex radius is attained at a pair (u,k), and an optimum over finitely many vertices is one of the n conceptual rows (0,w,...,Dw). A feasible incumbent D*max(w) has every vertex as witness. Retaining inclusive row intervals and deleting the weak upper side after a feasible pivot requires saving the pivot only when it decreases the incumbent. The invariant is: the incumbent is feasible, and either it is optimum or at least one remaining row entry is optimum. Infeasible deletion is also safe. Empty intervals imply incumbent equals optimum; the saved feasible witness is a center and the final threshold returns exactly all centers.

A lower row midpoint has at least L/2 entries on both weak sides. A weighted median of row midpoints with weight L has at least M/2 weak row weight on either side. Whichever branch is taken, at least M/4 entries are removed, including ties, repeated zero values, and singleton intervals. Initially M=n^2; O(log(2n)) calls suffice. Sorting and row deletions add O(n log^2(2n)) total comparison work, dominated by O(n log^5(2n)) oracle work. A rational comparison uses bounded integer multiples of cross-products; the model is not an encoding-independent bit claim.

## Imported source mechanism, reconstructed rather than black-box assumed

The imported additive objective is max_y(d(x,y)+a(y)), not multiplicative weighting. BDH allows nonnegative integer labels. Incident ladder classes that separate a vertex from the root form a pairwise orthogonal family and hence have cardinality at most log_2(s).

When all cuts are unbalanced and f(s)>=2, there is no equal-size cut. The majority median is unique: all majority halfspaces intersect at the median set, and an edge in a nontrivial median interval would force an equal-size cut. Select a farthest-to-root vertex z for additive labels, preferring the root itself in a tie. If root is farthest, triangle inequality makes E(x)=d(x,root)+a(root) for every x, including the root.

Otherwise the wide ladder consists of incident classes separating root from z. Remove their minority halfspaces in order: G_i is the intersection of the previous majority halfspaces, and S_i is G_i intersect the next minority halfspace. These nonempty gated graphs partition the removed union; root survives. Nonemptiness of every listed slice follows from the cube on pairwise orthogonal incident edges at root. A residual vertex v has no shared root ladder with z. Independently, if root were not in I(v,z), the triple median m(root,v,z) would differ from root. A first edge on a root-to-m geodesic has a class in both ladders, contradiction. Thus root lies on a shortest v-z path and E(v)=d(v,root)+E(root).

For each slice S in its current G_i, gate every outside vertex onto S and assign each boundary gate p the maximum d(p,y)+a(y) over its outside fiber. Nonboundary values retain a(p). For x in S take their maximum. For a vertex in a later slice, combine its previous label with d(x,g_S(x))+E_(S,a)(g_S(x)).
