# Independent weighted and boundary control

The same mechanism holds with any parameter t in(0,1): let phi_t=(1-t)delta_00+t delta_11 on C^4. The joint-law constraint and exchangeability give ||P_i Omega-Q_j Omega||²=t+t-t-t=0 whenever i differs from j. A third index identifies every P_i Omega and Q_j Omega. Projection identities then make every nonempty generator word send Omega to the same vector, giving moment t. Consequently every witness is exactly (1-t)chi_0+t chi_1, which is not extreme. This is a universal all-state/all-word proof, independent of finite counts.

Upstairs take the unit vector sqrt(1-t)e_00+sqrt(t)e_11 in M4. Its pure vector state restricts to phi_t; its folded state is pure and exchangeable and has the entire prescribed joint law. Thus the half-weight is not essential. At t=0 or1, the downstairs mixture becomes a character and is extreme, so this mechanism no longer obstructs independence. Both endpoint controls are consistent, rather than accidental failures of the theorem's interior assumption.

The independent exact checker uses six rational Pythagorean unit vectors and both endpoints. It checks matrix purity corners and joint moments through length8 with Fraction arithmetic. These checks supplement the universal argument, and establish no historical novelty. A faithfulness restriction is a different problem and is not inferred from these controls.
