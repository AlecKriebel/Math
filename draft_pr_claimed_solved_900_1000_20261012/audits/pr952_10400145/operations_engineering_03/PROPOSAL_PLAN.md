The ordinary absent-state merged gate is not bypassed generally: no saved pair means the original strict gate still runs; unrelated target state continues to reject.

Definitive races require a matching saved action with nonzero return code and explicit stale-lease/non-fast-forward/fetch-first evidence, exact race commit and saved observed main, and proof the prepared commit is absent from both saved and fresh main ancestry. Only a fully proven race can reach a separate new attempt at a fresh strict absent-state gate, with the unchanged exact parent force-with-lease. A contradictory race, unknown response, missing prepared record, or unconfirmed ancestry halts. There is no blind repush of a prepared commit.
