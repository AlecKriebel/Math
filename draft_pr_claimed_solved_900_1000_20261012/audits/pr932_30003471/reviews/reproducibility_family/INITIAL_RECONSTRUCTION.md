# Independent reconstruction before historical verdicts

Recorded 2026-10-15 UTC. Reproducibility-family completion estimate: 12%. Original author record remains 1/5; this routine audit adds zero author proof-search turns. This reconstruction was written after reading the charter, complete selected source record, complete frozen proof, all six original Python programs, and the portable patch, and before reading historical audit narratives, saved receipt conclusions, or acceptance documents. Acceptance labels embedded in program constants were unavoidable static input, not adopted judgments.

The mathematical candidate is a universal theorem: for compact full-dimensional convex three-polytopes with a fixed face-lattice correspondence, weak comparison of every corresponding interior dihedral angle implies equality of the entire outward-unit-facet-normal Gram matrix. It would imply the source's single-edge weak comparison by reversing the ordered pair. Nonsimple vertices are included. It claims neither support-number rigidity nor a theorem about finite samples.

The proof mechanism is geometric smoothing plus a smooth-domain Dirac input. A degree-one sphere map stays in the target-normal hemispheres; an exact fractional-arclength contraction handles each two-active-facet edge region; logarithmic vertex interpolation has vanishing actual-boundary L2 error; uniform H1-to-L4 trace constants absorb that error in a Dirac energy estimate. A nonzero constant matrix limit intertwines Clifford multiplication, forcing full normal Gram equality. The finite programs cannot establish the imported Dirac index/regularity/energy result, uniform analytic estimates, compactness, or universal construction. Those remain independent mathematical obligations.

What the programs actually do:

* `public/controls.py` evaluates 5066 expected finite algebraic/numerical checks: integer-sample Clifford relations and commutants, boundary involution/symbol identities, sampled hemisphere dilation, elementary target logic, and planar logarithmic rates. Its explicit exception checks survive optimization. It does not use polytopal geometric input or prove the analytic theorem.
* `public/verify_packet.py` externally pins an inner nine-file manifest, checks an exact flat public inventory and basic metadata, then executes `controls.py` and compares to saved JSON using ordinary Python equality. Its negative cases mostly challenge identity and unsupported status inflation. As a direct entry point it has to be trusted/authenticated before execution; its inner manifest cannot authenticate itself or its interpreter. It follows the resolved root and does not reject every symlink ancestor. JSON duplicate keys and literal nonfinite constants are rejected, but `1e999` can parse as an infinite float; ordinary JSON equality does not enforce recursive exact types. These are candidate standalone-schema limitations to test, not yet claimed failures of the frozen externally pinned packet.
* `audit_b/independent_controls.py` uses SymPy/NumPy/SciPy for stronger finite symbolic checks, sampled arc and Jacobi derivatives, actual smooth-level samples on an octahedron (four-facet vertices), and planar cutoff rates. It assumes a historical sibling directory and nine external reference PDFs. That source-bearing historical layout is absent from the 29-file publication packet. Merely reprinting source hashes would not reproduce source verification.
* `PORTABLE_INDEPENDENT.py` changes I/O and discloses the absence of separately supplied PDFs. It pins proof and inner-manifest bytes, but its direct entry point does not verify every file bound by that manifest before doing work, nor its own code. It is a finite diagnostic script, not a general hostile-packet verifier.
* `VERIFY_PUBLICATION.py` is a separate full-publication gate: it uses an external outer-manifest anchor, checks closed inventories, lstat regularity, modes, frozen inner anchors, assertion-free code, exact acceptance JSON, and exact portable diff. It must itself be externally authenticated first, as its docstring says. The gate replays disposable copies in ordinary, -O and -OO modes, removes inherited Python environment variables, and compares receipts by recursive types. Replayed children use the same interpreter in isolated mode. Its readonly write probes are permission tests under the executing user, not an OS sandbox. Lexical root ancestors and concurrent byte replacement are not obviously covered.
* `TEST_MUTATIONS.py` hashes the wrapper outside the payload before executing it and challenges 44 copies per mode. It is meaningful for the specified fixed wrapper anchor, not for a changed trusted checker or replaced external trust anchors. It records return codes, not mathematical witnesses. Negative mutation coverage and saved receipts still need independent replay.
