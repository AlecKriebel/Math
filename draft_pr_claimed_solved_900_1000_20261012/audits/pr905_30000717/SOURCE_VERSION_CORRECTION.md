# Release correction: Laurent manuscript versions

Fresh full-package reviewer 01 authenticated a version/locator mismatch.
The earlier published chapter, Springer 2009, pp.157–270, DOI
10.1007/978-0-387-09686-5_7, has a different Lemma 7.21 (gradient-component
constancy, printed p.242). Its DOI must not be used as the precise locator for
the tangency-infimum lemma.

The actual inspected primary source for that lemma is Laurent's updated
manuscript dated **6 February 2010**, 147 pages:
https://homepages.cwi.nl/~monique/files/moment-ima-update-new.pdf , Section 7.2.3,
Lemma 7.21, manuscript pp.117–118. Its recorded SHA256 is
37a4e2218a3a8af8093c8e984fad7d8acbbb8627efac9c75394ed3f6d01c52eb.
A separate updated manuscript dated 12 November 2009 contains the same tangency
lemma on manuscript pp.113–114, but that is not the 147-page file used here.

The active note, README and deposit metadata explicitly link/date the 2010
version. The 2009 chapter DOI remains bibliographic context only. Sealed original,
source-model, priority and proof review records are preserved unchanged; labels
“Laurent 2009” or the published DOI in those historical records do not authenticate
the updated manuscript's lemma number in the published chapter. This correction
supersedes their version attribution without altering any mathematical deduction.

Candidate revision 1 and the fresh review identifying R1 remain preserved.
