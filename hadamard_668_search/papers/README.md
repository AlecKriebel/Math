# H(668) pause-checkpoint papers

This directory contains three standalone, provisional manuscripts prepared
for the 25 July 2026 pause checkpoint:

1. `eliahou_repair_obstructions/` studies exact local repair obstructions
   around Eliahou's 64-modular order-668 seed.
2. `lp333_fixed_compression/` studies exact shell descent and finite-field
   norm gates in one prescribed-compression chart for Legendre pairs of
   length 333.
3. `semiregular_c37_conference/` studies semiregular cyclic order-37
   quotients and modular lift obstructions for conference matrices of
   order 334.

None of the papers constructs or excludes a Hadamard matrix of order 668.
All are unreviewed, substantially AI-assisted research artifacts intended
for independent checking. Each paper states its own hypotheses, exact
scope, limitations, claim-to-artifact map, and build instructions.

`SHA256SUMS` records the hashes of the release-edition sources and PDFs.
The tagged GitHub release also carries stable copies of the three PDFs and
the compact production-manifest archive used by the Eliahou short-case
census.
