# The exceptional quotient does not rescue constant rank two

## Result

The complete orbit-sum census has a unique sign-class whose diagonal
profile is

```text
(-4,-4,0,0,0,0,0,4,4).
```

Its diagonal block degrees are therefore

```text
(16,16,18,18,18,18,18,20,20).
```

This was the only sign-class not rejected by the earlier
similarity-invariant diagonal weight code for constant rank-two formal
conjugators.  That exception is now closed:

> Neither a nonzero `J2` block nor a nonzero eigenline plus `J2(0)` can
> produce even one binary diagonal block in the trace-corrected formal
> family.

The proof is stronger than an exceptional-class calculation.  It uses
only symmetry and the fixed coefficient of the `z^18 J` trace term, so
it excludes these two Jordan types for every quotient.

This remains a result about a named formal family.  It does **not**
exclude higher-`y` conjugators or a general semiregular `C37` lift.

## Restoring the coefficient that the universal code forgot

Work in

```text
R = F_37[y]/(y^37),  x=1+y,  z=log(x),  h=z^18.
```

Because `A` is symmetric, its primary components for coprime factors of
the minimal polynomial are orthogonal.  The projector `P` onto the
nonzero primary component is a polynomial in `A`; hence both `P` and the
nilpotent remainder `N` are symmetric in the original ambient
coordinates.  This avoids choosing a nonsymmetric similarity basis.

For a nonzero `J2` primary block, scale and decimate so that

```text
A = P+N,  P^2=P,  PN=NP=N,  N^2=0.
```

Then

```text
exp(zA)  = I + (x-1)P + x z N,
exp(-zA) = I + (x^-1-1)P - x^-1 z N.
```

For a nonzero eigenline plus `J2(0)`, the same normalization gives

```text
A = P+N,  P^2=P,  PN=NP=0,  N^2=0
```

and

```text
exp(zA)  = I + (x-1)P + zN,
exp(-zA) = I + (x^-1-1)P - zN.
```

Let `M` be symmetric.  Expanding either formula and using
`diag(UV)=diag(VU)` for symmetric `U,V` shows that every diagonal entry
of

```text
exp(-zA) M exp(zA)
```

belongs to the span of

```text
1,
f1 = (x-1)+(x^-1-1),
f2 = (x-1)(x^-1-1),
f3 = z(x^-1-x),
f4 = -z^2.
```

More explicitly, write

```text
E_- = I+bP+dN,  E_+ = I+aP+cN.
```

Reversal of a product in the symmetric letters `P,M,N` preserves its
diagonal, so

```text
diag(E_- M E_+)
 = diag(M)
 + (a+b) diag(PM)
 + (c+d) diag(NM)
 + ab      diag(PMP)
 + (bc+ad) diag(PMN)
 + cd      diag(NMN).
```

For the mixed zero-Jordan type, `c+d=0`,
`bc+ad=f3`, and `cd=f4`.  For the nonzero-`J2` type,
`c+d=-f3`, `bc+ad=f3`, and `cd=f4`.  The verifier checks all of these
polynomial identities exactly.

The sign of `f3` swaps between the two types and does not change the
span.

Apply this first to the symmetric matrix `N0`, and then to `J`.  After
removing the common `19 y^36 J` term, every possible diagonal word lies
in the affine code

```text
eta*h + U,

U = span(1,f1,f2,f3,f4,h*f1,h*f2,h*f3,h*f4).
```

This is deliberately an over-code: the nine scalar coefficients are
allowed to vary independently, ignoring all projector, nilpotent, and
specific-`N0` relations.  Consequently, an empty intersection is a
valid obstruction to the full family.

Removing the socle term is exact: both exponentials have identity
constant term in `y`, so

```text
y^36 exp(-zA) J exp(zA) = y^36 J
```

in the truncated ring.

The crucial restored datum is

```text
eta in {+1,-1}.
```

These are the two orientations of the integral `3/6` trace law.  The
older universal code allowed the coefficient of `h` to float freely.

## Complete affine-code census

In cyclic `x` coordinates, `U` has dimension seven with information
coordinates

```text
0,1,2,3,4,5,6.
```

For a binary diagonal block the reduced word `r` must obey

```text
r(0)=0,
r(t) in {18,19} for t != 0.
```

Only `2^6=64` information assignments are therefore needed for each
value of `eta`.  Exhausting all 37 cosets gives:

```text
eta =  3: two words, of weights 18 and 20
eta = -3: two words, of weights 16 and 18
all other eta: no words
```

In particular, both genuine trace orientations `eta=+1,-1` have empty
intersection.  The weight-16, weight-20, and weight-18 words seen in the
old universal code live in the spurious `eta=+/-3` cosets.  Hence the
previously reported 85 trace-compatible global assignments for the
exceptional quotient cannot arise after the fixed `J` coefficient is
restored.

No off-diagonal binary test is necessary: each diagonal coordinate
already fails in a safe affine over-approximation.

## Combined consequence for the full quotient census

Together with the two existing exact inputs,

1. the split semisimple rank-two types fail their local
   quadratic-character test for every quotient; and
2. the irreducible and pure-nilpotent types permit only weight-18
   diagonal words, while the complete 625-class quotient census contains
   no all-zero diagonal quotient,

this affine-coset obstruction removes the last two rational/Jordan
types.  Conditional only on replaying those companion certificates, it
follows that **no constant symmetric rank-two exponential conjugator
works for any semiregular `C37` orbit-sum quotient**, not merely for the
original `1+4+4` quotient.

Again, the word “constant” is essential: this does not constrain a
conjugator with genuinely higher-`y` coefficients.
