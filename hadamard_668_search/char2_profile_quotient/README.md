# Characteristic-two quotient of the order-three LP(333) profile equation

## Status

Reduction modulo two gives a new-within-this-project, exact **necessary**
quotient for every order-three invariant `LP(333)` profile.  Its invariant
group algebra is

```text
F_4[C_37]^H  ~=  F_4 x F_(4^6) x F_(4^6),
H={1,10,26}.
```

The complete shell/aggregate census is nonempty in all fifteen cells, so
this is not an exclusion theorem and does not produce a profile, Legendre
pair, or `H(668)`.  It is nevertheless a strong finite sieve: after fixing
the shell support and aggregate residue, it keeps almost exactly one word
pair in `2^11`.

The package has an assignment-level API, so the dense-shell classifier can
measure the actual intersection with its independent characteristic-three
quadratic layer instead of extrapolating selectivities.

## 1. Reduction to a unitary equation

Let `omega^2+omega+1=0`, `lambda=1-omega`, and write the exact invariant
profile equation as

```text
A A* + B B* = 167 e                    in Z[omega][C_37]^H.       (1)
```

Here star conjugates Eisenstein coefficients and inverts `C_37`.  Modulo
two, `omega` maps to `w` in

```text
F_4=F_2[w]/(w^2+w+1).
```

Eisenstein conjugation becomes the Frobenius square.  Also

```text
167 -> 1,       A(0)=-1 -> 1,       B(0)=2 -> 0.
```

Every nonzero profile letter—medium `+/- lambda omega^u` or high
`3 omega^v`—reduces to an element of `F_4^*`.  Therefore (1) implies

```text
a a* + b b* = e                         in F_4[C_37]^H.           (2)
```

This loses the sign and the distinction between medium and high letters,
so (2) is only necessary.

## 2. Factorization of the invariant algebra

The group `F_37^*` is generated by `2`, and

```text
H=<2^12>,       F_37^*/H ~= C_12.
```

The fourth-power Frobenius on characters adds two to the exponent modulo
12.  It has exactly two nonzero orbits:

```text
(0,2,4,6,8,10),       (1,3,5,7,9,11).
```

Since characteristic two does not divide 37, the algebra is étale.  The
trivial character and these two length-six orbits prove

```text
F_4[C_37]^H ~= F_4 x K x K,             K=F_(4^6).                (3)
```

Choose the two nontrivial Fourier coordinates at character indices `1`
and `2`, and call them `X,Y`.  Fourier star sends a character `k` first to
`-k/2` and then squares the value.  Since

```text
-1/2 = 2^17 modulo 37,
```

the two factors are exchanged, with

```text
(a,X,Y)* = (a^2, Y^32, X^128).                              (4)
```

Indeed `32*128=1 mod (4^6-1)`, so (4) is an involution.  The two nontrivial
factor equations in (2) are Frobenius conjugates of the single equation

```text
X_A Y_A^32 + X_B Y_B^32 = 1                in K.             (5)
```

Equation (5) is a compact spectral form of the quotient.  The assignment
API uses direct correlations, avoiding any finite-field representation
choice.

## 3. Why the apparent selectivity is 11 bits

Let `D=a a*+b b*-e`.  Order-three invariance and Hermitian symmetry pair
the twelve nonzero class coefficients as

```text
D_(j+6)=D_j^2,          0<=j<6.
```

For all three dense shells the total nonzero class support is

```text
18-2h,                 h=0,1,2,
```

which is even.  Hence the zero-lag coefficient of `a a*+b b*` is one.
The five aggregate residue types also satisfy the trivial-factor equation

```text
Aug(a)^3 + Aug(b)^3 = 1.
```

The sum of all nonzero residual coefficients is therefore zero.  Pairing
opposite classes gives the forced bit relation

```text
sum_(j=0)^5 Tr_(F_4/F_2)(D_j) = 0.                         (6)
```

Thus the six displayed `F_4` residuals occupy an 11-dimensional
`F_2` hyperplane before they are required to vanish.  Zero should have
neutral density `2^-11`, not `2^-12`; the exact census is within a factor
`2047.4--2048.9` of the corresponding aggregate/support-only counts.

## 5. Dense-classifier API

From this directory:

```python
from verify_char2_profile_quotient import check_profile_assignment

result = check_profile_assignment(
    coefficients_a,                 # twelve integers in 0..3
    coefficients_b,
    target_aggregate=(3, 0),
    high_count=1,
)
assert result["passes_all_requested_gates"]
```

For exact Eisenstein class coefficients `(a,b)`, use
`check_eisenstein_profile`.  The result includes the six exact `F_4`
residual coordinates, aggregate, support, and trace-dependency bit.  Even
when the optional aggregate and shell pins are omitted, the API checks all
three factors of (3): the six nonzero-lag conditions, the zero-lag
condition, and the trivial-character norm.  This is suitable for witness
replay and for measuring the true intersection with the 729-character
dense-shell front end.

## 6. Reproduction and trust boundary

Dependency-free semantic checks:

```text
python3 verify_char2_profile_quotient.py
python3 -m unittest -v test_char2_profile_quotient.py
```

Complete compiled census:

```text
clang++ -std=c++20 -O3 -DNDEBUG -Wall -Wextra -Wpedantic -Werror \
  verify_char2_profile_census.cpp -o /tmp/verify_char2_profile_census
/tmp/verify_char2_profile_census
```

The compiled verifier derives its Boolean quadratic map from direct
`F_4` autocorrelations, checks the incremental state against direct
correlations throughout the complete `2^24` walk for both origins, and
pins every displayed count.  The JSON certificate is compact census data,
not a list of solutions.

On the Apple M1 Pro reference host, the complete compiled run took under
one second and less than 6 MB maximum resident memory.  The Python verifier
and tests each used less than 25 MB.  No solver, randomness, network
access, or external communication is involved.

## 7. Next gate

Do not multiply the `2^-11` and `3^-6` densities and call the result a
survivor estimate.  They act on the same ternary phases.  The next bounded
experiment must:

1. stream actual `h=1,0` signed skeleton/phase witnesses from the
   characteristic-three character layer;
2. apply `check_profile_assignment` before upper exact replay;
3. record the exact intersection rate by support and target;
4. retain enough data to recover and replay every surviving word.

Only a measured contraction of that actual intersection justifies making
the characteristic-two quotient part of the full classifier.
