# Proof-grade seed-frontier certificates

This directory is the first independently replayable SAT-proof layer for the
raw seed-distance exclusion. It does not import OR-Tools and does not merely
trust the `INFEASIBLE` strings in the existing JSON artifacts.

The current result is a verified prototype, not yet a proof of the complete
radius-18 theorem. Four representative UNSAT leaves are pinned:

- one radius-16 root leaf;
- one exact-distance-17 root leaf;
- one exact-distance-18 root leaf; and
- one exact-distance-18 primitive-7 compression leaf.

The full proof gate contains **1,296 UNSAT leaves**, not 1,284:

| Layer | Leaves |
|---|---:|
| radius at most 16, root relaxation | 197 |
| exact distance 17, root relaxation | 276 |
| exact distance 18, root relaxation | 811 |
| exact distance 18, primitive-7 compression | 9 |
| exact distance 18, primitive-14 compression | 3 |
| **Total** | **1,296** |

The existing shell-18 verifier independently checks the 12 decoded root
witnesses and the artifact selection graph. It does **not** independently
prove the 9+3 compression-model `INFEASIBLE` statuses.

## Encoding

`export_seed_frontier_cnf.py` reconstructs a target model directly from a
pinned artifact using standard-library Python and the dependency-free
repository data. Its primary variables are 334 flip bits relative to
Eliahou's published seed. The CNF contains:

1. exact ordinary and alternating margins;
2. the raw Hamming-distance interval;
3. even flip parity in all 83 paired-endpoint quads;
4. exact primitive-3, primitive-4, and primitive-6 norm identities;
5. independently derived classwise flip-direction budgets;
6. independently derived long/short pair-distance lower bounds; and
7. for root-only models, enabled-by-default exact sorting of exchangeable
   endpoint-quad masks.

Linear forms use bidirectional finite-state sum automata. Quadratic root norms
use explicit allowed-row selectors, followed by exact one-hot norm sums. The
v2 propagation constraints in items 5–6 are consequences of items 1–4.
Item 7 is a satisfiability-preserving symmetry quotient: it removes unsorted
labelled representatives while retaining one representative in every valid
exchangeable-quad orbit. Its correctness therefore also depends on the
declared quad groups really being exchangeable for the root constraints.

For primitive-7/14 leaves, the exporter additionally constructs all 28
compressed residue sums, exact product tables, and the four periodic
autocorrelation equations `(334,0,0,0)`. Primitive 14 uses the same encoding
after multiplying coordinate `i` by `(-1)^i`. Exchangeable-quad sorting is
automatically disabled because it is not valid at compression layers.

`--compression z7`, `z14`, or `both` may soundly strengthen a root artifact:
every exact `BS(84,83)` must satisfy both identities. Metadata records both
the artifact layer and the exported layer.

`--exchangeable-quad-symmetry off` retains all v2 mathematical consequences
but omits the root-layer sorting quotient. This is required when pinning an
arbitrary historical witness rather than its orbit-sorted representative.

## Replay the pinned proofs

The compressed proofs and their raw/compressed SHA-256 hashes are recorded in
`representative/manifest.json`. CNFs are regenerated byte-for-byte, rather
than stored.

```sh
cd /Users/alec/Documents/Math/hadamard_668_search
python3 proof_certificates/verify_representative.py \
  --drat-trim proof_certificates/.tools/drat-trim/drat-trim
```

To check only one case, append, for example:

```sh
--case r18_z7_i002_v2
```

The wrapper:

1. pins the source artifact checksum;
2. regenerates the deterministic CNF;
3. checks its size, variable count, clause count, and SHA-256;
4. decompresses and hashes the binary DRAT trace; and
5. requires `drat-trim` to return `s VERIFIED`.

## Positive soundness regression

The exporter has also been tested on a root-feasible artifact record, guarding
against a vacuously overconstrained UNSAT encoding:

```sh
python3 proof_certificates/export_seed_frontier_cnf.py \
  --artifact output/variable_q_seed_frontier_shell18_root_table_0p5s.json \
  --result-index 466 \
  --expect-status OPTIMAL \
  --propagation cp-sat \
  --output proof_certificates/work/r18_sat_i466_v2.cnf

proof_certificates/.tools/cadical/build/cadical --quiet \
  proof_certificates/work/r18_sat_i466_v2.cnf \
  > proof_certificates/work/r18_sat_i466_v2.model

python3 proof_certificates/verify_seed_frontier_sat_model.py \
  --metadata proof_certificates/work/r18_sat_i466_v2.cnf.metadata.json \
  --cnf proof_certificates/work/r18_sat_i466_v2.cnf \
  --model proof_certificates/work/r18_sat_i466_v2.model
```

CaDiCaL returned SAT in 2.93 seconds at 90 MB RSS. The independent checker
verified all 251,113 CNF clauses and reconstructed:

```text
distance = 18
margins = ((-10,10),(-4,12),(13,3),(-7,-9))
small-root norms = (334,334,334)
long/short distances = (10,8)
sorted quad comparisons = 24
```

### All 12 stored root witnesses

`verify_all_root_witnesses.py` closes the all-recorded-root-witness positive
gate:

```sh
python3 proof_certificates/verify_all_root_witnesses.py \
  --cadical proof_certificates/.tools/cadical/build/cadical
```

It reconstructs the six-stage root artifact chain by exact `(shard,target)`
keys and verifies the selection edges and pinned artifact hashes. Repeated
witnesses in earlier and later stages must be byte-identical or the checker
stops. The final provenance is unambiguous: 11 witnesses come from the
2-second unresolved artifact and one from the 5-second artifact.

For each witness, serially and in disposable storage, the checker:

1. exports the unquotiented v2 root CNF;
2. adds 334 DIMACS units fixing the primary flips to that exact witness;
3. requires CaDiCaL to return SAT;
4. confirms the SAT model's primary variables equal the stored witness; and
5. independently checks every DIMACS clause, margins, distance, endpoint
   quads, pair-distance bounds, and primitive-3/4/6 norms.

The run took 161.44 wall seconds, 155.24 summed per-case seconds, and peaked
at 87,425,024 bytes RSS. It used one process at a time and retained no CNFs

One important diagnostic preceded the final run. Pinning shard 29 directly
into the symmetry-quotiented v2 CNF returned UNSAT. This is expected rather
than an encoding contradiction: the stored witness artifacts predate the
exchangeable-quad sorting layer and store arbitrary orbit representatives.
With only that quotient disabled, the exact stored witness returned SAT and
passed all independent checks. The four-bit truth-table regression below
checks the mask-order comparator clauses, while the earlier index-466 positive
sample passes with quotienting enabled.

A separate exhaustive regression now audits the global grouping without
calling the exporter's grouping helper. It reconstructs all 83 physical
endpoint quads, computes the complete contribution signature of each of the
eight even four-bit masks, and independently groups quads by those signatures.
It checks that this partition is exactly both the exporter's declared
partition and the connected components of its acyclic comparison forest. For
every declared orbit and every even mask, it therefore checks invariance of
distance, all eight class-margin deltas, separate seed-sign direction counts,
long/short pair distance, and every primitive-3/4/6 linear form.

This is an executable finite audit of the declared root grouping, within the
Python implementation's trust base. It does not justify grouping at the
primitive-7/14 compression layers, where sorting is disabled. It also does not
independently prove that the enumerated observable list is a complete semantic
specification of the root CNF; that correspondence remains part of the
human-auditable encoding bridge.

Small exhaustive regressions are:

```sh
python3 -m unittest -v proof_certificates.test_seed_frontier_cnf
```

They cover the flip-direction identity, pair-DP lower bounds against brute
force, the exact truth table of the four-bit orbit-order clauses, and the
independent global exchangeable-quad audit described above.

## Hard-leaf and scaling audit

Naively archiving one proof per leaf is not yet justified. The three easy
root samples compress to roughly 1 MB each, suggesting about 1.3 GB for 1,284
root leaves before the 12 compression leaves. The z7 sample suggests another
roughly 82 MB for nine z7 leaves. That estimate is too close to the 1.5 GiB
local-output budget and is invalidated by the hard stratum:

| Hard6 index 0 pilot | CNF | Outcome |
|---|---|---|
| raw-bit root v2 | 62,532 vars, 281,622 clauses, 5.32 MB | stopped at 155.81 s; 247 MB RSS; incomplete DRAT reached 387,559,424 bytes |
| root strengthened with z7+z14 | 313,072 vars, 4,152,496 clauses, 95.21 MB | `UNKNOWN` at 60.12 s; 1.785 GB RSS; incomplete DRAT 42,697,196 bytes |
| root strengthened with z7 | 187,802 vars, 2,215,619 clauses, 49.49 MB | stopped at 21.70 s after exceeding the 1.2 GB pilot cap; peak 1.707 GB RSS; incomplete DRAT 22,384,640 bytes |

The failed scratch proofs and CNFs were removed after these measurements.
The verified representative proofs were not removed.

The z14 exporter is implemented through the same residue/product machinery
with alternating coordinate coefficients, but no z14 leaf has yet been
solved and checked. Therefore a full batch must not start yet.

### Recommended next step

Implement an exact orbit-count CNF for the six formerly hard root leaves.
The existing CP-SAT quotient already specifies the mathematics: within each
modulo-12/seed-sign endpoint-quad orbit, introduce one-hot bounded counts for
the eight even flip masks; require the counts to sum to orbit multiplicity;
express margins, distance, and root statistics linearly in those counts; and
reuse the explicit quadratic root tables. Independently decode any SAT model
back to 334 flips and recheck it as the present verifier does.

This should remove permutations that made the raw-bit proof explode while
keeping a small, ordinary DIMACS+DRAT trust base. It is preferable to the
tested `z7+z14` strengthening, which approached the 2 GB memory ceiling.

Longer-term alternatives are:

- a single global CNF with margin-target selectors and one proof per distance
  scope;
- an incremental selector proof deriving `not target_i` for every target and
  stitching the result in FRAT/LRAT; or
- a shared exact orbit-state dynamic program with a compact independently
  replayable reachability transcript.

A global selector model could share most clauses, but target-conditioned
direction budgets and symmetry must be encoded carefully. Its proof size is
unknown. No global or full-corpus run has been started.

## Files and trust boundary

- `export_seed_frontier_cnf.py`: deterministic mathematical CNF exporter.
- `verify_seed_frontier_sat_model.py`: positive-model and CNF checker.
- `verify_all_root_witnesses.py`: serial 12/12 pinned positive checker.
- `verify_representative.py`: hash, regeneration, decompression, and DRAT
  replay wrapper.
- `test_seed_frontier_cnf.py`: small exhaustive regressions.
- `build_proof_tools.sh`: pinned single-process tool build.
- `representative/manifest.json`: exact hashes, sizes, and measurements.
- `representative/*.drat.gz`: four checked representative proof traces.
- `work/`: ignored, regenerable scratch.

An UNSAT trace proves the exported DIMACS formula inconsistent. The remaining
human-auditable bridge is that the exporter faithfully encodes necessary
conditions for an exact base sequence. The positive regression, exhaustive
micro-tests, independent SAT-model checker, deterministic hashes, and small
external DRAT checker substantially reduce—but do not magically eliminate—
that implementation trust.
