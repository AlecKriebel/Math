# Orbit-relation cost versus L2-Betti number

Independent research effort by Alec Kriebel (ORCID 0009-0001-9320-500X).

The target is a free p.m.p. orbit relation of an infinite finitely generated group with first L2-Betti number zero and cost strictly greater than one. The proposed input is OpenAI's **A group without fixed price** (family 259), pinned to repository commit `adc7f1241b42e322a6451854ab7e4b4c146bf78a`. The initial triage is not a validation of that input.

Current status: input auditing; no unconditional result promoted and no deposit created. The group infimum-cost equality is outside the purported counterexample: the proposed group has infimum cost one.
