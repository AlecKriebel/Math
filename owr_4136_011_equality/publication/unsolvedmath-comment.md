The answer is yes: equality holds if and only if K is a nondegenerate simplex whose vertices all have Euclidean norm r.

This holds for arbitrary convex bodies under the stated extreme-point hypothesis, in every dimension n ≥ 1. The proof extends the Fradelizi–Paouris–Schütt polytope argument using an almost-everywhere partition into countably many simplices with vertices in ext K. An exact nonnegative deficit identity shows that equality forces all simplex centroids to coincide; disjoint interiors then leave only one simplex.

The deposit includes the proof, an exact-arithmetic verifier, and independent AI review reports. The written proof establishes the general result; the finite computations are supporting checks.
