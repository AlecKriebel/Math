# Function Theory Problem 7.42: annular counterexample candidate

Problem identifiers: 2307042 / AMR-022-7042.

The authored proof gives a negative answer to the proposed equality-along-a-Green-line extension. In the annulus \(1<|z|<e\), with base \(a=e^{1/2}\), the minimal Martin kernel at \(-1\), normalized at \(a\), is strictly below the Harnack envelope throughout a punctured neighborhood of \(a\). It therefore cannot agree with the envelope along any nontrivial Green line issuing from \(a\).

The proof is analytic, not a finite numerical experiment. It verifies the Martin limit and minimality, then uses four explicit positive harmonic competitors and a uniform first-order gap. One substantive mathematical approach was used: periodized-strip kernel plus local gradient separation. Kernel identification, minimality, and derivative estimates are steps of that approach, not separate attempts.
