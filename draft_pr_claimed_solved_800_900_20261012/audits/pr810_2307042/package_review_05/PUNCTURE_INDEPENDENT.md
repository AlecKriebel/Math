# Independent punctured-disc calculation

Saved before historical verdicts are consulted. For Ω=unit disc minus {0}, base a=1/2, normalized boundary Poisson kernel with pole -1 has gradient (-8/3,0). The normalized kernels with poles ±i have gradients (-32/15,±8/5). The normalized logarithmic function -log|z|/log2 has gradient (-2/log2,0). Since 0<log2<3/4 (e^(3/4)>1+3/4+(3/4)^2/2=65/32>2), we have -2/log2<-8/3<-32/15. Hence target lies strictly inside triangle, with weights λ=8log2/(30-32log2) for log kernel and (1-λ)/2 for each ±i kernel. λ∈(0,1). Each target and competitor is globally positive, harmonic on Ω and normalized at a. Triangle interior yields strictly positive directional maximum gradient difference uniformly on unit circle by compactness; finite family Taylor remainder yields local isolation.

Minimality can be checked without assuming a metric result: a positive harmonic v dominated by the target Poisson kernel is bounded near 0, extends across it, and is a constant multiple by disc Poisson minimality. The logarithmic competitor need not itself be minimal for the gap argument. The classical Bôcher representation v+b log(1/|z|), v positive harmonic on the full disc, b≥0, gives the complete minimal classification and envelope.
