## Threat model

This is a trusted-interpreter, independently authenticated startup-body, explicit external inventory-pin model, without concurrent hostile filesystem substitution. Ancestor aliases outside a selected root are allowed; aliases inside package trees and nonregular leaves are rejected. Isolated Python excludes cwd/site/PYTHONPATH startup influence. It is not a multiuser hostile execution sandbox or a proof of arbitrary code safety. My 81 negative/7 positive controls per interpreter mode test their enumerated mechanisms only; repeated modes are not new distinct attacks. The historical 106-control claim was not reconstructed and is not reasserted.
