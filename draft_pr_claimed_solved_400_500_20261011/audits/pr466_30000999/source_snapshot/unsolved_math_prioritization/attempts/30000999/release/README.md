# Inverse Wasserstein bound for spherical equator averaging

Problem 30000999 / OWR-2042-008.

A stronger, self-contained construction disproves it for smooth positive even densities on S^{n-1} when n>=3 and 1<=p<infinity. On even measures of S^1, the transform is an isometry.
