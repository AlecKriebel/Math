# 30000689 — Embedding Obstructions from Missing Simplicial Faces

**Complete affirmative candidate, frozen for independent review.** For a triangulated topological 2d-sphere S, adjoining a missing d-face to its d-skeleton prevents topological embedding into S^{2d}.

The proof handles the category distinction explicitly. A Koszul dimension jump and published Lefschetz/ambient-extension theorems rule out PL embeddings in all dimensions; Haefliger–Weber covers topological embeddings for d≥3. Dimension four is handled by extending Nevo–Wagner's bistellar argument from a flag subdivision, using only a contractible complementary manifold. No standardness of a potentially exotic PL 4-sphere is assumed.
