# Independent analytic obligations

UTC: 2026-10-12T21:17:22.932307+00:00. Completion estimate: 25%; producer implementation remains unread.

The following sufficient error mechanisms are to be matched against actual implementation, not imposed as its design.

1. Exact polynomial recurrence: every coefficient operation occurs in Z[i]; factor exponents are 2^t with the source order fixed. All supports and counts are checkable. The recurrence and any unitary gauge reduction must be proved for every evaluated x.
2. Exact autocorrelation: C_k=sum_entry sum_l a_(l+k) conjugate(a_l). A modular convolution must have enough zero padding to avoid cyclic aliasing and a proven primitive transform root. Recovering separately real/imaginary integers requires uniqueness of their signed lift. If the polynomial is proved real and even, a real coefficient convolution can suffice; sampled imaginary cancellation is insufficient. Native fixed-width products and additions need explicit machine bounds; Python integer arithmetic avoids overflow.
3. Cell means: for cells centered at j/M, m_j=sum_k C_k sinc(πk/M) exp(2πikj/M). For centers at (j+1/2)/M, the coefficient includes exp(πik/M). Negative frequencies must use conjugation. This is an exact integral formula, not a sampling estimate.
4. Interval roots: sqrt lower L=floor(sqrt(q times numerator)) and upper L or L+1 must be justified by squared integer comparisons. Half-angle subtraction reverses endpoints; division requires a positive denominator. Recurrence-generated twiddle centers require a total error enclosure covering every multiply and accumulated phase error.
5. Sinc: sin(t)/t=sum_(j>=0)(−1)^j t^(2j)/(2j+1)!. Taylor/alternating remainders need the actual argument range and monotonic-term check, or an absolute-tail bound. Any rounded coefficients/arguments carry their own outward error. t=0 is handled exactly.
6. FFT: exact butterfly outputs y±wz obey a propagated error that accounts for both input errors, twiddle error, its interaction with input error, and real/imaginary rounding. For a max complex-norm error E and stage amplitude A, a conservative recurrence has E'≤2E+δ_w(A+E)+ρ. A sharper implementation is acceptable only with its norm convention proved consistently. Do not confuse a per-stage arithmetic bound with a final transform bound.
7. Jensen: on each cell ∫log S≤cellwidth log m. Thus upper m endpoints yield an upper integral bound. A lower endpoint >0 validates evaluating log and should be checked before any series. S positivity from determinant ensures the exact function is legitimate but does not by itself certify approximate mean intervals.
8. Logs: normalize a positive rational m into 2^e y, 1≤y<2, then t=(y−1)/(y+1)∈[0,1/3]. The identity ln y=2 Σ_(j>=0) t^(2j+1)/(2j+1) has positive tail ≤2t^(2K+1)/((2K+1)(1−t²)) after K terms. When e<0, using a lower bound on log2 is needed for an upper bound on e log2. Rational integer inequalities, not printed float decimals, decide the strict threshold.
9. Runtime proof checks: every claimed invariant and strict acceptance comparison must survive Python -O. A fail-closed guard must reject the relevant invalid state with a nonzero exit code or explicit non-certification; raw records and verdict must refer to the same controlling hash.
