# Claimed-solved draft PR audit and publication program, #400–#500

User-authorized persistent goal: rigorously audit, repair where reasonably possible,
publish qualifying preprints with reproducibility materials through the repository's
Zenodo tool, append verified DOI records using Google Workspace CLI, and merge
accepted results. Close irreparable in-scope claims with an evidence-backed comment.

Strict scope: only open draft PRs in the inclusive range #400–#500 whose selected
problem's status is exactly `claimed_solved` in `QUEUE.md` at that PR's exact head
revision. Every other status is skipped without a mathematical review, priority
audit, repair, merge, closure, comment, or paper. Recheck eligibility before actions.

Order: descending, #500 to #400, following the user's final repeated direction;
an optional clarification of the contradictory initial ascending phrase is pending.

Every eligible PR receives its own subfolder under `audits/`. Source revisions,
exact target, claims, audit families, reproduction commands/results, decisions,
reviews, fixes, publication metadata, external action receipts, and completion
estimates will be preserved. Claims remain hypotheses until validated. No individual
is contacted; public repository and publication operations are explicitly authorized.

The shared checkout remains on `main`. Other efforts' changes and commits must not
be staged, reset, overwritten, or published as part of this program. Remote-main
checkpoint publication will use only this program's paths and explicit concurrency
checks. No routine GitHub release is authorized or necessary.

Publication gates: exact original target resolved; proof and reproduction clean;
priority checked against primary sources; concise manuscript accurately states
scope, author ORCID, extensive AI use, and unrefereed status; successive fresh
complete adversarial reviews clean after global repairs; manuscript and supplement
consistent; metadata and uploaded checksums verified; DOI/tracker/merge receipts saved.
