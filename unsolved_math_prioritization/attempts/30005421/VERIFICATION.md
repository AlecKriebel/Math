# Verification scope and exact comparisons

The current checker is the unchanged independently authored standard-library program independent_check.py. Every clean execution checks 323,049 exact conditions over 16,883 enumerated vectors, 1,386 eligible nonzero proper vectors, 7,919 strict cutoffs and 634 negative restricted-Rayleigh samples. Its four cases cover unequal dimension coordinates, negative restricted spectral branches and a nonconstant integral Perron vector. The universal conclusion is established by the written proof and independent audit.

Twelve semantic mutants must fail with exit 1 and the exact expected label and full output: reverse_skew / Euler_skew_identity; negative_sign_reversed / uniform_numerical_estimate; minimum_instead_of_maximum / unweighted_box; zero_epsilon / strict_epsilon_positive; gap_ignores_cutoff / strict_expansion_gap; transpose_incidence / incidence_dimension; reverse_avoidance / negative_euler_locus_excluded; missing_n_normalization / weighted_orthogonality; missing_f_normalization / Euler_homogeneity; wrong_coordinate_sign / coordinate_square; all_Rayleigh_quotients_equal / Rayleigh_quotient_variation; zero_offcomponent_kappa / disconnected_full_cone_positivity.

Each Python mode has explicit reference stdout/stderr pins. Fresh execution must match complete bytes and recursively exact JSON types and values. There is no normalization, extraction of only PASS, float/int coercion, or bool/int coercion. Mutant rejection must be substantive, not an arbitrary crash. The full output, exit code and stream hashes are preserved in receipts.

The delivery controls test every changed member, missing/extra members, symlinks, hardlinks, special files, malformed/duplicate/nonfinite JSON, strict manifest and acceptance schemas, altered expected outcomes, direct output-comparator attacks and hostile Python import environments. The controls themselves are authenticated before execution. The baseline and hostile full verification outputs must be byte-identical. Packet inventories, explicit before/after SHA-256 and byte-count maps, real UID/EUID, 0444/0555 modes and physical EACCES failures are recorded.

These checks are reproducibility and finite arithmetic support, not formal proof-assistant verification or a claim to have reexecuted historical source inspections. Original assert-checker replay, full legacy-archive replay, source-body replay, dataset replay and formal proof-assistant verification are NOT_RUN.
