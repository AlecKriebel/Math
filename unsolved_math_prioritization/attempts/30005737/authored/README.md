# Post-Lie structures with semisimple target

Problem 30005737 / OWR-14298013-001, rank 953.

The candidate proves that a unimodular finite-dimensional complex source admitting a post-Lie structure with semisimple target must itself be semisimple. Since every perfect Lie algebra is unimodular, this gives the exact requested nonexistence statement for a perfect nonsemisimple source.

The key steps are a determinant covariance identity for the integrated left-right action, globalization from its open orbit, a genuine homogeneous-space covering argument, and the top homology degree of compact real forms.
