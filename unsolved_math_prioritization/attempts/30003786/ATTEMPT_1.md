# Attempt 1: a finite cyclic block changes the congruence topology

**Target:** 30003786 / OWR-16160-016. **Author attempt:** 1/5.  
**Date:** 2026-10-03 UTC. **Status:** complete elementary certificate; independent AI audit PASS; broad negative answer is also a verified consequence of prior published theory.  
**Scope:** the family of all congruence subgroups induced by an arbitrary faithful embedding of a finitely generated abstract group into SL_N(Z). Both embeddings below have the same N = 7. No historical priority or novelty claim is made.

## 1. Exact meaning of the family

For an embedding rho: G -> SL_N(Z), write

    K_rho(m) = {g in G : rho(g) = I_N modulo m},  m >= 1.

The induced congruence subgroups of G are precisely the subgroups containing some K_rho(m). Indeed, intersection with an ambient congruence subgroup has this property. Conversely, if H contains K_rho(m), let C be the inverse image of the subgroup red_m(rho(H)) under SL_N(Z) -> SL_N(Z/mZ). Then C is an ambient congruence subgroup and rho^{-1}(C) = H. This verifies the equivalence with the intersection definition in the source.

We will exhibit a subgroup H that is exactly K_rho1(2), but contains no K_rho0(m).

## 2. An explicit free integral group and a cyclic quotient

Put

    A = [[1,2],[0,1]],       B = [[1,0],[2,1]],
    G = <A,B> <= SL_2(Z).

The group G is freely generated by A and B. Here is the standard ping-pong proof, included to remove any dependency on a presentation computation. On the real projective line, the actions are

    A^r(x) = x + 2r,
    B^s(x) = x/(2sx+1).

Let X_A = {real x : |x| > 1} union {infinity}, and X_B = {real x : |x| < 1}. For every nonzero integer r or s,

    A^r(X_B) is contained in X_A,
    B^s(X_A) is contained in X_B.

The first containment follows from |x+2r| > 1. For finite |x| > 1, the second follows from |2sx+1| >= 2|s||x|-1 > |x|; at infinity, B^s(infinity) = 1/(2s). A nonempty reduced alternating word whose first and last syllables are powers of A sends X_B into the disjoint set X_A; the analogous assertion holds with A and B reversed. A reduced mixed word whose first and last types differ can be conjugated to one whose first and last types agree: for example, if it starts with A^a and ends with a B-power, conjugate by A^r with r different from 0 and a. The resulting first A-exponent a-r and last exponent r are nonzero. Pure nonzero powers are plainly nonidentity. Thus no nonempty reduced word is the identity.

Consequently there is a well-defined surjective homomorphism

    chi: G -> Z/5Z,       chi(A) = 1, chi(B) = 0.

Let H = ker(chi). It has index 5 in G.

## 3. No congruence quotient of this embedding has a C_5 quotient

We prove, uniformly in m, that every homomorphism

    red_m(G) -> Z/5Z

is zero. This is the essential infinite assertion; the finite computation below is only a check.

### Lemma 3.1: elementary generation

For every positive odd integer n, SL_2(Z/nZ) is generated by

    U(1) = [[1,1],[0,1]],       L(1) = [[1,0],[1,1]].

For n = 1 the group is trivial. For n > 1, let M = [[a,b],[c,d]] have determinant 1 in R = Z/nZ. For each prime p dividing n, the pair (a,c) is not (0,0) modulo p. Choose t modulo p so that a+tc is nonzero: if c is nonzero, avoid the single forbidden residue, and otherwise use any residue. The Chinese remainder theorem supplies t in R satisfying all these conditions, so u = a+tc is a unit. Left multiplication by U(t) makes the top-left entry u. Left multiplication by L(-c/u), followed by U(-bu), where b is now the current top-right entry, reduces the matrix to diag(u,u^{-1}). This diagonal matrix is elementary too: putting

    w(u) = U(u)L(-u^{-1})U(u) = [[0,u],[-u^{-1},0]],

one has w(u)w(-1) = diag(u,u^{-1}). Finally U(t) and L(t) are integer powers of U(1) and L(1). This proves the lemma.

### Lemma 3.2: the odd-modulus factor has no C_5 quotient

Let n > 1 be odd. In SL_2(Z/nZ), the matrix D = diag(2,2^{-1}) satisfies

    D U(1) D^{-1} = U(4) = U(1)^4.

For any homomorphism f into the additive group Z/5Z, invariance under conjugation gives f(U(1)) = 4f(U(1)); hence 3f(U(1)) = 0 and therefore f(U(1)) = 0. The element L(1) is conjugate to U(-1), using J = [[0,-1],[1,0]], since J U(-1) J^{-1} = L(1). It also has zero image. Lemma 3.1 shows f is zero.

### Lemma 3.3: separation of the 2-primary factor

Write m = 2^k n with n odd and k >= 0. If k = 0, the 2-primary factor below is the trivial group. Let H_k be the image of G in SL_2(Z/2^k Z), and let J_m = red_m(G). Under the Chinese remainder identification,

    J_m = H_k x SL_2(Z/nZ).

To prove the equality rather than merely subdirectness, note that A^{2^k} and B^{2^k} have identity 2-primary component and odd components U(2^{k+1}) and L(2^{k+1}). The parameter 2^{k+1} is a unit modulo n, so powers of these two elements give (1,U(1)) and (1,L(1)). Lemma 3.1 gives the entire factor {1} x SL_2(Z/nZ). By the definition of H_k, every h in H_k occurs as the first component of some element (h,s) of J_m. Multiplication by (1,s^{-1}) gives (h,1). The claimed product follows. Cases n = 1 and k = 0 use the same argument with their trivial factors omitted.

For k >= 1, H_k is a 2-group. Both A and B are the identity modulo 2, so H_k lies in the kernel of reduction modulo 2. For 1 <= j < k, the filtration by matrices equal to I modulo 2^j has successive quotients embedding into the additive group M_2(F_2), via I+2^j X -> X mod 2. The multiplication cross-term vanishes modulo 2^{j+1}. Each quotient is therefore a finite 2-group, as is the kernel and its subgroup H_k. When k = 1, H_k is trivial.

Every homomorphism H_k -> Z/5Z is zero by Lagrange's theorem. Lemma 3.2 handles the odd factor. Lemma 3.3 now proves that every homomorphism J_m -> Z/5Z is zero.

### Corollary 3.4: H is not congruence for the original representation

If some K(m) = ker(G -> SL_2(Z/mZ)) lay in H, then chi would descend to a nonzero homomorphism J_m -> Z/5Z. That contradicts the preceding theorem. Thus, for every m >= 1,

    K(m) is not contained in H.

In particular H is noncongruence in the exact sense of Section 1. This conclusion does not use a finite search, the congruence subgroup property, strong approximation, simplicity of finite groups, or a classification theorem.

## 4. Two faithful embeddings in the same SL_7(Z)

Let P be the permutation matrix on Z^5 with P e_i = e_{i+1}, subscripts read modulo 5. It is the matrix of a 5-cycle, so det(P) = (-1)^4 = 1 and P has order 5. Its five powers remain distinct after reduction modulo 2: they are distinct 0-1 permutation matrices.

Define

    rho0(g) = diag(g,I_5),
    rho1(g) = diag(g,P^{chi(g)}).

Both are homomorphisms into SL_7(Z). The exponent in rho1 is well-defined modulo 5 because P^5 = I_5. Both are injective because their first block is g itself. They are embeddings of the very same finitely generated abstract group into the very same integral special linear group, with no coefficient-ring or characteristic change.

For rho0, K_rho0(m) = K(m), so H is not congruence by Corollary 3.4.

Every g in G is the identity modulo 2 in its first block. Therefore

    rho1(g) = I_7 modulo 2
       iff P^{chi(g)} = I_5 modulo 2
       iff chi(g) = 0.

Hence

    K_rho1(2) = H.

The subgroup H is a principal level-2 congruence subgroup for rho1, while it is not a congruence subgroup for rho0. The induced families differ. Thus the answer to the source's question “does the notion depend on the embedding?” is **yes, it can depend on the embedding**; embedding independence is false in the stated generality.

## 5. Why algebraic-embedding invariance is a different statement

The familiar embedding-independence result for a fixed linear algebraic group concerns algebraic embeddings, or maps extending to morphisms of the fixed algebraic group. The source here instead allows abstract-group embeddings of finitely generated groups. The extra finite block is a homomorphism of abstract groups. There is no assertion that it extends algebraically from the connected group SL_2. Restricting to embeddings of one fixed algebraic group would be an additional hypothesis absent from the reported question.

The construction is also an instance of a general elementary mechanism: append a finite permutation representation detecting a finite-index subgroup to a faithful integral representation. A normal noncongruence subgroup with finite quotient then becomes congruence in the larger representation, because finite permutation matrices are distinguished modulo 2. If determinant signs occur, append their sign as a one-dimensional block. Here the cyclic group of odd order 5 already has determinant-one permutation matrices, and padding rho0 makes the ambient dimension identical.
