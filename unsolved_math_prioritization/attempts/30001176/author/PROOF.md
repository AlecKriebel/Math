# A tail-trivial exchangeable sequence whose canonical filtration is not a factorization

Problem 30001176 / OWR-3392-002. Author checkpoint: 2026-10-06.

## Result and exact scope

There is a minimal exchangeable sequence of state-preserving, normal, injective homomorphisms from the same four-dimensional commutative probability algebra into a von Neumann algebra with separable predual and a faithful normal trace, whose tail algebra is scalar, but whose canonical filtration fails the intersection axiom for a noncommutative factorization. All the other axioms hold.

More specifically, writing the images as B_i and A_I = vN(B_i : i in I),

    A_{ {0,1} } intersect A_{ {0,2} } strictly contains A_{ {0} }.

Consequently no factorization having the prescribed singleton algebras B_i can exist: its binary join axiom would force its two-site algebras to be the displayed canonical ones.

This is a counterexample to the canonical-filtration interpretation of Conjecture 5 in Claus Köstler's contribution “Noncommutative Factorizations,” Oberwolfach Report 09/2009, pp. 521–523. The report says that a sequence “gives rise” to a factorization, without specifying a separate enlargement procedure. The canonical filtration is defined in its cited reference [5], Definition 1.6, and the immediately preceding example in the report uses generated local algebras. The precise theorem above, including the singleton-preserving impossibility, is what is proved here. It is not a claim that the ambient algebra admits no other factorization. In fact an explicit enlargement does admit one, as explained below.

## 1. An explicit countable group

Let V be the direct sum of countably many copies of F_2, indexed by N_0. Thus each vector has finite support. Put s(b) = sum_j b_j in F_2, and define a bilinear map F: V x V -> V by

    F(a,b)_i = a_i (s(b) + b_i) = a_i sum_{j != i} b_j.

All additions in this construction are in F_2. On G = V x V x V set

    (a,b,c)(a',b',c') = (a+a', b+b', c+c'+F(a,b')).                 (1)

The output has finite support. Bilinearity gives

    F(a,b') + F(a+a',b'') = F(a',b'') + F(a,b'+b''),

so (1) is associative. Its identity is (0,0,0), and

    (a,b,c)^(-1) = (a,b,c+F(a,b)).

Hence G is a countable discrete group. For the coordinate vectors e_i, put

    p_i = (e_i,0,0), q_i = (0,e_i,0), z_i = (0,0,e_i).

The z_i are central involutions, and p_i and q_i are commuting involutions. With [g,h] = ghg^(-1)h^(-1), direct multiplication gives

    [p_i,q_j] = z_i     if i != j,
    [p_i,q_i] = 1.                                               (2)

In particular z_i is nonidentity. The group is noncommutative.

## 2. Exact local subgroups

For I contained in N_0, let H_I be the subgroup generated by p_i,q_i for i in I. Let K_I consist of all triples whose three coordinates are supported in I. The latter is a subgroup because F(a,b') is supported inside the support of a. We have

    H_empty = {1};
    H_{ {i} } = { (a e_i,b e_i,0) : a,b in F_2 };
    H_I = K_I                         if |I| >= 2.               (3)

For the last assertion, choose, for each i in I, any j in I distinct from i. Equation (2) puts z_i in H_I. Thus H_I contains all p_i,q_i,z_i with i in I. These generate K_I: a desired finite a-coordinate can first be formed, then the b-coordinate, and the central error F(a,b) and any desired c-coordinate can be corrected using the z_i. The reverse inclusion follows from support preservation. This proof works equally for infinite I because every group element has finite support.

It follows that the p_i,q_i for all indices generate G, and

    intersection_{n >= 0} H_{[n,infinity)} = {1}.                 (4)

Indeed H_{[n,infinity)} = K_{[n,infinity)}, and a finite-support triple supported in every such tail is zero.

## 3. Faithful tracial von Neumann realization

Let lambda be the left regular representation of G on l^2(G), and let M = L(G) = lambda(G)''. Write tau(x) = <x delta_1,delta_1>. This is the canonical faithful normal tracial state. Countability of G makes l^2(G) separable, and therefore M has separable predual.

For a subgroup H of G, its group von Neumann algebra is naturally the subalgebra L(H) of L(G). The trace-preserving normal conditional expectation E_H onto it is the Fourier projection

    E_H(lambda(g)) = lambda(g) if g in H, and 0 otherwise.        (5)

For completeness, compressing a finite group-algebra sum to l^2(H) deletes precisely the coefficients outside H; the usual coset decomposition identifies its range with L(H). This gives the normal positive unital trace-preserving projection, or equivalently (5) is the orthogonal projection l^2(G) -> l^2(H) in the trace L^2-space. In particular, if x belongs to L(H), then x delta_1 belongs to l^2(H). The trace is faithful: x delta_1 = 0 implies x = 0 because x commutes with all right translations, whose orbit of delta_1 spans l^2(G).

Let D = L(C_2 x C_2) with its normalized trace, with its two canonical commuting generating involutions p,q. Define

    iota_i(lambda(p)) = lambda(p_i),
    iota_i(lambda(q)) = lambda(q_i).

By (3), each iota_i is an injective normal unital *-homomorphism identifying D with B_i = L(H_{ {i} }). It preserves the state, since the four group elements have exactly their usual regular trace. Each image is tau-conditioned by (5). Thus these maps are random variables in the precise sense of Definitions 1.1–1.2 of the reference cited by Conjecture 5. No nonfaithful state or unbounded random variable is being used.

The canonical algebra generated by an index set is exactly

    A_I = vN(B_i : i in I) = L(H_I).                             (6)

Equations (2)–(3) show that A_{N_0} = M, so the sequence is minimal.

## 4. Exchangeability and stationarity

Every permutation sigma of N_0 relabels the coordinates of a,b,c. Because s(b) is invariant and exclusion of i is preserved, F(sigma a,sigma b) = sigma F(a,b). Thus relabeling is a group automorphism beta_sigma of G. The unitary U_sigma delta_g = delta_{beta_sigma(g)} implements a normal tau-preserving automorphism of M and satisfies

    Ad(U_sigma) iota_i = iota_{sigma(i)}.

In particular the joint distribution is invariant under every finite permutation, with arbitrary elements of D and arbitrary repeated indices, exactly as exchangeability requires. This is ordinary permutation exchangeability of noncommutative variables, not quantum-permutation invariance.

Coordinate relabeling by any injection also preserves (1), so joint moments are invariant under order-preserving injections. The sequence is spreadable and stationary as well. More explicitly, the injection i -> i+1 is a group isomorphism from G onto K_{[1,infinity)} and yields the trace-preserving normal endomorphism of M carrying iota_i to iota_{i+1}. A bilateral variant indexed by Z gives an automorphic shift if that separate convention is desired; it is not needed here.

## 5. The von Neumann tail really is trivial

This must be checked at the von Neumann level, not inferred solely from the abstract subgroup intersection. If x lies in every A_{[n,infinity)}, (5)–(6) give

    x delta_1 in intersection_n l^2(H_{[n,infinity)}) = C delta_1

by (4). Hence (x - tau(x)1)delta_1 = 0, and faithfulness implies x = tau(x)1. Scalars plainly belong to every local algebra. Therefore

    A_tail = intersection_n A_{[n,infinity)} = C1.               (7)

This is an infinite-sequence argument; no finite group alone could establish (7).

## 6. Failure of the required meet identity

Take I = {0,1} and J = {0,2}. Equation (2) gives

    lambda(z_0) = [lambda(p_0),lambda(q_1)] in A_I,
    lambda(z_0) = [lambda(p_0),lambda(q_2)] in A_J.

But z_0 does not belong to H_{ {0} }, whose c-coordinate is identically zero by (3). In fact

    E_{H_{ {0} }}(lambda(z_0)) = 0,

whereas lambda(z_0) is a nonzero unitary. It follows that lambda(z_0) is not in A_{ {0} }. This proves the claimed strict intersection.

Even more precisely, subgroup Fourier projections commute and show L(H) intersect L(K) = L(H intersect K). Thus

    A_I intersect A_J = L(K_{ {0} }),

an eight-dimensional commutative algebra, while A_{ {0} } is four-dimensional. The strictness already occurs on three sites, but exchangeability and (7) hold for the whole infinite construction.

## 7. Other axioms, and why de Finetti does not repair the failure

For disjoint I,J the support condition gives H_I intersect H_J = {1}. Equation (5) yields E_{H_I}(y) = tau(y)1 for y in L(H_J), first on group-algebra sums and then normally. The bimodule and trace-preserving properties give

    tau(xy) = tau(x)tau(y)   (x in A_I, y in A_J).

This is full scalar independence in the cited noncommutative sense, also for infinite disjoint index sets. Joins satisfy A_{I union J} = A_I vee A_J by their definition. If I_n increases to N_0, every p_i and q_i eventually occurs, so vee_n A_{I_n} = M. All A_I are tau-conditioned, and the index Boolean algebra P(N_0) is atomic. The failure is exactly the meet requirement; it is compatible with the established de Finetti independence conclusion.

The algebras from distinct sites need not commute: (2) is nontrivial. They are also not scalar-free: lambda(p_i) and lambda(q_j) are centered involutions for i != j, but their alternating product of length eight is lambda(z_i)^2 = 1 and has trace 1. Thus neither tensor-product independence nor amalgamated freeness may be silently substituted for the weaker scalar independence in the report.

If a single selfadjoint operator per site is preferred, set X_i = lambda(p_i) + 2 lambda(q_i). Its four distinct spectral values are -3,-1,1,3, each of trace 1/4. Functional calculus recovers lambda(q_i) = sign(X_i) and lambda(p_i) = X_i - 2 sign(X_i). Hence vN(X_i) = B_i, and the same counterexample holds for this bounded selfadjoint sequence.

## 8. The enlargement qualification is substantive

Define instead C_I = L(K_I) for every I, including singletons. Support intersections, Fourier projections, generation by p_i,q_i,z_i, and the same disjoint independence argument show that (C_I) is a factorization. It agrees with A_I when |I| >= 2, but strictly enlarges every singleton from dimension four to dimension eight. This does not preserve the original random variables' image algebras. Accordingly the result is not a disproof of the different statement allowing arbitrary enlargement, or merely asking whether M admits some factorization.
