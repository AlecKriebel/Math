# A singular quadric obstruction to openness of the ample-subvariety cone

Problem 30003590 / OWR-15586-001. The accompanying independent mathematical
audit accepts a scoped counterexample and a general normal codimension-one
criterion. The original smooth-ambient and higher-codimension problem
remains unresolved by this work.

Over C, the normal singular quadric threefold X = V(x0*x3 − x1*x2) in P^4
has N_2(X) = R^2 in the two ruling-plane classes, while the positive cone
of integral Ottem-ample surfaces is exactly R_{>0}(1,1). It is not open
in the full numerical surface space. The result persists with only smooth
or only lci generators, because a smooth ample hyperplane generates the
ray. Requiring smooth generators does not make the ambient variety smooth.
This example has codimension one.

For any normal integral projective T over C, dimension n at least two,
the cone generated by all integral ample codimension-one centers equals
the image of Amp(T) in N_(n−1)(T). It is open in the full numerical space
if and only if the numerical Cartier-to-Weil map is surjective. The
general criterion does not require smooth generators on arbitrary T.
