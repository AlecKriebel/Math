- SOURCE_METADATA.json records source hashes, byte counts, bibliographic and inspection limits. Source documents and dataset contents are excluded.
- VERIFICATION.json records actual checker runs and denied-write checks.
- MANIFEST.json binds the source-free packet's other files.

The checker is not a Brownian simulation, an infinite-horizon probability calculation, or a replacement for the written proofs. No novelty or full-resolution claim is made.
