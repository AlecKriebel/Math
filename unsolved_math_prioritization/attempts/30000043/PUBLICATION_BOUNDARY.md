# Public-content boundary

Included: complete authored mathematical proof, independent audits, optional separately accepted bridge, source-scope adjudication, explanatory reader text, public bibliographic/version/retrieval metadata, cryptographic hashes and byte counts, and local verification scripts/results.

Excluded: copied third-party PDFs, extracted source text or source screenshots, dataset contents, private sources, private personal data, credentials, conversation exports or links, and private coordination material.

The original authored files are copied exactly. Editorial explanation is in separate reader files. No original proof or audit is silently rewritten to reflect later source discoveries. A strict file allowlist, hashes, anchor pins, path screening, and archive restoration tests support this boundary; these checks cannot by themselves judge all semantic disclosure risks.

The reader is prepared locally. Its creation is not publication, a repository commit, or a claim that a manuscript has been accepted by a journal. Any future repository publication should use precisely the sealed public files and independently preserve the stated boundary.
