# Reproducibility and the limits of finite checks

Requirements: Python 3.10 or later and its standard library. No third-party
packages, network requests, credentials, or external datasets are needed.

From the extracted public package root, run:

    python verify_package.py
    python run_checks.py > replay.json

Put redirected replay output outside the extracted package if you want its
exact file-set integrity check to keep passing. The runner itself writes only
in an automatically removed temporary copy. For example, from the package's
parent directory:

    python public/verify_package.py
    python public/run_checks.py > replay.json

`verify_package.py` checks every payload size and SHA-256 against
[MANIFEST.json](MANIFEST.json), rejects missing or extra files, and uses explicit
runtime failures. It does not authenticate external sources or prove a theorem.
The manifest's own hash is in the enclosing archive receipt, not in itself.

`run_checks.py` runs the nineteen preserved checker/diagnostic scripts listed
in its `RUNS` tuple. Each child uses isolated Python without optimization.
The runner refuses `-O` or `-OO`, strips an optimization environment setting,
and adds explicit result checks and six malformed-certificate controls.
Some preserved scripts use `assert`; do not run those scripts directly with
optimization enabled. Historical optimized-run receipts are retained where
present, but an optimized run of an assertion-based script is not evidence
that its assertions executed.

## Finite proof components

- The [four-known-deadlines theorem](pass3_deadlines/FOUR_DEADLINES.md) includes
  an analytic reduction covering every non-enumerated parameter regime and an
  exact infinite-tail identity. Its remaining finite part is regenerated by
  [the author checker](pass3_deadlines/verify_four_deadlines.py) and compared
  with an independent sparse-integer/rational implementation in
  [the independent replay](pass3_devil/replay_four_deadlines_independent.py).
  All 180 exact costs and denominator triples are recomputed; the maximum is
  34777/50976 at (2,2,2). The finite computation is part of that restricted
  computer-assisted proof. The analytic coverage cannot be replaced by the
  successful program run alone.
- The [one-dimensional six-round certificate](pass1_survival/terminal_1d_horizon6_certificate.json)
  lists all responses of a legal Devil strategy. A separate verifier checks
  its graph, and [absolute-coordinate replay](pass1_game_audit/replay_1d_certificate_independent.py)
  tests all 729 complete Angel move words. Six malformed variants must be
  rejected. The resulting theorem concerns the one-dimensional game only.

## Supplementary diagnostics

The other programs check finite geometry, exact arithmetic, selected bounds,
explicit periodic schedules, or specified counterexamples. In particular:

- Finite-game smoke tests cover horizons 1 through 4 and all 511 nonempty
  subsets of the nine-neighbor square. Survival through move 17 is proved
  analytically, not inferred from those four horizons.
- Three-deadline and concentration checks corroborate symbolic arguments.
  The step-27 denominator failure is failure of one sufficient recursion.
- Tracking/bridge, minimum-lead, and mass-family checks test the stated
  formulas; they do not solve arbitrary-H games.
- The adaptive 24-pair example replays all 729 three-move words from its
  specified preload. It does not force that preload from an empty history.
- The periodic heavy-layer replay reconstructs 15552 selected states of an
  explicitly safe history. Its all-H formulas have separate analytic proofs.

[CHECK_REPLAY.json](CHECK_REPLAY.json) records the package author's fresh run,
including each script's hash and output. The original per-script receipts
are supporting records, not substitutes for rerunning the corresponding
checks. No unbounded search, full conjecture certification, or formal proof
assistant verification is claimed.

## Version identities

[ORIGINAL_IDENTITIES.json](ORIGINAL_IDENTITIES.json) distinguishes exact copies
from public adaptations. Nearly all proof/audit/checker bytes are unchanged.
Two public adaptations are labeled: one audit drops only an ancillary
summary citation, and one acceptance inventory uses public relative paths.
The public rules document is newly authored and explicitly disclaims identity
with the historical source-contract hash. Some older audits pin earlier
versions; the linked anchor/version addenda in the
[results index](RESULTS_INDEX.md) accept the current versions.
