## Exact source scope

The AIM source uses proper singular points. Dimca–Harbourne–Sticlaru uses an all-infinitely-near default and explicitly distinguishes the proper-point variant. We keep the AIM convention. Orevkov proves the degree-ten example; that established existence theorem is credited. The new application uses the graph extension in his §1.3, not a claim that his example solves the Harbourne question.

During the historical source review, the author-hosted version was freshly retrieved as an additional current-version check. Its §1.3 still describes n≥5 as untried. No Fatou/Epstein reference was found in a targeted full-text search of that version.
