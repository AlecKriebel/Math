# Scope clarifications for the frozen partial results

Problem 10900010 / AMR-108-0010, rank 672. Status: **unsolved, 5/5 approaches; no general resolution.**

This separate supplement adopts the three optional precision improvements identified in the independent audit. The frozen author packet and the full audit are unchanged. Read these conventions with author/PROOF.md; they do not extend its theorems or claim novelty.

1. **Nonminimal trees and zero edge classes.** A fixed-point-free action can have a pendant edge outside its invariant core. For example, attach one terminal edge equivariantly at every integer vertex of the translation line. A map landing in the invariant line avoids the pendant midpoint, so its action-defined edge class is zero. One cut side has no ends. The nondegenerate end-separating interpretation is therefore limited to relevant core edges; no argument here requires every edge to have two nonempty end-sides. The zero class has the empty descending representative and norm zero. This is not a counterexample to the intended question.

2. **Ordinary homology uses closed surfaces.** Every compact oriented surface representing an ordinary H_2 class in these arguments is understood to be closed. A surface with unpaired boundary belongs to a separately specified relative-homology formulation. The packet does not prove a boundary-manifold extension.

3. **A selected scaled-translation orbit is primitive.** For an action obtained by multiplying a primitive line-translation character by a positive integer k, there are k edge orbits in one primitive period. Each selected edge orbit gives the primitive kernel-cover class. Taking all k orbits together sums k primitive classes and changes the chosen-edge problem.

The translation-line and exact surface-group results are qualified special cases. The dihedral example separates upstairs norm from the norm of the pushed-forward class while retaining a descending minimizer; it is not a counterexample to Agol's target. The unresolved task remains a general norm-preserving choice satisfying all translate-disjointness conditions, or a verified example where none exists.
