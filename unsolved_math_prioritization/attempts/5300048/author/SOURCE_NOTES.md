# Source interpretation and bounded literature findings

## Primary question

Przytycki's contribution to IMS 1992/7, printed pp.29–30, sets up an attracting
proper self-map of a simply connected spherical domain. Problem 1.1 literally
asks about every periodic boundary point. Its discussion explicitly includes
the polynomial basin at infinity. These features were checked in the page
image as well as the text. The catalogue research record's parenthetical
“Q2” is therefore an indexing discrepancy, not the primary problem number.

Source: https://www.math.stonybrook.edu/preprints/ims92-7.pdf

The 1992 comment also states a positive result for polynomial infinity basins.
This packet preserves that historical statement without treating the comment
as a proved neutral-point theorem. The inspected later accessibility theorem
has precise repelling/good-point hypotheses, and the literal all-periodic
wording is not silently narrowed. Clarifying a historical wording issue is
not a solution or a counterexample.

## Imported accessibility theorem

Przytycki (1994), printed p.260, defines a good boundary point using conditions
(0.0)–(0.3). Theorem A concludes accessibility. Corollary 5 of this packet
verifies each condition for its restricted rational-map criterion. In contrast,
the coding-tree Theorem D, printed p.266, has uniform edge shrinking and an
inverse-branch basin-side condition. Omitting these restrictions would change
the theorem. The 2020/2021 survey's Theorem 8.1 retains corresponding conditions.

Sources: https://www.impan.pl/~feliksp/access.pdf and
https://www.impan.pl/~feliksp/Siles.pdf

## Bounded polynomial components

Roesch–Yin (2008), Theorem 1, covers bounded polynomial Fatou components not
eventually Siegel. It yields the Jordan-boundary case used in the introduction.
It is credited prior work, and does not resolve all rational/local-holomorphic
basins or the infinity-basin issue under the literal wording.

Source: https://archive.numdam.org/articles/10.1016/j.crma.2008.06.004/

## Local hedgehogs and global realization

Biswas's version 4 Theorem 1.2 concerns a nonlinearizable local germ and a
hedgehog with an inaccessible fixed point. It does not supply the required
global rational or polynomial realization. Only that precise conclusion is
used. The packet makes no stronger claim about all prime-end impressions.

Source: https://arxiv.org/abs/1010.4496

Blokh–Oversteegen's Lemma 5.3 supplies a conditional inaccessible Cremer point
for red-dwarf Julia sets. The Blokh–Buff–Chéritat–Oversteegen existence theorem
is for solar Julia sets, and the discussion after Theorem 1.2 in the public
arXiv PDF leaves red-dwarf existence as a question. It is invalid to combine
the two statements into an existence proof of an inaccessible periodic point.

Sources: https://arxiv.org/abs/0809.1071 and https://arxiv.org/abs/0812.1239

The recovered solar PDF has 19 pages and author-format metadata from 2007;
the public arXiv version has 20 pages. Both relevant theorem statements were
inspected. The metadata does not claim these files are byte-identical.

Cheraghi's version 5, Remark 8.16, discusses the distinction between high-type
rational hedgehogs and arbitrary local germs. It does not provide the missing
realization or an accessibility theorem for the stated basin problem.

Source: https://arxiv.org/abs/1706.02678

## Limits of the source work

These are bounded source checks, not an exhaustive modern literature or
priority review. Recovered PDF and extraction hashes identify exactly the
local inspection inputs; their original retrieval timestamps were not recovered.
Public URLs and current version metadata were checked again on 7 October 2026,
but live PDF bytes were not re-downloaded to assert hash equality. No source
text or PDF is included in the authored packet.
