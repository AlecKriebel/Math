# Candidate literature resolution

For every nonempty link L and odd N>1, the original2001 Borel QHI normalization used by Ohtsuki’s defining reference satisfies

K_N^old(S³,L) = N^(-2N) J_N(L)^N.

Multiplying K_N^old by N^(2N), equivalently normalizing its unknot value to1, gives J_N(L)^N. The proof uses credited Kashaev, Murakami–Murakami and Baseilhac–Benedetti results, with an explicit root-only closed-triangulation gauge comparison. PROOF.md records the later mirror, differing notation and short-survey edge-sign discrepancy.
