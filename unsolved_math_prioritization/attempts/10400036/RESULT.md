## Strongest proved substitute

For an arbitrary smooth or tame based string link, delete the distinguished last strand and form the exterior of the others. Fix a nonrepeating target word. There is a canonical based representation into an upper unitriangular integer matrix group, constructed by solving integral flatness equations relative to the bottom punctured disk. The pair is integrally acyclic, so the extensions exist and their holonomy is unique up to boundary-fixed gauge.

Pass to the marked cover associated to the quotient by the top central matrix entry. The central residual along its lifted edges is an ordinary closed integral one-cocycle. It is represented by a genuine properly embedded oriented surface in that cover. A boundary return path calculated only from proper-subword coefficients makes the distinguished strand's lift closed. Its signed intersection with the surface is exactly the desired Milnor coefficient. Filling choices, representative surfaces and alternate return words with the specified full matrix image do not change this integer.

The surface can be noncompact and the return path depends on lower data. The covering surface has not been identified with the original recursively derived downstairs link. This difference is the remaining target gap; it is not concealed by redefining holonomy to mean the requested linking number.
