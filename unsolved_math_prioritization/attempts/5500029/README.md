# Hamiltonian-path tetrahedralizations: accepted partial

Problem 5500029 / AMR-054-0029 / TOPP 29. The unrestricted problem remains
unresolved here; the recorded TOPP source labels it Open.

## Exact target

A full-dimensional convex 3-polytope, using its original extreme vertices,
with no Steiner points, positive-volume face-to-face tetrahedra, and a
Hamiltonian path in the triangular-face-adjacency dual. Coplanarity and
nonsimplicial facets are allowed. This is not a cycle-only problem or an
arbitrary-point-set problem with extra prescribed boundary points.

## What is established

[PROOF.md](PROOF.md) retains the complete degree-three deletion/reinsertion
proof, including the flat-boundary flip and outside-complex conformity
argument. A vertex-minimal counterexample must have minimum degree at
least four. Credited positive classes include simplicial boundary duals
with a Hamiltonian cycle, simplicial polytopes with at most twenty vertices
using Holton–McKay's theorem, pyramids of any size, and their applicable
degree-three extensions.

The explicit seven-vertex family disproves naive generic specialization
followed by deleting flat tetrahedra. The degree-four fixture disproves
one independent local replacement rule. Both polytopes still have other
Hamiltonian tetrahedralizations; neither is a counterexample to TOPP 29.
