# Massive double-cone modular generators: partial investigation

Problem 30005723, OWR-14298009-001. Research date: 3 October 2026.

**Verdict: unresolved after five substantive attempts.** No full answer is claimed
to either the continuum mass-independence question or the unrestricted
multiplication-operator question. The exact finite-dimensional calculations below
are not counterexamples to the continuum statement.

parabolic multiplier ansatz creates an unwanted Yukawa tail in its conjugate
block. Its modular interpretation requires the global operator realization
specified in [the report](REPORT.md); it does not exclude every possible
mass-dependent multiplier or prove convergence of a numerical scheme.
