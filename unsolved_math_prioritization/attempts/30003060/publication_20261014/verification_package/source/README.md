# Positive-characteristic obstruction to unrestricted higher Koszul equivalence

Problem 30003060 / OWR-14218-004, queue rank 865. The literal unrestricted-field equivalence is disproved in every positive characteristic: the free algebra k<x,y> is Koszul, but its higher Koszul homology in degree one is nonzero. The characteristic-zero vanishing-to-Koszulness converse remains unresolved in this investigation. This does not resolve the converse named by the queue title.

The algebraic argument covers every field of positive characteristic, not only sampled primes. One substantive approach was used. Two independent AI-assisted mathematical and source-scope reviews accepted the literal counterexample. This is an unrefereed mathematical contribution with no novelty, first-priority, human-review, or formal proof-assistant certification claim.
