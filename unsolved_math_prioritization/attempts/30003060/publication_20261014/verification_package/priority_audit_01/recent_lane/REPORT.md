## Adversarial priority assessment and limits

Several tempting shortcuts fail: the same word “higher” need not denote this e_A complex; tensor-algebra cohomology does not equal coefficient-A homology; trivial-module coefficients erase the defining differential; duality can change coefficients; quiver results can change the degree-zero base; and a characteristic-zero theorem does not settle its positive-characteristic extension. None of those substitutions was accepted as an earlier exact answer.

Conversely, failure to locate an exact sentence does not create a new theorem. The candidate specializes the established two-term free-algebra complex and cap formula; the orbit computation uses the elementary invariant-to-coinvariant map. An explicit classical derivation could already be known without using BLS terminology. This lane does not determine first priority for those underlying mechanisms, and the parent classical-sources lane must be considered before any stronger originality assessment.
