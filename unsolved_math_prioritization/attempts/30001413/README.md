# Hinged-plate positivity: known improvements and remaining gap

The [source/proof audit](PARTIAL_SOURCE_AUDIT.md) preserves the original curvature-dependent variational problem and its all-load meaning. Romani's published 2017 result already permits convex C¹,¹ boundaries for the full -1<sigma<1 interval. A stadium gives an explicit domain outside the original regularity class. Gazzola–Sweers 2008 also gives positivity on any fixed smooth domain, including a nonconvex annulus, in a domain-dependent interval immediately below sigma=1.

**Conservative overall status: unsolved, 2/5 approaches.** The latter interval cannot be replaced by an arbitrary prescribed sigma or the entire original parameter range. No optimal geometric/minimal-regularity classification is proved. These are credited results and specializations, with no novelty claim.
