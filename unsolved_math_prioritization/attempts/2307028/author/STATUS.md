# Function Theory Problem 7.28 status and attribution

Both alternatives have an affirmative answer in an existing preprint: Qiteng Guo and Ao Xiao, *An Infinitesimal Circular Morera Theorem*, arXiv:2608.04540v1, submitted 5 August 2026. Theorem 1.1 covers the pointwise limit condition; Corollary 1.2 covers exact vanishing at all sufficiently small radii. This report credits that result and claims no new resolution.

The source problem is Hayman–Lingham, *Research Problems in Function Theory (New Edition)*, arXiv:1809.07200v2, Problem 7.28, printed page 168. Its 2018 update reports no progress. That historical update is superseded, for status assessment, by the 2026 preprint. The complete preprint was inspected. Its listed arXiv record has one version and no journal reference; journal acceptance was not established.

Let D be a plane domain and f continuous on D. Set J_f(a,r) equal to the positively oriented integral of f(z) dz around |z-a|=r. The weaker hypothesis is J_f(a,r)/r² → 0 at every a as r → 0 through all positive radii for which the closed disk lies in D. There is no uniformity assumption in the center and no differentiability assumption. The stronger hypothesis gives J_f(a,r)=0 for every sufficiently small r, with a center-dependent threshold. It implies the weaker one.
