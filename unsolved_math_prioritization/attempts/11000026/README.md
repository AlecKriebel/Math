# Uniform intrinsic detours in Teichmüller balls

Problem 11000026 (AMR-109-0026). A theoretical proof and its independent AI mathematical audit.

For each fixed closed oriented genus g ≥ 2, any two points in any original closed Teichmüller ball can be joined inside that ball with length at most their ambient distance plus 4c_g. Thus N_g(k) = k + 4c_g for every fixed k > 0, including the distance-two bound 2 + 4c_g. The substantive uniform quasiconvexity input is Lenzhen–Rafi (2011), Theorems C and 17. No historical novelty is claimed.
