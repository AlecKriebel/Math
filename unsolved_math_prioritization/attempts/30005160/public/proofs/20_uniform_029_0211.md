# Proof 20  Fixed counterexamples on zero two nine and zero two eleven

This is a reading edition of an accepted authored proof. Its mathematical scope is unchanged. Source and reading-edition hashes are recorded in the [inventory](../CONTENT_AND_DEPENDENCIES.md). No novelty claim is made.

Proof dependencies included in this package: [A fixed counterexample on zero two seven](19_uniform_027.md).

Public analytic inputs and exact attribution are listed in [References](../REFERENCES.md).

## Theorem

For every 4<p<6, each of the following plus-minus norm-power differences is strictly negative:

    integral |70+90z²+63z⁹|^p − integral |70−90z²+63z⁹|^p;
    integral |90+110z²+63z¹¹|^p − integral |90−110z²+63z¹¹|^p.

Consequently both frequency supports fail the real constant-one majorant property throughout (4,6). These are fixed integer coefficients independent of p.

## Analytic framework

Use exactly the convergent normalized series and endpoint-zero factorization proved in [A fixed counterexample on zero two seven](19_uniform_027.md). For general odd K≥7 and positive integer amplitudes A,B,C, put M=(A+B+C)² and

    P_±=A±Bz²+Cz^K,
    U_±=1−|P_±|²/M,
    μ_j^±=CT(U_±^j),
    w_j(q)=product_(r=4)^(j−1)(r−q)/j!,  q=p/2.

The primitive affine relation (K−2,−K,2) has mass K, so the S-moments agree below K; in particular μ_j^+=μ_j^− for j≤3. Thus

    D_p=−M^q q(q−1)(q−2)(3−q) F(q),
    F(q)=sum_(j=4)^infinity w_j(q)(μ_j^+−μ_j^−).

The same tail identity and moment bound apply. It is enough to certify F(q)>0 for the closed q interval [2,3].

The integer Laurent kernels for the moments are

    M U_± = M−A²−B²−C²
            ∓ AB(z²+z^(−2))
            ∓ BC(z^(K−2)+z^(−K+2))
            − AC(z^K+z^(−K)).

## Bounded-error integer convolution

The separate program [certify_uniform_odd_family.py](../certificates/certify_uniform_odd_family.py) avoids the growth of exact numerators M^j while retaining rigorous bounds. Let b=160 and B_work=b+N+4. It starts with the integer array representing 2^(B_work) at exponent zero. At each step it convolves that integer array with the displayed integer kernel, divides each new entry by M, and rounds downward using integer floor.

If the true Laurent coefficients of U^j are multiplied by 2^(B_work), the absolute error at every array entry after j steps is at most

    E_j=2^j−1.

Indeed the kernel's coefficient l1 norm is

    (M−A²−B²−C²)+2(AB+AC+BC)=4(AB+AC+BC)≤2M.

Therefore the next error is at most 2E_j+1=E_(j+1). The starting error is zero. Signed coefficients cause no difficulty because the absolute-value bound uses the l1 norm. This argument includes coefficients outside the previous support, which are treated as exact zeros before convolution.

Each desired moment is enclosed by taking the rounded constant coefficient, adding/subtracting E_j, and outward-rounding again to the grid of step 2^(−160). All subsequent weight recurrences, interval products, finite sums, and tails use the same outward integer arithmetic as the exact-moment {0,2,7} certificate. Thus neither the convolution nor the exponent interval verification relies on floating-point approximation.

## Exact certificate output

The script takes amplitudes (A,B,C)=(10(K−2),10K,63). Only K=9 and K=11 are certified here; the formula is not a theorem for other K.

For K=9:

- (A,B,C)=(70,90,63), M=49729;
- N=512, 1024 adjacent rational q bins, B_work=676;
- saved output: [uniform_029.json](../certificates/uniform_029.json);
- every bin's lower bound is positive; the minimum is

    119319445447135259339564580153619857222443 / 2^160 > 0.

For K=11:

- (A,B,C)=(90,110,63), M=69169;
- N=1024, 2048 adjacent rational q bins, B_work=1188;
- saved output: [uniform_0211.json](../certificates/uniform_0211.json);
- every bin's lower bound is positive; the minimum is

    44306455945107035590549525769604875516432 / 2^160 > 0.

The displayed decimal margins in the JSON files are diagnostics only. Acceptance uses the exact integer numerators. The script raises an exception on a nonpositive lower bound. Reproduce with:

    python certify_uniform_odd_family.py --K 9 --N 512 --bins 1024
    python certify_uniform_odd_family.py --K 11 --N 1024 --bins 2048

## Scope and remaining family

These two certificates, together with the separate {0,2,7} certificate, exclude K=7,9,11 throughout (4,6). They do not classify {0,2,5} or {0,1,3}. The separate [Proof 30](30_all_odd_triples.md) excludes every odd K>=7 at each prescribed exponent; the present tuples retain the stronger fixed-coefficient full-interval conclusion.
