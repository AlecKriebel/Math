# Five-generator principal matrices: proved partial obstructions

Problem 30003308 / OWR-15178-016. The original non-complete-intersection
classification remains OPEN/PARTIAL. No complete classification or novelty
is claimed.

The proof preserves two results:

1. Two primitive minimal five-tuples have identical singleton sets of genuine
   rank-three principal matrices but different Gorenstein outcomes. The
   Gorenstein member is a complete intersection, so this information-loss
   obstruction concerns the full class including complete intersections.
2. Every genuine rank-four, column-balanced principal matrix with primitive
   adjugate and exactly the specified five cyclic off-diagonal zeros has at
   least two pseudo-Frobenius numbers. One such matrix certifies the underlying
   semigroup non-Gorenstein; no necessity or pattern-invariance claim is made.

The gcd assumption is collective. All choices and the saturation hypothesis
remain explicit.
