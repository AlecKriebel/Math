# Mean-curvature flow from isolated conical singularities

**Problem 30001005 / OWR-2045-001, queue rank 445.**

## Result and scope

Universal short-time smoothing in the unrestricted locally finite integral-Brakke class, with noncompact initial data allowed, has a classical counterexample in hypersurface dimension n = 7: the stationary Simons cone

\[
C=\{(x,y)\in\mathbb R^4\times\mathbb R^4:|x|=|y|\}.
\]

It has a smooth compact link and exactly one singular point. Its multiplicity-one stationary integral Brakke flow stays singular at every positive time. It is already self-similar, since \(\sqrt t C=C\). Thus requiring both expander asymptotics and short-time smoothness is false under this explicit interpretation of the unspecified flow class. This does not separately disprove self-similar asymptotics.

This is a **credited classical obstruction and source-scope correction**, not a new mathematical discovery. The original report distinguishes its selected flows from arbitrary weak flows. No claim is made here to settle every interpretation of its two separately stated questions, or a compact-data variant with additional selection assumptions.
