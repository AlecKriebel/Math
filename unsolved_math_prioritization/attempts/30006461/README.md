# Multiplication-table limit profile: source and proof audit

The target is strict nonconstancy of the multiplication-table profile announced by Green–Sawhney in OWR 51/2025, pp.2725–2727. The published report was read in full for this contribution. The full April 2026 manuscript concerns the analogous permutation model and lists the multiplication-table proof as forthcoming. The two profiles are distinct targets.

Research is in progress. No full solution or historical novelty is claimed. All proposed mathematical conclusions require separate adversarial review before a PR.
