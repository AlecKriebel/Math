## Independently reconstructed candidate mechanism

For any source-form allocation, theta_(0,y)nu=nu implies tau((i,y))=(i,y)+pi(theta_(i,0)nu), i=0,1: each entire source line undergoes a fixed translation. Preservation forces both image lines into {0,1}; every target line has positive mass, so the induced two-element map is surjective and hence a permutation. Unequal weights prohibit swapping, so both lines map into themselves. In particular tau(0) is vertical and theta_tau(0)nu=nu. Thus every admissible preserving allocation fixes the rooted pair law, not just a chosen finite list. Identity shows the class is nonempty.
