# Source interpretation and retrieval issues

- Exact target: OWR 54/2009, Problem 10, printed p.2961. The report meeting was 6-12 December 2009; the publication file was produced in 2010. The imported title uses 2010 while proposed_year is 2009. This is bibliographic, not a new mathematical theorem.
- The displayed report codomain has a bar: f maps C to the Riemann sphere. Plain extracted text can lose that bar. It is a meromorphic elliptic function, not an entire doubly periodic nonconstant map to C.
- The cited 2004 paper explicitly uses the spherical metric for its principal Hausdorff/packing theorem. The normalized atomless conformal measure is spherical. Its Euclidean conformal version is weighted and infinite on the whole plane.
- h denotes the dimension of the full Julia set. The next report problem concerns a radial Julia set of an exponential map; that is a different problem.
- Gauge equality, equivalence, and comparable ball densities are different statements. Only the first is the exact target. Gauge normalization is free.
- The 2020 manuscript imposes regularity in its general compactly nonrecurrent class and proves it for the parabolic subclass. No extension to all compactly nonrecurrent maps without that condition is asserted here.
- The source phrase concerning attraction is treated in the usual basin sense. Critical points merely landing on parabolic cycles should not be silently identified with the no-critical-points-on-J subclass.
- The 2004 author PostScript and its locally converted PDF are not claimed byte-identical to the journal version. EMS and TIB report PDFs have different fingerprints; both contain the same relevant question, with the EMS page visually checked.
- Simmons's theorem is a Kleinian-group theorem with explicit log-gauge regularity assumptions. Its abstract is broader than the theorem's written hypothesis. Neither an unrestricted-gauge conclusion nor an elliptic theorem is inferred from it.
