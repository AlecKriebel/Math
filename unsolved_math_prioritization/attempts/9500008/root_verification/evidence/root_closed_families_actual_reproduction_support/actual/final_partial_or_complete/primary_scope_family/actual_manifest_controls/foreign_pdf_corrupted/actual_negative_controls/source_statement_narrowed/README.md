# Bounded Brownian concatenations

The original random-time-origin problem remains **unsolved**. [PARTIAL.md](PARTIAL.md) proves a pathwise Brownian approximation with almost-sure logarithmic-scale error and a two-sided diffusive scaling limit. It does not construct the exact finite random shift required by the original source.

The frozen mathematical artifact passed [separate adversarial review](review/REVIEW.md). The report, reproduced submitted tests, and independent controls are preserved unchanged in review/. No novelty or priority claim is made; the piece-rotation mechanism is credited to Burdzy and Scheutzow.

Two of five substantive attempts were used. Run python3 verify.py in this directory for the finite exact diagnostics. These checks are not a substitute for the probabilistic proof.
