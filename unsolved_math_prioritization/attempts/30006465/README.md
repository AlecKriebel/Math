# Signed representatives: validated prior resolution

Problem 30006465, rank 1214, corpus ID OWR-14299577-018.

**Both original questions are answered by Alper Ferudun's 28 September 2026 note.** This packet is an independent mathematical acceptance audit of that existing public argument, with no correction required and zero new-proof-search turns. The prior note is [*Differences of Signed Representatives: Sharp Answers to Two Questions of Bernert and Arala Santos*](https://doi.org/10.5281/zenodo.23006720), version 1.0, explicitly unrefereed and AI-assisted.

For a set A containing exactly one of k and -k for each 1<=k<=n:

- At most two integers in [1,n] fail to lie in A-A.
- For every B subset of [1,n], the number of ordered pairs (a,b) in A squared with a-b in B is at least floor((|B|-1)^2/4).
- The first bound is attained for every n>=2. The second is attained for every n>=2 and each 1<=m<=floor(2n/3)+1, with |B|=m.
- For fixed 0<epsilon<=1 and n>2/epsilon, the original positive-density question admits the explicit bound epsilon^2 n^2/9. The leading coefficient 1/4 is optimal for 0<epsilon<=2/3.

The equality cutoff is proved sufficient. Its necessity for arbitrary n and the ancillary classification and uniqueness remarks are not proved. Positive epsilon-dependent quadratic lower bounds require the asymptotic interpretation; small n can have zero counted pairs.
