# EP757 / 2291: a seed-specific strong-Sidon extension obstruction

For the exact 14-point integer seed in Ma–Tang, arXiv:2602.23282v2,
Lemma 5.1, printed page 13, every real (4,5)-extension by k<=2 points has
largest strong-Sidon subset of size 8+k. The statement includes irrational
additions and every nonconstant affine image of the seed. It rules out a
16-point example with maximum nine containing that affine seed. It does not
rule out other 16-point constructions. No global improvement or novelty is
claimed; the located bounds remain 9/17<=c_*<=4/7.
