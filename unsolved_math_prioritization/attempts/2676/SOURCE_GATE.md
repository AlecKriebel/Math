## Source and edition

The pinned record asks whether two links, exactly one of which is alternating, can have homeomorphic double covers branched over the links. Links are understood in the standard tame/smooth category in S^3. The question does not restrict to knots, prime links, nonsplit links, or a particular geometry of the covering manifold. Alternation is a property of the link type, not of a supplied diagram. Orientation reversal does not change alternation, so oriented-cover reductions must explicitly allow mirroring a branch link.

The actual 2026 preliminary K3 book, edited by Baykur, Kirby and Ruberman, has this question as Problem 1.17 on printed p.26, scribed by J. Greene. Its brief discussion conjectures a negative answer and records only partial evidence. The catalog's cited AIM URL, https://aimath.org/pastworkshops/kirbylistrep.pdf, currently gives a four-page workshop report rather than the full problem list. The full author-posted preliminary book is https://bpb-us-e2.wpmucdn.com/websites.umass.edu/dist/b/22144/files/2026/04/K3-problem-list-watermarked.pdf . This copyrighted reading copy is not reposted in the repository.

Greene's complete arXiv:1103.0487v1 (2 March 2011), https://arxiv.org/pdf/1103.0487, states the same conjecture as Conjecture 1.3 on p.4. The K3 reference to Conjecture 1.4 is to the published Inventiones edition, volume 192 (2013), pp.717–750, DOI 10.1007/s00222-012-0421-4. Publisher metadata confirms that edition; its PDF URL returned an HTML landing page here, so the published full-text numbering is attributed to K3 rather than misrepresented as directly read. Greene's December 2011 follow-up questions independently state the same target as Conjecture 0.3. Older Kirby Problems 1.22 and 3.25 concern the broader classification of common-cover knots and are related, not identically numbered versions of this item.

Greene's Theorem 1.1 assumes both diagrams are connected reduced alternating diagrams. It classifies that already-alternating pair via mutation and cover/Floer invariants. It cannot be used to prove that an unknown branch link is alternating. Conway mutation preserves alternation, so merely constructing a mutant is not a mixed-alternation counterexample.

Paoluzzi's complete 2021 paper, DOI 10.5802/ahl.89, still explicitly discusses the unresolved two-fold conjecture. Its prime alternating knot uniqueness theorem is for cyclic degree strictly greater than two; neither the degree-two case nor all links can be imported from it. Targeted later searches on 2026-10-01 found no primary full resolution of the present question. The 2026 K3 edition still presents the question. This is a dated literature check, not a novelty guarantee.
