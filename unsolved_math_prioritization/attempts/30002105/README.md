# kNN recovery: observation scope and necessary hypotheses

**Unsolved, two approaches.** The [partial result](PARTIAL.md) preserves the original undirected union-kNN observation. It gives an exact finite ambiguity in recovering directions and a smooth disconnected-support coupling obstruction to globally normalized density and geometry recovery when `k/n → 0`.

The connected-support undirected problem remains unresolved here. The finite example is not an asymptotic counterexample, and the disconnected example is not transferred to a connected sampling class. Existing directed-graph density/metric and ordinal-embedding results are credited. The 2013 roadmap's explicit graph-only conjecture and the 2015 theorem's additional equicontinuity assumption are retained.

Run `python3 verify.py` for 11,803 exact controls over 48 rational clouds and 144 coupled graph pairs. These controls supplement the proof, not replace it. Separate adversarial review is pending. No novelty claim or source-PDF redistribution is made.
