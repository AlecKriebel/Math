# A known affirmative answer to Rényi's two-value question

**Catalogue:** 2302005 / AMR-022-2005  
**Source item:** Hayman–Lingham, *Research Problems in Function Theory*, Problem 2.5  
**Checked:** 3 October 2026  
**Outcome:** The specific two-value existence question was answered affirmatively by A. A. Gol’dberg in 1968. No new resolution is claimed.

For an entire function \(f\), define
\[
 E(f)=\{a\in\mathbb C:\text{every nonempty open angular sector contains infinitely many distinct solutions of }f(z)=a\}.
\]
There exists a transcendental entire function with \(E(f)=\{0,1\}\). More generally, Gol’dberg's published theorem realizes every bounded, closed, at-most-countable subset of \(\mathbb C\) as such a set.

The original theorem and proof occur on pp.191–198 of A. A. Gol’dberg, *О распределении значений целой функции по аргументам* [On the distribution of the values of an entire function with respect to arguments], *Acta Mathematica Academiae Scientiarum Hungaricae* **19** (1968), 191–199. The [Hungarian Academy's journal archive](https://real-j.mtak.hu/7416/) provides the original scan.

The [2018 source edition](https://arxiv.org/abs/1809.07200v2) already credits this work in Update 2.5, printed p.24. Thus the catalogue's earlier open-status triage overlooked the update. The original theorem is sufficient: apply it to the compact two-point set \(\{0,1\}\).
