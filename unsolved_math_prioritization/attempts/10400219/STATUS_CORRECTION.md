# 10400219 / AMR-103-0219: credited source-status correction

**Recommended status: already_solved, 0/5 new substantive author turns.** The answer to Askitas's Problem12.14 is negative. Livingston proved that the knot7_4 has four-genus1 and slicing number2. Ohtsuki's final source already records this in the Update immediately following the question on printed p.538.

The target is the minimum total number of ordinary crossing changes needed to reach some slice knot, allowing any diagram. It is not the unknotting number, a signed maximum of positive/negative changes, a generalized multi-strand twist count, or the number of double points of an immersed disk. The full published proof of the known counterexample was read; the verification and a minor arithmetic correction are documented in SOURCE_AUDIT.md and checked locally.
