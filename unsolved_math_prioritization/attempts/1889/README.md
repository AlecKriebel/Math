# Finite affine residue patterns: accepted partial theorem (EP25 / 1889)

This unrefereed, AI-assisted proof and independent internal AI audit establish
a sufficient condition for logarithmic density in the singleton truncated
congruence problem. The unrestricted singleton Erdős problem is unresolved
by this work. No novelty, external human peer review, journal acceptance of
these authored documents, formal proof-assistant certification, or fresh
worldwide open-status determination is claimed. “Accepted” means only the
internal audit's stated partial mathematical scope.

For strictly increasing positive integer moduli n_i, choose one canonical
residue 0 <= a_i < n_i and exclude m congruent to a_i modulo n_i only when
m >= n_i. Suppose that, outside a family with convergent sum of 1/n_i,
each residue satisfies one of finitely many fixed identities
q a_i = p n_i + c, with integers q >= 1, p, c. The survivor set then has
logarithmic density equal to the decreasing finite-periodic sieve-density
limit. Coprimality, disjointness, bounded residues, and reciprocal summability
of the patterned family are unnecessary. Natural density of the infinite
survivor set is not asserted.

Only in the fully patterned class may every modulus instead have an
arbitrary finite positive activation threshold, without changing that
logarithmic density. Summable exceptions must retain the original activation.
The audit gives an explicit counterexample to extending threshold invariance
to arbitrary summable exceptions. This is a scope control, not a counterexample
to the accepted theorem or to the unrestricted original problem.
