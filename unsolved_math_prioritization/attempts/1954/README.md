# Erdős Problem 143: prior harmonic corollary (record 1954)

This unrefereed, AI-assisted authored application and independent internal AI audit record a known partial result. For a real set A contained in (1,infinity), the condition |kx-y| >= 1 for every ordered pair of distinct elements and every positive integer k implies sum_{x in A, x <= X} 1/x = o(log X). The strict integer-cutoff formulation follows as well.

The non-elementary input is Koukoulopoulos, Lamzouri and Lichtman (2025), Theorem 1. Their theorem is explicitly imported, not independently reproved.
