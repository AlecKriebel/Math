# Verification scope and limits

The author checker is `the original checker`. It is run from the final same source bytes in ordinary Python, `-O`, and `-OO`; the three sealed the original optimization receipts files are its receipts. Every guard uses an explicit exception and remains active in optimized modes.

## Exact positive checks

- 74,389 exhaustive substitutions: quotient orders one through three, every orientation/color quotient, and independently every singleton or two-vertex colored tournament factor. Expanded order is at most six.
- 2,592 further exhaustive substitutions: all two-vertex quotients, every three-vertex factor in either position, and a singleton in the other position.
- For each of these 76,981 cases, independently computed Boolean-matrix reachability is compared with the full color-by-color composition formula and the exact universal-source formula. Direct cyclic-triangle inspection checks the exact rainbow decomposition. Uniform partition recovery must reproduce the quotient.
- Four recursive certificates at orders 3, 9, 27, and 81 are expanded and directly checked. At orders 27 and 81 the entire incidence core survives; every quotient core is empty. The general unbounded family is established by proof, not by extending these tests indefinitely.
- 1,728 known-model propagation fixtures: all 216 labeled three-vertex tournaments and all eight fixed-pair masks. Every domain contains the known model's actual value. Forbidden pairs, mandatory restricted-vertex paths, and optional global relation seeds are verified against the actual matrix. No known model may be lost; no false color reachability may be introduced. These tests remove 7,620 domain states in total and are not an always-accept fixture.

## Negative and boundary controls

The receipts separately count 17 invalid-input checks, six false-stronger-claim controls, and nine propagation gates. Additional recursive certificate checks reject a cyclic rainbow quotient and an undecomposed 27-vertex core under bound eight.

Important distinctions directly tested include:

- A positive monochromatic quotient return cycle can provide reachability missing inside a factor.
- A zero-length self-path is not a positive return cycle.
- Reachability colors must not be merged.
- An internally universal vertex in a non-source quotient block need not be globally universal.
- Direction-uniform blocks with nonuniform cross colors do not satisfy the composition theorem, even in a cyclic-rainbow-free example.
- A transitive rainbow triple is allowed.
- A global path assertion through an outside vertex must not serve as an actual edge inside a restricted interval.
- A unique possible mandatory path color can force a virtual reachability even before its actual path's chord directions are fixed.

## Integrity checks

The manifest binds every payload by SHA-256 and byte count. Its external pin binds the entire manifest. `the original checker` checks the exact directory file set, each payload, the target-status boundary, and equality of substantive optimized receipts. Its self-test rejects five copied-packet mutations: edited proof, edited receipt, missing payload, added payload, and a self-consistently rehashed manifest that does not match the external pin.

Integrity checking does not rerun the mathematical tests. Replaying `the original checker` does not independently prove the all-order lemmas, establish the credited source incidence results, or reproduce any finite tournament-completion search. Those roles are kept separate for independent review.
