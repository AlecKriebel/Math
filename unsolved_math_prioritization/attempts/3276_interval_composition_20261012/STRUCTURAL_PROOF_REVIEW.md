## 1. Source credit and interval lemma

The recovered primary source is Georgakopoulos and Sprüssel, *On 3-coloured tournaments*, arXiv:0904.1967v2, 17 April 2009, https://arxiv.org/pdf/0904.1967v2. Its text and PDF hashes were freshly verified. The relevant source text was read, and PDF page 4 containing Lemmas 2.5 and 2.7 was visually inspected. The later typesetting date does not change the arXiv version date.

The source credits Shen Minggang for Lemma 2.1. It provides the distinguished obstruction Hamilton cycle of an induced-minimal counterexample. Each vertex fails monochromatic reachability to exactly its predecessor. This determines that obstruction cycle up to rotation, without excluding other Hamilton cycles. Minimality is with respect to induced subtournaments, not merely deletion of selected arcs.

For distinct x,y with y not the predecessor of x, the forward interval xCy has between two and n-1 vertices and is a proper nonempty induced subtournament. It inherits cyclic-rainbow exclusion. Minimality gives a universal monochromatic source in the interval. Every z other than x has its predecessor in the interval and cannot reach that predecessor even globally. Thus only x can be the source. This proves the existential interval-path assertion of Lemma 2.5. It does not preserve an arbitrarily chosen global path color. If only one global color is possible, then the interval path must have that color. Self-endpoints are unnecessary in the propagator and explicitly excluded; predecessor endpoints are excluded because their forward interval would be the whole tournament and minimality would not apply.

Proposition 2.4 and Theorem 3.1 are credited dependencies for the incidence restrictions. ## 2. Sound generic interval propagation

Fix a completion satisfying the initial domains, forbidden pairs, seeds and mandatory interval paths. The invariant is that all its actual pair states remain in the domains and every current global relation assertion is true in that completion. Taking transitive closure composes same-color paths into a same-color walk; removing repeated segments leaves a directed path between distinct endpoints. Reflexive relation entries merely implement zero-length paths and cannot violate a forbidden distinct pair on their own.

Every actual witness for a mandatory path lies in the possible actual-arc graph on the required vertex set. That graph may contain incompatible possibilities from different completions; it is intentionally a necessary superset. Its being reachable is not a certificate of a consistent completion. Conversely, its failure to reach rules out that color. Adding a true reachability assertion to the global relation cannot force a forbidden pair in the fixed completion. Therefore at least one color of every mandatory actual witness survives both tests; if exactly one survives it is valid to force that global color assertion. The same reasoning justifies rejecting actual arc states, assigning singleton domains, and continuing after every sound update.

Virtual global reachability is not an actual interval arc. A global route between two interval vertices may use vertices outside the interval. The independent counterfixture forces a red 0-to-2 route through 1 while the actual edge inside {0,2} points 2-to-0 in blue; admitting the global red relation as an interval witness would be false. In the inspected implementation, `potential` reads only actual arc domains, while `link` and `close` enforce global consequences. A distinct fixture verifies forcing of a non-arc path before intermediate arc directions are fixed. Another verifies a forbidden pair arising only after composing two seeds.

Only domain deletions and relation additions occur, in finite spaces. A changing iteration makes at least one such irreversible change, so fixed-point iteration terminates. This proves soundness and termination for arbitrary valid finite inputs and arbitrary mandatory vertex sets, not only the cyclic intervals of a hypothetical counterexample. Nonrejection remains only a necessary relaxation. The generic code intentionally omits a completion DFS and rainbow pruning. Its finite known-model tests are therefore nonvacuous without pretending known tournaments are counterexamples.

## 3. Exact substitution formulas

Every block and the quotient are nonempty, finite tournaments. All cross-block arcs have the direction and color prescribed by one quotient arc. Both properties are essential to lifting arbitrary endpoints. All factors use the common palette. For different blocks, a monochromatic path projects, after deleting consecutive equal block labels, to a same-color quotient walk. Repeated quotient vertices can be removed to obtain a path. Conversely a simple quotient path lifts by picking one vertex from each intermediate nonempty factor, retaining the prescribed endpoints. The resulting lifted vertices are distinct.

For different vertices x,y in the same block, an internal path gives the internal alternative. A path that leaves the block projects to a positive closed monochromatic walk through that quotient vertex. A shortest positive return to that vertex is a directed cycle through it: an interior repeat could be excised without removing the endpoint return. Conversely that cycle lifts through distinct external blocks and back to y. The distinct endpoints in the original block and the distinct intermediate blocks give a simple path. No reflexive self-reachability is counted as a positive return; in a loopless tournament a return cycle has length at least three.

Thus external factors affect within-block reachability exactly through a positive quotient return cycle of the chosen color. The exact source formula follows: the block index must reach every other quotient vertex, and then either any monochromatic return cycle supplies all within-block destinations, or the original vertex must itself be an internal source. The return color need not be the color used to other blocks. For a singleton quotient there are no positive return cycles, and the formula reduces exactly to the sole factor. For a singleton factor the within-block obligation is vacuous.

Rainbow transfer is exact. A triple in one block is inherited. A triple in three blocks has precisely its quotient directions and colors. A triple in exactly two blocks cannot be cyclic because the vertex in the other block points toward both blockmates or away from both. There is no restriction on transitive rainbow triples. Nonempty blocks ensure every quotient triangle actually lifts.

The specified color-nonuniform four-vertex fixture is cyclic-rainbow-free and has sources {0,2,3}. Its direction-uniform block {0,1} would produce a monochromatic cyclic representative quotient; falsely using its return cycle would add vertex 1 as a source. Vertex 1 in fact has only its blue outgoing edge to 2 and cannot reach 0 or 3 monochromatically. This establishes the necessity of the color assumption even under cyclic-rainbow exclusion. A separate monochromatic three-cycle partition {0,1},{2} fails direction uniformity. The validator rejects both defects.

## 4. Minimal counterexample primeness

Suppose a minimal counterexample D has a colored module M with 1<|M|<|D|. Contracting M yields a quotient isomorphic to the proper induced subtournament retaining one representative and every outside vertex. The quotient and D[M] are nonempty proper induced tournaments and inherit rainbow exclusion. Minimality supplies sources in both, and outside singleton factors are sources. Substitution closure yields a source in D, contradiction.

This argument needs neither the obstruction Hamilton cycle nor the incidence source theorem. It proves colored-primeness, not primeness for ordinary direction-only tournament modules. It neither bounds the number of colored-prime vertices nor resolves prime cases. The entire vertex set and singleton sets are trivial modules and are correctly excluded from the contradiction.

## 5. Core criterion and arbitrary recursive certificates

The recovered accepted core theorem was checked at its stated proof hash. Every stable set survives peeling: at the first attempted deletion of one of its vertices all its witnesses remain. The terminal stable set contains all stable sets, giving the unique largest one and schedule independence. Witness preservation for an old vertex is monotone under enlarging the ambient set; the proof does not incorrectly assert that every superset is itself stable.

A nonempty rainbow-cycle-free tournament without a source contains an induced-minimal counterexample. Its incident-color witnesses force it to survive in the core. If the target is established for every nonempty order at most b and the core has size at most b, this is impossible. An empty core needs no computational premise. Merely finding a source of the core would not establish the conclusion and is not used.

In a recursive certificate every internal node has a quotient of at least two vertices and one nonempty child per quotient vertex; the finite tree ends in singleton leaves. At each node, rainbow-free quotient plus children implies rainbow-free parent. The core condition supplies a quotient source; inductively the children have sources; exact composition then gives a parent source. The induction uses no equal-block-size assumption, no canonical decomposition, no particular choice of modular decomposition, and no upper bound on the root order. A leaf-only tree also satisfies the result. Finite repeated copies of an isomorphic child are allowed; each substitution creates its own disjoint vertex block.
