## Reduction reconstructed independently

Choose a counterexample minimal under induced subtournament containment. For distinct x,y define an auxiliary arc y→x when x has no monochromatic path to y. Such an arc must be an actual tournament arc, and the auxiliary graph is loopless with no opposite pair. Each vertex has positive indegree. A directed cycle therefore exists and has length at least three. In the induced subtournament on its vertices, each vertex still fails to reach its predecessor, and no cyclic rainbow triangle has been created. This is a counterexample, so minimality makes the cycle spanning. This is the reduction credited to Shen in Lemma 2.1. The search requires the spanning actual cycle and its predecessor failures; it need not use the uniqueness part of that lemma.

For distinct x,y with forward cyclic distance d between 1 and n−2, the interval I=xCy is a proper nonempty induced subtournament. It has no cyclic rainbow triangle, and minimality forces a universal outgoing monochromatic source in I. Every vertex z other than x has its cycle predecessor in I and cannot reach it even in the whole tournament. Hence that source must be x. In particular there is a monochromatic x-to-y path using only vertices of I. This proves exactly the portion of Lemma 2.5 used by the search.

Crucially, this is an existential assertion about a color within I. It does not allow an arbitrary color realizing a global x-to-y path to be transferred to I. The primary source explicitly warns about this distinction, and the candidate respects it.

## State invariant and pruning proof

Fix any complete model D satisfying the cycle, triangle, predecessor, and interval conditions and extending a branch. The stronger useful invariant is that every recorded c-relation is realized by a c-colored directed walk in D. For distinct endpoints a walk contains a path; positive-length diagonal entries denote genuine directed cycles. This invariant also applies to relaxed controls when the corresponding model conditions are explicitly imposed.

1. Actual-arc insertion first checks only actual arcs for a newly completed cyclic rainbow triangle. Any new forbidden triangle contains the new arc, so the two-arc test is complete for partial assignments. Transitive rainbow triples are permitted. Actual arcs and virtual reachability assertions are separate arrays.
2. Given a transitive relation R and a new required link u→v, let A be u together with its R-ancestors and B be v together with its R-descendants. Its exact updated positive-length closure is R union A×B. Even if the link closes a directed cycle, any new walk can be reduced to old segments separated by the new link, giving this formula; the formula includes newly realized diagonal entries. The second engine independently runs Warshall on the old closed relation plus the new link. Neither engine seeds a reflexive diagonal. Both preserve the old state when rejecting a predecessor implication.
3. Testing each of the six actual values of an unassigned pair against the current mandatory relation cannot remove the value occurring in D. Its added actual arc, current required paths, and their concatenations all occur in D. A rejected cyclic triangle or predecessor path would therefore already contradict D. An empty domain is impossible for D; a singleton domain forces its actual value.
4. P_c contains assigned actual c-arcs and every actual oriented c-value surviving the independent tests for its pair. Every actual c-edge of D is present in P_c. P_c can contain incompatible values simultaneously, which only gives extra possible paths. Restricting P_c to I still contains every actual D[I] edge. Thus an actual interval path witnesses reachability in the restricted possibility graph. No virtual R_c entry is inserted directly into P_c, because its witness could leave I.
5. For a possible interval color c, a trial link x→y is also tested against predecessor failure. If D has a c-path in I, this trial cannot create an implication absent from D. Therefore the true path's color survives both filters. An empty retained-color set excludes D; a singleton implies a genuinely required global c-reachability in every compatible model and can be safely closed.
6. During one pass, P_c may have been built before additional mandatory links were deduced. This older graph still contains every actual model edge. Enlarging R can only reject additional candidate actual values, so using the stale graph weakens pruning. The next changed pass rebuilds every domain. A singleton actual chord restarts domain construction immediately.

Every forced actual pair decreases the number of unassigned pairs; every virtual addition strictly increases some relation. There are finitely many pairs and at most 3n² relation entries, so propagation terminates on the correct implementation. A stable branch selection uses domains from the final pass. Every surviving value is tried, and the six values encode both orientations and all three colors. Consequently every compatible reduced minimal counterexample survives into a distinct complete branch.
