# Reproducing this independent review

Run `python check_independent.py` and compare complete stdout with INDEPENDENT_CHECKS.json. The script uses only the standard library. Author replay evidence is in AUTHOR_REPLAY.json, raw immutable remote bindings in REMOTE_BINDING.json and nested/source checks in INTEGRITY.json. Read ADVERSARIAL_REVIEW.md for the universal mathematical argument and exact source-scope verdict; finite controls alone do not prove it. No raw source PDFs are redistributed here.
