# Unbounded taut Godbillon--Vey numbers on one fixed hyperbolic manifold

The verified theorem gives smooth cooriented taut foliations F_N on one fixed closed hyperbolic M with ordinary GV(F_N)=Na, a>0, for every finite N>=1. The same embedded positive closed transversal meets every leaf. This answers the literal volume-only bound in Calegari arXiv:math/0209081v1 Question 10.6 negatively. Compact leaves are allowed; no minimal-foliation or all-hyperbolic-manifolds claim is made.
