## Exact target

- Numeric ID: 30005507.
- Code: OWR-13750328-012.
- Title: Frobenius–Schur Indicators in Real Nilpotent Blocks.
- Source: Benjamin Sambale, Conjecture 2 in “Local determination of Frobenius–Schur indicators,” Oberwolfach Report 19/2023, pp.1055–1056.

For every real, nilpotent, nonprincipal 2-block B of a finite group, with defect pair (D,E), the question asks for a bijection Gamma from Irr(D) to Irr(B) such that degree 2^h corresponds to height h and

    epsilon(Gamma(lambda)) = (1/|D|) sum_{e in E outside D} lambda(e^2)

for every lambda. Here [E:D]=2, including the defect-zero boundary D=1. The original source poses this as a conjecture. The catalogue's imperative “Prove” does not supply an assumption that it is established.

The catalogue page was inaccessible to the web reader. The pinned catalogue record was used to identify the target, then checked against the primary report. The separate cached research-results file had no matching OWR/ID entry; the catalogue's embedded dated literature triage was available. It contains no substantive proof attempt.
