# Jet curvature and the first Chern class: scoped research packet

Research date: 2026-10-05. Result: **the original problem is not solved here; five substantive approaches are retained**. There is no novelty, priority, comprehensive literature-search, global-openness, or peer-review claim.

The question is whether nondegenerate negative k-jet curvature, for some positive integer k, forces c1(T_X) to be nonzero in real cohomology for a positive-dimensional smooth compact projective complex manifold X. The negative curvature is required only on the directed subbundle V_k of the Demailly–Semple tower. Replacing it by negativity on the entire tangent bundle changes the problem.
