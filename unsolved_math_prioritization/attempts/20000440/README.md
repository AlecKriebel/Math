# Conditional Brauer compatible lifting for a fixed Enriques K3 cover

Problem 20000440 / AIM-ALGEBRAIC_NUMBER_THEORY-0092.

The accepted result is an exact finite-character criterion for lifting one Brauer-orthogonal adelic point through a specified Enriques K3 double cover, assuming that every local fiber of that cover already has a rational point. It characterizes when a compatible lift exists; it does not assert that the criterion is always satisfied.

Read [the complete proof and mathematical audit](BRAUER_LIFT_CRITERION.md), followed by [the acceptance report](ACCEPTANCE.md). The theorem treats the full Brauer group and the algebraic Brauer group separately. All hypotheses, both directions of the criterion, finite support, change-of-base invariance, the transfer identity, and the prior negative examples are retained.
