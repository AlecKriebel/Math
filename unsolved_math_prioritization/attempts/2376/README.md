# Cofinite zeros of high derivatives

This packet records an accepted proof and independent audit for database 2376 / Erdős Problem 906. Almost every sample of the planar Gaussian entire series is transcendental and has the following property: every nonempty open set contains a zero of every sufficiently high derivative. Equivalently, derivative-zero sets have dense union along every infinite subsequence of derivative orders.

The Gaussian construction and main mechanism are credited to Adriano Almeida and Przemek Chojecki's April 2026 proposals, with Almeida's earlier posting acknowledged. No novelty claim is made.
