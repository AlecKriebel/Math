# Torelli density in ambient word balls: accepted partial results

Problem 11000037 / AMR-109-0037, priority rank 1254. Substantive attempt 1/5. The arbitrary-generating-set density conjecture remains unresolved by this work.

## Accepted mathematics

For the mapping class group G of a closed oriented genus-g surface, g>=2, let I_g be the Torelli kernel. Balls B_S(n) count distinct ambient group elements for a finite symmetric generating set S.

1. The [mathematical report](MATHEMATICAL_REPORT.md) proves that every prescribed finite subset of G lies in a finite symmetric generating set for which |I_g intersect B_S(n)|/|B_S(n)| tends exponentially to zero. Its complete elementary proof gives the free-tree adjacency estimate, the quotient regular-representation decomposition, a labelled-word numerator upper bound, a genuinely distinct-element denominator lower bound, explicit constants and the homological free-subgroup construction.
2. The authored F_3 x F_2 example has a normal infinite-index subgroup with nonamenable quotient and density 1/3 in the sum metric, but exponentially vanishing density in the max metric. It disproves the proposed general generating-set transfer; it is not a mapping-class-group counterexample.
3. The separate [logarithmic appendix](LOGARITHMIC_APPENDIX.md) proves, for every finite symmetric S, that the logarithmic liminf is at least 1/2. Its complete conjugacy-fiber count and ambient centralizer bound use a Torelli pseudo-Anosov, a virtually cyclic centralizer and an explicit Teichmuller-axis undistortion estimate.
4. For generating sets containing any fixed finite subset, both the infimum of the logarithmic liminf and the infimum of the logarithmic limsup equal 1/2. Neither equality of liminf and limsup for a fixed set nor attainment of either infimum is asserted.

The [mathematical audit](MATHEMATICAL_AUDIT.md) reviews all these arguments and accepts them as scoped partial results. Identity generators are allowed as harmless padding when a prescribed finite subset contains the identity. The genus-one aside and genus-zero exclusion are retained; punctured, bordered and extended variants are not covered.
