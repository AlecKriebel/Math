# Source and scope gate: Function Theory Problem 2.58

## Exact claim

Catalogue ID 2302058 / AMR-022-2058 is Hellerstein's existence question: does a nonconstant entire function of infinite order have a finite nonzero Picard exceptional value α but no curve tending to infinity in |F|=|α| along which F tends to α? The witness checked here omits α completely and works for each prescribed α≠0 by scaling. There is no coefficient or derivative normalization.

The live UnsolvedMath page could not be retrieved. The pinned catalogue record supplied the identification only; the original problem and its update were read from the source edition. The cached report's claim that the question remained open in that edition is contradicted by the edition itself.

## Important verification distinction

Eremenko's main formulation uses real-image natural curves, and the final exponential omits zero. Neither the main theorem alone nor a bare translation supplies the catalogue's nonzero omitted value and circle level. The verification note explicitly bridges this difference by a bounded quasiconformal deformation followed by F=1+1/q. Its key identity is |1+1/q|=1 if and only if Re q=−1/2. All topology, nonvanishing, and growth checks are given there.

The original p.309 multi-line sewing is a published construction input and is comparatively terse. This package checks its mechanism and the exact transfer; it does not claim a newly self-contained reconstruction of the entire surface theorem.
