# Twice-punctured-torus automorphisms: credited prior negative answer

Problem **11000109 / AMR-109-0109**, rank 878. **Already solved, 1/5 approaches.**

The answer to Korkmaz Problem 2.4 is no for the orientation-preserving, full puncture-permuting mapping class group of the twice-punctured torus, with no boundary. The proof gives an index-48 normal subgroup and an automorphism of that same subgroup that extends to no ambient abstract automorphism. The characteristic-center quotient argument includes central transvections.

This is a reconstruction of the prior Behrstock–Margalit construction, with Bridson–Wade corroborating the conventions. There is no new-priority, minimal-index, or broad classification claim. The topological inputs are cited theorems, not re-proved here.
