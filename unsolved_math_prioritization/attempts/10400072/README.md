# Hair-map noninjectivity: credited source audit

Problem 10400072 / AMR-103-0072, Ohtsuki Conjecture 3.22, has a prior published
negative resolution. Bertrand Patureau-Mirand's Theorem 4 in Noninjectivity
of the “hair” map, Algebraic & Geometric Topology 12 (2012), 415–420, gives a
nonzero kernel element for the exact Laurent-polynomial map (30), equivalently
map (29) at A(t)=1.
[Credited published result](https://msp.org/agt/2012/12-1/p16.xhtml).

The finite connected witness has first Betti number 17 and Ohtsuki loop-degree
16. The audit checks the exact map and quotient, cohomological-content
separation, termwise hair vanishing and degree conversion. No new theorem,
counterexample, proof novelty or priority is claimed.

## Essential dependency and scope limits

Acceptance uses Vogel's published rational module-freeness and zero-divisor
results. Their imported computational dependencies were not reproduced;
no complete graph-reduction certificate or raw calculation files for those
steps were recovered or rerun. The elementary character-arithmetic check is
conditional on the imported formula. This is a source-credit audit, not a
self-contained reconstruction or independently reproduced computer proof.

The accepted negative resolution concerns the exact original Laurent case.
It does not assert noninjectivity for every nontrivial localization, minimal
possible loop degree, or a theorem about knots with identical invariants.
The complete substantive argument and all these limitations are in
[AUDIT.md](AUDIT.md); no shortened substitute replaces that audit.
