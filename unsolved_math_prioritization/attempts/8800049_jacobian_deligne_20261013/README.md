# Detecting Jacobians through Deligne modules and geometric recognition

Problem 8800049 / AMR-087-0049. Prepared 13 October 2026.

The claimed solution is a **theoretical algorithmic connection** over an explicitly represented finite field for a promised realizable ordinary, absolutely simple degree-six Weil polynomial. It connects polarized Deligne ideal data to exact geometric recognition of genus-three Jacobians over the original field in every characteristic. The procedures terminate in principle. They are impractical, unimplemented, and have not been executed end to end. No useful complexity bound or worldwide novelty is claimed.
