# Fat connected components: corrected partial reductions

Problem 20000822 / AIM-ARITHMETIC_GEOMETRY-0068 remains unresolved.
AIM Problem 21 asks whether a polynomial-ring multigraded Hilbert scheme,
with its full Hilbert function fixed, has an entire connected component
isomorphic to a nonreduced local fat point. No such example or general
impossibility theorem is claimed here.

The accepted partial arguments establish:

- A nonreduced Artinian FULL completed local ring at a closed point of a finite-type scheme certifies an entire fat component.
- An existing fat component has monomial support and can be extracted for a cyclic-kernel grading, using diagonalizable group schemes and the full refined Hilbert function. Torsion is retained unless the original grading group permits saturation.
- A negative tangent step with E_i < 2|c_i| integrates through explicit monic S-pair reductions to a flat one-parameter family. In particular, squarefree support is excluded in every characteristic.
- For the specified full SST nonnormal chart, in characteristic zero only, refinements diagonal on its five displayed minimal coordinates cannot isolate a nonreduced fixed point.

The squarefree mixed-sign integrability result is credited to
Altmann–Sturmfels. No novelty or priority is claimed for any result.
Exploratory global-chart dimension tests do not certify local isolation;
the interrupted dense search supports no negative conclusion.
