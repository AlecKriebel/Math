# Entropy and Deligne periods: a conjugacy obstruction

[OBSTRUCTION.md](OBSTRUCTION.md) proves that no topological-conjugacy invariant on Q_p multiplication maps can satisfy h_p(T_lambda)=log_p(lambda) for every nonzero scalar. The maps x↦px and x↦p(1+p²)x are explicitly isometrically conjugate, while their normalized p-adic logarithms differ. The argument works for every prime, including 2, and also for the inverse expanding maps.

This settles the explicit two-axiom formulation. Ward gives topological invariance as an example of a desired axiom, and the broader entropy/period request is not fully axiomatized. The package therefore recommends **unsolved, 1/5, with a complete scoped obstruction**, preserving known compact periodic-entropy results and making no novelty claim.
