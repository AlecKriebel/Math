# Orthogonal-pair theta modules and Jacobi principal series

Problem 30003033 / OWR-14211-008. Accepted partial result, not a solution
of the original unrestricted principal-series connection question.

For the chamberwise rational-isotropic orthogonal-pair theta family,
the cyclic infinitesimal module is P^tensor(p) tensor (A_1/A_1(xd))^tensor(r),
with trivial residual sl2. The simple essential oscillator socle has an
infinitesimal injection into the specified normalized Jacobi principal
series at parameter -1. Its Schwartz globalization has the corresponding
group injection. For r>0 the full extension has no nonzero infinitesimal
map to any specified ordinary smooth or distribution-vector principal
series, at any parameter.

Arithmetic modularity and discriminant Weil type use an integral/even
lattice. The correctly shifted Casimir is retained. Residual lowering
annihilates the theta generator; ordinary lowering generally does not.
The source discrepancy concerns that extra printed subspace assertion,
not every theorem in the source. The original OWR annihilators remain
verified.

A larger meromorphic/localized induced realization, its global analytic
behavior, general irrational-isotropic-edge coverage, and a full
reconciliation of affected source statements remain unresolved.
Westerholt-Raum's prior Schrödinger–Weil-extension interpretation is
explicitly credited. No novelty or priority is claimed.
