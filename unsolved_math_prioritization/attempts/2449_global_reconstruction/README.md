# EP1038 / database 2449: global reconstruction appendix

Dated 2026-10-12. This appendix records the accepted computer-assisted reconstruction for nonconstant monic real polynomials whose roots lie in [-1,1]: the infimum of the length of {|f|<1} is L=Lambda(q_*), with

    1.834430475762661 < L < 1.834430475762662.

Every individual finite polynomial has strictly greater length, and a positive-platform empirical construction approaches L, so the infimum is not attained. The one-cut parameter q_* is unique within that specified family. Arbitrary relaxed minimizers are not classified. The supremum 2sqrt(2), with equality exactly for (x^2-1)^m, is credited to Tao's external theorem.
