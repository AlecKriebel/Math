# Coarse Schottky problem: known resolution

**11000048 / AMR-109-0048, rank 449: already_solved, 0/5 substantive proof-attempt turns.**

For each fixed genus, the smooth Jacobian locus determines the whole asymptotic cone of A_g with its ambient locally symmetric metric. This is Ji and Leuzinger’s prior theorem, published in *Geometric and Functional Analysis* **19** (2010), 1693–1712, [DOI 10.1007/s00039-010-0049-8](https://doi.org/10.1007/s00039-010-0049-8).
