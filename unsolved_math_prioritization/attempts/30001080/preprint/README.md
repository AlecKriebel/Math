# Measure-only preserving Markov transports characterize mass-stationarity

Research note by Alec Kriebel, ORCID https://orcid.org/0009-0001-9320-500X. The main result answers Last–Thorisson's formal Annals2009 Problem7.3 in its stated arbitrary-flow, sigma-finite, lcsc Abelian setting. It retains the full ambient state. The narrower non-discrete deterministic Cox-allocation converse remains unresolved here.

`paper.tex` is the standalone manuscript source; `mass_stationarity_markov.pdf` is its seven-page compiled note. `CLAIM_SCOPE.md`, `BIBLIOGRAPHY.md` and `PRIORITY_NOTE.md` state the exact assumptions, credited inputs, checked versions and bounded-priority limits. `record_metadata.json` is the exact requested Zenodo metadata. The upload manifest `zenodo-deposit.json` selects the PDF and `mass_stationarity_verification.zip`.

The verification archive includes this source and documentation plus `verification/`, containing unchanged original finite-control programs, complete expected scientific outputs and a portable verifier.
