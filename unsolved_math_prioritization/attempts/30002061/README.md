# 30002061: collapse preservation under linear subdivision

Research in progress; **no full result claimed**. The precise target is Hudson's relative-collapse question for finite simplicial complexes and linear subdivisions, with the prescribed restricted target retained.

Original source: OWR24/2012, printed1460. The cited Adiprasito–Benedetti theorem permits one additional barycentric subdivision and therefore does not settle this target. No arbitrary nonconvex triangulation is being presented as a counterexample to a linear subdivision statement.
