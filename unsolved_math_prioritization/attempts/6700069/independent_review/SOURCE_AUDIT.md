## Representative convention

The claimed negative answer is accepted in the original geometric evaluation context. Every fixed smooth fundamental form is covered. So is a geometric cochain model differing from such a representative by a coboundary with uniformly controlled evaluation on the boundary chains in use. This is a geometric boundedness condition on controlled chains, not an assertion about arbitrary algebraic singular cochains or globally bounded singular cohomology.

An arbitrary unbounded singular cochain can be altered on noncycles in ways unrelated to the metric question. The author expressly excludes that interpretation, consistent with the original quantitative discussion. This qualification belongs in any publication summary. It is not a missing hypothesis of the published ball theorem.
