# Scope addendum for the separate polygonal request

The period A,B,A,B,C,B,C,B refutes the unrestricted four-axiom realization statement. It is not a counterexample to a version of the separate OWR p. 2551 polygonal request that requires the input to contain the fully separated term (1,1',2,2',...,n,n'). The witness has no such term.

Indeed, from that starting term to its reverse-toggle counterpart there are exactly 4·C(n,2) endpoint pairs whose relative orders must reverse. The half-period has exactly that many adjacent swaps, so each required endpoint pair crosses once and no pair can backtrack. The full period is consequently switch-once. This additional starting-term condition is absent from Goodman--Pollack's abstract four-axiom Definition 12 and must not be silently imported into it.

The relevant general topological question is OWR Question 1 on p. 2492, with the affirmative historical attribution continuing to p. 2493. Keep that attribution and the weak-definition counterexample distinct from the separate normalized polygonal-construction request.

Source: [Discrete Geometry, Oberwolfach Report 44/2008, pp. 2492--2493 and 2551](https://ems.press/content/serial-article-files/46191?nt=1).
