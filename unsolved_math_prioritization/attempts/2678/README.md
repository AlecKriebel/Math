# Separating-sphere twists detected by knots

Problem 2678 / K3 Problem 1.19: an accepted scoped prior-result audit.

For every closed, connected, oriented smooth 3-manifold, one asymmetric hyperbolic knot detects every nonidentity orientation-preserving mapping class up to ambient isotopy. This implies the separating-sphere twist target whenever that twist is nontrivial in this category. The argument imposes no prime-summand restriction and does not require a knot orientation or framing.
