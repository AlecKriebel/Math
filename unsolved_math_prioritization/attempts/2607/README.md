# Multilinear commutator values covered by cyclic subgroups

Research notes on [Kourovka Notebook 21.98 / catalogue ID 2607](https://www.unsolvedmath.com/problems/2607).

**Status: unresolved after five substantive attempts.** This is an AI-assisted research package of partial arguments and explicit obstructions, not a solution or a novelty claim. A fresh [independent adversarial audit](INDEPENDENT_AUDIT.md) found no blocking errors in these partial claims. It preserves the unresolved verdict; see the [wording clarifications and audit reproduction instructions](CLARIFICATIONS.md).

## Exact target

For a multilinear (outer) commutator word w, assume that finitely many cyclic subgroups of an arbitrary group G cover all individual w-values. Must the subgroup w(G) generated by those values have a finite normal subgroup with cyclic quotient?

The group need not be finite, nilpotent, soluble or residually finite. The cover concerns individual word values, not arbitrary products of values. These distinctions are essential.

## Results of this attempt

1. [Normal-set reduction](turn_01.md): the covering hypothesis gives a finitely generated verbal subgroup with finite torsion kernel and free abelian quotient. The conjugation action on that quotient is finite. For the original question one may reduce to a finitely generated soluble ambient group, with the exact remaining target being free abelian rank at most one.
2. [Polynomial-coordinate method](turn_02.md): affirmative conclusion for every word in locally nilpotent ambient groups, using the standard Mal'cev/Hall structure of finitely generated torsion-free nilpotent groups. The standard input and lack of a general soluble extension are explicit.
3. [Affine variation](turn_03.md): H-perturbations of one tuple produce either one value or one rank-one affine lattice; a finite signed-permutation bound controls the conjugation image. The method is explicitly ineffective when H is central.
4. [Derived-word rigidity](turn_04.md): for delta_k, k>=2, one derived level above the target is class-two modulo a finite kernel. In finitely generated virtually abelian ambient groups the delta_k verbal subgroup is finite. The proof uses actual repeated-commutator values and determinant-one rigidity.
5. [Induction countermodel](turn_05.md): the direct product of two integral Heisenberg groups has a normal, inverse-closed, power-closed generating set X with [X,X] covered by two cyclic groups, although its derived subgroup is Z^2. This refutes an auxiliary inference. It is **not** a counterexample to the original question because X has not been realized as the required full verbal set.

The exact remaining gap is a mechanism using the full multilinear-word identities to force distinct rational value directions to coincide. Neither a rank-one proof nor an actual multilinear-word counterexample is supplied.

## Reproduce the finite controls

Run `python3 verify_controls.py` using Python's standard library. It recreates `control_results.json` and checks 2,210 signed-permutation power/rank identities, 20 determinant-one/rank-at-most-one cases, 201 distinct affine directions, and 23,409 Heisenberg commutator pairs. These modest computations are controls for the written mechanisms, not an exhaustive group search or a proof of the general problem.
