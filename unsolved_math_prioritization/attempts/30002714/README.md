# A prior negative answer for complete closure of total blow-up rings

Problem 30002714 / OWR-13351-013 has a negative answer in its original unrestricted form. This edition reconstructs an explicit instance of the already published counterexample: an infinite sequence of three-dimensional local quadratic transforms along a rank-three valuation has a union S whose complete integral closure is the two-dimensional regular local ring k(x)[y,z]_(y,z), which is not a valuation ring.
