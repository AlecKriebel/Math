# Density degrees under finite covers

Problem 20000357 · AIM-ALGEBRAIC_NUMBER_THEORY-0009 · [AIM Problem 1.18](http://aimpl.org/degreedsurface/1/)

## Result and scope

This packet contains complete authored proofs and an acceptance review of bounded density-degree results over number fields. It establishes both finite-cover transfers, the Galois divisor refinement, and the sharp inequalities \(b\le a\le nb\) for minimum density degrees. For nice curves, it proves the \(\mathbb P^1\) transfer and, for every \(r\ge2\), the dilated AV transfer with an actual closed-point/Hilbert-irreducibility step.

The full restrictions problem and the undilated AV inclusion remain unresolved here. There is no novelty claim. [Clark's index-existence theorem](https://plclark.github.io/PeteLClark/Research/crelle.pdf) and the parameterization and Hilbert results in [Viray–Vogt](https://msp.org/ent/2026/5-1/ent-v5-n1-p01-s.pdf) are explicitly cited dependencies.
