# First-turn candidate result

There is a smooth scalar σ>=0 of compact support, positive almost everywhere in a bounded connected Lipschitz toroidal conductor with connected exterior, and a smooth compactly supported solenoidal A, for which

div(σ(A+∇φ))=0

has no solution φ in H¹_loc(R³). Thus the original ordinary gradient-valued map, whose output must permit an electric field in W(curl), does not extend to every nonnegative bounded conductivity.

The proof uses a single meridional degeneracy. Periodic piecewise-linear potentials, subsequently approximable by smooth ones, cancel the circulation with conductivity-weighted squared error at most C epsilon. Any ordinary weak solution would therefore cancel it exactly. A smooth compactly supported divergence-free test field has strictly nonzero pairing with that circulation and zero pairing with all ordinary gradients, yielding a contradiction.

A canonical weighted-completion correction and divergence-free flux always exist for weighted-square-integrable input; this affirmative generalized construction is kept separate. The counterexample does not assert nonexistence of every distributional scalar or a theorem about the full transient PDE for all forcing terms.
