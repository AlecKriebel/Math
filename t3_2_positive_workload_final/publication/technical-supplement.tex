\begin{abstract}
This supplement contains the complete local analytic theorems used by the
main article.  Each section is a mechanical LaTeX rendering of a byte-frozen
Markdown proof that received an independent hostile audit.  The SHA-256
manifest shipped with the source package is checked before compilation.  The
finite executable certificate is used only for finite support, tier, affine,
and disjoint-set identities; no stochastic estimate is obtained by enumerating
orientations, reaction histories, or population boxes.
\end{abstract}

\textbf{Editorial supersession note.}
