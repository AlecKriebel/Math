# Global reaction-count Green contradiction and CTMC closure

Suppose an infinite closed irreducible class has infinite expected positive
return count for the embedded labelled chain. Terminal-chart localization
gives a nonzero chart occupation satisfying nonnegative outward workload
balance and zero structural-exit flux.

## Three active coordinates

Every bimolecular source is physically enabled. At the first occupied
workload-changing source layer all faster reactions are neutral. The
first-changing-source theorem makes every changing-layer reaction
nonincreasing and at least one strictly decreasing. Compact tied ratios give
strict negative physical flux, contradicting the chart balance. If no layer
changes the workload, it is a global nonnegative invariant.

## Two active coordinates

Use the aggregate-debt source-layer hierarchy. A strict class gives finite
mean debt clearing and unpaired service, hence strict negative workload flux.
A zero class passes to the next physical trace. If all layers are zero, the
bounded phase coboundary gives an affine invariant positive on the escape
cone. Closed shielded components invoke the certified invariant,
deficiency-zero or service atlas branches. Every possibility contradicts a
terminal escaping occupation or supplies a stationary probability.

## One active coordinate

The exact finite polynomial phase theorem gives quadratic descent, strict
corrected linear descent, a bounded-token affine invariant, or structural
exit. A nonzero-variance critical branch is excluded by the explicit
Poisson/variance calculation.

## No active coordinate

The chart is finite.

Thus no escaping reaction-count occupation exists. The embedded chain has a
state with finite expected positive return count.

At every nonabsorbing state some channel is enabled and its falling
factorial is a positive integer. Therefore total rate is at least the minimum
positive rate constant, and finite expected embedded return count implies
finite expected physical return time.

For nonexplosion, every population-increasing reaction has source
molecularity zero or one. Its aggregate rate is bounded by `C(1+|X|)`.
Comparison with a linear pure-birth process bounds upward jumps on finite
time intervals. Between upward jumps total population is nonincreasing and
the process remains in a finite shell, where total rate is bounded. Hence
the CTMC is nonexplosive.

The irreducible CTMC is positive recurrent. Its stationary probability is
unique.
