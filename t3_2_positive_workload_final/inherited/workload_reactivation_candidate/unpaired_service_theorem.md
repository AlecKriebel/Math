# Unpaired service at zero debt

At a zero-debt trial section, run the first strict effective source-layer
trial.

If a strict negative transition occurs before an unprocessed positive event,
the physical workload falls at least one integer unit below the excursion
baseline.

If a positive slower event occurs first, it creates bounded aggregate debt.
The subcritical debt theorem clears that debt in finite mean and returns to a
zero-debt section before another trial.

The finite strict phase gives a uniform positive success probability. Hence
the number of zero-debt trials is geometrically bounded and genuine descent
occurs in finite expected physical time.

If no strict effective edge exists, the finite hierarchy enters one of:

1. an edgewise-zero affine phase invariant;
2. a lower-ranked chart or active-set promotion;
3. a deficiency-zero product-form branch;
4. one of the two certified service architectures.

Cancellation is never called strict descent.
