# Technical summary

## Exact progress

This repair replaces future-activation conditioning by episodes which begin
only from the actual target of the most recent labelled physical reaction.
The episode partition is pathwise complete and nonoverlapping.  The inherited
same-linkage scalar envelope therefore remains valid at its certified
interface.

The one-active-coordinate process is reduced exactly to a finite phase and
one unbounded level with degree-two, degree-one and degree-zero rate blocks.
All degree-two channels strictly lower the active coordinate.  In the absence
of `2A`, degree-one channels are nonincreasing, and every degree-zero birth
has an actual creator-linkage return path containing linear service.

## New adversarial obstruction

Even pairing an activation jump with the target episode which it creates is
not a valid sign argument.  In

\[
A\rightleftarrows2A,
\qquad
0\to A+B\to B\to0,
\]

conditioning on `0->A+B` at population `(n,0)` with carried target `2A`, and
then appending the `A+B->B->0` target episode, gives

\[
J_n=\log n+o(\log n)>0.
\]

The honest episode begun before future randomness, from the already carried
target `2A`, is negative.  Hence all activation jumps, waiting motion and
subsequent target episodes must remain in one unconditioned source-layer
trace.

## Remaining interface

The finite Bellman, Poisson, Schur and Farkas tools are exact once a finite
trace kernel is supplied.  The unproved step is constructing that kernel
through every vanishing reaction-count layer while proving that its complete
unconditioned reward has strict negative mean, structural exit, or a genuine
affine invariant.  This is not supplied by the finite atlas alone.
