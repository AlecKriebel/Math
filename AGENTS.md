# Independent Research Policy

Never contact, message, email, call, or otherwise communicate with any other
individual on behalf of this project.

This work is conducted by independent researchers. Only the human user may
communicate externally. If outside input could help, record that fact in the
research notes without preparing or initiating outreach.

# Research Workflow

- Create a dedicated folder for every new problem or research program. Keep all
  work for that effort within its folder to avoid collisions with parallel work.
- Maintain a research log for each effort and checkpoint work frequently. Log
  important breakthroughs, findings, decisions, and the timestamps when they
  occurred.
- Stay on the `main` branch unless the human user explicitly requests a
  different branch.
- Commit and push changes to the remote regularly. Treat each push as the
  release of findings to the wider world, and prioritize timely publication of
  meaningful progress.

# Research Goal

The overall goal of this project is to produce novel contributions to
mathematics.
