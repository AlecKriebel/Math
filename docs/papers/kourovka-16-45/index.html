A negative answer

The largest inclusion-minimal permutation base can be smaller than the largest independent subset of a finite group.

Theorem. For the explicitly specified affine group \(G=\mathbf F_{29}^{2}\rtimes H\), with \(H\cong\mathrm{SL}_2(5)\),

\[|G|=100920,\qquad b_{\mathrm f}(G)=b(G)=3<4=\mu'(G).\]

This answers P. J. Cameron’s Kourovka Notebook Problem 16.45.

Here \(b(G)\) takes the maximum over all permutation representations, including nonfaithful and intransitive ones; bases are defined for the permutation image. Minimal means inclusion-minimal. The invariant \(\mu'(G)\) allows independent sets that need not generate the whole group. No minimum-order assertion is made.

Why the upper bound covers every action

The complement has \(b_{\mathrm f}(H)=2\) but \(b(H)=3\). Every subgroup of the affine group that does not contain its translation subgroup has faithful base invariant at most two. Restricting an irredundant intersection family to such a subgroup bounds faithful bases by three. Every nontrivial normal subgroup contains the translations, so every remaining action factors through the complement.

An explicit independent four-set and a faithful three-base attain the bounds. The omission subgroups of the four-set intersect in a nonnormal subgroup of order two, exposing the obstruction in Cameron’s Boolean meet-semilattice formulation.

Proof and exact checks

The proof is structural; it does not enumerate all subgroups of the order-100920 group. The companion code reconstructs the 120-element complement and all 76 of its actual subgroups, checks 1,215,450 four-member families and 67,525 three-member families, and verifies the explicit affine witnesses.

make verify
python3 audit_2026_09_21/independent_check.py

Run these from the extracted source directory with Python 3 and a C++17 compiler. Python uses its standard library. The additional audit checker should be run without Python’s optimization flag because it uses assertions.

Separate AI agents reviewed the structural proof, wrote an additional exact checker from the specification, and checked primary sources. The review corrected one product order from six to three; the generated subgroup still has order twelve, and the theorem is unchanged. No unresolved substantive error was identified within these checks. This is not external human peer review or complete proof-assistant verification. Version 1.0.1 clarifies the projective-pair and subgroup-intersection arguments and fixes stale-file inclusion in rebuilt upload kits. Two further fresh adversarial reviews are recorded in the source package; the second found zero actionable issues after the repairs.
