Abstract

Starting from the announced three-dimensional counterexample to the Jacobian conjecture, this note explicitly carries out degree reduction and symmetrization. It claims an explicit homogeneous quartic in 54 variables whose Hessian is nilpotent and whose gradient Keller map is noninjective, giving a concrete claimed counterexample to Zhao's Vanishing Conjecture.

PolynomialHomogeneous quartic in 54 variables
Expansion598 monomials over Q(i)
CertificateExact two-point gradient-map collision

What is potentially new

Zhang's consequence note records that the announced three-dimensional Jacobian example would make the Vanishing Conjecture false in some finite dimension. This paper's narrower potential contribution is an explicit quartic polynomial, a finite exact collision certificate, and a factor-reusing reduction that holds the construction to 54 dimensions. This priority assessment is provisional and may be superseded by contemporaneous work.
