Abstract

Gallagher's weighted-lift construction produces a three-dimensional Keller map of every generic degree n ≥ 3. This archived note studies one explicit seed and gives a uniform rational collision. Its monodromy proof is retained for provenance, but an earlier public artifact proves the stronger result for the entire family.

FamilyOne explicit map for every n ≥ 3
Claimed monodromyFull symmetric group Sn
CertificateUniform rational two-point collision

Scope and priority

Mikhail Szh's initial commit predates this note and proves full Sn monodromy for the entire weighted-lift family. That also implies the trivial rational deck group in this specialization. The explicit seed and uniform rational collision are preserved in the canonical paper as a potentially new certificate, without an unconditional priority claim.
