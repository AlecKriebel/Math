# Attributed Thompson-family consequence note

Author: Alec Kriebel; ORCID https://orcid.org/0009-0001-9320-500X. No affiliation or coauthor is asserted.

Title: Reduced C*-algebras of the Thompson family: an attributed consequence of nonamenability.

The four-group reduced simplicity/trace conclusions are obtained by applying OpenAI's nonamenability input to Le Boudec–Matte Bon's published reductions and BKKO's trace theorem. This is an attributed consequence note, not a new criterion, independent nonamenability proof or first-priority claim. T unique trace predates the input. The circle extension is also inherited.

AI tools were used extensively; this work has not undergone conventional human peer review/refereeing. Two complete-package AI adversarial reviews must pass before deposition. The source proof was manually audited; the Lean build was not reproduced because of insufficient disk space, and no result is represented as freshly kernel-verified or as a formalized C*-algebra consequence.
