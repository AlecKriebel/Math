# R2 independent referee re-review

This directory contains the independent re-review of the revised Paper I
referee package.  The editor's remediation summary and all revised package
language are treated as claims to test.

- `work/package/` is the disposable byte-identical delivery copy.
- `records/` contains transcripts, diffs, source audits, and independent tests.
- `report/` contains the final re-review and remediation matrix.
