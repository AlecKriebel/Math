# Claim and evidence manifest

## Publication claims

There is an explicit infinite family \((H_k)\), with
\(n_k=|V(H_k)|\), satisfying

\[
2\leq\gamma^\infty(H_k)\leq3,
\qquad
\vartheta(H_k)=\Theta(n_k^{1/3}).
\]

Consequently,
\(\vartheta(H_k)/\gamma^\infty(H_k)=\Theta(n_k^{1/3})\), so the standard
one-guard eternal domination number is not universally bounded below by the
Lovász theta function and the separation ratio is unbounded.

For the graph with graph6 record `IEhbtj{ro`,

\[
\gamma^\infty(G)=3
<\frac{7593}{2500}
\leq\vartheta(G).
\]

The graph has minimum possible order among counterexamples, using the
published exhaustive order-at-most-nine classification of MacGillivray,
Mynhardt, and Virgile together with
\(\vartheta(G)\leq\chi(\overline G)=\operatorname{cc}(G)\).
